Tier S · 已核实正文

Memento: Learning Context Management for Long Context Processing Agents

arXiv:2611.00244 · 2026-10-30 · Qwen3-8B · HTML 正文 · Venue 未核实 · Code 未核实

人话版

模型读一本几十万乃至几百万 token 的小说时，无法把全部历史放进上下文。通常会让模型自己总结，但总结经常遗漏真正重要的证据。Memento 先从正确的教师轨迹中事后补入结构化笔记，教小模型在关键步骤记笔记，再使用强化学习把最终回答是否正确、笔记是否有效以及置信度是否可靠共同作为奖励。推理时，笔记不仅用于压缩上下文，还能成为回溯重试的检查点。论文最有价值的是把记忆管理变成策略学习问题；最值得怀疑的则是全轨迹奖励是否真的能精确定位有用的记忆。

Background & Research Gap

长文档 QA 不只是检索相关段落，还需要跨多轮保留人物关系、事件时间线和否定证据。例如先在第 50 页发现某角色的别名，后在第 400 页发现其行为，再在第 900 页寻找反证；若压缩笔记只记住最终猜测，下一窗口无法重建证据链。传统 ReAct 历史累积超预算；外置总结器缺少任务 outcome 的学习信号。作者在试验中发现即便更强的现成模型也不会可靠调用笔记工具，说明仅提供工具不等于学会使用工具。

Core Insight 与 Method Deep Dive

输入为书籍和问题；工具提供 semantic_search、ripgrep_search、view 与 create_notes。第一阶段采集 GLM-5.3 的正确轨迹，事后插入记录发现、错误与下一步计划的笔记，并用频率、位置、差异性规则过滤，约 6K 轨迹做 SFT。第二阶段用 GRPO 在多窗口轨迹上训练：一个窗口耗尽后只保留任务和笔记；一条完整轨迹所有 assistant token 共享同一个 group-normalized advantage。第三阶段测试时可选择直接重置、folding（保留最后一条笔记之后的近期历史）和按低置信度从早期笔记 checkpoint 回溯。核心不是更大的窗口，而是让写笔记成为可以优化的行动。

RL Formulation / Objective

State 是当前任务、已保存笔记、搜索结果与窗口上下文；Action 是文本生成、检索、查看与写笔记；Trajectory 跨越多个上下文窗口；Reward = λF·F + F·[Y + λM·M + λC·(1−(Y−p)²)]。F 表示格式有效且未检测到 reward hacking，Y 表示答案正确，M 表示笔记规则有效，p 为口头置信度。GRPO 对同题 G 条轨迹做组内标准化，随后使用 clipped importance ratio 与相对 SFT policy 的 KL 正则。优点是最终答案能训练早期笔记；缺点是一个无关笔记与关键笔记得到相同轨迹 advantage，存在 credit dilution。

Toy Example

假设问“主角为何拒绝继承？”第 1 窗口检索到遗嘱，第 2 窗口发现亲属关系，第 3 窗口找到拒绝的真正原因。普通压缩只写“查过遗嘱”，可能丢掉人物别名。训练后的笔记则记录“别名 A=B；遗嘱第 x 段；尚需确认动机”。如果最终答对，GRPO 会强化整条轨迹；但它仍不能证明“别名”与“遗嘱”两条笔记哪一条更重要，需要反事实删除验证。

Experiment Setup / Research Questions

训练集来自 LiteraryQA、NovelHopQA 和 SagaScale 英语子集，NovelQA 仅测试；训练/验证/测试按书籍隔离，约 17K / 2.3K / 4.7K 问题。最长书籍 2.5M token，agent 窗口不超过约 20K。RQ1：学会笔记是否改善正确率？RQ2：SFT 与 RL 是否互补？RQ3：folding 和 backtracking 是否在同一训练策略上有效？RQ4：与更大模型相比成本收益如何？使用单独评估 judge，避免直接用训练 judge 报分。

Baseline / Results / Table Reading

Table 1：原始 Qwen3-8B 在 folding+backtracking 下为 36.9%；SFT 单独为 59.1%；Memento SFT+RL 为 67.8%。仅 folding 时 SFT+RL 为 66.3%，说明 backtracking 进一步 +1.5 点，但同时引入重试开销。GLM-5.3 同 harness 为 69.3%，完整书籍上下文为 74.3%；GPT-5.5 同 harness 为 13.1%，完整上下文为 56.7%，该异常大的 harness 差异提示工具使用能力会显著影响模型比较。Memento 4 个子集分数为 70.2 / 72.8 / 64.9 / 70.3；其中 NovelQA 最弱。完整测试集成本论文估计为 $48，对比 GLM-5.3 agent $448、完整上下文 $1270。

Ablation 与 Claim vs Evidence

作者声称 SFT 解决“不会写笔记”的探索瓶颈，RL 再提高任务正确率；Table 1 的 SFT-only 与 SFT+RL 对照支持这一解释，但不能排除教师轨迹分布差异。作者声称置信度回溯提高准确率；66.3→67.8 的结果支持小幅收益，但不证明所有任务都值得多次重试。实验没有证明笔记语义正确性、跨任务长期稳定性，也没有证明每条笔记的因果贡献。奖励中的笔记规则可被策略机械满足，仍有 reward hacking 风险。

Contribution / Limitation

New Mechanism：后见笔记生成 + 轨迹级 RL + 可回溯上下文管理。New Objective：答案、笔记规则与置信度的混合奖励。New Empirical Finding：仅靠提示或直接 RL 难以学到有效笔记动作。局限：任务主要是 book QA；笔记有效性依赖启发式；模型比较受 harness 适配程度影响；测试成本估计依赖硬件与服务价格；跨 1000-step Agent 和多智能体共享记忆的证据不足。

Research Value / Migration

Original Problem：长文档 Agent 忘记关键证据。Transferable Mechanism：后见轨迹中提取记忆行动，再以 outcome RL 优化。New Question：是否能通过反事实 memory credit 替代统一 trajectory advantage？Method Modification：对成功轨迹的每条笔记执行删除/替换/扰乱，测量最终任务成功率变化，训练 memory selector 或 reward model。Minimum Experiment：Qwen3-8B + NovelHopQA 小子集，比较全笔记、随机删除、recency 删除、反事实重要度删除；Metric 为 QA accuracy、tokens、wall-clock、每条笔记因果贡献的置信区间。Expected Contribution：更细粒度的记忆归因。Risk：重跑成本高，删除笔记会改变后续状态分布，需使用 matched seeds 和多次采样。

五句话总结

Memento 的关键是让 Agent 学会何时记笔记。SFT 先解决有效动作的探索问题。RL 再将最终答案反馈传给跨窗口的行为。上下文折叠和回溯提供推理时的成本—准确率选择。下一步最值得做的是验证每条记忆的真实因果价值。

Idea 2: Action-Space RL with Learned Memory Intervention

Inspiration：RLiD × Pulse；Research Gap：动作可枚举但何时触发记忆干预难以优化；Hypothesis：将 memory intervention 纳入 action menu 可降低无效调用。
