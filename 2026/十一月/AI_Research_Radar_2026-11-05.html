RL Highlights

BLPO: Beyond-Local Policy Optimization for Long-Horizon LLM Agents — 跨任务共享进度状态和抽象动作，利用全局记忆聚合上下文相对回报，缓解长轨迹局部比较样本不足。

From Single-Agent Self-Discovery to Multi-Agent Adaptation: Scaling Laws of Partner Feedback and Convention Rigidity in Meta Reinforcement Learning Algorithms — 探索单智能体学习到多智能体适应的迁移，以及伙伴反馈和约定刚性的影响。

Beyond Outcome Rewards: Constructing and Assigning Retrieval Credit for Search Agents — 将检索步骤中间监督与最终 outcome reward 结合，研究 credit 放在不同轨迹位置的差异。

Agent Highlights

Learning by Doing: Autonomously Compiling and Curating Agent Skills from Verified Traces — 从已验证的轨迹中编译和筛选可复用技能，强调技能来源的可验证性。

A State Change Is Local, Its Consequences Are Not: Dependency-Aware State Revision for Long-Term Agent Memory — 研究长期记忆中局部状态改变对依赖事实的连锁影响。

Coati: Host-Grounded Execution for Installable Mobile GUI Agents — 在 Android 端安装 agent，由宿主记录动作效果和跨应用状态，减少仅凭模型推断执行结果的偏差。

AffToM: Benchmarking Recursive Affective Theory of Mind in Dynamic Multi-Party Interactions — 提供动态多人交互下递归情感心智推理评测，公开摘要称有1922测试对与19759训练对。

Multi-Agent Transactive Memory — 跨 agent 共享可检索的历史轨迹，让不同 agent 无需联合训练即可复用经验。

Who Schedules Agent Memory? A Sidecar Approach to Long-Horizon Tasks — 将记忆调度从主 agent 的关键路径中分离，降低同步检索等待。

Pulse: Long-Horizon Tasks Need Streaming Personalization — 在长时任务执行中持续感知新的个性化需求，而非只在任务开始时检索一次记忆。

Video Highlights

ContextTom: Training-Free Video VLM Acceleration with Early Spatial Context — 先进行时间压缩，保留锚帧空间网格完成早期多模态交互，再用 query attention 压缩空间 token。

Idea Mining

Idea 1：跨任务可信 Credit Memory

Inspiration：BLPO 与 retrieval credit；Gap：不同任务的状态抽象会产生错误优势迁移；Hypothesis：引入反事实校准和置信度门控可提高长轨迹稳定性。

Method：轨迹片段归一化 → 匹配历史状态 → 反事实去除某经验 → 估计贡献 → 门控更新优势；MVE：WebArena 小任务集对比无记忆 GRPO、BLPO 式共享、随机记忆；Model：可训练小型开源指令模型；Dataset：WebArena；Metric：成功率、方差、训练 tokens、wall-clock、负迁移率；Expected contribution：可信 credit transfer；Novelty：★★★☆☆；Feasibility：★★★☆☆；Compute Cost：★★★☆☆；Risk：反事实估计开销；Collision：高；Venue：ICLR / NeurIPS（仅潜在投稿目标）。

Idea 2：事件感知的跨帧 Cache + Agent 查询预算

Inspiration：ContextTom、TempCache；Gap：静态压缩容易遗漏后续查询所需的短暂事件；Hypothesis：以事件变化与查询不确定性联合决定帧/缓存保留可改善精度-延迟曲线。

Method：轻量事件变化检测 → 预算分配 → 保留关键帧和历史 KV → 按查询触发局部重编码；MVE：Qwen3-VL-8B 在 Video-MME / LongVideoBench 上对比均匀采样、ContextTom 式策略与不压缩；Metric：准确率、TTFT、显存、tokens、端到端延迟；Expected contribution：面向流式 Agent 的动态预算策略；Novelty：★★★☆☆；Feasibility：★★★★☆；Compute Cost：★★☆☆☆；Risk：缓存失配；Collision：高；Venue：CVPR / ICCV。

Collision Detection

⚠️ Collision Warning：YES。 BLPO 已研究跨任务进度状态与全局经验的 credit 聚合，因此 Idea 1 不能只做“历史轨迹检索+优势估计”。剩余差异化空间是可校准的反事实贡献、负迁移检测和分布外任务的可靠性。ContextTom 已进行 query-aware 时空压缩，TempCache 已做时序缓存复用，因此 Idea 2 需要明确事件级缓存失效检测与流式查询协议，不能只拼接现有模块。
