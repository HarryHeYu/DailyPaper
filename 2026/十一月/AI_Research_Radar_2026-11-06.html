Using Experience Twice: Dynamic Process Rubrics for Privileged Token-Level Credit Assignment

Tier S · RL NEW arXiv:2611.06543 · 2026-11-04 arXiv · full Method/Experiments checked · preprint

Shumao Wu, Kongcheng Zhang, Jianqiang Huang, Baisheng Lai · Official Code

人话版

Agent 在一个任务中可能试错 8 次，终于成功，传统 GRPO 把成功轨迹中每个 token 都加分，连侥幸、冗余步骤也一并鼓励。ORSD 把相同任务的成功/失败轨迹重新利用：让当前模型生成若干自然语言“过程检查准则”，用冻结 verifier 为每条轨迹打分并挑选与真实结果最一致的准则；再让同一个模型在看过/没看过准则两种上下文下重新计算原 token 的概率，取两者的对数概率差作为 token 信用。结果显示 ALFWorld、WebShop 上对照 GRPO 有明显提升。这提供了一条不用新环境交互、却能从旧 rollout 中提取细粒度过程监督的路线。

Background & Research Gap

轨迹结果是全局标签，不能告诉模型哪个动作对后续回报负责。例如 WebShop 挑商品时，“先核对颜色尺寸”是关键决策，翻页或重复搜索则可能不重要；只把最终购买成功当奖励，会给上述动作相同优势。GiGPO 可以到 step 粒度，但一个步骤内部不同 token 仍共享信用。Rubric 监督能够表达过程规则，不过离线规则无法随着 policy 的失败模式变化。ORSD 把“轨迹间行为差异”当成可学习的监督源：规则生成与当前 policy 同步更新，又不消耗额外环境步骤。

Method Deep Dive

Input：同一任务 x 的 8 条 on-policy 轨迹及其训练回报。① 每次更新从当前 policy 独立采样 M=4 组 rubric bundle；生成条件包含任务和轨迹，但刻意不告诉模型回报，以防把结果直接复述成规则。② 冻结 verifier 检查每组规则在每条轨迹上的满足度，取平均后计算与真实轨迹回报排名的 Spearman 相关，选最高者。③ 把选出的规则作为 privileged context，分别计算原样采样 token 在“有规则/无规则”两种上下文中的 logprob：Δ=logπ(y|x,rubric,history)−logπ(y|x,history)。④ 在基础轨迹 GRPO advantage 上加 αΔ，对每个 token 产生不同的更新力度；环境 observation token 不参与该修正。⑤ 继续用 PPO/GRPO 风格的 clipped objective 更新 policy。重要的是两次 forward replay 对象是同一条轨迹，不是产生新的环境 rollout；节约的是 environment interaction，不等于额外计算为零。

关键公式 / Objective

A_i=(r_i−μ_r)/(σ_r+ε) 是组内 outcome advantage；ρ_m=Spearman(s_m,r) 是 rubric 选择分数；Δ_{i,l}=logπ_old(y_{i,l}|x,B*,history)−logπ_old(y_{i,l}|x,history)。最后 A_{i,l}=A_i+αΔ_{i,l}。默认 α=0.01；本方法本质属于带 privileged context 的自蒸馏，而非逐 token 的独立因果效应估计：对数概率变化可以反映提示敏感性，也可能被规则措辞和 verifier 偏差干扰。

Toy Example

玩具案例：给定“买蓝色 M 号衬衫”，A 轨迹先确认颜色尺码后购买成功，B 轨迹直接选择搜索首项并失败。模型可能提出“购买前核实颜色、尺码”准则。若这一准则对 A/B 满足度的排序与回报一致，被保留。回放 A 时，“筛选 M 号”几个 token 在加入准则后概率上升，获得正的 Δ；若“忽略尺码”概率下降则受负修正。此例仅解释设计，不等于实验已经证明该信号识别出真实因果动作。

Experimental Setup + Research Questions

模型：Qwen3-1.7B 与 Qwen3-4B；环境 ALFWorld（家务交互，binary success）及 WebShop（任务 score + success）。每个 optimizer update 8 tasks × 每 task 8 rollouts；300 steps，学习率 1e−6，全参数微调，4 张 A100 80GB。WebShop 最多 15 次 assistant action。M=4，α=0.01。ALFWorld reward 为成功指示；WebShop reward 将官方任务分、成功指示、无效动作及无进展循环惩罚结合。对照：GRPO、GiGPO、OPSD、GRPO+OPSD、SDAR，另列 ReAct 等 prompting 方法。RQs：整体任务成功是否提升？online rubric 是否优于离线？多候选和相关性选择有无增益？α 对效果影响如何？

Results：strongest / weakest / trade-off

Table 1：Qwen3-1.7B ALFWorld 总成功率 GRPO 53.92% → ORSD 66.04%（+12.12 pp）；4B 为 74.07% → 77.43%（+3.36 pp）。WebShop 1.7B 成功率 55.40%（GRPO）/60.20%（GiGPO）→ ORSD 63.00%，比 strongest baseline GiGPO 高 2.80 pp；4B GRPO 66.15% → ORSD 77.05%（+10.90 pp）。WebShop score 4B 82.69 → 89.02。注意 ALFWorld 子任务存在弱项：4B Pick 单项 GRPO 83.33 与 ORSD 83.33 持平，Look 为 86.11 → 77.78 下降，因此不能说所有动作类型都更优。论文将已有工作发表的部分 baseline 数据与自跑数置于同一表，协议可比性需仔细检查。

Ablation / Failure Modes

去掉在线生成、改用 offline rubric：1.7B WebShop success 63.00→58.20（−4.80 pp）。去掉相关性选择仅生成单束：63.00→60.85（−2.15 pp）；改为随机选束：63.00→59.60（−3.40 pp）；4B 对随机选束从 77.05 降至 69.90（−7.15 pp）。因各消融可能同时影响生成/筛选开销，这些数字证明组件对终点指标有贡献，但不能单独证明规则的因果正确性。

Authors Claim vs Actual Evidence vs Unproven

Authors Claim：自生成动态准则能将轨迹结果转成细粒度信用，并加速学习。Experiments Actually Show：在两环境、两模型、相同环境交互预算下，success 和部分 score 提升；在线生成及 alignment 消融有效。What Is Not Yet Proven：未证明 token Δ 与可干预的动作因果贡献一一对应；训练时生成 verifier+双次推理的 GPU 开销没有被“无新增 rollout”抵消；长期规则漂移、reward hacking、100/1000-step 轨迹和跨环境泛化未充分验证。

Contribution / Research Value / Limitations

贡献类别：New Mechanism（online rubric 筛选）、New Objective（token advantage shaping）、New Empirical Finding（旧 rollout 可自提炼过程信号）。Baseline Potential：适合 Agent RL credit 研究的强基线。System Value：不加环境交互，但多 verifier 与 replay 计算。Benchmark Value：ALFWorld/WebShop 有效却偏窄。Attack/Evaluation：可以针对错误规则、评分偏差或生成规则泄漏设计反事实评测。New Paper Potential：把准则扩展到 memory/skill/communication 归因，并加入可干预验证，而不是继续仅优化 α。

Research Migration & Minimum Experiment

Original Problem：动作 token 信用不清；Transferable Mechanism：同组轨迹的行为差异→可解释规则→配对回放 logprob gap；New Research Question：哪些记忆写入和多智能体消息真正促成后续成功？Method Modification：替换 token 比较对象为带/不带 memory/message 的固定后缀 replay，记录 Δsuccess 与 model logprob 并用随机 placebo 校验；Minimum Experiment：50–200 组短轨迹进行 counterfactual memory ablation；Model：Qwen3-4B Agent；Dataset：ALFWorld/WebShop；Baseline：GRPO、ORSD、随机写入、无记忆、MemAgent；Metric：成功率、信用排序的 intervention consistency、token/cost；Expected Contribution：从提示敏感性升级到可干预记忆归因；Risk：状态改变导致不可比、回放成本增长。

RL / Agent / Video 专用分析

RL Formulation：state=任务/历史/环境观测；action=token 序列组成的交互动作；policy=Qwen3；reward=ALFWorld binary / WebShop 混合 shaped reward；trajectory=多轮动作+环境反馈；advantage=组内标准化 outcome + αΔ token 校正；KL/Entropy 在此处不应凭空补数。Reward Analysis：ALFWorld sparse rule-based；WebShop semi-dense 的任务评分与惩罚，非完全人工 reward；verifier 是冻结模型对 rubric 的评价，可能被生成规则投机影响。Training Efficiency：每步 64 environment rollouts；论文称无新增环境交互，但额外采样 rubric、verifier 与 paired replay 必须算入 GPU 成本。

五句话总结

① 核心创新是把已有 agent rollout 使用两次。② rubric 与 outcome 相关性筛选有助于去除弱规则。③ token 级 logprob gap 细化 GRPO 信用但不等同因果估计。④ 1.7B ALFWorld +12.12 pp 证明了潜在价值，同时部分子任务仍回退。⑤ 下一步应把规则信用和真正的反事实干预连接起来。

SUMONE: A Simple and Efficient Summarizer for Plug-and-Play Agent Memory

Tier S · Agent NEW arXiv:2611.06445 · 2026-11-04 arXiv · full Method/Experiments checked · preprint

Jizhe Zhang, Ang Li, Chenheng Zhang, Yisen Wang · Official Code: Not Verified

人话版

长时程 Agent 最烦的是工具输出越积越多：删掉历史会丢证据，一直携带又贵。SumOne 不用先收集人工摘要或在每个任务上奖励训练，而是把过期轨迹压缩成摘要，再随机遮掉原轨迹部分段落，请冻结重构器只凭摘要和剩余上下文恢复被遮掉的信息。若恢复准确、摘要又短，给摘要模型较高 RL 奖励。实际部署时扔掉重构器，只留独立小摘要器，插在不同 Agent 框架里。它在两个任务上将输入 token 和估算费用大幅降低，但成功率相比完整历史下降 0.04，属于较明确的成本—效用交换。

Background & Research Gap

SWE Agent 在搜索 bug 的第 20 步可能需要第 2 步某条测试失败信息。完整 4M 级累计上下文代价高；简单截断会忘掉细节；下游任务 reward 训练摘要器又被具体 solver 与环境绑死。SumOne 把信息保持变为 self-supervised 代理任务，使摘要器不直接看到最终任务成败。关键假设：若摘要能恢复被随机遮挡的历史，它也会包含未来问题需要的重要信息；这个假设并非必然成立。

Method Deep Dive

Input=C（系统指令、任务、近期交互、已有 memory）+H（过期轨迹）。① 独立 summarizer πθ 生成文字摘要 S。② 按角色、工具边界把 H 切成约 512 token 的块，随机 mask 50%，形成 H~。③ 冻结 reconstructor D 接收 C、H~、S，预测缺失块。④ judge 按 precision/recall 比较预测与原文，并加摘要长度惩罚得到 R(S)=Q(S)−λ|S|/Lmax。⑤ 对同一上下文采样 8 个候选摘要，按组内 reward 标准化优势，训练 πθ（GRPO）；D、judge 不参与训练更新。⑥ 推理只用 πθ，把 H 替换成 S，再让原 Agent 继续调用工具。训练阶段昂贵的遮挡、D 和 judge 不在部署时调用。

关键公式 / Objective

S~πθ(.|C,H)；H~=Mask(H;Ω)；D 从 (C,H~,S) 恢复被遮挡块。信息理论动机是条件互信息 I(S;HΩ|H未遮,C)，但作者明确没有直接估计这个量。Q(S) 将遮挡段 precision 和 recall 平均；R(S)=Q(S)−λ|S|/Lmax；组内 A_k=(R_k−mean(R))/(std(R)+ε)。与 task-outcome reward 不同，这个 reward 可从离线 raw trajectory 直接生成。风险是复原看似精确却保存了一堆与未来动作无关的噪声。

Toy Example

玩具例子：程序 agent 已经看过“测试 A 失败，依赖版本 2.1，不能升级到 3.0”的长日志。摘要若只写“测试失败”则无法还原版本约束，重构评分较低；若保留版本、失败位置和下一步建议则较高。但假如未来只问最终修复 diff，重构越完整不一定使最终修复越好，因此仍需终点质量评测。

Experimental Setup + Research Questions

约 5K compaction instances，来自搜索轨迹与 SWE-smith；16K/32K context，512-token block mask 50%。摘要器 Qwen3.5-2B，重构器 Qwen3.5-9B，judge 为 DeepSeek V4.1 Flash；600 optimizer steps，batch 6，group 8，LR 1e−6。评估 DeepSearchQA（F1）、SWE-bench Verified（resolved rate），另有 LongMemEval-S；下游 agent 为 Qwen3.5-35B-A3B + OpenCode，32K compaction threshold。对照 Full History、Recency Truncation、Self-Summary、Prompt-2B、CoMem；另测跨模型、跨 harness 与 task-specific RL agent。

Results：strongest / weakest / trade-off

DeepSearchQA Table 1：Full History F1 .52、输入 2.83M、cost $0.170；SumOne F1 .48、输入 591K、cost $0.038，性能下降 .04、总费下降约 78%。SWE-bench Verified：Full .63、4.10M、$0.286；SumOne .59、1.09M、$0.071，性能下降 .04、费用下降约 75%（注意抽象中的近似成本口径与表格需对齐）。相较 Self-Summary，DeepSearchQA .44→.48；SWE .56→.59。另一个对照：CoMem DeepSearchQA .32、SWE .57，说明同等压缩 budget 下并非所有学习型摘要器都同样有效。弱项：Full History 始终更高；在 Codex harness 中 SumOne .47、Self-Summary .47，差距消失。

Table / Figure Reading

Figure 2 完整呈现摘要器训练与部署解耦，而不是“每次调用再重构”。Table 1 要同时读 Score、Compression Ratio、Input Tokens 和 Total Cost，不只说提速。Table 2 显示结合 task-specific RL agent 时 SumOne DeepSearchQA .55、SWE .68，与 Self-Summary .57/.65 出现任务依赖交叉；Table 3 跨 harness 的 OpenCode .48、OpenHands .46、Codex .47、DeepSeek Harness .42，说明 transfer 并非无损。

Ablation / Failure Modes

Prompt-2B 与 SumOne 使用相同基础架构但未经该 RL 训练：DeepSearchQA .29→.48、SWE .51→.59，支持重构奖励确有帮助。Self-Summary .44→.48 / .56→.59 但 full-history 仍优。跨 harness 值变化提示“训练摘要器独立”不等于完全 framework-agnostic。还需要比较不同遮挡方式、稀有关键事实、长期重复压缩次数，避免从一次 mask 的重构分数推断终生记忆可靠性。

Authors Claim vs Actual Evidence vs Unproven

Authors Claim：不用 downstream outcome 的独立摘要器可跨任务跨 Agent 迁移。Experiments Actually Show：两类任务在大幅减少费用时只损失 .04 终点分数，并有若干跨 harness 结果。What Is Not Yet Proven：重构精度一定反映未来价值、长期累积错误可控、在高危不可逆工具动作中可接受。费用为论文设定的推理成本估计而非通用 GPU 延迟测量。

Contribution / Research Value / Limitations

New Objective（masked reconstruction + length penalty），New System（独立 plug-in summarizer），New Empirical Finding（跨 harness 成本—效用曲线）。可以作为 memory compression 的强对照，特别适用于 long-horizon coding/search agent。最大的研究空间是加入“未来决策价值”约束、可信来源与关键事实不会被反复压缩抹除的保证。

Research Migration & Minimum Experiment

Original Problem：过期轨迹太长；Transferable Mechanism：用遮挡重构作为 task-agnostic 信号；New Research Question：能否同时保留事实可恢复性与未来动作效用？Method Modification：双头评分＝masked reconstruction + held-out action outcome/counterfactual utility；Minimum Experiment：100 个 SWE 小任务、3 轮连续 compaction，对比两种 reward；Model：Qwen3.5-2B summarizer + 4B solver；Dataset：SWE-bench Verified / LongMemEval-S；Baseline：SumOne、Self-Summary、Recency、Full History；Metric：resolved rate、关键约束召回、累计 token、错误传播；Expected Contribution：task-agnostic + task-aware 稳健压缩；Risk：outcome 训练与跨框架泛化冲突、评测成本高。

RL / Agent / Video 专用分析

Agent Architecture：历史轨迹 → Summarizer → 精简 memory → 原 Planner/Tool Agent → Environment；训练时才有 Masker/Reconstrutor/Judge。Agent State：C、过期 H、摘要 S、最近 tool history。Long-Horizon：研究在长时程 search/SWE 任务有效，但未证明 1000-step 稳定性。Failure Propagation：遗漏一个依赖版本会误导后续检索、代码修复与测试；重复 compaction 可把最初错误固化。RL Formulation：摘要是 action，冻结重构模型+judge 提供 dense-ish sequence reward，不是环境终点稀疏奖励；group size 8，reward 可受 judge 与重构器偏见影响。

五句话总结

① 用 masked reconstruction 为记忆摘要建立不依赖任务成功的奖励。② 部署仅保留一个独立小摘要器。③ 在 DeepSearchQA 从 $0.170 降到 $0.038，F1 从 .52 降到 .48。④ 节省成本不代表没有信息损失，跨 harness 也不总赢。⑤ 下一阶段应做长期压缩漂移和下游行为因果检验。

NanoKV: High-Ratio KV Cache Compression for Autoregressive Video Generation

Tier S · Video NEW arXiv:2611.06377 · 2026-11-04 arXiv · full Method/Experiments checked · preprint

Jiacheng Lu, Haoyi Zhu, Sipei Yi, Enze Xie, Cheng Zhuo, Yu Li · Official Project/Code linked on arXiv

人话版

自回归视频生成器要一边生成新帧一边读取旧帧的注意力 KV cache。旧帧越多，显存与反复读取成本就越大。NanoKV 并不是简单把每个 head 独立量化：它先把历史 token 的共享内容汇聚到聚类中心，再把跨 head/channel 的残差压进低比特系数；并针对 K、V 的不同功能采用不同拟合目标。NanoKV-Fast 进一步直接在压缩系数上做部分低维 attention。HY-WorldPlay 上有 26.09× 有效 KV 压缩，但普通 NanoKV 的总速度仍为原版的 0.96×；Fast 版本压缩比稍降至 20.53×，才取得 1.06× 对原版加速。这是“容量压缩不等于系统加速”的非常典型例子。

Background & Research Gap

流式/自回归视频生成越来越长，重复注意旧帧的 KV。逐 head 压缩忽略头之间共享内容；高比例压缩破坏画面一致性；先从低维恢复全维 KV 再 attention 虽少占显存，却未降低注意力乘法量。关键洞见：存储形式与在线计算形式必须联合设计；K 是用于相似性打分，V 是用于聚合输出，不能只采用同一个均方重构目标。

Method Deep Dive

Input：预训练冻结的视频 backbone 和历史 KV。① 对各层的历史 KV 做聚类，以少量共享中心表示共同语义，后面的 token 只存对应中心索引与残差。② 跨多个 heads/channels 联合提取低秩 residual 系数并压为 INT4；保留 BF16 scale 等元数据。③ Value 路径优先做经过部署量化后的 reconstruction 拟合，减小值向量误差；Key 路径则优化恢复后的 downstream attention/block 输出，而非只压低 K 的逐元素误差。④ 普通 NanoKV 解码压缩历史再送入原 attention，以提高质量—存储 tradeoff。⑤ NanoKV-Fast 额外训练低维 query/key 映射并让不敏感历史在低维参与注意力；敏感层、头、token 仍走高维分支，两个 softmax 分支用 log-sum-exp 合并。这样计算 savings 发生在 attention 本身，而不只是常驻 KV。

关键公式 / Objective

NanoKV 的名义比率和有效压缩率不同：后者把系数之外的聚类中心、索引、scale、常驻 codec 算子也算入。Fast 低维 attention 在历史上约省至 d_h/D 的乘法，但只有历史部分与安全路由部分能受益；日志的两路归一化通过 Λ=logaddexp(Λ_low,Λ_full) 合并。论文区分“表示保真”“attention 输出保真”两类损失，这是对普通 PCA 或纯 quantization 的关键改进。

Toy Example

玩具视频：连续十几帧静态客厅，背景的颜色/墙面在不同 token、attention head 中高度重复，人物移动则是稀有残差。存一份背景中心，再用 INT4 表示每帧局部差异；若窗户边缘 token 对后续画面很敏感则仍保持全维注意力。若把所有 K 都按普通像素重构精度压缩，微小相似度误差可能放大到错误的注意力分配。

Experimental Setup + Research Questions

模型：HY-WorldPlay、Matrix-Game 3.5、LingBot-World 2.0 三种自回归视频 backbone。24 张训练图像产生 48 条 fitting trajectories；100 张 evaluation images 与训练图不重叠（来自固定 200 图像池），四种镜头动作。HY-WorldPlay 253 帧、LingBot 125 帧、Matrix 169 帧；HY 使用四步 denoising，另两模型设置见 Appendix。对照：Quant VideoGen、TurboQuant、KVTC 和未压缩原版。指标：KV GiB、有效 CR、PSNR、SSIM、LPIPS、VBench、E2E 时间、GPU peak memory；计时含在线生成和 VAE decode，不含 model load，三次有效运行中位数。

Authors Claim：高比例 KV 压缩、生成质量保留且 Fast 可以加速。Experiments Actually Show：HY-WorldPlay 的有效压缩 26.09× 与 PSNR +1dB over KVTC；普通版不是 E2E 加速器，Fast 版本获得 modest E2E 1.06×。What Is Not Yet Proven：对 video VLM 理解任务可直接套用、不同 GPU/不同 batch 的 wall-clock 一样、极长小时级视频保持质量、视频内容突变时 residual 模式仍有效。

RLVR 模型常在训练中早早进入“正确输出越来越集中、后续没有大幅进步”的平台。Reward Budgeting 不是强行增加 entropy，而是限制每个 prompt 可提供的总奖励，把多条成功 rollout 的优势差距压低，使已经被做熟的题贡献更少更新信号。论文通过 implicit target policy 和 sharpness factor 解释何时会过早收敛。 Gap：仅监测 entropy 不等于控制 reward 的有效锐化。Method：从组内二值/一般 reward 推导固定预算的 advantage transformation；在二值 reward 的独立采样假设下给出 finite-G 凹目标的无裁剪 score-function 解释，一般 reward 只有渐近解释；把新的 advantage 插入既有 RL 算法。不能把理论直接外推到 clipped implementation 的严格等价。 Setup：Qwen3-8B 与 Llama3.2-3B-Instruct，多套 RL baselines；数学测试 AMC23、AIME24/AIME25。RQ：是否比单纯提高 entropy 更能摆脱平台？不同 reward 形状与算法稳健吗？ Results：摘要报告最高 AMC23 +12.50、AIME24/AIME25 各可达 +10.00（这些是相对特定 baselines 的最高提升，并不是全部配置一致提升）。表格具体每一组 baseline/seed、cost、KL 与样本效率尚未从全文核对，不虚构。图表重点应读 reward-gap/sharpness 曲线、训练收益随成功率变化以及 ablation。 贡献：New Objective / Policy Dynamics Finding；Limitation：需要独立 rollout、裁剪目标非等价、某些环境 reward 不是 binary；迁移：对 agent memory/skill 的 reward 进行 per-task budget normalization，比较不同难度任务 credit 的有效性。最小实验：Qwen3-4B+可验证工具任务，GRPO vs entropy bonus vs reward budgeting，测 pass@1、unique trajectories、KL 与 token。Worth Deep Reading：YES。

Idea Mining · 3 个可执行研究切入点

1. Counterfactual Memory Credit

灵感：ORSD 以动态 rubric 产生 token credit；SumOne 以重构质量奖励压缩。但“回想得出”不等于“后续做得好”。

Hypothesis：在多轮 agent 中，使用真实后续成功变化验证 memory 写入重要性，优于仅依靠 logprob gap 或 reconstruction 的记忆筛选。

Method：同一轨迹冻结中间状态、后缀随机种子，分别注入真实 memory / placebo / deleted memory，得到 Δsuccess 和 Δaction；将 intervention consistency 作为写入分数，定期更新 memory controller。

MVE：Qwen3-4B，ALFWorld/WebShop 各 100 个任务，2–3 次压缩/记忆更新；baseline=SumOne、ORSD、随机记忆、无记忆；metrics=任务成功率、counterfactual uplift、action KL、token 与墙钟成本。

3. Recovery-Adjusted Agent RL Under Irreversible Budgets
