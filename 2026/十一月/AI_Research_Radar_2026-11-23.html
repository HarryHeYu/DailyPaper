Tier S · WEIR: Watershed Exploration and Drift-Aware Prefix Shrinkage for Multi-Turn Agent Reinforcement Learning

Pixel Nomand, Elena Voss, Marcus Hale, Sofia Reyes｜University of Wisconsin–Madison / University of Washington｜v1 提交：2026-11-20 21:05（北京时间）｜预印本；Venue 未核实；Project / 公开代码未核实。arXiv · PDF。已阅读 §3–6、Table 1–3、Figure 2–4、Appendix B–D。

人话版：把续跑预算花在“命运分叉口”

想象一个购物智能体，前面十步都在浏览商品，最后选错规格，整条轨迹只得到失败。直接把失败分给每步，会连正确检索也一起惩罚；把相同行动历史的所有结局平均，又可能拿旧策略的失败压制已经进步的新策略。本文把行动前缀组织成跨轮保留的树，用访问量与漂移约束决定相信多少历史结果，再把额外续跑投到仍有成功希望、且相邻价值变化很大的位置。它不是多造一种人工过程奖励，而是同时改造价值监督与数据采集。七十亿参数模型上，四项问答平均正确率为百分之三十七点八五，最强可比基线为百分之三十五点六三；生成的训练轨迹词元也更少。最重要的是，方法给出了为什么重用历史、又不能完全相信历史的可检验解释。

背景、缺口与核心洞见

终局二值奖励的问题不只是稀疏。一次失败购物可能包含正确搜索、有效筛选和错误购买，把统一负优势广播到整条轨迹不能区分这些决定。已有组相对方法利用同题多条轨迹估计优势，树方法进一步复用共享前缀，但若每个节点都只拿一次结局训练价值函数，目标依然很嘈杂。论文先指出一个容易忽略的退化：当折扣与优势迹参数都设为一，回报目标会望远镜式相消，每轮最终仍回归同一个终局结果；引入逐轮价值网络本身并没有创造新的监督信息。

另一端是过度池化。相同行动前缀昨天经常失败，今天模型学会了后续工具操作，历史均值便带有策略漂移偏差；固定混合系数既不知道节点见过多少次，也不知道旧数据应当被限制到什么程度。采样同样不能只追随词元熵：卡死后重复尝试的智能体也可能输出很高熵，继续在那里分支不会提供有用成功对照。核心洞见是把终局不确定性拆成沿行动前缀变化的条件期望增量，价值剧烈跳变、同时尚未完全成功或失败的位置，才是值得额外询问结局的候选。理论中的真实条件期望与实现中的近似价值网络必须区分，后者是否可靠要靠独立校准实验回答。

Method Deep Dive：输入、监督、分配与更新

输入是一批任务、冻结的当前采样策略、更新前价值网络和每题保留的行动前缀树。智能体的真实策略状态仍是任务、观察与推理行动历史；树节点却只用任务和规范化行动序列作键，不把冗长思考文本纳入。环境返回观察，整条轨迹结束后才有任务成功奖励；问答还加格式门。这样把“策略看到了什么”和“哪些结果可以合并统计”分开，价值网络预测同一行动前缀后续能成功的概率，而不是辨识某种思考措辞。行动相同不保证隐藏状态相同，因此这一压缩在随机环境下会损失信息，不能当作无条件充分状态。

第一步是查树。具身和网页行动用大小写、空白等规范化后的精确匹配；问答搜索若精确匹配失败，只在同一父节点的子节点中用语义向量合并，余弦阈值为零点九五。父节点约束防止把不同来路的相似查询错误合并。每轮结束，把节点累计访问数与奖励和乘以历史折扣，再加入本轮结果。这里折扣作用于统计量，不是把任务终局奖励提前折现。跨轮保留可降低方差，但同一动作在不同检索结果下的意义也可能改变，维护键的语义比单纯缓存字符串更关键。

第二步构造价值监督。对正在训练的轨迹，先从节点统计中减掉它自己的访问和回报，得到留一的样本数与历史均值；否则一条成功轨迹既参与均值又成为预测目标，会让效果看起来比实际更确定。目标是当前轨迹结局与留一均值的加权和。历史样本越多，权重越大；漂移约束越强，权重越小。罕见节点没有其它样本时完全用本次结果；即使节点极密，权重也不会在有漂移约束时升到一。这是反直觉但重要的设计：数据无限多并不等于旧策略的均值没有偏差，仍须保留新鲜结果作为锚。价值网络在冻结目标上做平方损失回归，问答另有终局答案样本。

第三步用更新前、而不是刚拟合本批答案的价值网络安排探索。每题先生成少量主干轨迹，取前缀预测估计成功率。跨题预算按成功率乘失败率的平方根分配，有最小和最大分支数并修正整数取整，保持总预算不变。这不是简单只训最难题：完全不会的题与几乎都会的题都获得较少额外分支，中间能力边界获得更多。由于每题轨迹数不同，后续策略目标还要按题目样本数的倒数重加权，否则预算分配会悄悄变成任务分布偏置。

第四步在题内给非终局转折打分：成功概率与失败概率的乘积，乘上相邻价值差绝对值、保底常数和低访问探索项之和。生存门防止巨大价值落差把预算吸引到已经没救的状态，低访问项防止价值网络早期误判造成永久不再探索。按分数无放回选择分叉，恢复环境状态与完整交互历史，再在冻结策略下并行续跑。这里需要真实可恢复的环境快照，不是把一句文本前缀交给线上购物服务重放；有不可逆副作用的现实工具不满足条件。

最后用完整新轨迹更新。逐轮广义优势由终局奖励与冻结前缀价值计算，观察词元被屏蔽，推理和行动生成词元参与策略梯度。重要性比例采用一轮内词元概率比的几何平均，配合截断和任务平衡权重，另有相对参考策略的约束。价值网络与策略分别优化，更新后的树和策略进入下一轮。输出既是更好的行动策略，也是可供下轮分支使用的前缀价值估计。信用分配发生在逐轮优势与分支选择两处，并非直接学得每个工具调用的因果贡献；也没有额外学习一个密集奖励模型。长链能力依赖价值校准和环境恢复共同成立，不能从算法流程直接推出千步任务适用性。

实验与 Results：三个可复查的研究问题

研究问题一：相同轨迹条数下，优势来自有效采样还是额外样本？作者训练两种规模的指令模型，价值网络统一为三十亿参数；问答在训练集上做强化学习，再测同域及另外三个组合泛化集。问答每题两条主干加平均四条分支，具身和网页每题四条主干加四条分支，与多轨迹基线分别匹配六条和八条。最强可比方法是同表的 CAPO；引用的 StepSearch 有不同过程监督，不能作为完全等价对照。表一中七十亿模型四项问答均值从 CAPO 的 35.63 到 37.85，是增加 2.22 个百分点而非相对增加百分之二点二二。三十亿均值从 28.99 到 32.18，说明小模型同样受益。

同一表中，七十亿模型在具身成功率上从 84.33 到 87.81，在网页购物从 80.40 到 81.90；最弱的这项增益只有 1.50 个百分点，不应只展示更漂亮的具身结果。生成词元比例为独立链的 0.72，三十亿为 0.71，分别少百分之二十八与二十九。共享前缀确实省去重复生成，但这不是训练总时间下降同样比例：论文没有在这些表里给出完整训练墙钟或硬件小时，价值网络、语义合并、状态恢复都有成本。具身与网页平均三个随机种子，问答不能据此声称也有相同多种子置信度。具身最多四十轮、网页十五轮，尚未验证百轮或千轮。

研究问题二：改进是否真来自更好的价值估计？作者把第百五十步冻结的在线价值网络放到二百五十六个问答任务上，以每个前缀六十四次续跑估计作参考。表三显示，完整方法的均方误差为 0.0982，固定混合为 0.1274，全历史单结局监督为 0.2076；题内相关性从后者的 0.142 到 0.586。误差与同题排序同时改善，支持它不是只把所有预测向总体均值压缩。另一个受控离线实验固定训练数据与轮数，完整方法误差为 0.0384，前缀经验均值为 0.0445，进一步降低“采样分布本来就更简单”的解释力。不过蒙特卡洛参考本身是有限样本估计，不是真实价值神谕。

研究问题三：为什么不直接按熵分叉？图三在七十亿具身设置统计，均匀分支有 41.2% 落到近乎已确定结局的节点，熵分支中 31.5% 落入死胡同；完整方法把确定结局浪费降到 8.7%，并把 67.2% 分支投向分水岭。表二中仅改为均匀题内分支，具身成功率降到 86.19；另一个独立变体去掉生存门时降至 85.62。它们支持“价值落差必须和剩余可救空间一起看”的解释，而不是“高不确定一概有用”。图四的方差守恒检验给出拟合决定系数 0.962，是估计量一致性证据，不构成对近似价值模型永不误导采样的保证。最关键的失效风险仍是早期网络把可救分支判断为必败，此时探索保底能缓解，却不能根除反馈闭环偏差。表一还有值得主动保留的反证：七十亿模型在 MuSiQue 上为 19.90，低于外部参考 StepSearch 的 22.60。后者使用不同过程监督，既不能据此否定匹配预算下的优势，也不能宣称本文已经超过所有已有方法。图三应先看分支终点分布，再看校准误差；表三必须把在线和受控离线两块分开读，因为数据分布不同，不能把零点零三八四直接当作在线误差的进一步下降。

迁移：让 Agent Memory 的旧经验按“漂移”而非年龄统一降权

原问题是旧策略的前缀结局污染当前价值；可迁移机制是有偏历史均值与新鲜样本之间的有界收缩。新问题不是再造一个分水岭分支算法，而是记忆库里同一技能的成功统计，在模型换版或工具接口变化后何时应该失效。可证伪假设为：按可观测工具分布变化调节漂移比例，比统一时间衰减在突变后更快恢复，同时不牺牲稳定阶段成功率。修改只放在记忆检索的效用估计层，保持当前策略和分支分配固定，避免三个改动叠加后无法归因。

最小实验用三十亿指令模型，在具身模拟器里构造固定任务与中途改变物品位置反馈的两阶段环境；训练或校准集与最终评估任务分离。先收集相同数量轨迹，比较当前批均值、固定混合、原文固定漂移收缩、按工具反馈差异调节漂移四组。至少三个随机种子，报告阶段前成功率、变化后恢复所需环境步数、价值校准误差、错误旧记忆命中率以及墙钟。先用冻结策略离线重放排除训练不稳定，再只对最有希望的两个版本做在线更新。

人话版、背景与关键洞见

这篇不是再给剪枝器增加一个重要性分数，而是先问模型到底把哪两帧混成了同一个词元。长视频预算有限，均匀采样的相邻帧可能相隔几十秒；某些视觉编码器却默认把相邻两帧一起做三维卷积，相当于把不同场景叠成一张重影。后面再精巧地删词元，也恢复不了已经混掉的信息。作者按时间相关片段而不是机械帧对分配网格，结合后层释放视觉词元，在无需训练的条件下改善精度与首词延迟。它的价值在于把加速决策前移到不可逆信息损失发生之前。

分析覆盖十六个开放模型的分词器：一类会混合多帧且支持变分辨率，另一类逐帧编码但输入网格固定。两类模型同样保留一半词元，最不伤精度的削减维度可能相反。前者在密集视频里可降低空间分辨率，稀疏视频则应分开编码不同瞬间；后者在密集视频里更适合去掉重复帧，而非破坏原生输入网格。约两秒的相关时间只是此处数据上的经验尺度，不是所有领域都成立的自然常数。

方法：预算在编码之前花，信息在足够深之后放

输入为采样帧、时间戳、用户给定词元预算和模型分词器属性。先按采样间隔估计独立瞬间数量。三维帧块模型的网格数至少维持原生帧对数，当独立瞬间更多时增加网格、降低每网格空间词元；稀疏到每帧都是独立瞬间时，用原生静态图接口复制同一帧构成帧对，避免混入另一时刻。这里复制不是凭空加新信息，而是规避时间核将两个场景相加。固定输入模型在密集视频保留可容纳的原生分辨率帧，稀疏视频则保留所有时刻、在编码输出侧池化。

之后把视觉词元送入语言模型，到约三分之二深度释放后续层的视觉隐状态；前面层的视觉键值仍保留供解码使用。释放并不是清空全模型视觉缓存。选择深度的证据来自无标注校准问题的首词翻转率，因而特别适合首词就表示选项的问答；长自由生成可能在后续突然需要视觉细节，不能无条件照搬。方法不改权重，也没有任务奖励学习，主要节省编码、预填充与部分后层缓存，而非减少视频文件解码时间。

最值得读图四的分词器分流和表五的分拆消融：前者解释为什么同一预算不能统一“多留帧”，后者区分精度收益主要来自分配规则，延迟收益还来自后层释放。与只看注意力的后编码剪枝相比，它在输入构造阶段修正了信息内容，比较时必须保持采样帧和计时起点一致。

人话版、方法与 Agent Architecture

同一套视频智能体脚手架，不一定适合另一个规划器或观察器。作者固定模型权重，从相同初始搜索与观察接口出发，查看失败轨迹，决定给这个模型组合开哪些总览、记忆、核查、文字识别或语音识别能力，再单独校准观察配置。不是模块越多越强，也不是一个大模型上调好的脚手架直接迁移就好。论文把“模型和执行系统是否匹配”变成优化对象，重点是精度与证据获取，而非宣称纯底层算子加速。

输入是问题和长视频，规划器用搜索定位时间区域，经观察工具获取局部证据，运行时维护交互状态并返回反馈。校准失败触发局部结构提案，只有在视频不重叠的验证集改善才接受；结构固定后，再调观察执行参数。初始只有搜索和观察，其余组件从固定小目录中加法启用，不是任意写出全新算法。记忆和核查可能减少重复查找及证据丢失，但若首次观察错误，也可能让错误记忆反复影响后续规划；因此跨模型适配测试比单次最终准确率更能揭示失败传播。

结果、边界与用途

表一中 Qwen3.5-27B 的 Video-MME Full 从初始 64.0 到 71.9，平均采样帧从 106.1 到 60.6；两个指标同时改善，但没有据此推断端到端耗时同比下降。最有警示性的表二：把 GPT-5.5 适配的脚手架移给 Qwen3.5-27B，其长视频得分只有 50.4，低于初始 53.9；匹配自身脚手架才有 65.2。适配不是单调升级，跨模型甚至可能负迁移。

还有平均数掩盖的反例：九十亿模型在 Video-Holmes 上，MoHA 为 29.4，共享脚手架为 30.9；因此不能说专属适配每个任务都胜过共享版本。贡献是模型条件化的系统匹配证据，限制是固定模块库、校准集成本和商用模型版本依赖。本次未完整核验所有适配资源附表，故仅列低级别而不靠大涨幅升格。最小迁移实验可在两个冻结开源规划器上互换记忆与核查配置，保持调用预算和视频划分不变，比较成功率、证据覆盖、失败重复率与总时延。长视频长度也不等于百步千步工具交互，论文不能作为无限长链可靠性的证据。工具调用是否反复消耗在同一错误时间区间，是比最终选项准确率更直接的过程诊断，也应作为后续验证指标。

Idea 1 / 工具突变下的逐记忆漂移校准（今日最佳）

Inspiration：WEIR的旧前缀有偏收缩。Research Gap：固定历史衰减无法判断模型更新与工具变化究竟污染了哪些记忆；本文的全局漂移比仍是常数。Hypothesis：在工具反馈突变后，逐记忆漂移比能够降低错误旧经验命中率并缩短成功率恢复时间，而稳定阶段不变差。

Proposed Method：在固定检索与策略下，为每条技能/记忆维护新鲜验证结果、历史均值和反馈分布差异；用验证集校准的差异上界控制收缩权重，不让异常变化直接触发永久删除。Minimum Viable Experiment：Qwen2.5-3B-Instruct + ALFWorld的受控物品反馈变化，三个种子；相同轨迹预算比较仅新鲜数据、固定混合、WEIR固定漂移、动态逐记忆漂移。先离线后在线，按S节方案限定总更新预算。

Metric：成功率、恢复环境步数、校准误差、旧记忆误用、GPU-hours。Expected Contribution：可解释的经验过期判据，而非新的经验池命名。Novelty：★★★☆☆；Feasibility：★★★★☆；Compute Cost：★★★☆☆。Risk：分布差异只反映表面措辞，或估计成本高于重新采样。Collision Risk：高；固定漂移收缩已由WEIR占据，经验复用也与CarryOn / ACE-RL相邻。Best Venue：ICLR / NeurIPS，前提是有突变恢复和消融证据。若只提升离线预测不提升成功率，否定系统收益。

Idea 2 / 查询边界保护的Tokenizer-aware Streaming Memory

Inspiration：ESSENCE在剪枝前避免场景混叠，结合ShelfKV的按需视觉记忆。Research Gap：平均时间相关性不能保证问题所指的短事件不被跨边界混合，流式问题还可能在事件之后才到达。Hypothesis：在匹配TTFT下，给查询相关的事件边界保留独立网格，比单纯全局多留帧降低关键证据漏失。

Proposed Method：先用分词器感知的瞬间预算，保留轻量时间边界索引；问题到达时只重编码候选边界附近的小段，缓存不跨这些边界做时间混合。Minimum Viable Experiment / Model / Dataset：Qwen3-VL-8B，Video-MME与LongVideoBench中单独标记跨切镜、短事件问题；冻结模型，对照ESSENCE、问题无关剪枝、固定额外帧预算以及查询引导抽帧；每组至少两个匹配TTFT点。

Metric：准确率、事件证据召回、首词和32-token总时延、缓存内存；把视频解码另列。Expected Contribution：问题后到时不可逆分词损失的诊断协议及最小修复。Novelty：★★★☆☆；Feasibility：★★★★☆；Compute Cost：★★☆☆☆。Risk：重编码抵消节约，查询定位本身出错。Collision Risk：高；ESSENCE已占分词器分配，11月21日Query-Aware对照和ShelfKV已占查询/缓存，必须证明“边界混叠”这个独立失效。Best Venue：CVPR / ECCV / MLSys。若与等量随机额外帧无差异，就否定边界机制。

Idea 3 / 多智能体消息依赖评分的“删除复核门”

Inspiration：R²的固定后续推理、替换反馈似然差，与OPSD4MAS的通信信用。Research Gap：语言模型可能在推理文字中复述消息却不真正改变答案，也可能不复述却内部使用；依赖分数不等于贡献。Hypothesis：只有经过小比例真实删除复核校准的低依赖消息，才适合进入通信成本奖励。

Proposed Method：先离线对替换消息打分，在分数分位点抽样重跑后续代理，学习保守的误删上界；没有通过复核的类别不施加效率优势。Minimum Viable Experiment / Model / Dataset：两个冻结Qwen2.5-3B代理做HotpotQA协作，一个检索一个作答；按问题拆分校准/测试，比较不删、等量随机删、直接依赖阈值、复核门四组，先不做RL，避免成本与训练效果混淆。

Metric：终局EM、消息tokens、误删有用证据率、校准错误、额外重跑成本；再决定是否接入同正确轨迹内效率优势。Expected Contribution：识别“依赖非因果”的安全适用区间。Novelty：★★★☆☆；Feasibility：★★★★☆；Compute Cost：★★☆☆☆。Risk：删除本身改变分布，重复重跑成本过高。Collision Risk：高；不能只把视觉反馈换成消息就声称新方法。Best Venue：ACL / EMNLP / ICLR。若复核门不能降低误删且维持净成本收益，则放弃奖励化。
