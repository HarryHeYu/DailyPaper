Paper 1 — Distance Is Not Enough: Forget-Retain Alignment Gap Predicts LLM Relearning Robustness

Authors: Yi Chen, Hanna Hsieh, Shuhong Liu, Chuanbo Hua, Zihan Ma, Kun Wang, Joo-Young Kim · Date: 2026-08-26 · Venue: EMNLP 2026 Main Conference · Paper · Code

5.2 一句话定位

用forget-critical / retain-critical weight alignment取代global L2，做attack-free relearning robustness prediction，并将同一principle实例化为FRP selective pruning。

5.3 人话版

随机大扰动也会造成巨大weight distance，因此“离原模型远”不等于真正难relearn。FRAG关心update落在哪里：用forget/retain calibration activations构造两张weight importance map，再比较真实ΔW²与两者的cosine alignment，得到FRAG=A_f−A_r。TOFU pooled Spearman=-0.78，L2只有-0.36；去掉FRP checkpoints后仍-0.74 vs -0.10。FRP把同一原则做成row-wise selective pruning；matched utility、forgetting、sparsity、norm下仍更难恢复。

5.4 Background & Research Gap

edit-time forgetting与长期robustness不是同一目标。已有global distance predictor无法区分selective edit和random/collapsed perturbation。本文寻找的是“update structure”的attack-free proxy。

5.5 Core Insight

线性层gradient含input-channel activation。如果某权重只在forget data上强激活、retain data上弱激活，那么retain-only finetuning天然较难覆盖该edit。因此robustness应奖励forget alignment、惩罚retain alignment。

5.6 Method Deep Dive

M0,Mu → ΔW → forget/retain calibration → xf,xr → F,R → D=(ΔW)^2 → Af,Ar → FRAG → predict robustness → optional FRP pruning

Calibration只需forward；F/R使用weight magnitude与activation ratio；cosine去掉update scale；FRP按row-wise score剪forget-critical、retain-unimportant且magnitude足够大的weights。

5.7 核心公式与数学直觉

F_ij=|W_ij|·xf_j/(xr_j+ε), R_ij=|W_ij|·xr_j/(xf_j+ε)
FRAG=cos(F,D)−γcos(R,D), D=(ΔW)^2, γ=1

若只看Af，随机破坏也会打中很多forget-important weights；减去Ar后这种同时伤forget/retain的update得分会下降。

5.8 Toy Example

同样L2的两个update：A只改某forget author专用channels，B改通用语言channels。retain-only finetuning不断触碰B，几乎不触碰A，所以A更难恢复。FRAG能区分，L2不能。

5.11 Metrics

5.14 Ablation / Mechanistic Analysis

随机noise可在L2上接近FRP但没真正unlearn；γ=0时noise会被误判。Alternative importance里activation-based FRAG最强且只需forward。Long-horizon attack显示FRP只是减慢恢复而不是永久阻止。

5.15 Claim vs Evidence

Authors Claim:weight selectivity比distance更解释robustness。Actually Show:多benchmark/model/method与matched controls支持。Not Proven:sample-level、black-box、MLLM/Agent、严格因果。

5.16 Contribution

New Metric FRAG；New Mechanistic Hypothesis；New Method FRP；New Finding：global distance可被random/collapsed update欺骗。

5.17 Limitation & Failure Modes

Paper 2 — CaSKG: Counterfactual-Causal Skill Graphs for Scalable Agent Skill Retrieval

Authors: Zhiyuan Li, Linyuan Gao, Xuechun Ding, Hongwei Chen, Yuan Wu, Yi Chang · Affiliation: Jilin University / Ant Group · Date: 2026-08-26 · Paper · Code

5.2 一句话定位

先高召回发现skill graph候选边，再用remove/substitute/reorder三种counterfactual probes验证有向dependency，只让高confidence边参与retrieval diffusion。

5.3 人话版

Full Library噪声大，Vector retrieval忽略procedural relation，Graph-of-Skills虽能沿graph扩展，但错误edge会把relevance传播到错误skills。CaSKG把“发现边”和“相信边”拆开：semantic/lexical/I-O/structural/repair signals先建candidate graph，再对预算内edge做删除source、替换source、反转顺序三种probe；经Beta smoothing后标成confirmed/uncertain/rejected/unvalidated，再state-gated发布。六个backbones在ALFWorld+ScienceWorld共12个组合里全部task score最高；ScienceWorld macro72.62→80.50，ALFWorld80.01%→86.79%，steps也下降。

5.4 Background & Gap

Graph retrieval的新风险不是没有relation，而是relation不可靠。相似/共现不等于前置、repair、ordering dependency；弱边进入PageRank diffusion后会污染整个skill bundle。

5.5 Core Insight

一条有向skill edge至少应经necessity、specificity、directionality三个反事实检查。这里的“causal”是LLM-simulated textual counterfactual evidence，不等同严格SCM。

5.6 Method Deep Dive

skill library → multi-signal candidates → validation frontier → removal/substitution/reordering → evidence → Beta-smoothed c_ij → edge states → state-gated publication → frozen graph → query diffusion → compact skills

5.7 核心公式与数学直觉

Ã_ij=clip(Σλ_kφ_k(i,j)/Σλ_k)
P_rem=(∅,s_j), P_sub=(s~_i,s_j), P_ord=(s_j,s_i)
α=1+Σz_mδ_m, β=1+Σ(1-z_m)δ_m, c_ij=α/(α+β)

Candidate阶段追求coverage，counterfactual阶段追求reliability，state gate避免中等可信边集体污染graph。

5.8 Toy Example

A=找杯子、B=装水、C=加热、D=检查。A→B的remove/substitute/reorder都可显示强依赖；B与C虽都含water，不一定有固定方向。删除A后若存在另一条E→B替代路径，就可能重构A的功能。
