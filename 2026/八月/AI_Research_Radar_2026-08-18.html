Tier SThe More Popular, The Harder to Forget: Adaptive Popularity for LLM Unlearning

人话版：这篇论文指出：不同事实不是同样难忘。热门事实因为在预训练中被反复强化，往往具有更深、更分布式的参数表示；冷门事实则更脆弱。如果对所有 forget samples 使用相同压力，就会出现热门事实残留、冷门事实过度擦除。AdaPop 用外部 popularity score 为每个 fact 自适应设置梯度指数，同时用 dual-ascent retain controller 防止 utility collapse。

Core Insight / Method

forget fact → popularity score s_i → β_i = a·s_i^{-b} → token probability p_i,t → adaptive weight p_i,t^{β_i} → forget loss + dynamic retain controller → update

Experiments & Main Results

在 Llama-3.1-8B、Gemma-7B-it、Qwen2.5-7B-Instruct 与 DUET/RWKU 上，AdaPop 在 adversarial reformulation 和内部表示指标上优于 WGA/NPO；热门 fact 的收益尤其明显。其价值不在于所有表面 ROUGE 都绝对最低，而在于对深层残余的持续追击更强。

Contribution

提出 popularity gap；提出 per-fact adaptive unlearning pressure；加入动态 retain constraint；使用内部表示和鲁棒改写评估真正 erase 程度。

Limitation

Popularity 只是 memory depth proxy，不等于真实参数因果贡献；主要仍是 factual text knowledge，规模集中在 7B–8B。

Research Value

最值得迁移到 Agent Unlearning：把 popularity 替换为 retrieval frequency、provenance out-degree、cross-agent copy count、LOO sensitive influence，形成 depth-adaptive deletion。

Tier SWrong but Useful: Trajectory Value Beyond Answer Correctness in Multi-Agent Messages

人话版：这篇多智能体工作证明：一条消息自己答错，不代表它对最终 trajectory 没价值。作者固定 candidate pool，只做 leave-one-out replay，直接测某条消息是否提升最终任务成功率。大量 wrong-but-helpful 消息的价值主要来自 reasoning，而不是错误 final answer。对 Trajectory Unlearning 的启示是：不能按局部 correctness 或关键词来决定删哪一段，而要估计真正的 downstream causal influence。

Background & Gap

这篇多智能体工作证明：一条消息自己答错，不代表它对最终 trajectory 没价值。作者固定 candidate pool，只做 leave-one-out replay，直接测某条消息是否提升最终任务成功率。大量 wrong-but-helpful 消息的价值主要来自 reasoning，而不是错误 final answer。对 Trajectory Unlearning 的启示是：不能按局部 correctness 或关键词来决定删哪一段，而要估计真正的 downstream causal influence。

Core Insight / Method

same question → 5 role-diverse agent proposals → fixed candidate pool → integrator K5 → hide one message → replay → helpful/harmful/neutral → reasoning/answer component masking

Experiments & Main Results

Omni-MATH-2、JEEBench、SciBench、LAB-Bench、MaScQA 上，wrong-helpful 在所有 model-benchmark 组合都出现；错误但能改变最终结果的消息中，约 39.5%–48.1% 是 helpful。component masking 显示隐藏 reasoning 比隐藏错误 final answer 损失更大。

Contribution

提出 proposal correctness 与 trajectory value 的分离；提供固定候选池 LOO evaluation；实证定位 wrong-but-helpful 的价值主要来自 reasoning。

Limitation

LOO 成本高；当前主要是静态 candidate-pool + integrator；accuracy contribution 也不等价于安全/隐私上应该保留。

Research Value

可直接迁移成 Sensitive Influence / Utility Influence 双 attribution，用于 Causal-Value-Aware Trajectory Unlearning。

Tier AOBLIVION: Workflow-Level Operational Skill Unlearning for Deployed Agents

人话版：OBLIVION 研究 deployed agent 的 operational skill unlearning。作者强调：删掉 skill registry 并不够，因为 skill 还可能藏在 transcript、tool schema、archive、memory 中，被 agent 重新拼出来。真正的 skill unlearning 必须覆盖 source-to-sink reconstruction path。

Background & Gap

Core Insight / Method

enumerate skill carriers → cross-surface coherent erasure → source-to-sink path tracking → sink-side remediation → attack episodes → benign utility check

Experiments & Main Results

在受控 attack episodes 中，OBLIVION 将 skill resurrection ASR 从 1.0 显著降到约 0.114，同时保持 locked utility。独立 sandbox 中也明显降低 exposure。

Contribution

提出 operational skill unlearning、cross-surface reconstruction model、coherent erasure 与 sink-side remediation。

Limitation

环境仍受控；主要是外部 operational recipe，而非模型参数内部 procedural capability；跨 agent 与 continual reacquisition 尚未覆盖。

Research Value

对 Agent Skill Unlearning 是直接 collision paper。后续必须强调 cross-agent propagation、procedural distillation、parameter-memory-tool closure 或 adaptive reconstruction attack。

Tier AMeasuring Task-Agnostic Training Data Influence Across Language Model Pretraining

人话版：这篇论文尝试回答：不用 downstream task，能否直接从整个 pretraining trajectory 判断某条训练样本对最终参数有多重要？作者把 influence 定义为该样本更新是否让参数更接近最终 checkpoint。

Background & Gap

这篇论文尝试回答：不用 downstream task，能否直接从整个 pretraining trajectory 判断某条训练样本对最终参数有多重要？作者把 influence 定义为该样本更新是否让参数更接近最终 checkpoint。

Core Insight / Method

checkpointed pretraining trajectory → estimate θ_t and final θ* → per-example contribution aligned with θ*−θ_t → aggregate across training phases

Experiments & Main Results

在多种 Pythia 规模上观察到 influence 并非训练越晚越高，而是在中期达到峰值；后期还会出现更多 negative/opponent examples。不同 perplexity 与 domain 的贡献也随阶段变化。

Contribution

提出 task-agnostic pretraining influence 定义；把 influence 放回完整训练过程分析 phase/domain/difficulty。

Limitation

真实优化器与理论近似存在差异；checkpoint sampling 会丢掉细粒度过程。

Research Value

可检验 influence 是否比 popularity 更能预测 forget difficulty，形成 Influence-Adaptive Unlearning。

Background & Gap

MobileMem 把长期 agent memory 拉到一年级别的移动端生活轨迹，覆盖跨 app、多模态、时间更新与长期偏好。对 Agent Unlearning 来说，它很适合构造“删除某月/某 app/某旧地址后，跨 app blackboard 是否仍能恢复”的 continual deletion benchmark。

Core Insight / Method

year-scale experience synthesis → cross-app/multimodal trajectory → memory update → multi-hop/temporal/relational/update evaluation

Experiments & Main Results

结构化 memory systems 明显优于简单 long-context / naive RAG；同时 hard distractors 会让浅层检索更容易失败，说明长期 memory 需要真正的组织机制。

Contribution

Limitation

Research Value

Tier BRippleMem: From Isolated Retrieval to Associative Recollection for Long-Term Agent Memory

人话版：RippleMem 将长期 memory 从一次 top-k retrieval 改成多轮 associative recollection：先找到 cue，再沿事件图、人物关系和缺失证据继续扩展。对 unlearning 来说，它天然就是一个 recovery adversary。

Background & Gap

RippleMem 将长期 memory 从一次 top-k retrieval 改成多轮 associative recollection：先找到 cue，再沿事件图、人物关系和缺失证据继续扩展。对 unlearning 来说，它天然就是一个 recovery adversary。

Core Insight / Method

cue-rich episodic memory + event graph → initial recall → controller chooses anchors / missing support → expand neighborhood → evidence consolidation

Experiments & Main Results

LoCoMo、LongMemEval-S 上相较简单 memory baseline 有稳定提升，multi-session 场景尤其受益，说明间接邻接证据能够补足 direct retrieval 的不足。

Contribution

提出 controlled associative recollection 与 provenance-aware evidence consolidation。

Limitation

它不是安全/删除方法，主要关注恢复正确答案。

Research Value

最适合直接改造成 Agent Memory Unlearning attack：direct retrieval 已失败但 associative recollection 仍成功，就说明 deletion closure 不完整。

Tier BPredictive Memory Localization: Forecasting Selective Intervention Paths from Internal Signals

人话版：Predictive Memory Localization 关注一个比普通 activation steering 更实用的问题：找到 direction 后，能不能预测它是否存在一个“既能改变 target、又不伤 neighbors”的选择性 intervention window？

Background & Gap

Predictive Memory Localization 关注一个比普通 activation steering 更实用的问题：找到 direction 后，能不能预测它是否存在一个“既能改变 target、又不伤 neighbors”的选择性 intervention window？

Core Insight / Method

low-dose causal probes → observe target/collateral response → predict higher-strength path → selector chooses coefficient or abstains

Experiments & Main Results

在多域 intervention paths 上，低剂量响应能够预测后续更强干预的可用性，并比固定强度策略减少 collateral damage。

Contribution

把 direction discovery 推进到 selective operating-regime prediction。

Limitation

依赖内部信号，不适合纯黑盒；仍需验证是否能迁移到真正 knowledge unlearning。

Research Value

适合作 inference-time selective forgetting 的 gating：若不存在低 collateral window，就 abstain 或切换训练式方法。

Best Idea

Depth-and-Propagation Adaptive Agent Unlearning

Inspiration：AdaPop + MobileMem + RippleMem + Wrong but Useful。

Research Gap：当前 Agent Unlearning 很少显式建模不同 memory / trajectory / skill 的删除难度差异。

score(o_i) = retrieval frequency + provenance out-degree + cross-agent copy count + LOO sensitive influence + associative recovery frequency → adaptive deletion pressure → adaptive closure radius → re-probe until residual leakage disappears

MVE：AppWorld / AgentDojo 派生 3-agent workflow；控制同一 fact 被引用 1/5/20 次并传播到 1/2/3 agent。比较 local delete、uniform suppression、whole-store purge、adaptive closure。

Metric：Direct Forget、Associative Recovery、Cross-Agent Leakage、Utility、Deleted Mass、Reacquisition。

Collision Detection

⚠️ Collision Warning

Agent Skill Unlearning — OBLIVION

只测 direct retrieval / direct QA 已不够，至少需要加入 associative recollection 与 derived-memory recovery。
