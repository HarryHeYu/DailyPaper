Tier S

Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses

Full text

人话版

Recuris把长期Agent记忆拆成Experiential Memory、Working Memory、Invocation Policy和Checker四个组件。Working Memory维护经过环境验证的当前状态；Invocation Policy基于当前state而不是整段聊天历史调用skill；结构化trace记录state→skill→action→observation→checker；Meta-Agent只patch出错组件，再用held-out validation gate决定是否接受。4个long-horizon benchmark和10个模型中37个完成pair有35个提升；GPT-5.6 Sol在tau²-Retail上+17.8pp，Claude Opus 5 +15.6pp，最长horizon +32.2pp。

Core Insight

memory-control layer可以被显式分解和局部诊断。对Unlearning而言，删除失败也可定位到E/W/ρ/C具体残留通道。

Results

  • 35/37 pairs提升
  • GPT-5.6 Sol +17.8pp
  • Claude Opus 5 +15.6pp
  • 最长horizon +32.2pp
  • 常见failure最多下降80%
  • fault localization：13.0% → 37.0% → 64.8%

Migration

Component-Scoped Agent Unlearning：20 targets×E/W/ρ/C四组件，逐层disable/patch，测Localization Accuracy、Residual Leakage、Deletion Closure、Retain Utility。

Memory Is Not Always Needed: Characterizing Conditional Memory in Scientific Reasoning

Full text

人话版

同一memory在不同input、task、backbone和注入layer上可能修复知识缺口，也可能干扰本来正确的推理。作者用External Data Router决定哪些query开memory，再用Internal Parameter Router决定在哪些layer-stage注入。Activation-Rate-Matched Random Router与方法拥有相同memory-on比例，但仍被feature router持续击败，说明关键不是“开多少”，而是“给谁开、在哪开”。

Results

  • Matched Random Router在展示setting里全部低于Data Router
  • Qwen2.5-7B MolEdit accuracy 0.495→0.513
  • MolUnd MAE 0.536→0.501
  • MolUnd accuracy 0.562→0.573

Migration

Conditional Memory Unlearning Router：只在target-specific query/layer条件下block memory influence，保留benign memory benefit。

Reading Is Not Using: Retrieval, Judgment, and the Design of AI Financial Research Workflows

Full text

人话版

模型能retrieve信息，不等于会在最终判断里使用。Qwen3.5-9B的风险披露影响从2k context的+0.032降到128k的+0.004，32k/128k与irrelevant insertion noise floor不可区分；但128k时目标事实仍12/12正确retrieval。Extract-then-decide能把128k influence retention从12%恢复到67%。

Migration

Access-vs-Influence Unlearning Audit：同时测Residual Access、Residual Decision Influence和Integration Gap。

Idea Mining

1. Component-Scoped Agent Unlearning

用structured trace定位E/W/ρ/C中的deletion residual。Novelty ★★★★★ · Feasibility ★★★★☆。

2. Access-vs-Influence Unlearning Audit

构造“可访问/不可访问 × 有影响/无影响”四象限，避免把recall与behavior混为一谈。Novelty ★★★★★ · Feasibility ★★★★★。

3. Conditional Memory Unlearning Router

query-level external blocker + layer-stage blocker，只切断target-specific influence。Novelty ★★★★★。

4. Co-Evolving Unlearning Verifier

verifier根据新恢复失败模式更新，但保留独立holdout，防止直接优化audit导致隐藏。Novelty ★★★★☆。

Collision Detection

Residual/Relearning已有Margin Cliff、J-Access、AdaPop。新的Residual Auditor必须突出black-box + sample-level + MLLM/cross-modal + Access-vs-Influence。Agent Memory侧已有Coalition-Aware、InjecMEM、Agentic Unlearning；新工作应锁定E/W/ρ/C residual localization + long-horizon closure。
