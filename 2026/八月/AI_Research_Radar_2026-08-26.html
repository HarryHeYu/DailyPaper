Tier S

Coalition-Aware Skill Reliability for Self-Evolving Agents

Paper

人话版

Outcome-only skill gate会把几乎无贡献甚至负贡献的新skill收进bank；同一skill换partner或domain后贡献还会反转。CASS用sampled Shapley marginals做coalition-aware selection，u-SMCO再用target-domain无标签retrieval quality做mask。

Background & Gap

Bank-level gain无法识别内部贡献符号，也无法预见domain transfer后的utility reversal。

Core Insight

可靠性应写成R(s;B,D)，不是R(s)。

Method

Bank → candidate → coalition knockout → sampled Shapley → CASS → target queries → mask skill → retrieval quality → u-SMCO

Results

CASS 12个proposal只accept 1，MemSkill accept 6；固定bank size后baseline additions平均-1.38pp；u-SMCO对6/6 banks提高HP-50，MemSkill banks平均+7.17pp。

Figure/Table

Figure2/3看acceptance≠contribution、partner/domain reversal；Figure5看1/12 vs6/12；Table3/4看net-negative additions和u-SMCO。

Contribution

SMRA、CASS、u-SMCO、outcome-only non-identifiability。

Limitation

coalition sampling成本，高阶interaction可能漏，部分target reversal证据仍directional。

Migration

删除target后采样2–4 skill coalitions，定义Coalition Closure Rate、Minimum Recovery Coalition、Retain Utility与cross-domain marginal shift。

BLADE

Paper

人话版

LoRA限制破坏方向，repair-first bilevel先修retain，再做一次小forget；ALM constraint让retain violation后保护快速增强；clamped entropy让已足够不确定的token停止更新。最强证据是sequential stress而不是单次headline。

Core Insight

bounded forget + adaptive retain protection + low-rank bottleneck共同决定重复删除稳定性。

公式

L_forget=mean max(0,τlogV-H(p_t))
L_outer=L_fgt+λr+(ρ/2)[max(0,r)]²

Results

TOFU1B HM约0.808/0.800/0.803；MUSE Books0.818。MUSE News单次PDU0.577>BLADE0.544，但4× scale时PDU0.005；BLADE四轮sequential仍0.523–0.552。

Ablation

ALM off0.233；No LoRA0.459；swap bilevel0.506；替换GA/NPO/logit-margin也严重collapse。

Migration

Deadzone Residual Audit：进入entropy deadzone后继续测white-box margin、black-box preference与K-shot recovery。

Crossing the Margin Cliff

Paper

人话版

14类unlearning方法在41/42个method×size cells中停在retain reference之上的answer-margin窄带。cliff gap强预测relearn；Margin Calibration用non-saturating hinge继续压margin，97/97 LoRA relearn cells与46/46 FPFT cells获胜，但utility代价明显。

Core Insight

token-saturating forget loss在gold probability下降后gradient自然消失，因此多训练相同objective不会跨cliff。

公式

m=log p(gold)-log max p(other); Δ=m_unlearn-m_reference

Results

41/42 cliff-side；panel mean post-attack ROUGE约0.41→0.18；cliff gap与recovery Spearman约0.91/0.89/0.78；utility仅少数cells改善。

Migration

Black-Box Cliff Proxy：用pairwise/direct/paraphrase/cloze preference近似margin并预测K-shot recovery。

Measure, Don't Optimize

Paper

人话版

J-Access审计398个公开unlearned models：model-level residual accessibility能预测recovery speed/extent，但无法识别具体facts；直接最小化J-Access反而让模型学会隐藏，post-attack recovery更高。

Research Value

适合Baseline / Evaluation / Migration。Worth Deep Reading: YES。

人话版

57 repositories、105 transitions；六frontier agents macro F1仅29.9%–69.7%。Stale recall与preservation precision天然对应Skill Unlearning的forget completeness与retain selectivity。

Research Value

适合Baseline / Evaluation / Migration。Worth Deep Reading: YES。

Idea Mining

Black-Box Residual-to-Recovery Auditor

融合Margin Cliff与Measure Don't Optimize：不用white-box logits/Jacobian，只用direct/paraphrase/pairwise/cloze/cross-modal traces预测K-shot recovery。Novelty ★★★★★ · Feasibility ★★★★★。

Deadzone-vs-Cliff Verification

同步记录BLADE deadzone、white-box margin、black-box preference与relearn slope，验证“优化停止≠真正不可恢复”。

Coalition-Aware Skill Unlearning

删除target skill后采样remaining coalitions，测Minimum Recovery Coalition与Coalition Closure Rate。

Memory-Drift Deletion Closure

删除后继续写入benign memories，再测Residual Retrieval、Conditional Leakage、Joint Reacquisition。

Collision Detection

⚠️ Hard-to-Unlearn/Relearning 已有AdaPop（external popularity）、Margin Cliff（white-box margin）、Measure Don't Optimize（white-box residual accessibility）。继续时必须突出black-box、sample-level、MLLM/cross-modal，否则撞题明显。Skill/Agent Unlearning则应从single object升级到coalition/context-conditioned closure。
