Paper 1 — Coalition-Aware Skill Reliability for Self-Evolving Agents

Full HTML

基本信息 / 一句话定位

arXiv:2608.22610v1，2026-08-23。把Skill reliability从per-skill scalar改写为R(s;B,D)，并用SMRA、CASS、u-SMCO分别诊断/修复coalition pollution与cross-domain utility reversal。

人话版

Bank整体涨分不等于刚加入的Skill有用。作者发现一个新accept的Skill实际Δ=-0.005，而旧Skill_IN Δ=+0.084；移除partner后Skill_IN掉到+0.018；到target domain方向甚至变成-0.035。CASS因此不只看outcome，而采样coalitions做knockout；u-SMCO则在target domain无label情况下，根据删掉某Skill是否改善retrieval quality来mask。CASS 12个candidate proposals只accept1个，MemSkill accept6个；后者新增Skills总体平均-1.38pp。u-SMCO对6个banks全部改善target performance。

Background & Gap

现有skill evolution以aggregate reward当gate，无法识别内部skill marginal和interactions；single-skill评价又忽略partner/domain dependence。

Core Insight

skill contribution必须通过composition intervention测，而不是从bank endpoint推断。Theorem 1说明outcome-only endpoint在结构上不可识别内部负贡献Skill。

Method Deep Dive

B_e → propose s_new → outcome gain → SMRA knockout Δ_s → Shapley coalition view → CASS sampled coalition margins → gate Target domain → unlabeled queries → rebuild memory with skill masked → RQ knockout ψ(s) → greedy u-SMCO

公式与数学直觉

Δ_s^D(B)=V^D(B)-V^D(B\{s})
φ_s^D(B)=Σ_C w(C)[V(C∪{s})-V(C)]
Δ_S(B)=[V(B)-V(B\S)]/|S|
σ(B)=mean_N Δ_S(B)+0.2·r_out(B)
ψ(s)=RQ(B)-RQ(B\{s})

Δ_s是full-bank marginal；Shapley平均所有partner compositions；CASS以固定budget采样coalitions；u-SMCO用target-conditioned retrieval proxy替代训练policy偏见。

Toy Example

A Skill单独看+8，但只有B存在时才成立；删B后A只+2。C虽然加入时overall reward略升，实际Δ_C=-1。Skill Unlearning删B后必须重新估A/C贡献，而不能只检查B是否不再retrieve。

Baseline Comparison

Strongest baseline=MemSkill，因为除gate外protocol匹配。另有CoN、ReadAgent、MemoryBank、A-MEM、Mem0、MemoryOS做performance reference。Selection entropy是最关键无标签proxy反例：ρ=-0.18；target RQ达到+0.76。

Experiment Setup

Llama-3.3-70B-Instruct extraction policy；8×H20；LoCoMo、LongMemEval、HotpotQA、ALFWorld；3 seeds；CASS每outer epoch8 coalition eval，额外成本约5%。

Metrics

Δ_s：knockout causal-ish contribution；Shapley φ：跨coalitions平均；RQ：target query与retrieved memory的语义局部性；ρ：proxy与label utility ranking一致性；ALFWorld SR/#steps与LoCoMo/LME F1、LLM-Judge共同覆盖。

Results Deep Dive

  1. Skill_AP被accept但Δ=-0.005。
  2. Skill_IN Δ=+0.084，partner去掉后+0.018。
  3. Skill_IN LoCoMo +0.084，HotpotQA point estimate -0.035。
  4. CASS1/12 accept，MemSkill6/12。
  5. MemSkill新增skills平均-1.38pp。
  6. Ours LoCoMo F1/LJ41.48/56.58 vs MemSkill39.45/54.78。
  7. ALF unseen SR83.22 vs80.09。
  8. u-SMCO六banks全提升。
  9. MemSkill banks target提升平均+7.17pp，CASS banks+3.59pp。
  10. entropy proxy ρ=-0.18，RQ proxyρ=+0.76。

Table/Figure Reading

Figure2/3看coalition/domain dependence；Table1看AP负贡献；Figure5看acceptance稀疏化；Table3看baseline additions net-negative；Table4看无标签mask改善。

Ablation / Claim vs Evidence

K-controlled ablation证明并非bank size假象。Cross-domain reversal关键case CI跨0，因此应称directional。Coalition pollution证据更强。

Contribution

SMRA audit、CASS、u-SMCO、non-identifiability theorem、coalition/domain reliability empirical finding。

Limitation

文本Skills、coalition sampling漏高阶interaction、u-SMCO O(K²)、target probes少、部分指标用LLM judge。

Reproduction View

先对现有10-skill bank做single knockout与20–50个2–4 skill joint knockouts，画single vs coalition marginal；出现sign flip后再训CASS。

Research Value

对Skill Unlearning极高。最自然新metric：Coalition Closure Rate、Minimum Recovery Coalition Size、Cross-Domain Marginal Shift。

Migration 1

删除Skill A后，对remaining bank sampled coalitions做paired audit；测Target Suppression、Coalition Marginal Shift、Retain Utility、Unsafe Coalition Gain。

Migration 2

删除A后黑盒搜索2–4 remaining skills组合是否联合恢复target；比较single vs coalition recovery，定义Minimum Recovery Coalition Size。

Attack / Verification Lens

攻击者寻找删除后产生最大正recovery interaction的coalition；验证器则检查所有单Skills安全但组合是否恢复target。

与Paper 2关系

两篇都表明“单元素测试”不够：Skill contribution依赖coalition，memory behavior依赖future retrieval context。

记住10句话

  1. Skill reliability不是intrinsic。
  2. Outcome-only gate结构性盲。
  3. accepted Skill可以实际负贡献。
  4. partner会改变marginal。
  5. domain会改变verdict。
  6. CASS采样coalitions。
  7. u-SMCO用unlabeled target RQ。
  8. CASS 1/12 vs MemSkill 6/12。
  9. baseline新增skills平均-1.38pp。
  10. Skill Unlearning必须审计删除后的整个bank。

Paper 2 — InjecMEM: Memory Injection Attack on LLM Agent Memory Systems

Full HTML · Code

基本信息 / 一句话定位

arXiv:2608.23471v1，2026-08-24，COLM 2026 accepted。一次interaction即可造成topic-conditioned persistent memory injection；攻击被拆成retrieval persistence与conditional generation两阶段。

人话版

InjecMEM不需要直接改memory store。它在一次对话里放一个semantic centroid anchor和Multi-GCG command；系统自己把它写进memory。之后用户问同topic不同措辞的问题时，anchor提高被retrieve概率，command则在动态长context里控制输出。MemoryOS上RSR46.5%、ASR-c76.6%、joint35.6；DPI/BadChain/vanilla GCG在generation侧全0。MemGPT仍有37.2/48.6/18.1。对Agent Memory Unlearning，最强启发是把post-delete failure拆成“残留还能不能被retrieve”和“retrieve后generator会不会泄漏”。

Background & Gap

Memory系统让攻击经历write→store→future retrieve→dynamic fusion→generate；普通prompt injection只优化当前prompt，位置和上下文稳定假设不成立。

Core Insight

Retriever-agnostic centroid anchor解决broad topic召回；Multi-GCG对多context/位置/长度优化，解决fusion robustness。

Method Deep Dive

target topic τ → centroid anchor + c_adv → one injected interaction → persistent memory → future q~τ → poison retrieved → fused STM/MTM/LPM prompt → Multi-GCG command → target y*

公式

L(c)=E_(i,p)[-log Pθ(y* | C_i,p(c))]
RSR=P(poison retrieved|topic query), ASR-c=P(target|retrieved), ASR-j=P(retrieved AND target)

Toy Example

一次health对话写入覆盖health/ache/symptom/treatment等cue的memory；之后100条非health内容造成drift；一个月后问joint pain，poison仍可能被topic retrieval召回并在长prompt中触发target。

Baseline Comparison

DPI、BadChain、vanilla GCG都依赖较静态prompt；普通on-topic paragraph是retrieval baseline。Multi-GCG与centroid anchor分别隔离generation和retrieval两侧改进。

Experiment Setup

MemoryOS主系统、MemGPT transfer；Qwen2.5-7B主backbone，另测Mistral/Llama/Qwen family；19 domains、约50 queries/domain、10 seeds；每method只inject一次，之后仅追加non-target dialogues。

Metrics

first-/multi-hit RSR测memory drift persistence；ASR-c隔离generation；ASR-j测端到端；non-target query用于检查局部性。

Results Deep Dive

  1. DPI/BadChain/GCG ASR-c/j=0。
  2. Multi-GCG76.6/35.6。
  3. MemoryOS46.5/76.6/35.6。
  4. MemGPT37.2/48.6/18.1。
  5. 7B command对FT7B75.6，但3B/14B直接0。
  6. 1.5B+7B family-joint后3B36.8、14B64.2。
  7. Cross-family shared command对Llama0。
  8. Concat-3对Qwen/Mistral/Llama78.2/66.3/75.4。
  9. centroid anchor随memory增长比普通paragraph更稳。
  10. tool被修复后，已写memory仍能长期触发。

Table/Figure Reading

Table2隔离Multi-GCG价值；Table3看跨memory system；Table4同family transfer；Table5跨family/concat；Figure2看tool-side persistent poisoning生命周期。

Ablation / Claim vs Evidence

普通GCG→Multi-GCG说明context-distribution robustness；paragraph→centroid说明retrieval coverage。强rewrite/summarization memory未验证。

Contribution

single-shot memory injection、centroid anchor、Multi-GCG、RSR/ASR decomposition、transfer analysis。

Limitation

需white-box surrogate；主要针对保留原interaction text的memory；RSR不高；cross-family transfer弱；target是非操作性marker。

Reproduction View

先复现5个domains：paragraph vs centroid的RSR drift；vanilla vs Multi-GCG的ASR-c；然后把攻击替换成delete-after-write，测删除后Residual RSR。

Research Value

对Agent Memory Unlearning极高：直接给出Residual Retrieval Rate、Conditional Leakage Rate、Joint Reacquisition Rate。

Migration 1

delete target后追加100 benign records，每10条same-topic probe一次；比较entry delete、dependency closure、summary rewrite。

Migration 2

黑盒攻击者用topic-expansion queries提高残留memory被retrieve概率，不需要知道具体残留文本；指标ASR@budget与behavioral Residual Retrieval proxy。

Attack / Verification Lens

unlearning verifier应把“memory没清干净”与“generator仍残留”分开；这比单一ASR更可解释。

与Paper 1关系

Coalition-Aware强调不同Skill组合改变贡献；InjecMEM强调不同retrieval context改变behavior。共同指向composition-conditioned unlearning。

记住10句话

  1. 一次interaction即可持久污染memory。
  2. 攻击必须同时解决retrieval和generation。
  3. centroid anchor提高topic召回。
  4. Multi-GCG建模动态context。
  5. DPI/BadChain/GCG在memory fusion中全0。
  6. Multi-GCG ASR-c76.6%。
  7. MemoryOS joint35.6%。
  8. 跨system/跨family transfer明显下降。
  9. 修复tool不等于清理memory。
  10. Unlearning必须长期测Residual Retrieval×Conditional Leakage。

Cross-Paper Synthesis

两篇共同说明Agent Unlearning真正的状态单位是 target + coalition/context distribution。Skill删除后要重新audit剩余bank；memory删除后要在future queries和memory drift下持续audit。

Combined Research Opportunities

Coalition-Aware Skill Unlearning

删除A后sample remaining coalitions；测marginal sign flips与unsafe coalition gains。

Coalition Reacquisition Attack

单个remaining skill都安全，但2–4个组合是否恢复被删能力。

Memory-Drift Closure

删除后正常使用数百轮，再测Residual RSR和Joint Reacquisition。

Collision

Behavioral Skill Reconstruction、Agentic Unlearning、MemCollusion已经分别覆盖skill reconstruction、parameter-memory closure、memory coalition攻击。新工作的差异化必须是 post-unlearning coalition search + cross-domain marginal audit + future retrieval drift。

Reading / Reproduction Priority

先做Coalition-Aware的10-skill knockout audit；再做InjecMEM式delete-after-write memory drift audit。最值得立即跑：删除一个skill/memory target后，采样50个remaining coalitions + 50个future topic queries，同时测Coalition Recovery ASR与Residual Retrieval。
