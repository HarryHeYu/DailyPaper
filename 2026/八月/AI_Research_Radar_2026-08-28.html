Distance Is Not Enough: Forget-Retain Alignment Gap Predicts LLM Relearning Robustness

Paper

人话版：这篇论文到底干了什么？

FRAG反驳“unlearning 后离原模型越远就越难 relearn”的简单直觉。它不看global L2，而看真实 update 是否落在 forget-critical、retain-sparing weights 上。用forget/retain calibration activation构造两张importance map，再让ΔW²分别与它们做cosine，得到FRAG=A_f−A_r。30个healthy checkpoints上 pooled Spearman=-0.78，而L2只有-0.36；去掉作者自己的FRP checkpoints仍-0.74 vs -0.10。FRP再把同一原则变成selective pruning。

Method

M0,Mu→ΔW→xf/xr→F,R→D=(ΔW)^2→Af,Ar→FRAG→predict robustness
F_ij=|W_ij|xf_j/(xr_j+ε), R_ij=|W_ij|xr_j/(xf_j+ε), FRAG=cos(F,D)-γcos(R,D)

Experiment Setup

TOFU LLaMA-3.2-1B/3B，forget01/05/10；retain/forget/mixed relearning attacks。WMDP-cyber Qwen2.5-14B；MUSE-News LLaMA-2-7B。

Key Results

  • Pooled FRAG -0.78 vs L2 -0.36。
  • w/o FRP：-0.74 vs -0.10。
  • Matched forgetting：RMU pre-ES .056 比 FRP .062更低，但ΔES .644 vs .059。
  • Matched sparsity2.5%：SP .173 vs FRP .067。
  • 10 epoch后FRP仍可恢复到ES=.752，因此不是绝对删除。

Figure/Table

Figure2的noise/collapse control最关键；Table3是predictor correlation；Tables14–17依次控制utility、forgetting、sparsity、update norm。

Claim vs Evidence

强支持white-box checkpoint-level predictor；不支持sample-level/black-box/MLLM结论。

Migration

White-box FRAG做teacher，黑盒direct/paraphrase/pairwise/cloze/multi-hop行为做features，预测target-levelK-shot recovery。Metric：Spearman、AUROC、ASR@budget、retain FPR。

记住5句话

  1. L2不够。
  2. 关键是update在哪里。
  3. FRAG pooled -0.78。
  4. random noise能骗L2。
  5. 黑盒sample-level FRAG是最强空白。
EvoMal: Self-Poisoning in Self-Evolving Coding Agents

Paper

人话版：这篇论文到底干了什么？

EvoMal利用self-evolving coding agent会模仿retrieved skills来写新skills这一机制，让payload从攻击者seed复制到agent-authored descendants。六个模型ASPR 20.3%–41.8%，恶意skill数量扩大4.9–9.0倍；targeted description最高86.7%。最关键的是seed skill被删除后，Qwen3到round5 ASPR仍68%。这对Skill Unlearning是非常强的deletion-closure反例：删掉source artifact并不等于删掉它产生的行为lineage。

Method

seed→retrieve→imitate→author new skill→copy payload→store descendant→cascade→remove seeds→test persistence

Results

  • ASPR20.3%–41.8%。
  • library恶意skills 4.9–9.0×。
  • 无banner仍11.1%。
  • targeted description 86.7%。
  • Qwen3 seed removal后round5仍68%。
  • counter-prompt≤6.7%。

Mechanism

真正的攻击面是create-path，不是reuse-path。descendant进入trusted library后，source-centric blocklist/signature/reuse monitor失效。

Migration

Lineage-Closed Skill Unlearning：建立provenance DAG，对source-only/signature/lineage-closure delete做对照；指标Descendant Survival、Behavioral Reacquisition、Minimum Lineage Cut。

记住5句话

  1. Agent会复制retrieved skill。
  2. descendant可继续传播。
  3. seed删后Qwen3仍68%。
  4. artifact delete≠lineage delete。
  5. Skill Unlearning必须测descendant closure。
When Stale Constraints Go Unchecked

Paper

人话版：这篇论文到底干了什么？

这篇论文研究 inherited memory 中“曾经正确但已被新权威记录撤销”的constraint。固定只有2个verification slots时，memory明确写着constraint反而让Agent更少检查其provenance：大约只有1/5会查。constraint已superseded时，native allocation导致约75%–77%的stale-consistent decisions。只把一个slot强制给critical path，不增加预算，就改善+74.0/+72.7/+61.3pp；修正held-out时间矛盾后+73.3pp。

Method

memory stated/removed × world valid/superseded × budget=2 × native/forced-critical → retrieve → decide

Results

  • stated critical inspection≈20%；removed≈67%–73%。
  • native stale decisions≈74.7%–77.3%。
  • forced-critical改善61–74pp。
  • source与memory一致时影响只有约0.7–2pp。

Mechanistic Evidence

预算不变只换slot就大幅纠错，说明allocation而非理解能力是主要瓶颈。

Migration

Freshness-Aware Continual Agent Unlearning：delete后保留Deletion Provenance Path与supersession marker，后续memory/model update固定验证critical path。

记住5句话

  1. 写得越明确不一定越会被验证。
  2. stale error约75%。
  3. 换一个slot就改善61–74pp。
  4. 关键是查哪里。
  5. Continual Unlearning需要freshness-aware verification。

Idea Mining

1. Black-Box Target-Level FRAG

用white-box FRAG做teacher，direct/paraphrase/pairwise/cloze/multi-hop做features，预测target-levelK-shot recovery。MVE：50–100 targets×5 probe families×4 methods。Metric：Spearman/AUROC/ASR@budget/retain FPR。Novelty ★★★★★ · Feasibility ★★★★★。

2. Lineage-Closed Skill Unlearning

source-only vs signature vs provenance-DAG closure；20 skills×3 generation rounds×5 post-delete rounds。Metric：Descendant Survival、Behavioral Reacquisition、Minimum Lineage Cut。Novelty ★★★★★。

3. Counterfactual Skill Deletion Closure

借CaSKG，target node删除后重新probe 1–3 hop edges，搜索minimum recovery path。Novelty ★★★★★。

4. Active Black-Box Unlearning Auditor

Auditor作为RL policy自适应选择probe，retain models作为negative controls；避免把audit score训练回被审计模型。Novelty ★★★★☆。

Collision Detection

⚠️ Relearning predictor已有Margin Cliff、J-Access、AdaPop、FRAG。新的方向必须突出black-box + sample-level + MLLM/cross-modal + query-budget-aware。Skill Unlearning应从node deletion升级到descendant/path/coalition closure。
