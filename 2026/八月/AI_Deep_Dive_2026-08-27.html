Paper 1 — Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses

Full HTML · Code

一句话定位

固定base model，仅进化外部memory-control layer，并用structured trace把失败定位到Experiential Memory、Working Memory、Invocation Policy或Checker。

人话版

长horizon Agent经常不是不会做，而是状态被历史淹没、skill在错误时机调用、旧状态没有被正确更新。Recuris把memory拆成E/W/ρ/C四部分，执行时生成结构化trace，Meta-Agent只patch出错组件，并用held-out validation gate接受/拒绝patch。37个完成model-benchmark pair有35个提升；GPT-5.6 Sol +17.8pp，Claude Opus 5 +15.6pp；最长horizon +32.2pp。更关键的是故障定位：只看outcome 13.0%，raw trajectory 37.0%，structured trace 64.8%。

Background & Gap

Initial-query retrieval无法处理中途状态变化；full-history retrieval会引入旧状态与噪声；final outcome无法定位究竟是skill、state、invocation policy还是checker出错。Agent Unlearning面临同构问题：显式target删掉后，残留可能仍存在于其他control component。

Core Insight

真正创新是把memory execution变成结构化可观测对象，使局部诊断和局部修改成为可能。对于Unlearning，可以把failure localization改成residual localization。

Method Deep Dive

Task → Working State → Invocation Policy → Experiential Skill → Frozen LLM Action → Environment Observation → Checker → Verified State → Structured Trace → Component Diagnosis → Scoped Patch → Held-out Validation
M_k=(E_k,W_k,ρ_k,C_k)

Toy Example

旧地址profile skill已删，但Working Memory schema仍把旧地址设为默认，或ρ仍在付款前触发旧profile，或Checker拒绝新地址更新。只删entry会误判成功；component knockout能定位真正残留。

Experiment Setup

4个long-horizon benchmark、10个target models，从3B open-weight到frontier。核心实验包括总体success、按horizon分层、failure mode、component fault localization、memory transfer和test-time adaptation。

Metrics

Task Success看完成率；Horizon-stratified success看方法是否只对短任务有效；Fault Localization Accuracy是在已知注入故障下猜对组件的比例。Balanced setup的constant-answer floor是33.3%，outcome-only的13.0%甚至低于这个floor。

Ablation / Mechanistic Analysis

Working Memory fault recall从raw trajectory 50.0%到structured trace 83.3%；Invocation fault从0到38.9%；Skill-content fault只61.1→72.2，因为skill错误本来就容易出现在文本里。这符合“structured trace主要补充隐藏control events”的机制预期。

Claim vs Evidence

强支持component-localized memory evolution；不证明这些component label是严格因果解释，也尚未直接做deletion/privacy。

Contribution

New Memory Architecture / Harness Mechanism / Trace Diagnostic / Validation-Gated Evolution。

Limitation

依赖environment observation与checker；Meta-Agent可能patch错；validation需要held-out evidence；未测对抗delete request和multi-agent shared memory。

Reproduction View

先选一个tau-bench环境和Qwen Agent，仅实现E/W/ρ三个组件，人为注入fault，复现Outcome→Raw→Structured定位趋势。确认机制后再做递归evolution。

Research Value

Baseline ★★★★★；Migration ★★★★★；Evaluation ★★★★★；New Paper Potential ★★★★★。

Migration 1 — Component-Scoped Agent Unlearning

20 targets×4 component knockouts；把fault label换成target-residual label；指标Localization Accuracy、Residual Leakage、Closure、Retain Utility。

Migration 2 — Minimum Component Cut

删除E后保留W/ρ/C，测试target behavior是否可重构；交换删除顺序，定义使target不可恢复所需的最小组件集合。

Attack / Verification Lens

白盒可直接component knockout；黑盒可用事件序列诱发component-specific signatures，预测target residual所在control path。

Paper 2 — Memory Is Not Always Needed: Characterizing Conditional Memory in Scientific Reasoning

Full HTML

一句话定位

证明memory是否有益取决于input与knowledge-circuit位置，最优策略不是Always ON，而是conditional memory allocation。

人话版

如果base model本来就知道答案，memory可能引入错误shortcut；如果缺知识，memory才有帮助；即使要用memory，也不是所有layer都适合注入。作者用External Data Router决定哪些query开memory，用Internal Parameter Router决定在哪些layer-stage注入。最关键控制是Activation-Rate-Matched Random Router：它和方法拥有相同memory-on比例，因此可以排除“只是少用memory所以更好”。Data Router在展示setting里全部胜出；Qwen2.5-7B internal router让MolEdit accuracy 0.495→0.513，MolUnd MAE 0.536→0.501、accuracy 0.562→0.573。

Background & Gap

Always ON、固定layer injection默认memory总有益，但现实中memory effect随input/task/backbone/location变化。Unlearning同样不应默认“删了整个memory模块就最好”。

Core Insight

memory utility是input×task×backbone×injection location联合属性。Unlearning可把这个结论反转成target influence的conditionality。

Method Deep Dive

Input → Knowledge Boundary Proxy → External Router ON/OFF → screened cohort → Internal Router layer-stage/strength → memory-augmented reasoning → output

Baseline Comparison

Always OFF测试纯parametric能力；Always ON测试固定memory；Matched Random控制memory access rate；S0 internal control在同cohort上测试固定注入。最强机制对照是Matched Random。

Experiment Setup

Qwen2.5-7B、Qwen3-8B；biology/chemistry scientific reasoning；BioProBench和ChemCoTBench；Random Router使用100个fixed masks匹配activation rate；Internal Router使用same-cohort offline replay。

Results

  1. Feature Data Router在展示的matched-random settings全部更好。
  2. MolEdit acc 0.495→0.513。
  3. MolUnd MAE 0.536→0.501。
  4. MolUnd acc 0.562→0.573。
  5. 不同metric不存在一个固定memory配置全局最优。

Figure Reading

Figure2：knowledge boundary到两级router；Figure4：Always OFF/ON、Matched Random、Feature Router；Figure5：Internal Router同cohort paired replay；Figure6：不同layer的memory effect。

Ablation / Mechanistic Analysis

Random Router严格匹配activation rate，所以Data Router的额外收益来自sample selection；Internal Router同cohort排除“换了更容易样本”的解释。但它仍是mechanism validation，而不是独立generalization。

Claim vs Evidence

强支持conditional memory allocation优于static strategy；尚未证明router找到严格因果knowledge boundary，也未在长期Agent memory或隐私删除中验证。

Contribution

New Empirical Characterization / Boundary-Aware External Router / Internal Parameter Router / Matched-Random Control。

Limitation

scientific reasoning领域较窄；task-specific proxy迁移成本；internal router需白盒；没有unlearning攻击。

Reproduction View

Qwen2.5-7B选一个Chem task，先做Always OFF/ON、Matched Random、Feature Router；Random用100 fixed masks匹配memory-on rate。确认External Router后再做Internal Router。

Research Value

Migration ★★★★★；Evaluation ★★★★★；New Paper Potential ★★★★★。

Migration 1 — Conditional Memory Unlearning Router

30 targets×50 query variants；router目标改成target leakage suppression + benign memory preservation。Metric：Conditional Leakage、Retain Benefit Preservation。

Migration 2 — Layer-Conditional Residual Probe

unlearning后在不同layer-stage注入target cue/memory，测Layer Residual Influence、Recovery Surface、Retain FPR；可与RULER-style white-box residual结合。

Attack / Verification Lens

攻击者寻找最容易打开target memory的query family，形成Conditional Recovery Attack；Verifier报告worst-case conditional leakage，而不是平均值。

记住10句话

  1. Memory不是越多越好。
  2. 作用依赖input/task/layer。
  3. Matched Random控制memory-on rate。
  4. Feature Router仍赢。
  5. MolEdit 0.495→0.513。
  6. MolUnd MAE 0.536→0.501。
  7. MolUnd acc 0.562→0.573。
  8. Internal Router有独立收益。
  9. 不存在固定memory配置统治所有metric。
  10. 最强迁移是Conditional Memory Unlearning。

Cross-Paper Synthesis

Recuris给出Component轴：E/W/ρ/C；Conditional Memory给出Condition轴：query/task/layer-stage。两者组合后，Agent Unlearning的自然审计对象变成一个二维Residual Tensor：target influence在哪个组件、什么条件下重新出现。

Best Migration Direction — Component × Condition Residual Auditor

20 target memories；4 component interventions；5 query/event families；每个cell 3–5 probes。白盒先得到Residual Leakage tensor，再用纯黑盒最终行为预测该tensor，测Spearman/AUROC。这样可以把Agent Unlearning、black-box verification、hard-to-unlearn prediction真正连起来。

Collision

Coalition-Aware已覆盖skill composition，InjecMEM覆盖future retrieval，Agentic Unlearning/ATU覆盖parameter-memory-tool恢复通道。因此新工作应明确差异化为component-conditioned + query/layer-conditioned residual localization + black-box prediction。
