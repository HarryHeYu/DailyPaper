Tier S

On the Fragility of Self-Improving Agents: Variance, Task Order, and Underspecification

Full text

人话版：这篇论文到底干了什么？

Memory-based self-improving agents会把早期随机性写进未来状态。作者在WebArena、VisualWebArena、SCUBA上重复AWM/RBank实验并打乱任务顺序，发现17/24 case方差增加，默认easy→hard顺序可把原本不稳定的方法伪装成持续改进。对continual unlearning，这直接提示delete request order可能构成隐藏curriculum。

Background & Gap

AWM/RBank常只按benchmark默认顺序跑一次，忽略早期错误memory会进入未来state。默认task ID又偏easy→hard，因此method gain可能来自hidden curriculum。

Core Insight

在线memory让noise变成causal history；order不是无关排列，而是对future state的intervention。

Method Deep Dive

No-memory → AWM/RBank → 3 runs → std/best-worst → Default/Shuffle-1/Shuffle-2 → inspect memories → add rubric/env/prompt specification → re-run

Results

17/24 cases方差增加；GitLab gap4.44→7.78，Map2.75→8.26，Multisite2.08→10.42；overall baseline54.8/54.9/49.6，RBank56.3/55.6/51.1；WebArena +1.5%对应p=0.23；Shuffle-1 AWM49.1、RBank49.8低于54.8 baseline；specification只追回约31%退化。

Table/Figure

Table1看variance；Table2看strong initialization；Figure2看implicit curriculum；Figure3看shuffle；Figure4看API/Haversine contagious memory。

Migration

最小实验：20 forget requests×10 orders×3 seeds；比较default/random/easy-first/hard-first/adversarial；测Final Forget、Retain、Rebound、Order Std、Best–Worst。

Contribution

New Evaluation / Mechanism / Protocol / Empirical Finding。

Limitation

当前证据主要来自web/memory agent，closed black-box stage access与更长stream仍需验证。

Research Value

对continual/agent unlearning的order stress、lifecycle closure和diagnostic verification价值极高。

如果只记住5句话

  1. 在线历史是状态，不是背景。
  2. 默认order可能隐藏curriculum。
  3. memory泄漏可沿生命周期传播。
  4. 最终accuracy不足以解释失败。
  5. 最强新方向是Adversarial Deletion Order + Deletion-DCR。
MAPLE-Guard: Memory-Aware Link Enforcement Against Memory-Link Poisoning in Multi-Agent Systems

Full text

人话版：这篇论文到底干了什么？

MAPLE-Guard把persistent memory风险拆成write、retrieval、promotion、cross-agent reuse四个生命周期link。去掉promotion gate后MDSR约73.6→60.0、ASR0.9→14.5，说明private→shared是关键传播瓶颈。对Agent Unlearning可直接改成lifecycle deletion closure。

Background & Gap

memory poisoning可延迟数轮，通过private memory→promotion→shared reuse传播，prompt guard看不到原攻击。

Core Insight

删除/安全策略必须覆盖memory lifecycle，而非只过滤当前输入。

Method Deep Dive

Write Gate → private memory → Retrieval Gate → Promotion Gate → shared memory → Cross-Agent Reuse Gate

Results

LongMemEval ASR约0.9%；AppWorld约0–0.2%；去promotion gate后MDSR73.6→60.0、ASR0.9→14.5；大规模50-agent效果下降。

Migration

把四gate改成delete-lineage enforcement；deleted source不能被write back/retrieve/promote/reuse。

Contribution

New Evaluation / Mechanism / Protocol / Empirical Finding。

Limitation

当前证据主要来自web/memory agent，closed black-box stage access与更长stream仍需验证。

Research Value

对continual/agent unlearning的order stress、lifecycle closure和diagnostic verification价值极高。

D²ACCI: A Dual-Loop Diagnostic Protocol for Evidence-Preserving Agent Memory

Full text

人话版：这篇论文到底干了什么？

D²ACCI要求任何memory feature改动都必须有paired statistics、protected-slice gate与stage-level trace。DCR专门测失败是否可诊断。Forget Guard、Session、Supplement有显著paired gain，而BM25/RRF被判null feature flag。对Agent Unlearning可直接定义Deletion-DCR与Earliest Leakage Stage。

Background & Gap

同一memory错误可能来自ingestion、retrieval、forget filter、context assembly或generation，总accuracy无法定位。

Core Insight

系统改动必须同时有paired evidence、protected slices和stage-level diagnosability。

Method Deep Dive

Inner: ingest→L0/L1/L2/session→retrieve→forget/update filter→context→generate+trace Outer: paired ablation→McNemar/CI→slice gate→DCR→Accept/Reject/Feature-Flag

核心公式

DCRτ(F;S)=|F|^-1 Σ 1[C(d_i)≥τ]。默认DCR@3，coverage threshold 0.90。

Results

LoCoMo93.59、LME90.93、PersonaMem57.20；Supplement+2.71pp p=.0009；Session+3.67pp p=.0026；Forget Guard+1.92pp p=.0030；BM25/RRF无显著改善；trace-adapted vs result-only同为43.33% accuracy，但DCR100% vs0%；PersonaMem错误57.1%来自generation、29.8% constraint、13.0% retrieval。

Migration

定义Deletion-DCR与Earliest Leakage Stage：delete provenance ID贯穿store/retrieve/filter/context/generate。

Contribution

New Evaluation / Mechanism / Protocol / Empirical Finding。

Limitation

当前证据主要来自web/memory agent，closed black-box stage access与更长stream仍需验证。

Research Value

对continual/agent unlearning的order stress、lifecycle closure和diagnostic verification价值极高。
