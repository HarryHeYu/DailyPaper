Executive Summary

Machine Unlearning：今天最强趋势并不是“又一个新 objective”，而是评测粒度升级。Scientific Claim Unlearning 表明训练 view 被遗忘，不代表同一 claim 的另一种表示也被遗忘；WMDP++ 则表明 direct Target 准确率很低，不代表 jailbreak / ICL 下仍然低，而且 MMLU 稳定也可能掩盖 near-distribution 安全知识 50pp 级损伤。

Agent / Multi-Agent：SKILL.state 把 long-horizon execution 压缩成 bounded mutable state，而不是永久保留全部 trajectory。它对 Trajectory Unlearning / Agent Memory Unlearning 最值得迁移的机制是“最小 state dependency closure”：删除真正对未来决策有因果影响的状态闭包，而不是粗暴删除整段 history。

今天的研究结论：Unlearning evaluation 正在从“单数据集分数”向 semantic closure、adaptive recovery、boundary preservation、future influence、state provenance 迁移。对现有黑盒 residual 审计方向而言，最有潜力的下一步是 Cross-View Residual-to-Representation Auditor，而不是继续增加同义 paraphrase 模板。

Tier S

1. Can Scientific Claims Be Removed from Large Language Models?

Paper

人话版：这篇论文到底干了什么？

大多数 LLM unlearning benchmark 把删除对象写成固定 QA 或固定段落，因此方法很容易学会“遇到这种形式就不回答”，而没有真正处理底层语义。本文把删除单位提高到 scientific claim。同一条 claim 被转写成 MCQ、True/False、Fill-in-the-Blank、Assertion-Reason 等多种形式，并拆成互不重合的 F1/F2。方法只在 F1 上 unlearn，却同时测试 F1 和 F2。若 F1 大幅下降而 F2 基本不动，就说明模型只针对训练表面做了局部抑制。

Background & Research Gap

旧范式默认 “forget sample = knowledge target”。但同一知识可以通过选择、生成、补全、因果判断等不同输出形式暴露。只训练一种形式，模型可能只改变局部 input-output mapping。SciUnlearn 覆盖 CS、Medical、Retracted 三类 scientific claims，并显式构造互补 views。

Core Insight

真正 claim-level unlearning 需要跨表述等价类泛化。F2 不是简单 paraphrase，而是同一 latent target 的另一种 behavioral projection。因此 cross-view transfer 能更严格地逼近 semantic deletion closure。

Method Deep Dive

Scientific papers → extract atomic claims → generate multiple QA forms per claim → split same-claim QA into F1 and F2 → construct external/internal retain sets → apply GD / NPO / NPO+RT / SimNPO → evaluate trained forget view → evaluate complementary forget view → evaluate retain/general utility → per-paper cross-view error analysis

指标与直觉

Forget set 用 ROUGE-L F1 与 Exact Match，越低代表越不能生成 reference；Retain 越高越好。真正关键不是某个单值，而是 F1 的下降是否会同步迁移到 F2。训练 view 大降而 complementary view 不动，就是典型 surface-specific forgetting。

Toy Example

目标 claim：“药物 A 抑制酶 B。”F1 中放 MCQ“哪个药物抑制 B？”和 cloze“A 抑制___”；F2 放 True/False 与 assertion-reason。若模型只在 F1 上做 GD 后，F1 答不上，但 F2 仍能判断“A 抑制 B”为真，那么底层 claim 并未形成 behavioral closure。

Baseline Deep Comparison

GD：直接提高 forget loss，forget 强，但 utility 风险大。NPO：偏好式降低 forget response，通常更平滑。NPO+RT：加入 retain term 抑制 utility collapse。SimNPO：简化偏好目标。本文最强的“baseline 思维”其实是 protocol 本身：同一个方法训练 F1、测试 F2，把传统单 view 指标的盲区暴露出来。

Experiment Setup

Models：OLMo-3-7B-Instruct、Llama-3-8B-Instruct；更新方式包括 LoRA 与 full-parameter；数据包括 CS、Medical、Retracted；Retain 包括 internal / external，另测 MMLU、ARC-Challenge、HellaSwag。

Results Deep Dive

  • OLMo base CS：F1 R-F1 = 97.54，F2 = 93.92。
  • GD(F1) 后 F1 = 71.70，下降 25.84pp；F2 仍 93.51，只下降 0.41pp。
  • NPO+RT(F1) 后 F1 = 88.81，而 F2 = 93.67。
  • LoRA GD(F1) 可把 F1 R-F1 降到 58.20，但 F2 仍有 75.40。
  • Full-parameter OLMo 中 GD(F1) F1 = 71.33，F2 = 91.73。
  • Per-paper GD F1：39 篇两个 view 都出现 forget error，30 篇只有 F1，只有 1 篇只有 F2。

Table/Figure Reading

Table 3 看 claims 与 F1/F2 数据规模；Table 4 看 LoRA 下的 cross-view asymmetry；Table 16 看 full-parameter 是否能解决；Table 19 看 per-paper error distribution。最有说服力的是 Table 19，因为它显示问题不是少数平均值异常，而是系统性偏向训练 view。

Ablation / Mechanistic Analysis

LoRA 与 full-parameter 都表现出 cross-view mismatch，说明简单增加可更新参数范围并不会自动得到 semantic closure。因此问题更像 objective/evaluation mismatch，而不是某个 optimizer 或 parameter-efficient tuning 的局部缺陷。

Claim vs Evidence

Authors Claim：现有 unlearning 难以真正删除 claim。
Experiments Actually Show：跨模型、更新方式、三类 scientific data 都存在明显 F1/F2 asymmetry。
Not Yet Proven：自动生成的 F1/F2 仍不能代表所有自然语言表达；output failure 也不能证明内部 representation 真正消失。

Contribution

New Benchmark/DatasetNew Metric/ProtocolNew Empirical Finding

真正创新主要来自 evaluation framing：从 sample-level forgetting 转向 claim-level semantic closure，而不是提出新的 unlearning loss。

Limitation

科学 claim 域较窄；自动 QA 生成可能产生 style artifact；生成指标低并不能证明 latent knowledge erase；强方法仍可能以 utility 为代价获得更低 forget score。

Research Value

Baseline ★★★★★；Migration ★★★★★；Attack ★★★★☆；Evaluation ★★★★★；New Paper Potential ★★★★★。

Migration Analysis

Original Problem → claim-level forgetting；Transferable Mechanism →互补 semantic views；New RQ →MLLM/identity unlearning 是否只对 direct/paraphrase 有效？；Method →direct/pairwise/cloze/multi-hop/cross-modal 五 view；MVE →20–50 targets × 5 views × 3–10 checkpoints；Baseline →direct score、GPWR、white-box residual；Metric →Cross-View Transfer Matrix、Worst-View Leakage、ASR@budget、Retain FPR；Expected Contribution →Semantic-View Deletion Closure；Collision Risk →中低。

如果只记住 5 句话

  1. Forget sample 不等于 forget concept。
  2. 互补 views 比普通 paraphrase 更严格。
  3. F1 忘了，F2 常常几乎没忘。
  4. LoRA 和 full-parameter 都存在此问题。
  5. 最值得迁移的是 Cross-View Residual Auditor。
2. Stress Testing Unlearning Algorithms — WMDP++

Paper

人话版

传统 WMDP 只看危险 Target 准确率是否下降，并用很宽泛的 MMLU 当 retain。这会产生两个假象：模型可能只是 direct ask 时不答，一换 jailbreak/ICL 就恢复；或者危险知识删掉的同时，把附近安全 biology/cybersecurity 知识也一起抹掉，但 MMLU 整体变化很小。WMDP++ 因此加入 Max-JB 与 Boundary 两条轴。

Core Insight

Unlearning 至少是二维问题：Robust Erasure 与 Boundary Preservation。只看 Target 低可能把 suppression 当 erase；只看 MMLU 稳定可能掩盖 concept bleeding。

Method

Original WMDP → identify core topic categories → construct safe near-distribution Boundary questions → evaluate standard Target → ICL / GCG / Crescendo / DIA recovery → Max-JB = worst recovered target accuracy → MMLU / MMLUS / Boundary utility → compare safety–utility frontier

Setup

Models：Llama-3-8B、Zephyr-7B Beta；Domains：Biology、Cybersecurity；Methods：RMU、ELM、NPO、simNPO、OrthoGrad；Boundary 每 domain 100 题；攻击包括 ICL、GCG、Crescendo、DIA。

Results

  • Llama Biology：RMU Target = .2498，simNPO = .2608，direct 指标几乎相同。
  • 但 Max-JB：RMU = .2812，而 simNPO = .6009，后者恢复超过一倍。
  • Zephyr Biology RMU：MMLU 仅约 -1pp，但 Boundary 从 .98 降到 .47，下降 51pp。
  • Llama Cybersecurity ELM：MMLU 只约 -6pp，但 Boundary 从 .97 降到 .38，下降 59pp。

Table/Figure Reading

Table 1 是 Biology 综合主表；Table 2 是 Cybersecurity；Table 3 展示不同 ICL context 对 Target 恢复；Table 4 展示 Boundary 在不同 context 下的变化。

Claim vs Evidence

实验支持传统 WMDP 指标会高估成功，而且 method ranking 在更强评测下发生变化。但 Boundary 有部分自动生成，规模不大，攻击也并非穷尽所有 adaptive recovery。

Contribution

New Benchmark ExtensionNew Metric Max-JBNew Boundary Evaluation

Migration

把 WMDP++ 迁到 MLLM：构造 Target / Attack / Visual-Boundary 三集合。Boundary 取视觉近邻、同场景 public entity、共享 attribute 但非 target。指标：Max-Recovery、Boundary Accuracy、Retain FPR、general utility。

如果只记住 5 句话

  1. Target accuracy 低不代表真忘。
  2. Max-JB 测最坏恢复。
  3. Boundary 测邻近安全知识。
  4. simNPO 与 RMU direct 很接近，但 robustness 差很大。
  5. MMLU 稳定也可能掩盖 50pp 级 near-distribution 损伤。
3. SKILL.state: Scalable Long-Horizon Agent Skills

Paper

人话版

长时程 Agent 常把 observation、reasoning、action 不断 append 到 history，prompt 越来越大。SKILL.state 把 immutable Skill 与 mutable structured State 分开：每步只给 Skill + current State + latest Observation，执行后提交 validated State update，然后丢掉中间 reasoning。这样 prompt footprint 近似常数。

Core Insight

长期任务真正需要的是最小充分状态，不是全部过去。对未来决策有因果作用的变量应该持久化，其他 reasoning trace 可以丢弃。

Method

Immutable Skill + bounded State + latest Observation → Action → proposed State update → schema / consistency validation → commit new State → discard intermediate history → next step

复杂度直觉

Append-only history 使每步 prompt 随 T 线性增长，因此总 token 消耗近似 O(T²)；bounded state 让每一步 prompt 大小基本固定，因此总消耗约 O(T)。

Results

  • Warehouse T=200：SKILL.state score = .94±.02，avg prompt = 1811±184，总 token = 122,384±4,522。
  • Memory baseline：score = .84±.09，总 token = 6,175,509。
  • Stateful baseline：score = .88±.03，总 token = 5,041,164。
  • T=100：Stateful 1,062,387 tokens vs SKILL.state 65,408，约 16.2× reduction。
  • T≥50 的差异达到 paired t-test p<.01。

Table/Figure Reading

Table 1 看 Warehouse scaling；Table 6 看 Software Repository replication。真正值得看的不是最终 score，而是随着 horizon 增长，token 曲线的增长阶数发生了变化。

Ablation

Truncated、Budget-Matched、Summary、Stateful controls 说明性能提升不是简单“少给 token”，而是 bounded state 保留了任务所需的关键变量。

Contribution

New Agent Architecture PatternNew State AbstractionNew Scaling Finding

Limitation

需要高质量 state schema；state update 一旦错误会累积；如果 target influence 已经进入派生 state，删除一个字段并不足够，仍需要 dependency closure。

Migration

State-Scoped Agent Unlearning：target state labeling → transition dependency graph → minimal cut → post-delete state reconstruction attack。MVE：20 个 long-horizon tasks、100 steps、5 类 target memory；比较 history deletion、entry deletion、state-closure deletion。指标：Residual Behavior、State Reconstruction ASR、Retain Utility、Deletion Size。

如果只记住 5 句话

  1. Long-horizon 不需要永久保留完整 reasoning。
  2. Skill 是 procedure，State 是 execution memory。
  3. bounded state 把总 token 从 O(T²) 降到 O(T)。
  4. T=200 仍有 .94 score。
  5. 对 Agent Unlearning 可直接迁成 state dependency closure。

Tier A

PILOT in the Loop: Live Self-Improvement for Long-Horizon Agents

Paper

人话版

Supervisor 不等 episode 结束，能在 Worker 执行中实时 redirect/abort，并把刚发现的 procedure / failure 写进 persistent skills。它把“纠正当前 trajectory”和“改进未来 agent”合成一个闭环。

Method & Results

Worker 执行 → Supervisor 观察关键节点 → live redirect / correction → 成功经验转成 skill → 下一 iteration 复用。One-shot setting 中 5/6 backbone-benchmark 组合第一；Terminal-Bench 最高 +9.8pp。Self-improvement 中 GLM +14.6pp、Kimi +12.4pp；mean output tokens 下降 42.9% / 47.4%。

Contribution / Limitation

New System/Engineering + New Online Evolution Mechanism。限制是 Supervisor 质量决定闭环效果，persistent skill 也可能累积错误。

Migration

做 Online Reacquisition Audit：delete target skill 后不结束当前 episode，观察同一 active run 中何时重新写回等价 skill / memory。Metric：time-to-reacquire、skill-write provenance、post-delete ASR。Worth Deep Reading: YES。

When Memory Takes Gradients: Collaborative Vector Memory

Paper

人话版

不再把用户历史压成文本 summary，而是把完整 interaction history 通过协同图训练为 vector memory，再由 LLM reader 使用。这意味着 memory 本身可以通过梯度更新。

Results

四个推荐 benchmark 上，相对最强 text-memory agent，20 个主 metric cells 中 19 个 match 或更好；同时 memory maintenance 不需要逐 interaction 的额外 LLM calls。

Contribution / Limitation

New Vector Memory Mechanism。限制是推荐场景较专用，而且 continuous vector memory 的可解释、可定位、可删性更差。

Migration

Vector Memory Unlearning：删除用户/交互后比较 row removal、graph retrain、low-rank counter-update。指标：Residual Recommendation Preference、Membership AUC、Retain NDCG。Worth Deep Reading: YES。

FaultLens: Learning Compact Behavioral Test Suites

Paper

人话版

FaultLens 从巨大的 probe domain 中学习很小但互补的 test suite，用少量行为测试覆盖绝大多数新 program generation faults。对 Unlearning 的价值是把几百种 probe 压成固定 query budget。

Results

32-probe hybrid 覆盖 576/582 held-out dynamically killable faults = 99.0%，只用 1.2–2.0% exhaustive domain；16 probes 已有 98.1%，random 只有 89.2%。held-out fault family 时 diversity 让 macro coverage 84.6→94.9%。

Contribution / Limitation

New Evaluation / Test Selection Mechanism。限制是原始 fault space 来自程序行为，迁到 LLM unlearning 需要先定义稳定的 residual fault taxonomy。

Migration

从 direct/paraphrase/cloze/pairwise/multi-hop/cross-modal 500–1000 probes 中学习 32-query Residual Suite，在 held-out unlearning methods/checkpoints 测 coverage。Metric：Residual Fault Coverage、ASR@32、Retain FPR。Worth Deep Reading: YES。

Tier B

One Model, Many Minds: Mixture of Roles

人话版：MoRe 用 role codebook + query-aware router，把多个 latent role vectors 混合成一次 steering，从而用单次 model execution 逼近 multi-agent 角色互补。

Main Finding：Qwen3-8B 通用 benchmark 平均 71.48，接近 LLM Debate 71.60；Llama PersonalityBench MoRe AvgScore 9.80、AvgRank 1.0。

Connection：可迁成 Role-Level Unlearning：删除某个 role vector 后，router 是否能通过其他 role coalition 恢复同一行为。Potential Use：Mechanistic Baseline / Coalition Recovery Attack。

MUSE-Autoskill

人话版：把 skill lifecycle 显式拆成 create / remember / manage / evaluate / refine，让 agent 持续形成可复用 procedure。

Connection：Skill Unlearning 不能只删当前 skill 文件，因为 memory 与 evaluation feedback 可能重新生成等价 skill。Potential Use：Reacquisition Benchmark。

SkillsVote

人话版：关注大规模 skill collection、recommendation、evolution governance。

Connection：很适合研究 Skill Library Unlearning：retire/delete target skill 后，推荐、合并、evolution pipeline 是否会把它重新召回。

From Memory to Skills: Evidence-Grounded Co-Evolution Governance

人话版：把 grounded traces、procedural policies、declarative cognition 分层，并把有正 estimated gain 的 policy crystallize 成 callable skills，同时保留 evidence links。

Connection：天然存在 Memory→Skill provenance，可直接测试删除某个 memory 后 derived skill 是否应该被 invalidate。Potential Use：Provenance-aware Skill Unlearning / Dependency Closure。

Idea Mining

Idea 1 — Cross-View Residual-to-Representation Auditor

Inspiration：SciUnlearn。Research Gap：direct/paraphrase 仍可能属于同一 surface family。Hypothesis：不同 semantic views 的最坏残留，比单 view score 更接近内部 residue 与未来 recovery。

Proposed Method：direct/pairwise/cloze/multi-hop/cross-modal 五 view；白盒 RULER/J-Access residual 做 label，黑盒 view vector 预测。MVE：20–50 targets × 5 views × 10 checkpoints。Metric：Spearman、AUROC、Worst-View Leakage、ASR@budget、Retain FPR。

Novelty ★★★★★ · Feasibility ★★★★★ · Compute ★★★☆☆ · Collision Risk 中 · Best Venue NeurIPS/ICLR

Idea 2 — Boundary-Aware Multimodal Unlearning

Inspiration：WMDP++ + multimodal unlearning。为 forget identity 构造 visual boundary set：视觉近邻、同场景 public entity、共享 attribute 但非 target；同时跑 Max-Recovery attack。

Metric：Worst-Case Recovery、Boundary Accuracy、Retain FPR、Utility。Novelty ★★★★☆ · Feasibility ★★★★★ · Compute ★★☆☆☆ · Collision Risk 低中。

Idea 3 — State-Scoped Agent Unlearning

Inspiration：SKILL.state。Hypothesis：target behavior 由有限 state dependency closure 决定，删除最小 state cut 可比清空 trajectory 保留更多 utility。

Method：target state labeling + transition dependency graph + minimal cut + post-delete state reconstruction attack。Metric：Residual Behavior、State Reconstruction ASR、Retain Utility、Deletion Size。

Novelty ★★★★★ · Feasibility ★★★★☆ · Compute ★★☆☆☆ · Collision Risk 低。

Idea 4 — Learned Minimal Black-Box Unlearning Test Suite

Collision Detection

⚠️ Black-box recovery：Daydreaming、WMDP++、Can LLMs Truly Forget 等已经覆盖多种黑盒/自适应抽取。新工作如果只是增加一组 prompt 模板，创新度不够；更合理的是做 sample-level predictor、cross-view closure 或 query-efficient learned suite。

⚠️ Hard-to-Unlearn：FRAG、Margin Cliff、AdaPop、J-Access、entanglement predictor 等方向已经很拥挤。最安全的差异化是“cross-view black-box sample-level + future recovery prediction”，而不是再做一个静态 white-box scalar。

⚠️ Agent Skill/Memory deletion：Agentic Unlearning、OBLIVION、WikiSkill、When Unlearning Fails 已覆盖 parameter-memory backflow、workflow resurrection、recompilation、future influence echo。剩余 gap 更适合 State-Scoped、Cross-Agent、Cross-Modal 或统一 multi-layer closure。
