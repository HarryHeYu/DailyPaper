PAPER 1 · NEW

BLADE: Bilevel Low-rank Augmented-Lagrangian Erasure for LLM Unlearning

Md Toufikuzzaman, Ahmad Mousavi, Dongwon Lee · arXiv:2608.22557v1 · 2026-08-23

Full HTML · Code

5.2 一句话定位

用LoRA低秩约束、repair-first bilevel、非对称Augmented Lagrangian和clamped entropy，把LLM unlearning改造成bounded、retain-aware、可重复执行的sequential optimization。

5.3 人话版

BLADE不是又造一个单独forget loss，而是把重复删除最容易失控的环节拆开：LoRA限制更新方向；每次forget前先做retain repair；retain loss一旦超过预算，dual multiplier λ快速上升，恢复后只慢慢下降；forget token entropy达到阈值后gradient精确归零。TOFU 1B三个split HM约0.808/0.800/0.803，MUSE Books0.818。真正关键是MUSE News stress：单次PDU略强0.577 vs BLADE0.544，但4× scale时PDU掉到0.005，两次sequential后0.58→0.02，而BLADE四轮仍维持0.523–0.552。这说明部署级unlearning应看长期稳定性，不只是单次最佳点。

5.4 Background & Research Gap

GA无界，固定retain权重不能适应训练过程中的landscape变化，普通entropy即使token已经足够不确定仍继续更新。现实删除请求会持续到来，前一次更新会改变下一次的forget/retain几何，因此单次调好的权重不一定能重复使用。

5.5 Core Insight

① forget update必须有hard stopping condition；② destructive step之前先修retain；③ constraint protection应具有ratchet；④ LoRA是结构正则而不只是节省显存；⑤ single-shot optimum与sequential robustness不是同一个目标。

5.6 Method Deep Dive

freeze backbone + attach LoRA → estimate retain budget ε → K retain-repair SGD steps → clamped-entropy forget step → fresh retain batch gives r=L_ret-ε → Augmented-Lagrangian outer update → λ violation-fast / recovery-slow → repeat

5.7 核心公式与数学直觉

L_forget = mean_t max(0, τ·logV - H(p_t))
L_outer=L_fgt+λr+(ρ/2)[max(0,r)]²

达到entropy阈值的token进入deadzone，forget gradient精确为0；违反retain constraint时λ迅速增大，恢复后只慢慢减小。因此系统会逐步缩小forget gradient support，同时留下“保护记忆”。

5.8 Toy Example

目标token“Paris”从p=0.85被压到0.08且entropy过阈值后，BLADE停止继续破坏它，后续主要修retain。第二个删除请求到来时，λ仍保留前次constraint violation的保护。但如果攻击者随后用少量样本relearn，“Paris”仍可能快速回来，因为entropy deadzone不等于margin足够深。

5.15 Claim vs Evidence

PAPER 2 · UPDATED

Crossing the Margin Cliff: Toward Relearn-Robust LLM Unlearning via Margin Calibration

Xiangyu Yin, Jiaxu Liu, Zhen Chen, Chih-Hong Cheng · arXiv:2607.27836

Full HTML

5.2 一句话定位

把14类post-hoc unlearning的relearn脆弱性统一解释为answer-margin cliff，再用非饱和margin hinge改变stationary set。

5.3 人话版

模型当前不回答原答案，不代表离恢复很远。如果gold token只比最强competitor低一点，20条forget examples就能把它重新拉回。论文观察14种方法，在41/42个method×size cells中都停在retain reference之上的窄margin带。cliff gap与K-shot recovery高度相关。理论上，token-saturating forget loss在gold probability降低后gradient自然消失，再加retain coupling，就会停在cliff。MC继续按margin gap施压。结果：14/14方法K20-LoRA改善，97/97 LoRA stress cells和46/46 FPFT cells全胜，panel mean post-attack ROUGE约0.41→0.18；但utility显著下降，MIA还可能overshoot成反向可分。

5.4 Background & Gap

传统forget成功往往只说明当前输出变化，不能说明少量fine-tuning后的恢复难度。本文寻找跨方法统一的可预测几何量。

5.5 Core Insight

Relearnability与answer margin有关；很多loss family虽然表面不同，却共享token-saturating stationary geometry；因此“多训几轮”不是解决方案。

5.6 Method Deep Dive

post-hoc unlearned model → compute gold-vs-best-competitor margin → compare retain reference → Δ>0 means cliff-side → MC LoRA polish + KL probe → evaluate cliff crossing → run LoRA/FPFT/soft-prompt relearn attacks

5.7 核心公式

m=log p(gold)-log max p(other)
Δ=m_unlearn-m_reference
L_MC=mean softplus(κ(m-m_target))/κ

5.8 Toy Example

NPO后“Paris”当前已不是top-1，但margin=-0.3；reference=-4。20条relearn数据很容易把-0.3推回正值。MC继续把margin压向-4，使相同budget不足以恢复。

5.9 Baseline Deep Comparison

强项不在单baseline，而在14-method panel：gradient、preference、distillation与7种NPO robustness variants都出现相似cliff。GA能持续压margin但utility会collapse，说明“non-saturating”本身也不够。

5.10 Experiment Setup

TOFU forget01/05/10；Llama-3.2 1B/3B、Llama-3.1 8B；MUSE-News Llama-2-7B；Phi-3.5-mini；LoRA-r8/r32、FPFT、soft prompt、adaptive margin attacks。

5.11 Metrics

F.agg↓、MU↑、KS-p、K20-LoRA/FPFT ROUGE↓、cliff gap Δ↓。MIA必须看|AUC-0.5|，因为AUC=0.17仍可被反向利用。

  2. MC 66/70 cells跨reference。
  3. 14/14 K20-LoRA改善。

GA验证非饱和压力能跨但会发散；forget hinge only与two-sided retain hinge都更伤utility；KL probe主要负责降低general behavior损失。

5.15 Claim vs Evidence

跨方法、size、tier、benchmark和attack的证据非常强；尚未证明margin就是representation deletion，也未解决crossing带来的utility代价。

5.16 Contribution

New Empirical Finding：41/42 cliff；New Theory：stationarity解释；New Diagnostic：cliff gap；New Objective：Margin Calibration；New Robustness Evaluation：97-cell stress。

5.17 Limitation

utility显著下降；MIA可能反向可分；margin是output geometry；大模型/MLLM/Agent setting仍未知。

5.18 Reproduction View

先做Llama-3.2-1B forget10，只选四类方法：GradDiff/NPO/SimNPO/UNDIAL，复现base cliff与K20 recovery，再加MC。

Cross-Paper Synthesis

两篇共同把Unlearning升级成三维：Forget Depth × Retain Stability × Relearn Robustness。BLADE说entropy足够高就该停；Margin Cliff说margin没压到reference就不能停。最自然统一是双条件停止。
