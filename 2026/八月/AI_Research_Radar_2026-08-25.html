Executive Summary

今天最重要的统一结论：Agent Skill / Memory 的删除与可靠性不是单元素属性。 Coalition-Aware Skill Reliability证明同一Skill的贡献会随bank伙伴与domain变化；InjecMEM证明一次interaction可通过persistent retrieval在未来重新控制agent；Repo2Skill-Evo证明skill随software release静默过期，删除stale guidance同时保留valid guidance本质上就是precision–recall式selective forgetting。

最强Research Idea：Coalition-Aware Agent Unlearning。删除Skill A后，对剩余bank采样coalitions做paired knockout，检测marginal sign flip；再经历memory drift与future topic queries，测被删能力是否通过remaining skills / derived memories联合恢复。

Tier S

Coalition-Aware Skill Reliability for Self-Evolving Agents

Full text

人话版

Skill bank整体涨分不代表新Skill真的有用；同一Skill换partner/domain后还可能贡献反转。SMRA通过full-bank vs knockout测Δ，CASS用sampled coalition margins替代单outcome gate，u-SMCO在target domain用无标签retrieval quality做mask。

Background & Gap

现有self-evolving agents强调extract/retrieve/update Skill，但把Skill utility当intrinsic scalar。Outcome-only gate只看V(B_old)和V(B_new)，结构性看不到内部负贡献Skill。

Core Insight

可靠性应写成R(s;B,D)。coalition pollution与cross-domain utility reversal是同一事实的两种表现。

Method Deep Dive

Bank B → propose s_new → SMRA knockout Δ_s → sampled coalition knockouts → CASS gate → target domain unlabeled queries → rebuild memory with each skill masked → retrieval-quality ψ(s) → greedy u-SMCO

关键公式

Δ_s^D(B)=V^D(B)-V^D(B\{s})；Shapley φ_s对所有coalitions平均marginal；CASS用Δ_S(B)=[V(B)-V(B\S)]/|S|；σ(B)=mean coalition margin+0.2·outcome reward；u-SMCO用ψ(s)=RQ(B)-RQ(B\{s})。

Experiment / Results

Llama-3.3-70B-Instruct extraction policy，8×H20，LoCoMo/LongMemEval/HotpotQA/ALFWorld，3 seeds。Ours LoCoMo F1/LJ 41.48/56.58；ALF unseen SR83.22。CASS 12 proposals只accept1个，MemSkill accept6个；baseline新增skills整体-1.38pp。u-SMCO对6个banks全部提升HP-50；MemSkill banks平均+7.17pp，CASS banks+3.59pp。entropy preference与target utility ρ=-0.18，retrieval-quality ρ=+0.76。

Table/Figure

Figure2/3：acceptance≠contribution、partner effect、domain reversal；Table1：新accept的AP Δ=-0.005；Figure5：1/12 vs6/12；Table3：新增skills总体net-negative；Table4：u-SMCO全部bank提升。

Ablation / Claim vs Evidence

K-controlled ablation证明不是bank size差异。证据强支持coalition pollution；cross-domain reversal关键case CI仍跨0，因此应读作directional reversal而非已证明显著harm。

Contribution / Limitation

SMRA + CASS + u-SMCO + outcome-only non-identifiability theorem。限制：coalition sampling成本、文本Skill为主、u-SMCO O(K²)、target probes较少。

Research Value / Migration

对Skill Unlearning极高。最小实验：删除一个Skill后，对20–50 sampled coalitions做paired audit；定义Coalition Marginal Shift、Coalition Closure Rate、Minimum Recovery Coalition Size。

InjecMEM: Memory Injection Attack on LLM Agent Memory Systems

Full text · Code

人话版

只需一次interaction、不读写memory store，就能把topic-conditioned poison写入长期memory。centroid anchor提高未来同主题retrieval，Multi-GCG让短command在不同memory context/位置/长度中仍有效。MemoryOS RSR46.5%、ASR-c76.6%、joint35.6；DPI/BadChain/vanilla GCG在同setting ASR全0。

Background & Gap

Memory attack必须同时解决“未来还能retrieve到”与“retrieve后在动态长prompt里仍能控制generation”。传统prompt injection通常只假设当前固定prompt。

Core Insight

Retrieval persistence和conditional generation是两个独立failure modes，应分别设计anchor与command，并分别评估RSR和ASR-c。

Method Deep Dive

one interaction → centroid topical anchor + c_adv → persistent memory → future topic query → poison retrieved → dynamic STM/MTM/LPM fusion → Multi-GCG command → target output

关键公式

L(c)=E_(i,p)[-log Pθ(y*|C_i,p(c))]；Multi-GCG把prompt layout看作distribution而不是固定字符串。评估分RSR、ASR-c、ASR-j。

Experiment / Results

MemoryOS主、MemGPT transfer；Qwen2.5-7B主backbone，另测Llama/Mistral/Qwen family；19 domains、约50 queries/domain、10 seeds。MemoryOS 46.5/76.6/35.6；MemGPT37.2/48.6/18.1。Qwen7B command对3B/14B直接0，但1.5B+7B family-joint后3B36.8、14B64.2。Concat-3在Qwen/Mistral/Llama为78.2/66.3/75.4。

Table/Figure

Table2：DPI/BadChain/GCG=0 vs Multi-GCG76.6；Table3：MemoryOS→MemGPT transfer下降；Table4：family-joint修复同family transfer；Table5：cross-family joint难、concat有效；Figure2：tool-side injection即使tool修复后memory仍持久。

Ablation / Claim vs Evidence

centroid vs普通on-topic paragraph隔离retrieval robustness；vanilla GCG vs Multi-GCG隔离context robustness。强rewrite/summarization memory仍未验证。

Contribution / Limitation

single-shot persistent memory attack + centroid anchor + Multi-GCG + transfer evaluation。限制：需要white-box surrogate、RSR只有46.5%、cross-family transfer弱、主要针对保留原interaction text的memory系统。

Research Value / Migration

直接定义Agent Memory Unlearning的Residual Retrieval Rate、Conditional Leakage Rate、Joint Reacquisition Rate。删除后应继续写入benign memories并长期复测。

Repo2Skill-Evo: Repository Skills Go Stale in Silence

Paper

人话版

把V1→V2 repository release当Skill selective forgetting：删obsolete guidance、保留still-valid guidance。57 repositories、105 transitions中每次release都使部分Skill过期，六frontier agents patch-grounded removal macro-F1仅29.9%–69.7%。

Research Value

可直接把Stale Recall视为forget completeness、Preservation Precision视为retain selectivity，作为Skill Unlearning现实benchmark模板。

Let Credit Follow Computation

Paper

CompPO让credit transport跟Transformer attention-conditioned computation走。Qwen3-4B五seed final held-out 61.4% vs tuned GRPO53.8%；full interaction额外+2.4。可迁移到token/evidence-path-aware unlearning。

CONTRAMEM

Paper

Paper

Idea Mining

1. Coalition-Aware Skill Unlearning

删除A后采样remaining coalitions做paired knockout，测marginal sign flip；指标Target Suppression、Coalition Marginal Shift、Retain Utility、Unsafe Coalition Gain。Novelty ★★★★★ · Feasibility ★★★★☆。

2. Memory-Drift Reacquisition Audit

delete后继续写100条benign memories，每10条做topic probes；指标Residual RSR、Conditional Recovery、Joint Reacquisition。Novelty ★★★★★ · Feasibility ★★★★★。

3. Patch-Grounded Skill Unlearning Benchmark

Repo2Skill-Evo式Stale Recall + Preservation Precision，转成真实Skill deletion benchmark。Novelty ★★★★☆ · Feasibility ★★★★★。

4. Coalition Recovery Attack

删除显式target后搜索2–4 remaining skills/memories组合是否联合恢复能力；定义Minimum Recovery Coalition Size。Novelty ★★★★★ · Feasibility ★★★★☆。

Collision Detection

⚠️ Behavioral Skill Reconstruction已经覆盖“显式Skill删后重构”；Agentic Unlearning覆盖parameter-memory closure；MemCollusion覆盖多memory联合攻击。新工作不能停在single-skill disable。最清晰差异化：post-unlearning coalition search + cross-domain marginal audit + memory-drift future retrieval。
