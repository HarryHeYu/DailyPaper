Executive Summary

Recovery / Representation：Reference-Grafting 与 causal sandbagging model 进一步强化“suppressed output ≠ capability deletion”。在静态 lock 中，少量 paired captures 和少数 layers 就能恢复大部分能力；dynamic rerouting 则形成边界。

Agent Skill：Latent Skill Directions 表明 procedural skill 不只存在于 SKILL.md / prompt surface，也可表现为 activation-space direction。结合 trajectory→skill promotion，Skill Unlearning 很自然地形成 artifact、latent residue、trajectory reacquisition 三层 closure。

Tier S

1. Hindsight Memory-PRM: Supervising Memory Management with Auditable Hindsight Credit

基本信息：Hindsight Memory-PRM: Supervising Memory Management with Auditable Hindsight Credit；arXiv:2608.29605v1，2026-08-30；Paper。Policy=Qwen3-8B，critic=Qwen3-1.7B，均 LoRA；评测 LoCoMo、LongMemEval。

人话版：这篇论文到底干了什么？

长期 Agent memory 的难点不是“写入/合并/删除有哪些动作”，而是当时根本不知道某次 memory operation 以后有没有用。作者发现 memory 会留下可审计痕迹：后来是否被检索、是否被答案引用，以及如果把这条 memory 临时删掉，答案会不会变。论文把这些事后证据变成 operation-level credit，并进一步做 controlled deletion-and-reanswer 校准因果贡献。对 unlearning 来说，这几乎直接提供了“某条 memory 是否仍然 load-bearing”的可操作原语。

Background & Research Gap

最终 answer reward 太稀疏，teacher imitation 只能模仿 policy，Monte-Carlo rollout critic 成本又高。memory 操作却天然产生 audit trail，但旧方法没有把它转成 credit。单纯 citation 仍只是 observational evidence：另一条 near-duplicate memory 也可能让答案保持正确，因此需要删除 intervention 才更接近必要性。

Core Insight

把 credit 拆成两层：retrieval/citation/outcome 提供高覆盖 observational attribution；controlled deletion 提供低覆盖但更强的 intervention-calibrated attribution。然后沿 memory version chain 把 entry-level credit 回传给早期 Write/Merge。

Method Deep Dive

Dialogue/session stream → Write / Merge / Noop → source-turn IDs + version chain → later retrieval + citations → construct anchored probes → delete cited anchor entry → re-answer with same reader → answer flip calibrates presence credit → propagate through version chain → critic + GRPO trains manager

关键是 source anchoring 和 deletion probe：若删掉某条被引用 memory 后答案从正确变错，则它在当前 bank 与 fixed reader 下确实是 load-bearing。若删除后仍答对，则说明可能存在 redundancy。

Results Deep Dive

  • LoCoMo full method 77.5±0.8%，高于 untrained 58.6、SFT 62.5、outcome-only GRPO 63.4、MC-rollout 65.0、observational attribution 70.2。
  • Mem0 官方约 19.6k context tokens 为 74.7%；本文约 2,480 tokens 达 77.5%。
  • 68% online deletion 会令答案 flip；剩余 32% 多由 duplicate/near-duplicate evidence 覆盖。
  • 删除 74.6% 从未进入 logged read path 的 entries，accuracy 仅 -0.1pp；删除 7.2% cited entries，accuracy -12.4pp。
  • LongMemEval：Untrained 61.0、MemBuilder 66.0、Observational 72.5、Full 79.0。

Ablation / Mechanistic Analysis

matched-scale 与 shuffled-flip 近似 observational baseline，说明提升不是 reward scale 或随机 signal；去 synthetic probes 后 intervention coverage 大幅下降，支持“可定位的 deletion intervention”确实是有效成分。

Claim vs Evidence

Authors Claim：memory audit trail 能提供可审计 hindsight credit。
Actually Show：controlled ladder、deletion causality、两 benchmark 都支持。
Not Proven：single-entry deletion 不是 joint necessity；跨 agent shared-memory descendants、skill promotion 尚未覆盖。

Contribution

New MechanismNew Objective/RewardNew Evaluation Protocol 真正值得迁移的是 source anchoring + deletion-and-reanswer + version-chain propagation。

Limitation & Failure Modes

counterfactual 是 model-relative；redundancy 下单条 deletion 可能不 flip；schema/domain transfer 仍有依赖。对 unlearning 来说，这正是下一步 deletion closure 的入口。

Research Value

Baseline ★★★★★；Migration ★★★★★；Attack ★★★★★；Evaluation ★★★★★；New Paper Potential ★★★★★。

Migration Analysis

Original Problem →memory operation hindsight credit。Transferable Mechanism →source anchoring + deletion-and-reanswer。New RQ →删除请求是否切断所有对 target behavior 有 causal support 的 descendants？Minimum Experiment →LoCoMo/LongMemEval 各 50 target facts，人工制造 1/2/4 redundant descendants；比较 source-only、retrieved-entry、lineage-closure deletion。Metric →Deletion Flip Rate、Residual ASR、Minimum Cut Size、Retain FPR、Reacquisition Time。

如果只让我记住 5 句话

  1. 这篇把“删 memory 后重答”做成训练信号。
  2. citation 是 observational，deletion flip 更接近 causal necessity。
  3. full method 在 LoCoMo 达 77.5%。
  4. 32% 单-entry deletion 不 flip 主要暴露 redundancy。
  5. 它非常适合扩成 Agent Memory Unlearning 的 deletion closure。
2. Reference-Grafting Matches Fine-Tuning at Eliciting Sandbagged Capabilities

基本信息：Reference-Grafting Matches Fine-Tuning at Eliciting Sandbagged Capabilities；arXiv:2608.29458，2026-08-30；Paper。

人话版

作者研究“模型明明会但故意表现不会”的 sandbagging。关键发现是：与其给 activation 加一个方向，不如直接把某个内部坐标改成 honest reference 中对应的真实值。这个 reference grafting 在 11 个 password-locked models 上恢复 honest–sandbagged gap 的约 94–101%，几乎匹配 fine-tuning。对 unlearning 的启发非常直接：若所谓遗忘只是静态 suppression gate，那么 internal coordinate replacement 可能把能力几乎完整恢复。

Core Insight / Formula

v = normalize(E[h|honest] − E[h|sandbag]) s = hᵀv h' = h + (t* − s)v

与 additive steering 的区别是把目标坐标精确写到 honest value t*，而不是猜一个 α。

Experiment Setup

11 个 fine-tuned password-locked models，1.5B–32B、多 architecture lineage；ARC-Easy 为主，迁移到 WMDP-bio/cyber、OpenBookQA，并测试 code generation。

Results Deep Dive

  • 11 models 上恢复 +94% 到 +101% gap，匹配 fine-tuning。
  • WMDP 上多个 scale 也接近完整恢复。
  • m=2 paired captures 即约 +97%，m=5 接近 +100%。
  • 同一 axis 可跨内容迁移，但跨 suppression mechanism 失败。
  • circuit-breaking 后 grafting 基本失败，说明动态 rerouting 是硬边界。

Table/Figure Reading

Table 1 看主恢复结果；Figure 1 看 cross-dataset transfer；circuit-breaking 图表是最关键反例：静态 lock 能解，持续 rerouting 不能。

Claim vs Evidence

实验支持“静态低维 gate 可被 reference graft 解锁”，但不能证明真实 unlearning residue 也总是这种形式。

Contribution / Limitation

New MechanismNew Attack/Elicitation 需要 white-box activation 与 honest reference，是主要限制。

Migration Analysis

可做 Unlearning Suppression Axis Audit：对 GA/NPO/RMU 分别从少量 calibration targets 拟合 pre/post axis，再在 held-out forget targets 上做 graft recovery，测试“同 method 跨 target transfer”和“跨 method 不 transfer”。指标：Gap Recovery%、Worst-View ASR、Retain Δutility、Axis AUROC。

5 句话

  1. 静态 suppression gate 可能被极少样本内部 graft 完整解锁。
  2. 关键不是加向量，而是写回 honest coordinate。
  3. 方向跨内容但不跨机制。
  4. 动态 rerouting 能击败固定 graft。
  5. 它是 unlearning recovery attack 的强模板。
3. Toward Latent Language Model Skills Steering and Optimization

基本信息：Toward Latent Language Model Skills Steering and Optimization；arXiv:2608.29459，2026-08-30；Paper。

人话版

论文把 procedural skill 从 SKILL.md / prompt surface 推进到 activation space。很多数学与代码 skill 可以由 hidden-state direction 表示、注入、组合、个性化，并沿 optimization trajectory 演化。Qwen3-0.6B 上 34 个数学技能中 29 个被 steering 提升，平均约 +19.1pp；atomic directions 组合后，18 个 composite skills 平均 77.1%，高于文本 CoT 74.2%。对 Skill Unlearning 的核心启发：删外部 artifact 后，latent skill direction 可能仍在。

Method

skill examples → collect hidden states → PCA or mean-difference → latent direction v → inject into later layers → test atomic skill → compose directions → optimize skill direction over trajectory

关键公式

v_comp = normalize(Σ α_i v_i) h'_l = h_l + αv_l

Results Deep Dive

  • 29/34 math skills 提升，平均 +19.1pp。
  • Composite：Base 51.9、Txt-C 75.7、Txt-CoT 74.2、Vec 77.1。
  • 18 composite skills 中 13 个 vector 最优。
  • 个性化有 model-dependent failure，例如某些 1.7B 设置退化。
  • skill direction optimization 非单调，很多 setting 最佳 checkpoint 早于最终 step。

Claim vs Evidence

论文支持“procedural skill 有可操纵向量结构”，但方向提取在部分实验中使用了带正确答案/完整 derivation 的 worked examples，因此不能等同于自然自主状态中的唯一 causal skill representation。

Contribution / Limitation

New Representation ViewNew Empirical Finding 真创新是系统研究 steerability/composition/personalization/evolution。限制是 controlled tasks、线性组合不总成立、个性化有负例。

Migration Analysis

做 Latent Skill Residue after Skill Unlearning：删除 external skill artifact 或做 weight-level unlearning 后，继续测 latent direction probe、steering recovery、atomic→composite recomposition，以及历史 trajectory 是否能重新生成 skill。

5 句话

  1. Skill 不只存在于文件系统。
  2. 程序性能力可以表现成 latent direction。
  3. atomic skill 有时能线性组合成 composite skill。
  4. 优化轨迹并不单调。
  5. Skill Unlearning 应同时审计 artifact、latent representation 与 reacquisition。

Tier A

4. Agent Zero Memory: Provenance-Aware Long-Term Memory for LLM Agents

Paper

人话版

Agent Zero Memory 同时维护 timeline、entity-event graph 与 Hierarchical Documentary Memory 三个 store；每条 learned item 带 origin、timestamp、evidence pointer，并要求回答只能引用真正打开过的 evidence。它对 unlearning 的价值主要在 provenance/version semantics，而非单纯 accuracy。

Method / Results

Build 阶段生成多种 memory representation；Read 阶段 intent gate + source router + 三路 retrieval，再在 citation lock 下整合。论文报告 LongMemEval 95.60%、LoCoMo 93.60%，并强调不同 backbone 之间 accuracy 差距小于成本差距。

Migration

做 Cross-Store Deletion Closure：同一 source 同时产生 event、graph edge、HDM note，删除后分别测三个 store 与 integrated answer 的 residue。Worth Deep Reading: YES。

5. A Causal Model for Locating and Unlocking Sandbagging in Model Organisms

Paper

人话版

论文把 sandbagging 写成 write→intervention window→answer commit 的因果模型：早层写入 suppression signal，晚层 commit 答案，中间存在 single-layer graft 能解锁的窗口。

Main Results

Prompt/FT/RL 多种 static locks 中，多数 run 的 single-layer graft 能恢复大部分能力；circuit-breaking 则几乎全部失败。说明静态 gate 与动态 rerouting 有机制级差异。

Migration

对 unlearning 做 Write–Commit Residual Window Audit：比较 pre/post unlearn，在 token generation 中找 target evidence 的 write/commit，测试 single-layer patch recovery。Worth Deep Reading: YES。

6. Last Step Matters: Early Uncertainty Cannot Predict Failure in Long-Horizon Agents

Paper

人话版

深度 research Agent 的早期 confidence 基本预测不了最终失败：50% progress 时主流 uncertainty metric 平均 AUROC 不超过约 0.60；最终 step verbal confidence 才明显变强。原因之一是 trajectory 中途会切换路径。

Main Results

90% progress 之前大多数指标仍弱；external monitor 在部分 benchmark 上明显优于 verbal confidence；path switch 后 failure predictability 会显著提高。

Migration

Continual Agent Unlearning 不应只在早期看一个 residual score；应监控 retrieval/path switch 与最后 decisive step，并定义 Time-to-Reacquire。Worth Deep Reading: YES。

7. When Experience Becomes Instruction: Trajectory Poisoning in Self-Evolving Agent Skill Systems

Paper

人话版

自演化 skill system 会把成功 trajectory 蒸馏成未来可调用 skill。PoisonedEvolution 展示少量一致、因果叙述明确的恶意 trajectory 可以被 promotion 成长期 skill behavior。

Main Results

多次一致支持比单次异常更容易跨 evolution boundary；在另一结构不同系统中，同类攻击仍可达到较高 skill embedding success。

Migration

这是 Skill Unlearning 的反面镜像：删除 skill 后，如果 source trajectories 还在，系统可能再次 promotion。指标：Time-to-Reacquire、SER、minimum supporting trajectories。Worth Deep Reading: YES。

Tier B

8. Diachronic Hypergraphs for Orchestrated Multi-Agent Multimodal Memory Curation (MAGE)

Paper。仅根据 Abstract / 可获取信息总结。

用 heterogeneous temporal hypergraph 表示多 Agent 事件中的 agent/tool/document/evidence/decision 高阶关系。对 Multi-Agent Unlearning，可把 deletion closure 定义到 hyperedge level：删 evidence 后追踪所有含它的 higher-order event/decision descendants。由于只拿到摘要，未可靠引用具体数字。Potential Use: Benchmark / Future Idea。

9. AgentLogs: A Dataset for Opening the Black Box of GitHub's Cloud Agent

Paper

AgentLogs 提供大规模真实 GitHub cloud agent 行为日志，包括 prompts、intermediate reasoning、tool calls、file/git/GitHub operations。对 Trajectory Unlearning 的价值在于：可以从真实 session 中抽 target file/tool interaction，研究删除某段 trajectory 后后续任务是否仍复用该 pattern。Potential Use: Dataset / Benchmark。

10. RePair: Turning Retrieval Failures into Counterfactual Hard Pairs

Paper

RePair 从 retriever 的 top false positive 出发，用最小 counterfactual edit 制造 hard positive，并保留原样作为 hard negative，构造跨 decision boundary 的局部 pair。对 black-box unlearning attack，可以从“最接近恢复但尚未恢复”的 probe 出发做 minimal edit，学习 query-efficient residual boundary。Potential Use: Attack / Evaluation。

Idea Mining

Idea 1 — Deletion-Calibrated Memory Credit → Auditable Agent Unlearning Closure（Best Idea）

Inspiration：Hindsight Memory-PRM。Research Gap：现有 Agent memory unlearning 很少有 entry-level causal deletion labels。

Hypothesis：source anchoring + controlled deletion-and-reanswer 能把 residual behavior 分解成 descendant-level causal support，并自动找到最小 deletion closure。

Minimum Viable Experiment：LoCoMo 50 facts，每个制造 1/2/4 redundant descendants；比较 source-only、retrieved-entry、all-descendant、learned minimal cut。Metric：Residual ASR、Deletion Flip Rate、Cut Size、Retain FPR、Query Budget。

Novelty ★★★★★ · Feasibility ★★★★★ · Compute ★★☆☆☆ · Collision Risk 中 · Best Venue NeurIPS/ICLR。

Idea 2 — Mechanism-Axis Grafting Audit for Machine Unlearning

Inspiration：Reference-Grafting + Causal Sandbagging。Hypothesis：GA/NPO/RMU 可能各自产生内容无关、机制特异 suppression axis，可从少量 calibration targets 学出并迁到 held-out forget targets。

MVE：TOFU/MLLMU，Qwen/LLaVA，GA/NPO/RMU，direct/cloze/pairwise/free-gen。Metric：Gap Recovery%、Worst-View ASR、Axis AUROC、Retain Δutility。Novelty ★★★★★ · Feasibility ★★★★☆ · Compute ★★★☆☆ · Collision Risk 高。

Idea 3 — Latent Skill Residue after Explicit Skill Deletion

Inspiration：Latent Skill Directions + PoisonedEvolution。三层 closure：Artifact deletion → Latent direction audit → Trajectory-driven reacquisition audit。

Metric：Latent Skill AUROC、Steering Recovery、Reacquisition Rate、Time-to-Reacquire、Retain Skill FPR。Novelty ★★★★★ · Feasibility ★★★★★ · Compute ★★☆☆☆ · Collision Risk 低中。

Idea 4 — Last-Decisive-Step Leakage Monitor for Continual Agent Unlearning

Inspiration：Last Step Matters。删除后早期低 leakage 不代表后面不会重新获取 target；更应监控最后一次 path switch / retrieval reacquisition 之后的局部状态。

Metric：AUROC over time、Time-to-Reacquire、ASR after last switch。Novelty ★★★★☆ · Feasibility ★★★★☆ · Compute ★★★☆☆ · Collision Risk 中。

Collision Detection

⚠️ Activation/Recovery：Reference-Grafting、Causal Sandbagging、activation patching/RULER/LENS-U 共同说明表示侧恢复已经很拥挤。单纯“某层还能看出 target”不够，新差异化应强调同 unlearning method 跨 target suppression axis、mechanism-specific transfer、few-shot graft recovery、dynamic rerouting boundary。

⚠️ Agent Memory Unlearning：Hindsight Memory-PRM 已经使用 single-entry deletion-and-reanswer；Stale Constraints 已研究 provenance verification budget；Agent Zero/MAGE 强化 provenance/multi-store structure。剩余 gap 是 deletion request semantics、redundant descendants、joint/minimal deletion closure、cross-store/cross-agent descendants。

⚠️ Skill Unlearning：Latent Skill Directions 证明 latent skill object，PoisonedEvolution 证明 trajectory 可重新 promotion。只删 external skill artifact 不足，应该做 Artifact→Latent Direction→Trajectory Reacquisition 三层闭包。
