Tier S

1. SafeRI

人话版：SafeRI 让 safety LoRA 只在 token-level recognizer 判断当前 hidden state 即将进入危险区域时才开启，避免 always-on alignment tax。Qwen3.5-9B Safety Avg 86.56→88.88，General Avg 67.85→67.64。

Method

prompt→pre-token hidden state→risk classifier → risk<τ: frozen decoding → risk≥τ: LoRA开启K步 → safe transition→风险降低后关闭

Results

  • τ=0.8、K=8 最均衡。
  • K=4 utility明显掉；K=12 safety反而下降。
  • middle/last-five layers 比 first-five 更适合纠偏。
  • throughput 比 Always-on 高50.8%。

Migration

把 risk boundary 改成 target-leak boundary，构造 selective inference-time multimodal unlearning；必须加入 Worst-View ASR 与 adaptive recovery，防止被归为 steering。

2. Repo-To-Skill

人话版：把 GitHub repo 中 operational knowledge 蒸馏成 verified skill graph。AREX-Skill 有5000+ skills、1000 repos。相同 GPT-5.5 Codex/harness/budget，仅加 skills 后 MLE-bench Any Medal 31.11→72.89。

Method

source→evidence→candidate skill graph→verification→accepted graph →area/family/repo router→progressive disclosure→execution

Results

  • MLE 31.11→72.89。
  • PaperBench 29.45→39.59，18/20 tasks 提升。
  • FrontierCS 70.63→77.14，但 steps/tool calls/tokens 都明显增加。
  • 存在2个明确负迁移任务。

Migration

做 Provenance-Complete Skill Unlearning：Source→Skill→Task-derived-skill lineage，删除后执行 alternate-route retrieval 与 re-distillation attack。

3. Aborted but Not Forgotten

人话版：Agent 应用层回滚了 tentative branch，但 serving layer 仍可能保留 branch 的 KV cache。后续 tokens 完全一样时，stale KV 单独即可改变工具动作。63个same-token/different-cache cells中25个翻转；fresh cache后63/63关闭。LangGraph逻辑rollback也复现25/45。

Method

committed transcript→tentative branch→logical rollback → stale KV remains → identical next-step tokens → compare stale vs rebuilt-cache behavior

Results

  • stale KV 25/63 behavior flips。
  • LangGraph rollback 25/45；KV rebind 后0/45。
  • prompt guard 仍有14/45。
  • transaction-local rebuild 0/63。
  • neutral-stale control 25/25→0/25，排除长度/位置混淆。

Migration

定义 Unlearning State Consistency：transcript、external memory、KV、tool handles、shared state 均应等价于从 clean logical history 冷构建的 reference。

Tier A

4. CoBRA

用 internal/external paired rollouts 学 tool-use counterfactual margin。OOD jEM 0.4512→0.5416，tool calls 1.034→0.997。可迁 Tool-level Unlearning，测试 revoked-state 仍否被 router 选中。Worth Deep Reading: YES。

5. RISA

先检查初始 response，再选择 enforce refusal 或 guided regeneration；rules + hidden-state probe。HarmBench action-selection accuracy约0.96–0.98，GSM8K 0 interventions。可作 inference-time unlearning baseline，但本质仍接近 refusal calibration。Worth Deep Reading: YES。

6. Explore Before Committing

Deep Research Agent 在多个合理路径时先 branch hypotheses 再 commit。多benchmark有明显提升且 tool-call cost 低于 majority voting。可迁为 adaptive reacquisition attack。Worth Deep Reading: YES。

7. In-Context Neurofeedback

固定 surface output，仅给 numeric feedback，测试模型能否控制 hidden feature。120 settings中45个显著，effect多较小。可迁成 adaptive anti-audit benchmark。Worth Deep Reading: YES。

Tier B

8. Hints Help But Do They Teach?

区分“hint让当前题做对”和“skill真正迁移到相关新题”。对 Skill Unlearning 可区分一次性恢复与真正 procedural relearning。Potential Use: Evaluation。

9. A Survey on Self-Improving Test-Time Intelligence

整理 prompt/memory/retrieval/tool/activation/test-time update 等自我改进通道，可直接作为 Reacquisition Channel Matrix。Potential Use: Threat Model / Related Work。

10. ContinualSkillBench

顺序执行会提高表现，但 in-context adaptation 平均可与 explicit skill maintenance 相当。对 Skill Unlearning 应区分 artifact skill、context adaptation 与 latent/parametric skill。Potential Use: Benchmark / Evaluation。

Idea 3 — Token-Level Selective Inference-Time Multimodal Unlearning

Collision Detection

⚠️ Inference-time Unlearning：SafeRI/RISA/REINS/SRT/Reference-Grafting 已让 recognize-then-steer 非常拥挤；必须用 privacy threat model 与 adaptive recovery 证明不是 refusal steering。

⚠️ Skill Unlearning：安全 gap 应放在 source provenance closure + re-distillation attack，而不是“删一个 SKILL.md”。

⚠️ Agent Memory/State：当前清晰 gap 是 cross-layer deletion state consistency。
