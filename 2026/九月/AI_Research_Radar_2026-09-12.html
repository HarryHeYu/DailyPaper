Executive Summary

今天没有足够强的全新直接Unlearning论文，最值得迁移的机制来自 Agent Memory、RL Credit 与 Skill Evolution。

Memory：Grounding Agent Memory把长期memory的核心问题定位为evidence boundary，并用read-only environment probing在write time验证scope、drift与procedure。它自然迁成 Delete→Probe→Expand Closure。

Credit：Belief-Shift Branching直接读“模型何时改变最终答案belief”，比entropy更接近真实value pivot；这与hard-to-unlearn sample、token-level localization、adaptive recovery高度契合，是今天最强研究迁移。

Skill：COBRA-Skills用contextual bandit+evolution在动态skill空间分配有限execution budget，意味着skill删除后可以被高效、自动地重新搜索出来；这是Continual Skill Unlearning的强攻击模型。

Tier S

1. Grounding Agent Memory: Environment-Probing Curation for Enterprise Agents

基本信息：Susheel Suresh, Hazel Mak, Sahil Bhatnagar, Chhaya Methani, Alejandro Gutierrez Munoz；Microsoft Corporation；arXiv:2609.11060v1，10 Sep 2026；Paper HTML。

人话版

现有Agent Memory往往只根据刚结束的trajectory写总结，因此会把一次性答案、错误推断、过期schema或低效procedure固化成长期memory。本文让独立curator在写memory前获得最低权限read-only world tools：提出candidate memory后主动查数据库join key、验证另一slice、确认procedure前提、检测schema drift，再commit。任务Agent、retriever、memory schema和write authority都不改。CLBench上No Memory pass39%，普通Mem70%，Env-Probing73%；更关键是reward8.60→22.60、queries/task8.8→4.7、task-agent cost $3.38→$1.68。对Agent Unlearning的最大启发是：删除验证也不应只看内部接口，而应主动寻找外部世界、旧schema、derived records中的恢复路径。

Background & Research Gap

Mem0、ACE、ReasoningBank、ReMe能从trajectory与反馈写更精炼的memory，但证据边界仍是completed trajectory。如果Agent从未访问关键状态，curator无法知道“这个规则只是偶然成立”还是可泛化。典型例子是旧schema字段被写进长期memory，环境迁移后memory变stale，未来task才发现。

Core Insight

瓶颈不是reflection能力，而是evidence boundary。read-only probing扩展证据，使curator在write time验证scope、precondition、drift与alternate procedure。作者刻意让probe脱离task critical path，因而增益能归因于memory evidence质量。

Method Deep Dive

Task S_i + environment E_i → fresh task-agent Aθ → trajectory τ_i + grade g_i → non-writing distiller d_i=Dψ(τ_i) → curator reads τ_i,d_i,g_i,related memory → propose memory → read-only environment probes → verify scope / preconditions / drift / shorter procedure → create / update / narrow / delete / skip → commit M_i → next task
τ_i = Aθ(S_i ; T_Ei, R(·,M_{i-1})) d_i = Dψ(τ_i) r_i = p_i(1-q_i/B)

p_i为strict pass，q_i为task-agent tool calls，B在CLBench=15、APEX=100。reward同时奖励正确与少重复探索。

Toy Example

旧数据库中orders.customer_id→customers.id；迁移后字段改buyer_id。普通curator只看旧trajectory继续保留错误join；probe curator会查询新schema并刷新记录。Unlearning时也可在删target后主动探测alias、旧表、缓存与工具输出是否仍含等价信息。

Baseline Deep Comparison

No Memory每task从零开始；Full ICL直接追加旧trajectories、query少但input增长到5.42M；普通Mem把历史压成compact lemmas；Env-Probing只比普通Mem多curator-side read-only loop，是最干净的机制对比。

Experiment Setup Deep Dive

  • 普通Mem70±16 → Probe73±5；input tokens2.13M→1.69M、cost$1.99→$1.68。
  • queries/question8.8→4.7；比普通Mem5.6进一步下降。
  • Sonnet no-drift lift：Mem+0.351，Probe+0.421；Opus+0.252→+0.263。
  • APEX六world×三memory配置的18个memory-vs-baseline reward comparisons全部为正，task-agent calls下降16–75%。
  • Weakest：Probe相对Mem pass-rate只有+3pp且CI重叠，优势更多在稳定性、cost与drift handling。

2. Fork Where the Model Changes Its Mind: Belief-Shift Branching

基本信息：Bin Lei et al.；Salesforce AI Research / University of Minnesota；arXiv:2609.11061v1，10 Sep 2026；Paper HTML。

人话版

Tree-RL真正关键的是把有限fork budget放在哪里。固定位置、newline或next-token entropy常只反映文字不确定性，不告诉你哪一步真正改变最终答案。Belief-Shift Branching沿CoT读取模型当前“最终答案belief”，相邻boundary变化最大处就是value pivot，在那里fork更可能产生结果不同的siblings，从而给step-level credit。方法有black-box Probe-JS、white-box Lens-Shift和offline activation-direction BSV。Pre-RL的8个model×benchmark panels全部由belief-shift signal排名第一；OLMo数学aggregate20.7→23.3，AIME2026 12.3→15.2，code31.0→34.9、LCB-medium +6.5。对Unlearning可直接用于找“哪一步target belief重新进入reasoning”。

Background & Research Gap

TreeRL依靠中途fork后siblings终局reward差给step credit；若fork落在value已settled区域，siblings一致，budget浪费。Entropy测next-token uncertainty，不等于outcome/value uncertainty。

Core Insight

credit价值最高的是V*(t)=P(correct|prefix)发生跳变的pivot。真实V*不可观测，但final-answer belief shift可作为proxy；这比“当前token难不难”更贴近终局决策。

Method Deep Dive

reasoning chain y → candidate newline boundaries → read answer belief b_t → s_{t-}=D(b_{t-},b_t) → rank boundaries → fork BEFORE belief-moving segment → sample siblings → verifier outcome → sibling reward contrast → RL credit

Probe-JS插入约10-token“现在最终答案是什么？”probe并比较JS divergence；Lens-Shift读各层teacher-forced answer log-prob profile变化；BSV通过high-confidence vs doubt activation拟合belief-shift方向。

关键公式

V*(t)=Pr(correct | x,y≤t) s_{t-}=D(b_{t-},b_t) |V_e(t)-V_e(t-)| ≤ TV(p_{t-},p_t) ≤ sqrt(2 JS(p_{t-}||p_t)) = sqrt(2s_{t-})

若Probe-JS接近0，probe value不可能出现大移动；真实V*与probe value的关系则通过Monte-Carlo reconstruction实测，而不是假设。

Toy Example

模型前10步都相信答案42；第11步发现遗漏约束后转为36。Entropy可能在第5步复杂符号处很高，但那里不改变终局。Probe-JS会把fork放在第10步之前。Unlearning里同理：定位target identity/answer belief突然回升的位置。

Baseline Deep Comparison

Midpoint/Newline只按结构；Entropy测词级不确定；LLM Judge逐step generation成本高；belief shift直接读answer belief。OLMo数学最强baseline20.7，Probe-JS23.3。

Experiment Setup Deep Dive

Results Deep Dive

  • Figure1真实chain：Probe-JS value movement1.56 vs entropy0.44，约3.6×；entropy六个fork落settled region。
  • Pre-RL八个model×benchmark panel，belief-shift signal全部第一；BSV七/八超过全部baseline。
  • OLMo math23.3 vs20.7；AIME2026 15.2 vs12.3。
  • Nemotron math45.1 vs40.9。

3. COBRA-Skills: Contextual Bandit-Guided Evolution for Agent Skill Optimization

基本信息：Pingchen Lu et al.；arXiv:2609.11682v1；Paper HTML。

人话版

Agent skill优化最贵的是每个候选都要真实执行才能知道好坏。COBRA把skill optimization建模为动态candidate space上的contextual bandit：用skill embedding预测reward，同时给未充分探索的semantic region加LinearUCB bonus，只把昂贵execution budget给promising/uncertain skills；再用regeneration、rollout mutation、crossover持续进化skill population。六benchmark×三models中平均性能均最高，相对no-skill +13.1/+26.9/+22.5pp；相对SkillOpt总cost降低55–58%，Cost/ΔScore降低60–69%。对Skill Unlearning而言，这提供了很强的reacquisition attacker：删除target skill后，bandit可高效搜索语义邻域并重新生成等价skill。

Background & Gap

SkillOpt效果依赖大量target-agent executions；静态best-of-N浪费budget在重复/差候选。更现实的是candidate space随mutation/crossover变化，必须同时决定“评谁”和“生成谁”。

Core Insight

skill optimization是budgeted sequential optimization under uncertainty。embedding让一次评估可以更新附近skills的utility belief；UCB保护未探索区域；evolution动态扩展空间。

Method Deep Dive

initial trajectories → K candidate skills → embeddings z_s → neural reward predictor fθ(z_s) → LinearUCB bonus → U_t=fθ+b_t → evaluate highest-priority skill → collect reward + rollouts → update predictor → prune low-priority → regeneration / mutation / crossover → repeat 30 rounds
b_t(z_s)=ν sqrt(z_sᵀA^{-1}z_s) A=λI+Σz_i z_iᵀ U_t(s)=fθ(z_s)+b_t(z_s)

fθ负责exploitation，UCB负责探索；ν控制探索强度。

Toy Example

10个spreadsheet skills中多个是同一procedure变体；评估一个后bandit可推断附近候选，无需全部执行。但删除某PII导出skill后，mutation又生成相近版本，UCB可能把它当高价值未探索区域迅速重选。

Baseline Deep Comparison

No Skill为下限；LLM Skill只初始化一次；Trace2Skill从trajectory蒸馏；SkillOpt是strongest优化baseline。Best-of-30、w/o Bandit、w/o Evolution都比full低2.2–2.5pt，排除“只是多生成候选”。

Experiment Setup

SearchQA、SpreadsheetBench、DocVQA、LiveMathematicianBench、SocialMaze、ALFWorld；Qwen3.6-35B-A3B、GPT-5.4-Nano、Gemma-4-26B-A4B-it。Held-out test100；COBRA optimization只用50 examples。T=30，K=10，prune3，ν=0.1。

Results Deep Dive

  • No Skill→COBRA平均提升Qwen+13.1、GPT+26.9、Gemma+22.5pp。
  • Qwen full73.5；Best-of-30 71.0；w/o Evolution71.1；w/o Bandit71.3。
  • 总cost比SkillOpt低55–58%。
  • Cost/ΔScore低60–69%。
  • teacher tokens少67–80%。
  • 外部Codex/Claude Code harness下仍有效。
  • 单项不总赢：Qwen SearchQA Best-of-30 86.0高于COBRA84.3。

Table/Figure Reading

Table1六benchmark×三model；Table2成本；Figure3/4每轮优化；Table4 full73.5 vs71.0–71.3，是机制主证据。

Ablation

w/o Bandit -2.2；w/o Evolution -2.4；Best-of-30 -2.5。adaptive allocation与candidate evolution都必要。

Claim vs Evidence

六bench、三models、三seed、cost accounting、外部harness和ablation充分支持高效skill optimization；未覆盖删除、revocation、长期数百轮和恶意skill。

Tier A

4. Demystifying the Privacy-Utility Trade-off in LLM Interactions

人话版：把隐私sanitization的trade-off拆成三件事：某敏感属性的utility取决于intent；Remove/Replace/Keep策略不同；多个属性还存在synergy/redundancy。9,757 prompts、核心控制子集384条每条固定5个敏感statements。Task Execution删Social信息reward -14.25，但删Health +0.19；Health在Personalized Interaction -5.78。Veilmind-4B使utility-mode utility75.5→86.8%，privacy-mode leakage52.6→40.5%。

Method

Extraction→Strategic Sanitization→Remote Response→Local Restoration；interaction score I(A,B)=ΔR(A,B)-ΔR(A)-ΔR(B)，负为synergy，正为redundancy。

Results

Task Execution×Health Remove-vs-Replace differential+14.04；Health+Interest synergy -6.05；Behavioral+Social redundancy+4.14；extreme pair interaction+47.8。Veilmind extraction52.4→72.7，utility-mode Keep24.5→62.8，restoration+3.5→+7.0。

Contribution / Limitation / Migration

Empirical DecompositionInference-time Privacy。限制：privacy score不是真正server leakage，local restoration仍持有原数据。迁到Fine-grained Unlearning：构建同identity A/B/C属性interaction matrix，决定单删/联合删/neutral replacement。Worth Deep Reading: YES。

5. When Validation Stops Learning

人话版：Continual Agent的validation gate如果永远拒绝更新，也能做到零forgetting但完全不学习。本文要求同时测error control与missed learning opportunities。synthetic pushing中B=2000时paired gate接受81/256 updates，而Hoeffding/EB为0；closed-loop Fresh Paired final59.6、forget0，但miss60.4%，Replay final100。

Method / Results

比较Hoeffding、Empirical Bernstein、paired-binomial confidence gate；32 seeds。Direct FT final28.1且forget79.9pp；Replay100/0；paired59.6/0。B=20k paired229/256、EB195/256。learned-dynamics stress test中adaptive selection可制造约41pp proxy-vs-true gap。

Migration

Continual Unlearning gate必须同时报告Retain Violation与Missed Forget Opportunity。MVE：CLEAR sequential deletion，TOST/KL/paired gate对比。Worth Deep Reading: YES。

6. Learning What to Retain: Gated-Memory Routing

人话版：Multi-Agent完整execution history会带来history overload；该文用Memory Write Gate、Retrieval Gate和Adaptive Halting把history压成selective execution state。五benchmark平均77.73，比最强baseline+2.44；HumanEval cost比Puppeteer低31.9%、比MASRouter低43.86%。

Method / Results

Write控制什么进shared state，Retrieve控制当前agent看到什么，Halting根据filtered state决定何时停。MATH/GSM-Hard/MBPP/HumanEval/MMLU-Pro上4/5第一；MBPP79.60略低某fixed MacNet。平均对MASRouter+3.46，对Puppeteer+2.44。

Migration

Deletion-aware Write Gate：target-derived reasoning不写入shared state，并用Worst-Agent Recovery测其他Agent是否重建。MVE：multi-agent reasoning注入forget fact，比较raw-history delete、gated delete、lineage-aware gate。Worth Deep Reading: YES。

7. SimSkill

人话版：Agent在SUMO中自主发现能力缺口、生成任务、执行+critic验证，并把经验积累为episodic/procedural/semantic memory。约80小时形成150 procedural skills和153 semantic pages；两个40-task benchmark、三backbones中verified success最多+25pp。

Ablation / Results

Migration

10. MrM: Black-Box Membership Inference Attacks against Multimodal RAG Systems
