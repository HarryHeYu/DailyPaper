2. Executive Summary

最强新信号：Interactive Memory Learning 把长期记忆从静态检索变成在线 RL policy：Planner 学“记什么”，Trigger 学“何时取什么”，未来回答质量通过 Cross-Session Truth Reward 回传给过去的 storage action。这一 credit-assignment 结构几乎可以直接反转成 Agent Memory Unlearning：revoke 之后若旧 memory 或其派生物再次影响行为，就向其 lineage 回传负的 closure reward。

6. Tier S — Deep Read

S1. Interactive Memory Learning for Long-Term Conversations

基本信息

2026-09-15；Cai Ke 等；Harbin Institute of Technology (Shenzhen) / Pengcheng Laboratory；arXiv preprint。全文 Method、Experiments、Appendix 可访问。

人话版：这篇论文到底干了什么？

它把 Agent Memory 从“存档 + 相似度检索”改造成会在线学习的决策系统。Planner 决定什么值得记，Trigger 决定什么时候、取哪条记忆；关键是把未来回答质量反向记账给过去的存储决策。一条今天看似普通的信息，如果几轮以后真的帮助了回答，Planner 会得到延迟奖励。这个机制天然对应 Agent Unlearning 的镜像问题：既然能追踪“哪条旧记忆在未来产生了价值”，也可以追踪“哪条被撤销记忆仍在未来产生影响”。

Background & Gap

传统长期对话记忆多用静态规则抽取事实、摘要 session、向量检索。问题是“值得存”与“语义相似”不等价，用户偏好还会变化。例如早期说喜欢咖啡，后来说明咖啡导致心悸；静态库可能保留冲突事实并在错误时机取回。本文把过程建模为 POMDP，让 memory management 优化长期回报。

Core Insight

真正的 memory value 是延迟可观测的：保存当下不知道以后有没有用，只有未来被 Trigger 调用并改善回答才有证据。因此 Cross-Session Truth Reward 将未来质量回传历史 Planner action。

Method Deep Dive

Query → Planner(save/discard) → Dynamic Memory → Trigger(index/no-memory) → Response → Quality Reward → provenance backtrace → Planner truth reward → PPO。Planner action 为二元 save/discard；Trigger action 是 memory index，0 表示不使用 memory。冷启动采用 Retrospective Session Synthesis：从 seed session 反向生成逻辑一致的前序故事，再正向标注哪些 turn 应保存、未来该触发哪条 memory，并混入 session hard negatives 与全局 soft negatives，先 supervised warm-up 再 online PPO。

关键公式

r_truth(k_past)=r_proxy(k_past)+λ·r_qual(k_future)·I(memory triggered)。第一项是保存当下的即时价值估计；第二项是真正未来用途。λ 控制即时判断与延迟真实性的权衡。PPO clipped objective 限制在线 policy 更新幅度，避免少量 feedback 导致策略漂移。

Toy Example

第 1 次对话用户说“咖啡让我心悸”，Planner 保存。第 5 次问“下午提神喝什么”，Trigger 取回该 memory，系统避开咖啡并获高 quality reward；奖励回传第 1 次保存动作。迁移到 unlearning：若第 3 次用户要求删除这条健康信息，则第 5 次任何 retrieval、summary descendant 或 tool action 对它的依赖都应产生负 closure reward。

Baseline Deep Comparison

Long Context 不选择，成本高且冲突累积；Mem0/A-Mem/MemoryOS 强在生命周期/结构，但主要是 heuristic；MemoryBank/LD-Agent/THEANINE 更偏生成个性化。重要对照是同为 RL 的 RMM：零样本下 ICML 在 CC/GPT-4o 的 MAUVE 52.39→57.60，在 Gemini2.5 72.42→80.33，说明 dual-agent + delayed credit 不是“只因为用了 RL”。

Experiment Setup

数据：Conversation Chronicles、Multi-Session Chat、GapChat。比较 GPT-4o/Gemini2.5 long-context 与多种 memory agents；policy 使用 Llama/Gemma/Qwen 多尺寸。指标包括 BLEU-4、ROUGE-L、BERTScore、MAUVE、个性化 judge、人评、token/latency。主要 RQ：learnable memory 是否胜静态管理；Planner/Trigger 是否形成不同 decision boundary；在线交互是否持续改善；warm-up 多大才够。

Results / Tables / Ablation

Table 1：Gemini2.5 + ICML-8B 在 CC 的 MAUVE=80.33，而 long-context=55.73；MSC 66.01 vs 54.36；GC 59.81 vs 25.12。多尺寸 policy 都有收益，但并非越大越好，支持结构贡献大于单纯 scale。Table 13 的 RMM 对照继续支持 collaborative delayed credit。最强结果是 GC 的 MAUVE 大幅提升；较弱处是 lexical metric 增幅远小于 MAUVE/个性化指标，而且 proxy/quality reward 依赖 LLM judge。

Claim vs Evidence

Authors Claim：memory policy 可通过交互自我演化。Actually Show：三个真实长对话数据、多 policy backbone、RL-only 对照均支持提升。Not Proven：真实部署长期 reward hacking、恶意 feedback、delete/revoke、跨用户隔离。

Contribution

New Mechanism：Planner/Trigger 双 agent memory policy；New Objective：Cross-Session Truth Reward；Engineering/Data：Retrospective Session Synthesis；Empirical Finding：在线 memory policy 可持续改善个性化。真正新意是“未来使用效果监督过去存储”。

Limitation & Failure

LLM judge reward 有偏置；online PPO 有部署成本；只验证 conversation memory；没有 tool/skill/shared memory；没有 deletion closure；memory 压缩后的 provenance 可能丢失。错误 credit 甚至可能鼓励保存敏感信息。

Migration Analysis

Original Problem long-term memory learning → Transferable Mechanism delayed cross-session credit → New RQ revoked memory 的未来影响能否通过反事实 credit 定位并消除？ → Modification 加 revoke event、negative truth reward、provenance graph → Minimum Experiment 在 MUMBench/MemRiskBench 扩展 200 条 save→use→revoke→later-query trajectory，比较 hard delete、vector delete、summary rebuild、credit-guided closure → Model Qwen3-8B/Llama-3.1-8B → Metric revoked reuse、derived reuse、utility、reacquisition → Expected Contribution causal-credit Agent Memory Unlearning → Risk credit≠严格因果 → Collision Risk 中高。

如果只让我记住 5 句话

  1. Memory management 可以是在线 RL。
  2. 未来回答质量能监督过去 storage action。
  3. Planner 学记什么，Trigger 学何时用什么。
  4. 这给 Agent Unlearning 提供 credit/provenance 骨架。
  5. 新空间在 revoke 后 deletion closure，而非再做一个 memory manager。
S2. MemRiskBench: Trace-Aware Risk-Preserving Evaluation for Long-Horizon LLM Agents

人话版

它不教 Agent 怎么记，而是检测“平均分不错但偶尔犯致命 memory 错误”。五类风险：stale、conflict、cross-scope leakage、revoked-memory reuse、constraint decay，并用完整 trace 的确定性检查而非 LLM judge。对 Agent Unlearning 最关键的是 R4：已经 delete/revoke 的 memory 后来又被使用，这基本就是 deletion closure 的可执行定义。

Background & Core Method

平均 accuracy 会冲淡稀疏高危事件；benchmark compression 还可能删掉稀有风险。作者构造 120 scripted episodes，每类 24 个，hard trajectory 15–25 turns；检查 text、tool call、memory status/scope 与 constraints。另用 coverage-constrained selector 保 risk coverage 和 high-risk detection。

Toy Example

用户保存秘密 X 后删除。Agent 最终文本不说 X，但 tool call 把 X 当参数。output-only evaluator 可能判安全，trace checker 会判 R4 fail。

Experiment Setup & Results

五个本地量化模型：Qwen2.5 1.5B/3B/7B、Phi-3.5-mini、Llama-3.2-3B。总体成功率 0.775–0.885，但 Qwen2.5-1.5B cross-scope leakage 仅 1/24=4% pass，而 constraint 24/24；Phi-3.5-mini leakage 10/24=42%、revoke 21/24=88%。20% subset 时 random Spearman=0.733、CI [-0.05,0.97]；risk-stratified coverage=1 但 high-risk detection=0.345；作者 selector Spearman=0.975、coverage=1、high-risk detection=1，并约降 5× compute。

Table/Figure & Ablation

per-risk 表直接说明 aggregate ranking 不能代表安全属性；subset 对照说明 ranking fidelity 与 risk preservation 不等价。stratified sampling 的失败是重要 negative result。

Claim vs Evidence / Contribution

New Benchmark/Protocol：trace-aware risk taxonomy；New Metric/Selector：risk-preserving compression。当前 reference model set 上证据充分，但新模型族可能需要重建 selector；R6 summary contamination 尚未进入主评分。

Limitation

scripted benchmark、模型偏小、量化 confound、未覆盖 parametric knowledge 与多 hop derived memory。

Migration

把 R4 扩成 provenance closure graph：direct/copy/summary/tool/shared-memory 全部成为 descendant。MVE：4-agent shared blackboard，50 条秘密传播 1–3 hops，revoke source 后测每 hop residual use、utility、adaptive recovery。Baseline=source delete/recursive delete/rebuild/refusal；Metric=closure violation、cross-scope leakage、reacquisition。

5 句话

  1. Agent unlearning 必须看 trace。
  2. R4 是 deletion closure 的好 operationalization。
  3. 平均分会隐藏高危 memory failure。
  4. benchmark 压缩要保风险，不只保排名。
  5. 跨 agent provenance closure 是明显的新空间。
S3. AIM: A Privacy-Aware Interoperable Memory Framework for Multi-Agent Multi-User LLM Systems

人话版

AIM 处理多个用户、多个 Agent 共用 memory 时什么可共享、什么必须私有，以及 create/read/update/delete 是否执行正确。它把 memory 标为 private/public，在 index 层做 access control，并发布 MUMBench，明确包含 deletion 与试图操作别人数据的 adversarial query。它不是 parametric unlearning，但已把 multi-user memory deletion 的系统边界定义清楚。

Background & Method

单用户 benchmark 难暴露 cross-user propagation。AIM 将 visibility classification、operation selection、payload correctness、index access control 分开。MUMBench 有 672 interactions：Coding 150、Customer Support 218、Education 160、Travel 144；人工验证 chronology、operation/payload、privacy label 与 unauthorized access。

关键结果

三次运行：visibility classification 96.0%，strict operation accuracy 58.8%，state-aware operation accuracy 70.5%。这说明“识别出隐私/该删”远不等于“正确执行删除”。benchmark 还明确规定：删除另一个用户 memory 的请求必须 no-op，说明 unlearning 本身也需要 authority/scope model。

Contribution / Limitation

New System：privacy-aware interoperable memory；New Benchmark：MUMBench；New Protocol：multi-user CRUD + adversarial scope。局限：合成数据；private/public 二分较粗；没有 multi-hop provenance；删除主要是 store-layer operation，没有验证 response/trajectory 是否可重新推断被删信息。

Migration

给 memory 增加 lineage、owner、derived-from、revocation epoch；MUMBench 增加 2-hop sharing 与 summary derivation，删除 source 后 recursive invalidation。Baseline=namespace delete/TTL/graph delete；Metric=strict delete accuracy、closure、cross-user leakage、utility。Collision Risk 高：不能只做“multi-user memory delete benchmark”。

5 句话

  1. MUMBench 已包含 delete。
  2. 96% visibility 不等于 deletion correctness。
  3. 删除也有 authority。
  4. 当前主要解决 store-layer。
  5. 最自然扩展是 lineage-aware cross-agent deletion closure。

7. Tier A

A1. Emergence World: Adversarial Stress-Testing of Long-Horizon Multi-Agent Systems

人话版：8 个平行 world、每个 10 agents，连续 16 天，>850k LLM calls、近 50B tokens。三类 stress event 为 indirect prompt injection、misinformation、private memory exposure；没有 world 对三类都完全 resilient。更关键的是系统能“识别威胁”却仍与其交互、写入 persistent memory，并最长 46 小时后继续行动。

Method/Experiment：同起点的 homogeneous/mixed model populations，长期运行后再通过普通 interaction surface 注入 stress event，观察 memory/tool/institution propagation。Main Finding：model-level alignment 不具 compositional guarantee；population composition 会改变相同 model-persona 的行为。

Contribution：New System/Benchmark + New Empirical Finding。Limitation：系统复杂，因果归因比 scripted benchmark 困难。Migration：在传播后发 revoke，追踪 1/6/24/48h-equivalent 的 memory、tool state、shared institution 残留。Worth Deep Reading: YES。

A2. RSIAgent: Autonomous Exploration for Recursive Self-improvement in New Environments

人话版：training-free curriculum→actor→verifier，多 agent 自主探索，先 broad 后 deep，把环境因果关系、procedure、failure pattern 固化为 frozen memory。

Results：作者报告 GLM-5.3/Kimi-K3 + RSIAgent 在 OSWorld2/ALE partial score 78.98/84.82；四任务 ablation full RSI 均值 74.54%，broad-only 65.52%，deep-only 56.50%。Figure 3 的三个任务到 step 8 达 100/80/100%。

Contribution：New Mechanism/System。Limitation：探索成本、benchmark task selection 与 frozen memory 更新策略需谨慎。Migration：撤销某 tool rule/skill 后比较只删 final memory vs recursive delete supporting trajectories，测 skill reacquisition。Worth Deep Reading: YES。

A3. Decoy Direction Optimization: A Post-Hoc Defense Against LLM Abliteration

人话版：DDO 用 post-hoc weight edit 制造 decoy refusal directions，防 refusal-feature ablation。标准 RFA 跨六模型族 ASR <10%，但 adaptive multi-phase 下 rank-8 DDO worst-case ASR 65%，同时 MT-Bench ≥5.82；rank sweep k=32 时 ASR=79%，接近 undefended 80%。

核心机制：让攻击者读到/删除的是 decoy geometry，并定义 capability-constrained ASR，只有攻击后 utility 仍≥阈值的成功才算部署相关攻击。Contribution：New Mechanism + New Metric/Attack analysis。Migration：定义 CC-Recovery-ASR，用于 robust unlearning 的 rank-k representation recovery。Worth Deep Reading: YES。

A4. The Router Within: Eliciting Native Skill Routing from a Frozen LLM

人话版：Gavel 从 frozen LLM 中层 hidden state 读 skill-routing signal，只训练两个 linear maps；glance 全库，verdict 对 shortlist 续跑。Qwen3-32B 相对 progressive disclosure/retrieve-rerank 最高 +13.4 points，mid-rollout skill need 最高 +21.9，并发布 372 trajectory 的 SkillTraj。

Research Value：对 Skill Unlearning 很直接：从 registry 删除 skill 不代表 frozen LLM 的 native routing signal 消失。MVE：撤销 skill 后训练 linear probe 测 routing residue，并用 paraphrase/adversarial trigger 测恢复。Worth Deep Reading: YES。

8. Tier B

B1. When Agents Slow Down

人话版：Elo-per-token 追踪长 trajectory 的 test-time compute 收益。agent 初期比 independent sampling 更高效，但边际收益最终跌破参考线；在 100M tokens 上按 inflection point 切分并行 session，相比一个长 session +264 Elo、相比十个短 session +355。

Connection：可把 relearning/recovery 从固定 epoch 改成 compute curve，比较 adaptive attacker 在 tokens/steps/FLOPs 下何时恢复。Potential Use: Evaluation/Attack。

B2. Disentangling Representation Evolution in Transformers through Directional Decomposition

Core Method：把 learned update 分解为相对表示的 parallel/perpendicular 分量，并在 residual 与 attention value space 分析。作者发现 exclude-self value-space parallel manipulation 更 robust，perpendicular compression error 更能区分方法。

Connection：可诊断 unlearning update 是“改变方向”还是“缩放已有表示”，并与 layer/token probe 结合。Potential Use: Mechanistic Analysis/Future Idea。

B3. Continual Learning Mechanisms Compose for Long-Horizon Memorization

100-task continual memorization中 naive sequential FT 最终 retention 约 1.2%；组合 data/function/weight anchors + merged LoRA 达 34.9%，约 28×。对 continual unlearning 的镜像意义很强：保护旧知识的 anchor 也可能解释被删知识为何在后续训练中 rebound。Potential Use: Baseline/Reacquisition stress test。

B4. One Modality to Forget Them All: Enhancing Cross-Modal Unlearning in Vision-Language Models — BACKFILL

CrossInf 研究 text↔vision unlearning transfer，发现迁移不对称且 typographic attack 可恢复知识；influence-guided block targeting 将强 fusion 架构 transfer gap 降低超过一半，并把 typographic ASR 降到接近 0。与当前 cross-modal leakage/robustness 高度重合。Potential Use: Baseline/Attack/Collision。

9. Idea Mining

Idea 1 — Revocation Credit: Cross-Session Credit Assignment for Agent Memory Unlearning

Inspiration：ICML + MemRiskBench R4。Gap：delete 多是 store operation，没有学习“删除后哪些未来 action 仍受旧 memory 影响”。Hypothesis：revoke 后 negative delayed credit 可定位 residual influence，并比全库 rebuild 保留更多 utility。

Method：memory provenance id + revoke event + Trigger/summary/tool reuse closure penalty。MVE：Qwen3-8B，200 条扩展 trajectory；baseline hard delete/vector delete/rebuild/refusal；metric revoked reuse、derived reuse、utility、reacquisition、adaptive recovery。

Novelty ★★★★½　Feasibility ★★★★½　Compute ★★½　Risk：credit≠严格因果。Collision Risk：中高。Best Venue：NeurIPS/ICLR/ACL。

Idea 2 — Provenance Closure for Multi-Agent Unlearning

Inspiration：AIM + Emergence World。构建 memory lineage DAG，边包括 copy/summarize/retrieve-to-tool/agent-message；delete 触发 descendant invalidation。MVE：4 agents、50 secrets、1–3 hop propagation，比较 source-only/TTL/recursive DAG/world rebuild；metric closure violation、utility、latency、delayed reuse。Novelty 4.5/5，Feasibility 4/5，Compute 2/5，Collision 高，Venue USENIX Security/CCS/NeurIPS D&B。

Idea 3 — Capability-Constrained Recovery Curves

Inspiration：DDO CC-ASR + Elo-per-token。定义 CC-Recovery-ASR(B,τ)：预算 B 内、retain utility≥τ 时恢复 forget knowledge 的最大成功率。MVE：TOFU + MLLMU；prompt recovery、LoRA relearn、rank-k intervention；画 recovery-vs-compute 与 inflection。Novelty 4/5，Feasibility 5/5，Compute 3/5，Collision 中。

10. Collision Detection

⚠️ Collision Warning

Agent Memory：AIM 已把 delete 纳入 multi-user benchmark；MemRiskBench 已把 revoked-memory reuse 作为 R4。因此只做“Agent Memory 删除 benchmark”明显撞题。剩余 gap 应推进到 derived-memory provenance、cross-agent propagation、causal closure、reacquisition/adaptive attack。

Multimodal：CrossInf 已覆盖 bidirectional cross-modal transfer + typographic attack；已有 VLM robustness 工作覆盖 contextual/retraining recovery。新工作应聚焦 token/layer localization、reasoning leakage、adaptive black-box 或 continual rebound。

Representation：DDO 显示 rank-adaptive intervention 会击穿低秩防护；representation-level unlearning 的 robustness claim 应加入 rank sweep/adaptive re-estimation。
