Tier S

1. Confess What You Know: Forget-Set Misalignment with Model Knowledge in LLM Unlearning

基本信息：Confess What You Know: Forget-Set Misalignment with Model Knowledge in LLM Unlearning；Miso Kim, Georu Lee, Seungwon Jeong, Woojin Lee；Dongguk University-Seoul；arXiv:2609.00605v1，2026-09-01；Accepted to EMNLP 2026 Main；Full HTML。

人话版

绝大多数 unlearning 默认“用户给出的 forget set 就是模型真正记住的知识”。论文指出这个前提常错：用户会漏掉模型实际记住的相关事实，也会要求删除模型根本没学过的事实。前者留下 residue，后者白白伤 retain utility。作者提出 CONFS：Confession→SRO triplets→Reconfession→Competency Questions→多次采样与 NLI consistency filter，构造 model-aligned forget set。核心意义是把研究前提从“如何优化”推进到“到底删对东西没有”。

Background & Gap

TOFU/CLEAR 等 benchmark 通常知道注入了哪些事实，现实用户却不知道模型真实 memorized boundary。只删一个泄露事实不保证同实体其他 facts 自动一起忘；把 never-learned facts 加入 forget set 也仍会产生梯度，甚至与 retain gradient 高度同向。

Core Insight

可靠 forget set 需要同时高 Recall 与高 Precision：Recall 不足对应 Under Unlearning，Precision 不足对应 Out-of-Knowledge。gradient inner product 解释了为什么“删错集合”会直接改变 forgetting/utility trade-off。

Method Deep Dive

Target entity → Confession → SRO atomicization → Reconfession → QA generation → repeated sampling → NLI filter → model-aligned forget set → GA/GD/NPO/RT

Reconfession 负责发现遗漏事实，NLI consistency 负责去掉模型不稳定持有/幻觉的 facts；最终 forget-set construction 与 unlearning objective 解耦。

关键公式

ΔL_F(D) ≈ η⟨g_F,g_D⟩ E_tf = ΔL(D_L+) - ΔL(D_retain) E_eg = ΔL(D_L-) - ΔL(D_retain)

D_L+ 是记住且请求删除；D_L- 是记住但漏掉。若 E_tf 高而 E_eg≈0，表示 requested facts 被定向删除，但遗漏 facts 只是跟着 overall utility 衰退。

Toy Example

Alice 的真实 memorized facts 有 works_at=Lab A、lives_in=Boston、advisor=Bob。用户只请求 works_at，并误加 Company C。CONFS 通过主动 confession/reconfession 补出 Boston/Bob，又通过 consistency filter 丢掉不稳定的 Company C。

Baseline Deep Comparison

Gold-standard 是上限；FreeRecall-QA 简单但易混入 Out-of-Knowledge；RWKU-style coverage 较强但仍含不稳定 facts；CONFS 通过 reconfession+filter 同时改善 coverage/precision。Table 5 中 FreeRecall-QA D_N+ share 91%、gradient cosine 0.84、retain ΔL +3.53；RWKU-style 68%、0.46、+0.31；CONFS 54%、0.28、+0.11。

Experiment Setup

Controlled analysis：TOFU 20 targets，每 target 15 QA 分为 D_L+/D_L-/D_N+ 各5。Main：TOFU 10%、CLEAR 10% multimodal、RWKU real-world data-blind；Objectives：GA/GD/NPO/RT。

Results Deep Dive

  • Under Unlearning：E_tf 随 GA steps 上升，E_eg 接近0，说明遗漏 facts 没获得额外定向 forgetting。
  • GA step60：D_L+ Prob 0.995→0.312；D_L- 仍0.624；retain 0.658。
  • 加入 Out-of-Knowledge facts 后，retain Prob 可降到 0.412，而 Under setting 为 0.658。
  • CONFS 把 out-of-knowledge share 与 gradient cosine 显著压低，同时 targeted forgetting 仍强。
  • RWKU 上跨 GA/NPO/RT 也总体优于 RWKU-style。
  • Failure：D_N+ share 仍有 54%，不是完美 Gold-standard。

Table/Figure Reading

Figure1 看两种 misalignment；Figure2 看 E_tf/E_eg 与 retain-gradient coupling；Table1 看 step-wise trajectory；Table5 是最值得迁移的 forget-set quality diagnostic。

Ablation

去 Reconfession 主要损 coverage；去 Hallucination Verification 主要损 precision，分别对应漏删与错删。

Claim vs Evidence

论文证明 forget-set alignment 是实质问题，并在 synthetic/multimodal/real-world setting 支持 CONFS；但 stable confession 不等于完整 training-data membership，cross-view residue 仍可能存在。

Contribution

New Problem FormulationNew ProtocolNew Forget-set ConstructionNew Empirical Finding

Limitation

依赖 target model 与 NLI verifier；构造成本高；probe-family-relative；black-box API 无法直接复现 gradient diagnostic；多语言与 long-horizon Agent memory 未覆盖。

Research Value

Baseline ★★★★★；Migration ★★★★★；Attack ★★★★☆；Evaluation ★★★★★；New Paper Potential ★★★★★。

Migration Analysis

Original→forget-set misalignment；Transferable→active probing + atomicization + recursive expansion；New RQ→五视角是否形成 semantic closure；MVE→MLLMU/CLEAR 20–50 identities，direct/paraphrase/cloze/multi-hop/cross-modal，比较 raw request / CONFS / Cross-View-CONFS；Metric→Worst-View Leakage、ASR@budget、Retain FPR、MIA。

5句话

  1. unlearning 可能一开始就删错集合。
  2. 漏删留 residue，错删伤 utility。
  3. CONFS 主动构造 model-aligned forget set。
  4. Table5 把 forget-set quality 变成独立评测对象。
  5. 最值得迁的是 cross-view active forget-set closure。
2. Invalidation Contracts for Cross-Episode Agent Memory

基本信息：Invalidation Contracts for Cross-Episode Agent Memory；Michael Wu, Arquimedes Canedo；arXiv:2609.00243v1；Full HTML。评测 7 models、3 serving paths、2 domains，约 9,432 episodes。

人话版

Agent 把 API failure 的 recovery suggestion 缓存进长期 memory 后，一旦 server-side rule/data drift，旧 fix 会变 stale。论文提出 invalidation contract，并把成功拆成 Validity（memory 现在是否仍正确）与 Compliance（planner 第一次会不会真的使用正确状态）。这对 Agent Unlearning 极关键：storage 删对了，不代表行为层真的不再依赖旧知识。

Background & Gap

No-memory 每次重算，naive memory 会 stale，table-level flush 又过度删除 retain entries。更深问题是：即使系统精确指出哪些 memory 失效，不同 LLM planner 也可能拒绝遵循新的 valid state。

Core Insight

Validity × Compliance decomposition：前者属于 protocol/lineage，后者属于 behavior。对 unlearning，可映射为 Storage Deletion Correctness 与 Behavioral Forgetting。

Method Deep Dive

Failure → suggestion+versions+dependency → cache → drift → row-level diff → pre-reload dependency walk → selective eviction/restamp → planner → measure Validity & Compliance

最关键是 pre-reload edge walk：必须在覆盖旧 graph 前找 downstream，因为删除/刷新后旧 edge 可能消失。

Metrics

Validity = still-correct / cached Compliance = valid suggestions used at first try / eligible Eviction Precision = correctly invalidated / all evicted

Baseline Comparison

A0 no memory；A1 naive memory；A2 table-level；A2D row-level。A2D eviction precision=1.00，而 table-level≈0.25。

Experiment Setup

Payments 36 episodes + Recipe 48 episodes；models 覆盖 Claude/GPT/DeepSeek/Gemini；250 arm-level runs、9,432 episodes。

Results

  • 约 9,400 episodes，version-stamp validity checks 0 contract failure。
  • A2D vs A1：GPT-5-mini +66.7pp、Sonnet4.6 +63.0pp、Haiku +55.6pp、Gemini +48.2pp compliance。
  • Token saving 多模型从约 10–22% 提升到 22–33%。
  • DeepSeek-V4-Flash 是 failure：protocol 更精确但 compliance/token benefit 没改善。
  • Row-level invalidation 明显减少 retain over-deletion。

Table/Figure

Table1 看 L0–L6；Table3 看 first-try compliance；Table6 看 token savings；pre-reload graph 流程最值得迁。

Ablation

A1→A2D 是最干净 ablation：只改 invalidation granularity，就能带来多个模型 48–67pp first-try 提升；更丰富 metadata 没稳定继续提升，暴露 planner compliance floor。

Claim vs Evidence

controlled drift/negative control/多模型支持 validity-compliance decomposition；但自然语言 memory dependency 未必像 API schema 一样清晰。

Contribution

New ProtocolNew Evaluation DecompositionSystem Engineering

Limitation

structured API domain 较理想；dependency graph 相对明确；某些模型存在 schema conservatism。

Research Value

Baseline ★★★★☆；Migration ★★★★★；Evaluation ★★★★★；New Paper Potential ★★★★★。

Migration

定义 Unlearning Contract：memory/summary/skill 带 source-version 与 dependency vector；删除前冻结 lineage；删除后分别测 Storage Validity 与 Behavioral Compliance。MVE：LoCoMo 50 facts，每 fact 2 summaries+1 plan+1 skill；Metric：Invalidation Precision/Recall、Compliance@1、Residual ASR、Retain FPR、Token Cost。

5句话

  1. 删对 entry 与行为真正忘记不是一回事。
  2. Validity 属于 lineage，Compliance 属于 behavior。
  3. row-level invalidation 更精确。
  4. 删除前冻结旧 graph 很重要。
  5. 它几乎可直接改造成 Agent Unlearning Contract。
3. Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems

基本信息：Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems；Accepted to EMNLP 2026 Main；arXiv:2609.00237v1；Full HTML。

人话版

论文让 memory 从被动 store 变成 Multi-Agent 控制状态：Write Gate 决定留什么，Retrieval Gate 决定给下一个 Agent 看什么，Role Allocator 选角色，LLM Router 选 backbone，Halting Controller 判断是否停。五 benchmark 平均 accuracy 77.73%，比 strongest baseline +2.44pp。对 Multi-Agent Unlearning 的关键启发是：删除一条 memory 不只影响答案，还可能改变谁行动、选哪个模型、何时停止。

Background & Gap

query-only routing 无法利用中途 evidence，full-history 又造成冗余和成本。本文把 compact execution memory 当 active control state。

Method

Query + memory → Role → Model Router → Retrieve → Agent Execute → Write Gate → Halt → Aggregator

公式

u_i = R_i - λ_c Cost(τ_i) A_i = u_i - mean_group(u) L = -mean[logπ_i · sg(A_i)] + αL_VAE - c_H H(π)

同一 query 的 trajectories 做 centered advantage，避免小方差下 standardization 放大微小成本差。

Experiment Setup

MATH、GSM-Hard、MBPP、HumanEval、MMLU-Pro；多种 Qwen2.5 backbones；比较 MASRouter、Puppeteer、full-history。

Results

  • 平均 accuracy 77.73%，四个 benchmark 最优。
  • HumanEval 89.84 vs MASRouter 85.16；cost 0.032 vs 0.057。
  • 相对 Puppeteer，HumanEval cost 低约31.9%。
  • GSM-Hard full-history 70.27/cost0.985，gated 70.55/0.587。
  • 去 LLM router：GSM-Hard 70.55→56.53，HumanEval 89.84→71.88，是最大 ablation。

Table/Figure

Figure2 看控制回路；Table2 看 ablation；Table3 看 query/full-history/gated；Figure3 看 accuracy-cost Pareto。

Claim vs Evidence

结果支持 compact gated memory 是更好的 control state；但没有做单条 memory deletion causality，也没评估 privacy/provenance。

Contribution

New System/MechanismRL ObjectiveNew Empirical Finding

Limitation

closed benchmark、binary reward、无跨 episode persistence、安全/隐私目标缺失。

Research Value

Migration ★★★★★；Evaluation ★★★★☆；New Paper Potential ★★★★★。

Migration

做 Control-Flow Deletion Closure：删除 target record 后比较 role/model/retrieval/halt distributions，并测最终 Residual ASR。MVE：GSM-Hard/HumanEval 各100 queries；Metric：Routing KL、Role Flip、Halt Δstep、Residual ASR、Retain Cost。

5句话

  1. Multi-Agent memory 是控制面，不只是知识库。
  2. 写/读 memory 会改变 routing 与 halting。
  3. gated memory 比 full history 更准更省。
  4. 删除应看 control-flow residue。
  5. 这是新的 Multi-Agent Unlearning gap。

Tier A

4. REVISE: Validity-Guided Recovery for Online Revisions in Agent Workflows

人话版：用户中途修改需求时，REVISE 用 data/control provenance 精确 invalidate 受影响 nodes，避免 full restart。15,939 executions 中与 latest-version oracle 一致，0 stale output/effect；LangGraph model calls 相对 full restart -56.0%，相对 suffix -43.6%。最值得迁：deletion request≈semantic revision，做 Source→Memory→Tool Plan→Action selective invalidation。Worth Deep Reading: YES。

5. SoK: When Safe Agents Fail Together: The Security of Multi Agent LLM Systems

人话版：作者系统分析 197 works、审计44 MAS security evaluations，用 A-I-R execution-path taxonomy 组织攻击，并把 path closure/recovery列为 open challenge。42/44 固定 membership，只有2个支持有限 runtime spawning；13/44 使用 ASR 但定义不统一。对 Multi-Agent Unlearning，最值得迁成 Source Agent→Message→Shared Memory→Peer→Tool Effect 的 deletion path closure benchmark。Worth Deep Reading: YES。

6. Delegation Without Trust: Identity, Authorization, and Runtime Governance in Multi-Agent LLM Systems

人话版：论文把 authority enforcement 移到模型外 broker：即使 Agent 被 prompt injection 劫持，也不能越权。default runtime 四类 threat 全失败，broker 全阻断；200,000 forged/mutated tokens 接受0。对 Tool-level Unlearning，可把“忘记工具权限”从 prompt prohibition 改成 capability revocation，并测 Behavioral ASR + Authorization Reachability。Worth Deep Reading: YES。

7. EDGE: Error Dependency Graph-Guided Multi-Error Attribution in Multi-Agent LLM Systems

人话版：EDGE 构建 error dependency graph，并用 counterfactual repair rollout 验证 causal edges；推理时只验证当前 trace 可达 hypotheses。TRAIL/MAST 上多模型 F1 提升，GPT-4o MAST F1 22.87→29.96。可迁成 Information Dependency Graph，用 counterfactual deletion 找 minimal causal cut。Worth Deep Reading: YES。

Tier B

8. I-CARE: Interference as a First-Class Object in Generative Unlearning

仅根据 Abstract / 可获取信息总结。 I-CARE 把 related-concept collateral damage 从附属 utility metric 提升为正式 interference evaluation；可迁到 MLLMU 的 Retain-Near / visual-neighbor boundary。Potential Use: Evaluation / Benchmark。

9. TRU: Targeted Reverse Update for Efficient Multimodal Recommendation Unlearning

TRU 在 ranking fusion、modality branch、parameter group 三尺度做 targeted reverse update。对 MLLM 可借“vision/connector/LLM 不同分支 sensitivity 不同”的机制。Potential Use: Baseline / Mechanism。

10. ContextPipe: Database-Inspired Context Assembly for Long-Horizon Agents

ContextPipe 用 Plan→Bind→Optimize→Execute→Feedback 组装长程 Agent context，并输出 EXPLAIN trace。preliminary SWE-bench Pro subset 上 token -31%、calls -23%、response time -9%。Potential Use: Infrastructure / Deletion provenance audit。

11. Runtime-Independent Persistent Agents

把 persistent agent 拆为 continuity substrate（identity/memory/software body）与可替换 runtime（model/harness/host）。对 unlearning 的提醒：删除必须跨 runtime migration 保持 invariant，否则换模型/服务器后可能 rebound。Potential Use: Threat Model / Future Idea。

Inspiration：Invalidation Contracts + REVISE + Hindsight Memory-PRM。Hypothesis：Storage Validity 与 Behavioral Compliance 必须分开保证。MVE：LoCoMo/LongMemEval 50 facts，每 fact 2 summaries+1 plan+1 skill；比较 source-only/full reset/row contract/graph contract。Metric：Invalidation P/R、Compliance@1、Residual ASR、Retain FPR、Token Cost、Reacquisition Time。Novelty ★★★★★ · Feasibility ★★★★★ · Compute ★★☆☆☆ · Collision Risk 低中 · Venue NeurIPS/ICLR。

Idea 2 — Cross-View Model-Aligned Forget-Set Closure

CONFS + Scientific Claim Unlearning。direct/paraphrase/cloze/multi-hop/cross-modal 共同主动扩展 forget set；每轮找 Worst-View leakage→atomicize→加入 target。Metric：Worst-View Leakage、ASR@budget、Retain FPR、MIA。Novelty ★★★★★ · Feasibility ★★★★★ · Collision Risk 中高。

Idea 3 — Control-Flow Deletion Closure in Multi-Agent Systems

Gated-Memory Routing + EDGE。删除 target record 后不仅测 output，还测 role/model/retrieval/halt distributions 与 causal propagation graph。Metric：Routing KL、Role Flip、Halt Δsteps、Residual ASR、Minimal Causal Cut。Novelty ★★★★★ · Feasibility ★★★★☆ · Collision Risk 低。

Idea 4 — Runtime-Independent Deletion Invariant

persistent agent 中 deletion ledger/tombstone 作为 continuity-bearing policy state；跨 model/harness/server migration 必须继续生效。Metric：Cross-Runtime Residual ASR、Tool Reachability、Rebound Rate。Novelty ★★★★☆ · Feasibility ★★★★☆。

Collision Detection

⚠️ Cross-View/Forget-Set：Scientific Claim Unlearning + CONFS 已占据“view leakage”和“model-aligned target construction”两端；新工作应做 active Worst-View expansion 或 future-recovery predictor。

⚠️ Agent Memory：Hindsight Memory-PRM、Invalidation Contracts、REVISE 已覆盖 single-entry causality、row invalidation、provenance recovery；剩余 gap 是 privacy deletion semantics + behavioral compliance + incomplete provenance + cross-representation descendants。

⚠️ Multi-Agent Causal Attribution：DoCtOR/EDGE 已存在；应转向 information path closure / minimal causal cut。
