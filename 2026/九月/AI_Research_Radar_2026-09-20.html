1. Executive Summary

本期先广搜 46 篇 Candidate，再统一筛选。最强新信号是 Test-Time Unlearning via Sparse Autoencoder：ARIA 不改权重，而用 SAE latent detector 判断生成是否进入 forget-related state，仅在触发时做 latent intervention。DeepSeek-R1-Distill-Qwen-1.5B 的 WMDP-cyber forget accuracy 从 32.81% 降到 0%，MMLU 仅 -0.50pp；三类恢复攻击下 forgetting 变化小于 1%。

Agent 侧的新鲜机制是 Self-Evolving Search Index：检索失败后定位 responsible index keys，只修改责任项并验证，再用 Query Simulator 主动探索未来查询。它非常适合迁移成持续 Agent Memory Deletion Closure。与此同时，Execution-State Unlearning 已证明只删 memory record 不等于忘记，意味着“Agent Memory Unlearning”泛题已高度撞题。

3. Tier S

S1 · Test-Time Unlearning via Sparse Autoencoder

基本信息：Pingzhi Li 等，arXiv v1 2026-09-14。Models: DeepSeek-R1-Distill-Qwen-1.5B、Gemma-3-1B-it；Datasets: WMDP-cyber、R-TOFU、TOFU。正文可访问；未确认正式 venue/code，故不猜测。

人话版

传统 GA/GD/NPO/RMU 通过改权重让模型忘记，但越强的 forgetting 越可能伤 utility，而且被微调或 prompt attack 后知识会回来。ARIA 把模型权重冻结，用 Sparse Autoencoder 将隐藏状态拆成稀疏 feature，再训练轻量 detector 判断“当前 token 状态是否正进入目标知识”。只有触发时才干预 latent，普通状态完全沿用原模型，因此把全局参数损伤改成局部运行时控制。

Background & Gap / Core Insight

weight-based 方法对 forget、retain、attack input 都共享同一个 edited model，因此 suppression 与 utility 天生耦合。ARIA 的关键观察是 forget/retain generation state 在 SAE feature space 中可被线性 probe 区分。如果只在目标知识真正被访问时干预，就没有必要全局破坏参数。

Prompt → frozen LLM state → frozen SAE φ(s) → linear gate gψ(s) → trigger? → latent intervention / untouched base output → next token

关键公式

gψ(s)=σ(wᵀφ(s)+b)，阈值 τ 控制路由。论文给出：E[L_f] ≤ (1-ε_f)η_f + ε_f L_max，即 forget leakage 主要受 detector false negative ε_f 与 intervention 残余 η_f 控制；retain degradation 满足 E[Δ_r] ≤ ε_r U_max，由 false positive ε_r 控制。直觉是：忘不干净问“漏报多少”，utility 误伤问“误报多少”。

Toy Example

若要忘某 cyber 攻击细节，数学题的 SAE cyber features 不激活，gate<τ，模型完全不受影响；当回答逐 token 进入攻击步骤时，相关 sparse features 激活，gate>τ，ARIA 才改变 latent trajectory。它不是 prompt 关键词过滤，而是 generation-state 级触发。

Baseline Deep Comparison

GA 直接 ascent forget loss，简单但 utility 损伤大；GD 加 retain descent 稳定能力但仍全局改权重；NPO 以 preference-style objective 抑制 forget response，可能偏行为 suppression；RMU 已在 representation 层扰动目标知识，是最接近的强 baseline，但改变仍写进模型。ARIA 真正的新点是 state-dependent runtime routing，而非新训练 loss。

Experiment Setup / RQ

RQ1：WMDP forgetting 能否在保持 MMLU 时优于 weight baseline？RQ2：thinking model 的 final answer 与 CoT 是否同时忘？R-TOFU 用 AFE/CFE。RQ3：Gemma/TOFU 是否泛化？RQ4：weight-space / decoding-space recovery attack 能否恢复？RQ5：SAE feature 能否解释 retain degradation？

Results Deep Dive

  • DeepSeek：WMDP-cyber 32.81%→0.00%；GA/GD/RMU 仍约 27.16/27.98/28.18%。
  • MMLU 36.04→35.54%，仅 -0.50pp；GA 为 -6.51pp，说明不是靠大幅 utility sacrifice 换 forgetting。
  • R-TOFU：ARIA AFE 97.45%、CFE 97.24%、Average 73.02%；RMU Average 55.80%。CFE 对 reasoning leakage 尤其关键。
  • Gemma：WMDP 同样 0%，MMLU 35.89→34.53（-1.36pp）。
  • 三类恢复攻击下 forgetting 变化 <1%，但尚不等价于任意 adaptive white-box gate-evasion。

Table/Figure / Ablation

Figure 2 清楚显示 weight edit 对所有输入共享改变，而 ARIA 只在 detected state 触发。Table 1 最关键的是“0% forget + -0.50pp MMLU”同时成立；Table 2 也暴露 weakest signal：Gemma TOFU Retain RL 从 36.64 降到 34.85，说明 detector 并非无误伤。feature case study 还发现 retain degradation 可能来自数据中的 response-style feature，而非目标知识本身——这提示必须做 cross-template 与 feature semantics audit。

Claim vs Evidence / Contribution

证据支持“两个小模型、三个 benchmark、三类 attack 下 trade-off 很强”；尚未证明大尺度、跨语言、跨模态、开放世界 paraphrase 与知道 gate 后的自适应攻击。Contribution：New Mechanism detector-gated inference-time unlearning；New Protocol routing FN/FP 分解；New Attack/Evaluation post-unlearning recovery；New Empirical Finding response-style confound。

Limitation / Research Value / Migration

最大风险是 detector distribution shift；而且知识仍在 weights 中，所以不等价于严格 parameter deletion。迁移到 MLLM：在 vision token 与 LLM residual 分别训练 detector，用 cross-modal causal gate 触发 visual-grounded intervention。Minimum Experiment：LLaVA-1.5-7B、MLLMU forget5；baseline=NPO/RMU/prompt refusal/ARIA-style gate/VGID；metrics=Forget/Retain、CoT leakage、relearning、adaptive paraphrase。Collision Risk 高，必须与 LEMUR 区分为“cross-modal causal localization”。

只记住 5 句

  1. ARIA 不改权重，把 unlearning 变成 runtime routing。
  2. SAE detector 的 FN 控 leakage，FP 控 utility。
  3. DeepSeek WMDP 可到 0%，MMLU 仅 -0.50pp。
  4. 攻击后变化 <1%，但 adaptive gate evasion 仍待验证。
  5. 最值得迁移的是 token/state attribution × inference-time unlearning。
S2 · Self-Evolving Search Index

基本信息：Sangam Lee 等，arXiv 2609.19656，2026-09-17。它不是 unlearning 论文，而是 Agent retrieval/index adaptation 机制论文。

人话版

固定 index key 在 query distribution 变化后会失效，人工找原因再重建索引又贵。SELF-INDEX 让 Optimizer 自动诊断检索失败，只改造成失败的 key，验证改动后再提交；Query Simulator 还主动制造未来可能出现的查询。这套“定位责任→局部编辑→验证→主动找漏洞”的闭环，非常适合改造成 agent memory deletion closure。

Background & Core Method

Current index → retrieval failures → responsible-key diagnosis → selective revision → validation gate → commit → Query Simulator → new demands → repeat

真正可迁移的机制不是“LLM 写 key”，而是 update support locality：只允许责任子集变化。Unlearning 版本可把目标写成最小化 target exposure + λ·retain damage，并把可编辑 support 限制在 target provenance closure。

Toy Example

用户撤回“优先供应商 A”。源 fact 已删，但 summary key“长期偏好：A”仍会被检索。Deletion optimizer 用 revoke probes 找到该 key，局部 invalidate/rewrite，再跑 retain probes；Query Simulator 主动生成“你通常选哪家？”等 paraphrase，继续搜索 closure 漏洞。

Experiment / Evidence

原文可确认 SELF-INDEX 跨 diverse corpora/retrievers 持续提升 retrieval，并改善 search agents 与 agent memory 对 past interactions 的检索。当前可核验结果未提供足够逐表数字，因此不虚构百分点。应重点检查 ablation：无 validation、无 Query Simulator、global rewrite 与 selective edit 的差异。

Contribution / Limitation

New Mechanism/System：self-evolving index + diagnose-edit-validate loop；Empirical Finding：索引能随 retrieval environment 自适应。限制是 optimizer 可能错误归因，simulator 也可能覆盖不足；原文没有证明 deletion robustness。

Migration

Original=自演化 index → Mechanism=responsibility localization + validated local edit + query simulation → New RQ=索引持续演化后，删除约束能否仍闭合？ Minimum Experiment：LongMemEval/LoCoMo revoke episodes，Mem0/flat-RAG/summary memory；baseline=delete-only/full rebuild/execution-state replay；metrics=Target Retrieval@k、behavior residue、retain F1、closure rounds、edit cost。Expected Contribution=Continual Agent Memory Unlearning。Collision Risk 高，但“post-deletion index evolution”仍是明确 gap。

只记住 5 句

  1. 核心是诊断→局部修改→验证。
  2. Query Simulator 主动寻找未见需求。
  3. 可直接变成 deletion-closure adversary。
  4. 局部 attribution 有利于 retain utility。
  5. 最好的新问题是“删完以后继续演化会不会重新暴露”。

4. Tier A

A1 · Extracting Forgotten Prompts from Targeted Unlearned Models

人话版：攻击者不知道 forget prompt，只凭 retain data 与黑盒 API，也能先发现被删 entity，再重建 prompt；拒答/异常行为本身可能泄露 deletion membership。

Method：canonical templates + entity pool → 在 query budget 下选择最有信息量的 template-entity pair → 定位 forgotten entity → 实例化模板重建 prompt。本质是 active search，而非暴力枚举。

Results：3 unlearning methods × 3 datasets × 3 LLMs；forgotten entity recovery 100%，prompt reconstruction 最高 95%，相对 naive probing 最多省 99.7% queries。

Contribution：New Attack + New Evaluation Protocol。限制：依赖 template/entity prior，开放域非实体知识更难。Migration：在 MLLMU 隐藏 forget identity，仅给 attacker retain pool；比较 NPO/RMU/VGID/ARIA，测 discovery AUC、reconstruction、queries-to-hit，再扩成 image-entity pool。Worth Deep Reading: YES。

A2 · Locating Hidden Failures Makes Long-Horizon Agents More Reliable · Cooling

人话版：作者不只问 agent 最后成功没，而是人工定位“第一步从哪里错”。2,518 trajectories、6,967 mistakes、78 failure types。Scout 4B verifier 学 first-mistake localization。

Results：第一次错误后下一步错误概率约增 11–14×；仅 30.5% 失败 run 能恢复，38.5% 没检测到错误。frontier judge first-mistake 最强约 26.8%/32.3%。Scout 做 test-time selection 后 Terminal-Bench 81.8→90.2%，SWE-bench 75.6→78.0%，BixBench 50.1→53.2%。

Contribution：Traverse benchmark + first-mistake protocol + Scout verifier。Migration：把 first mistake 改成 first reacquisition：删除后继续 20–50 steps，标注 target 首次重新影响 memory/tool/action 的位置，训练 verifier。Worth Deep Reading: YES。

A3 · Forgetting Without Restarting: Execution-State Unlearning for Stateful LLM Agents · Cooling

人话版：memory 进入 summary、plan、tool trace、KV cache 后，只删数据库记录没用。论文把 runtime 写成 R_t=F(R_{t-1},o_t;θ)，target 在 τ 注入；τ 前 clean prefix 可复用，τ 后必须在没有 target 的世界里 replay。

Method：LocateSource → FirstEntry → TaintClosure → KV crop/restore → sanitize observations → shadow replay tools → regenerate state。理论最小重算 T-τ+1。

Results：Memory-Delete 与 No-Forget 相同；Forget-Instruction 在六 probe 下 Leak@probes=1.00；Source-Redaction 仍有 0.73–0.97 leakage，行为测试仍按 revoked preference 行动 80%。Selective Replay 与 Full Reset 一样达到 0 leakage / 0 action divergence，最多少算约 9.3× tokens。

Contribution：New Problem + Theory + Mechanism + behavioral audit。限制：deterministic/replayable runtime 与 oracle provenance。Migration：扩展 provenance graph 到 agent-to-agent messages、shared blackboard、skill library。Worth Deep Reading: YES，且直接 Collision。

A4 · LEMUR · BACKFILL

人话版：多模态 reasoning model 可能 final answer 已忘但 CoT 仍泄漏。LEMUR 发现 RL-trained MLRM 的敏感 reasoning 有 token-level entropy signature，于是用 entropy 决定 sanitization 的开始/结束，并用 visual-anchor latent injection 重定向轨迹。

Method：entropy onset/stop control → 敏感区间内 probability-weighted sanitized embedding → re-ground 到视觉证据。报告跨多个 MLRM 抑制 reasoning-trace 与 answer leakage，同时更好保留 utility/fluency；当前核验来源不足以安全给逐表数字。

Contribution：New Mechanism + New Empirical Finding。限制：entropy signature 是否跨任务稳定、adaptive attacker 是否可构造低熵泄漏。Migration：比较 entropy detector、SAE probe、combined gate；MLLMU forget5，测 CoT leakage、trigger FPR/FNR、POPS-style recovery。Worth Deep Reading: YES。

5. Tier B

B1 · Fresh Memory, Stale Plans / PlanFence

多 Agent 即使读到最新 shared facts，也可能执行基于旧事实生成的 plan。PlanFence 让 plan 显式引用依赖 records，执行外部动作前只验证相关依赖；30 个 post-plan revision workflows 中 freshness-only 全部执行 obsolete plan，而 PlanFence 全部无 invalid action。Contribution=dependency-scoped validation；对 unlearning 的意义是删除 target 后依赖它的 plan 也必须 invalidated。Potential Use: System mechanism / Baseline。

B2 · RepSelect · BACKFILL

RepSelect 认为 shallow forgetting 的根因是更新打到了 retain 与 attacker recovery 共享的 representation subspace。它对 weight gradients 做 PCA/SVD，压掉共享主成分，尽量只动 forget-specific representation。跨 knowledge/tendency 与 dense/MoE models，post-relearning answer probability 的下降幅度相对强 baseline 可大约 4–40×（不同版本摘要最高报告 50×），few-shot robustness 很强，MMLU 通常距原模型约 1–2%。Potential Use: Robust baseline / Mechanistic analysis。

B3 · UNLINK-VL · BACKFILL

它问“文字里忘了，图像里也忘了吗？”用真实视觉实体 + Wikidata one/multi-hop facts 建 cross-modal benchmark。核心发现是明显非对称：multimodal unlearning 在 text evaluation 下仍有效，而 text-only unlearning 向 visual/cross-modal transfer 很差；一般能力大体保留。Contribution=New Benchmark/Dataset + Evaluation Protocol。Potential Use: Benchmark / Cross-modal leakage evaluation。

6. Idea Mining

Idea 1 · First-Reacquisition Verifier for Agent Unlearning

Inspiration：Scout + execution-state unlearning。Gap：现有评测只看最终泄漏，不知道删除后第几步重新获得 target。Hypothesis：first reacquisition 是更稳定的 repair boundary。Method：trajectory 标注 clean / reacquisition / contaminated；小 verifier 读取 thought-action-observation + provenance，定位边界并触发局部 replay。MVE：200–500 LongMemEval/ToolSandbox revoke episodes，Llama-3.1-8B agent + 1–4B verifier。Baselines=string probe/final judge/MIA/full reset。Metrics=boundary accuracy、Leak@probes、behavior residue、recompute tokens。Expected Contribution=New Verification Protocol + Repair. Novelty ★★★★★ · Feasibility ★★★★☆ · Compute ★★☆☆☆。Risk=多源 reacquisition。Collision Risk=中高。Best Venue=NeurIPS/ICLR。

Idea 2 · Deletion-Closed Self-Evolving Agent Memory

Inspiration：SELF-INDEX + PlanFence + selective replay。Gap：一次删除正确，后续 consolidation/index evolution 仍可能重新合成 target。Method：revoke 变成持久 constraint；Query Simulator 生成 paraphrase/multi-hop attacks；若 target 暴露则只修 provenance closure 并验证 retain。MVE：LoCoMo/LongMemEval + 50 sequential revoke/update events；baseline=delete/full rebuild/SBU/replay；metric=Target Retrieval@k、behavior leakage、retain F1、closure rounds、latency。Novelty ★★★★★ · Feasibility ★★★★☆ · Compute ★★☆☆☆。Risk=query coverage。Collision Risk=高，但 post-deletion evolution 是明确 gap。Best Venue=ICLR/ACL。

Idea 3 · Cross-Modal Adaptive Gate

Inspiration：ARIA SAE + LEMUR entropy + UNLINK-VL asymmetry。Gap：单 detector 可被跨模态 paraphrase/低熵 reasoning 绕过。Method：文本 SAE、visual causal evidence、entropy 三路联合 gate，仅在 causal span 做 visual-grounded intervention。MVE：LLaVA-1.5-7B/Qwen-VL，MLLMU+UNLINK-VL；baseline=ARIA-style/LEMUR/NPO/RMU/VGID；metrics=answer/CoT leakage、utility、FPR/FNR、relearning、POPS recovery。Novelty ★★★★☆ · Feasibility ★★★★☆ · Compute ★★★☆☆。Risk=被视为 engineering，需 causal ablation。Collision Risk=高。Best Venue=NeurIPS/ICLR。

7. Collision Detection

⚠️ Collision Warning: YES

Agent Unlearning：Execution-State Unlearning 已解决 plaintext deletion 后 summary/plan/KV 污染，并给 exact replay；Agentic Unlearning/SBU 已覆盖 parameter-memory backflow 与 dependency closure。只做“删 memory + 清 summary”明显撞题。剩余空间：cross-agent propagation、shared blackboard、communication lineage、持续 consolidation 后 rebound、不可重放工具。

Inference-time：ARIA 占 SAE-gated 路线，LEMUR 占 entropy/visual-anchor 路线。单纯 activation steering 不够新，应做 multimodal causal localization、adaptive evasion、continual requests 或更严格 deletion semantics。

Robustness：TAS 已推进到 unknown-forget-prompt discovery；RepSelect 已覆盖 relearning/few-shot/adaptive recovery。新工作至少应包含 unknown-target discovery、adaptive attack、quantization/relearning、cross-modal recovery。
