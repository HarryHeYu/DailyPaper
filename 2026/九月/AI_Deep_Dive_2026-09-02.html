5.2 一句话定位

UDS 把“模型只是学会不说，还是目标知识已经从可被后续网络恢复的中间表示中真正消失”变成一个通过 cross-model activation patching 得到的 0–1 因果分数。

5.3 人话版

普通 unlearning 评测只看最终输出是否还会说出 forget knowledge，但这容易把“出口抑制”误判成“内部删除”。作者构造三个模型：学过全部数据的 M_full、从未见过 forget set 的理想参考 M_ret、以及执行过 unlearning 的 M_unl。对每个 forget QA，只取真正承载知识的实体 token，然后逐层把 M_ret 或 M_unl 的 hidden state patch 到 M_full 的同一层，让 M_full 剩余 Transformer blocks 继续计算。如果 patch M_unl 后 M_full 仍能恢复正确实体，说明该层 residual 仍携带可用知识；如果其影响接近 M_ret，则更接近真正 retraining。作者把这一相对因果退化归一化成 Unlearning Depth Score。UDS 在 faithfulness、量化稳定性、relearning 稳定性上都显著优于 CKA、Fisher、Logit Lens 和多数输出指标。

5.4 Background & Research Gap

现有 LLM unlearning 常用 Exact Memorization、answer probability、Truth Ratio、ROUGE、MIA、retain-normalized score 等输出侧指标。白盒侧又有 CKA、Fisher、Logit Lens、probe、causal tracing 等方法。问题是：输出失败并不等于 hidden representation 无知识；CKA 只测表示几何相似，Logit Lens 只测当前 hidden state 经最终 LM head 能否线性读出，trained probe 又引入额外模型容量和训练争议。

例子：一个 unlearned 模型对“作者 X 写了哪本书？”回答“I don't know”。中间层 Logit Lens 也看不到书名，但把该层状态送回原始 full model 后，后续 blocks 仍能把它变换成正确书名。这说明知识不是消失，而是“当前 readout 暂时看不到”。本文的 gap 是把这种 functional recoverability 变成一个标准化、可跨 checkpoint 比较的因果 metric。

5.5 Core Insight

核心 observation：linear decodability ≠ causal recoverability。Unlearning 可能旋转、重编码或扰动 hidden state，使固定 LM head 无法直接读出知识，但原模型后半段 nonlinear computation 仍能恢复。于是作者让 M_full 充当“知道目标知识的 nonlinear decoder”，再让 M_ret 提供“真正没学过”的 gold-standard erasure anchor。

这属于经验观察 + 因果测量设计。它不声称找到唯一“知识存储位置”，而是把“如果把这个状态放回原本会使用该知识的计算图中，它还能不能被利用”定义成 operational residual。

5.6 Method Deep Dive

Forget example (x_i, entity y_i) → M_full = train(D_r ∪ D_f) → M_ret = train(D_r) → M_unl = unlearn(M_full, D_f) → teacher-force entity tokens → Stage 1: patch M_ret residual stream into M_full → compute ΔS¹ per layer → KE_i = {l | ΔS¹_i,l > τ} → Stage 2: patch M_unl residual stream into M_full → compute ΔS² → LER = clip(ΔS²/ΔS¹,0,1) → weight by ΔS¹ → UDS_i∈[0,1] → average across forget examples → meta-evaluate faithfulness / quantization / relearning robustness

Step 1 — 三模型的角色

M_full 是具备目标知识的 decoder；M_ret 是理想 retraining 参考；M_unl 是待评对象。因此 UDS 不是问“这个 hidden state 绝对像什么”，而是问它的功能状态离 retraining target 多近。

Step 2 — Entity span 与 teacher forcing

作者只 patch 真正承载事实的实体 token，避免模板词稀释信号。Teacher forcing 使每个 token 都在相同 ground-truth prefix 下比较，避免 free generation 的路径分叉。

Step 3 — Stage 1 校准知识编码强度

把 M_ret 第 l 层状态替换进 M_full。如果正确实体 log-probability 大幅下降，说明该层对这条事实有 causal contribution。若 ΔS¹ 接近 0，分母会非常噪，因此通过 τ=0.05 只保留 Knowledge-Encoding layers。

Step 4 — Stage 2 测残留

同样位置改用 M_unl 状态。若 M_unl 已像 M_ret 一样“没有知识”，ΔS²≈ΔS¹；若仍保留知识，M_full 后半段能继续恢复，ΔS²≈0。

Step 5 — 聚合

层级 LER 由 ΔS²/ΔS¹ 归一化，再按 ΔS¹ 加权。知识编码越强的层权重越高；最终 UDS=0 代表像 full 一样可恢复，UDS=1 代表达到 retraining-level erasure。

5.7 核心公式与数学直觉

ΔS¹ᵢ,ₗ = (1/Tᵢ) Σₜ [s_fullᵢ,ₜ - s_S1ᵢ,ₜ] KEᵢ = {l : ΔS¹ᵢ,ₗ > τ}, τ=0.05 ΔS²ᵢ,ₗ = (1/Tᵢ) Σₜ [s_fullᵢ,ₜ - s_S2ᵢ,ₜ] LERᵢ,ₗ = clip(ΔS²ᵢ,ₗ / ΔS¹ᵢ,ₗ, 0, 1) UDSᵢ = Σₗ ΔS¹ᵢ,ₗ·LERᵢ,ₗ / Σₗ ΔS¹ᵢ,ₗ UDS = (1/N)Σᵢ UDSᵢ

ΔS¹ 是“真正从没学过”造成的标准退化；ΔS² 是 unlearned state 造成的退化。比值直接回答：M_unl 达到了理想 deletion 的几成。clip 到 1 的好处是解释清晰，坏处是 over-unlearning 也可能被记成 1，所以 UDS 必须和 retain utility 联合看。

与 strongest white-box baseline Logit Lens 的本质区别是：Logit Lens 只做 LM_head(h_l)，而 UDS 让 M_full 的后续 nonlinear blocks 参与解码。最关键超参 τ 控制噪声层过滤；τ 太低分母不稳，太高会丢掉过多样本。

5.8 Toy Example

忘记事实：“Alice Vane 写了 Blue Orchard”。M_unl 最终回答“I don't know”。第12层 patch M_ret 后正确实体下降2.0 nats，ΔS¹=2.0；patch M_unl 仅下降0.2，ΔS²=0.2，因此 LER=0.1。也就是说最终输出虽然拒答，第12层仍保留大量可被原模型后续计算恢复的信息。如果后层 LER≈0.9，说明 suppression 可能主要发生在网络后部。加权后 UDS 可能只有0.25，直接暴露“输出成功、内部仍残留”。

5.10 Experiment Setup Deep Dive

Dataset：TOFU forget10，共400 forget QA；GPT-5.2 定位 answer entity span。
Models：Llama-3.2-1B-Instruct 为主；scale validation 还覆盖1B/3B/8B。
Faithfulness：30个训练过 D_f 的 P-pool vs 30个没训练 D_f 的 N-pool，以 AUC-ROC 区分。
Robustness：150个 unlearned models，8类方法/多组超参；做4-bit NF4 quantization与1-epoch relearning。
Metrics：20类输出/MIA/白盒指标。
Relearning：1 epoch，LR=2e-5，batch=8，grad accumulation=4，effective batch=32，AdamW。
Compute：单RTX A6000；8B UDS约184.1s，对比 Logit Lens约26s、Fisher约211.7s。

Research Questions：跨规模 calibration 是否稳定？是否更 faithful？对量化/relearning 是否稳？是否会改变 method ranking 和最佳超参？Logit Lens 与 UDS 冲突时谁更能解释 residual？

5.11 Metrics 教学式解释

Faithfulness AUC-ROC↑：区分明确“知道”和“没见过”的能力，1最好。
Quantization Robustness↑：量化前后指标应尽量稳定。
Relearning Robustness↑：同样轻量relearning后，指标变化应合理且与reference一致。
UDS↑：1表示更接近 retraining-level erasure；必须与 utility 一起读。

5.12 Results Deep Dive

  1. Scale calibration：full UDS约0.002/0.008/0.000；retain99约0.153/0.151/0.101；retain95约0.496/0.482/0.455；retain90均为1.0，随“未见目标数据比例”严格单调。
  2. Faithfulness AUC：UDS=0.971，高于 Truth Ratio 0.947、Logit Lens 0.927、Fisher 0.712、CKA 0.648。
  3. Overall meta-score：UDS=0.951，为20个指标最高；Logit Lens≈0.902。
  4. Aggregate robustness：UDS=0.932，其中 quantization≈0.968、relearning≈0.900；Logit Lens≈0.879。
  5. Truth Ratio 虽 faithfulness 0.947，但 aggregate robustness 仅约0.379，说明传统指标“会区分”不等于“适合长期评测”。
  6. 关键 disagreement case：某模型 Logit Lens aggregate≈0.801，看起来 erased；UDS≈0.209，中间层 LER 多数≤0.230，证明后续非线性计算仍能恢复。
  7. Prompt-type heterogeneity：IdkNLL 对 Yes/No UDS≈0.624，而 Person Name≈0.025、Book/Title≈0.038、Biographical≈0.049、Descriptive≈0.042。
  8. 加入 UDS 会改变 method ranking：SimNPO 与 NPO 名次交换，说明 output-only 选择 checkpoint 可能系统性错。
  9. NPO 最佳超参也发生变化：更高 LR + 更强 retain coefficient 被 UDS 选中，UDS 提升约0.199。
Strongest result：UDS 同时取得 faithfulness 0.971、robustness 0.932、overall 0.951，并能解释 Logit Lens 明显误判的案例。
Weakest / Failure：严格[0,1] calibration依赖 M_ret；Stage2-only 虽与完整UDS rank高度相关，但失去绝对“达到retraining几成”的解释。

5.14 Ablation / Mechanistic Analysis

完整 residual stream patch 比单独 attention/MLP 更稳定，说明层输出更适合作为功能性因果状态。τ sensitivity 显示0.05在噪声和覆盖率间折中；entity length 与 UDS 的相关性弱，排除了明显长度偏置。Mechanistically，UDS证明的是“状态在 M_full 后半网络中可恢复”，不是现实黑盒 attacker 必然可恢复，也不是定位到某个唯一 neuron/circuit。

5.15 Claim vs Evidence

Authors Claim：UDS是training-free、causal、稳定的unlearning-depth metric。
Experiments Actually Show：TOFU、Llama 1B–8B、150个unlearned models、8类方法上，scale calibration、faithfulness、robustness与case study均支持其价值。
What Is Not Yet Proven：尚未证明它等于真实隐私泄漏概率，也未充分验证 WMDP/MUSE/MLLMU、long-form/multi-hop、跨architecture patch alignment和纯黑盒恢复。

5.16 Contribution

  • New Metric/Protocol：UDS。
  • New Causal Evaluation Mechanism：M_full 后续网络作为 nonlinear decoder。
  • New Meta-Evaluation：faithfulness + quantization/relearning robustness。
  • New Empirical Finding：输出/MIA、线性可读性、causal erasure 可以严重不一致。
  • Engineering：Stage1 caching。

5.17 Limitation & Failure Modes

Authors' Limitation：需要 M_ret；clipping 无法区分理想删除与 over-unlearning；集中 TOFU；实体 teacher forcing 不覆盖 long-form/multi-hop。
Additional：要求模型结构/层/tokenization 对齐；M_full 是强白盒 decoder；8B 成本明显高；M_ret 的分布差异可能混入无关变化；multimodal 模块无法直接照搬。

5.18 Reproduction View

核心模块：三模型统一loader、entity-span locator、forward hook/residual patcher、teacher-forced logprob collector、Stage1 cache、LER/UDS aggregator。最小复现用 Llama-3.2-1B + TOFU 30–50 QA，做 NPO 弱/中/强三个checkpoint，优先找“output forget很好但UDS低”的模型，再加入Logit Lens复现 disagreement。

5.21 Attack / Verification Lens

Activation patching 本身就是 white-box causal recovery existence proof；UDS 可作为黑盒 probe 的 teacher label；verification 应联合 output forgetting、UDS、retain utility，并检查低UDS target是否更易 recovery。可定义 Residual Recoverability Gap：行为恢复强但普通 output leakage 低的程度。

5.22 与另外 Top Paper 的关系

UDS 看“hidden representation → target knowledge”的后续 computation path；SkillGuard 看“contaminated state → forbidden action”的未来 execution path。一个在模型内部，一个在系统外部，本质都是 residual 到危险结果是否仍然可达。

5.2 一句话定位

SkillGuard 不试图让 LLM 准确识别每一段恶意文本，而是在 untrusted output 已污染 Agent 状态后，计算从当前状态到 forbidden state 的未来能力路径，并用最小代价 restriction 切断它们。

5.3 人话版

Indirect Prompt Injection 把恶意指令藏在网页、邮件、文档等工具返回内容里。传统防御往往问“这段话是不是恶意”或“这个动作现在是否危险”。SkillGuard 把问题改写成：Agent 一旦受到污染，从当前状态出发，未来还有没有一条 tool/skill sequence 能走到禁止状态？它建立 Skill Impact Graph，给每个 skill 配参数级 steerability signature，再用 Inline Reference Monitor 在可信 harness 上强制检查。当进入 contaminated state 后，系统求 binary 或 fractional min-cut：要么移除整个 capability，要么只收紧参数 envelope。AgentDojo 实验表明，binary cut 能把大量攻击 ASR 压到 0，但 utility 损失明显；fractional-flow 能保留更多能力。不过 adaptive attacks 也证明，如果 URL/email 等参数语义等价类没有被 policy 正确 canonicalize，形式化 reachability guarantee 仍会失效。

5.4 Background & Research Gap

Prompt-level defense 如 Spotlighting 通过标记不可信数据，让模型区分 instruction/data；CaMeL 更偏信息流/能力控制；AttriGuard 通过 attribution/provenance 约束来源与动作关系。这些方法大多围绕当前 prompt 或当前 action。

SkillGuard 的 gap 是“future capability”。例如 Travel Agent 读取恶意网页，当前只是 read，但它后续可能走 read_profile→send_email 把敏感信息发给攻击者。如果只检查当前 action，仍可能漏掉多步组合路径。作者把安全对象从“动作分类”提升为“状态 reachability”。

5.5 Core Insight

危险存在于 contaminated state 与可组合 skills 共同形成的可达空间，而不只存在于某一段文本。第二个 insight 是 capability restriction 可以是参数级的：send_email 本身可能必须保留，真正危险的只是 recipient/body 的部分取值。因此引入 steerability signature，把能力删除变成 envelope tightening。

这是系统 formalization + optimization。只要 restricted graph 从当前 q 到 forbidden B 不可达，且 IRM 真正执行这些 restriction，未来 continuation 就满足给定安全属性。弱点也因此非常清楚：policy/signature/B 定义错误时，数学优化再完美也没用。

5.6 Method Deep Dive

Registered skills Σ + deployment policy → define q0, K0, Sig0 → build Skill Impact Graph G=(Q,Σ,δ,q0) → LLM proposes invocation (σ,p) → IRM pre-check: σ enabled? p inside current envelope? → execute skill → post-check output → commit event e=(σ,p,o) → q'=δ(q,e) → contamination changed? YES → compute paths q→B → binary cut / fractional / fractional-flow → update K and Sig → rebuild restricted SIG → continue only in safe reachable region

SIG 中 Q 是安全相关状态，Σ 是注册 skill，δ 是执行事件改变状态的函数。Steerability signature 对每个参数定义允许 envelope。IRM 在 harness 层而不是 LLM 层执行检查。Binary restriction 从所有 q→B 路径中选最小代价 capability cut；fractional-flow 则在完整图上联合收紧参数范围，使危险路径断开而尽量保留正常用法。

5.7 核心公式与数学直觉

IRM: σ ∈ K(q) AND ∀p_i: Valid(p_i, Sig(σ)[p_i]) Binary cut: min Σ_c w(c)(1-x_c) s.t. Σ_{c∈C(π)}(1-x_c) ≥ 1 for every π∈Π(q,B) x_c=1 retain, x_c=0 remove Fractional: min_y Σ_c w_c(y_c) s.t. Reach_{G[y]}(q) ∩ B = ∅ y_c∈[0,1]

Binary 约束要求每条危险路径至少有一个 capability 被删，因此没有完整 q→B 路径存活。w(c) 是 utility cost。Fractional 把“整把删掉”变成“收紧参数空间”。与 strongest baseline CaMeL 的差异不只是更快：CaMeL 偏 runtime data-flow / auxiliary analysis，SkillGuard 则把未来风险写成 deterministic reachability optimization，执行时不需要额外 LLM calls。

5.8 Toy Example

Travel Agent 有 get_webpage、read_profile、book_flight、send_email。恶意网页让它把护照号发往 evil@example.com。读取后 q 变 contaminated。Binary cut 可能直接删除 send_email，最安全但用户也收不到 itinerary；fractional restriction 只把 recipient envelope 收紧到 verified address，保留正常邮件。如果攻击者用 plus-tag、URL 重写或其它语义等价形式绕过 envelope，而 policy 没做 canonicalization，则 graph 看似安全、现实仍可到 forbidden state。

5.10 Experiment Setup Deep Dive

Benchmark：AgentDojo v1.2.2；从949实例中过滤文本攻击相关任务，涉及97 user tasks、929 attack instances；Workspace、Slack、Travel、Banking。
Models：Gemini 2.5 Flash、Llama-3.3-70B。
Variants：IRM Only、IRM+Binary Capability cut、IRM+Fractional-Flow Confinement。
Baselines：No Defense、Spotlighting、CaMeL、AttriGuard。
Metrics：ASR、Benign Utility、Utility under Attack、Retained Capability Ratio、TPR/FPR restriction、Average Capabilities Removed、latency、extra tokens/calls。
Adaptive stress：8个 mechanism-aware attacks，覆盖 restriction scope、enforcement timing、parameter representation robustness。

Research Questions：IRM 单独有多少价值？Binary 是否能压到近0 ASR？Flow 能否恢复 utility？相对 CaMeL/AttriGuard 成本优势多大？知道机制的 attacker 能否绕过 policy/envelope？

5.11 Metrics 教学式解释

ASR↓：攻击目标成功率，但不能单看，因为禁掉所有工具也能0。
BU↑：无攻击时正常任务成功率。
UA↑：有攻击时仍完成用户任务的能力，是安全-可用性的核心指标。
RCR↑：污染后保留多少 capability，衡量 restriction 粗不粗。
TPR/FPR：危险 capability 是否正确限制、无辜 capability 是否误限。
ACR↓：平均删掉多少工具。
Latency/tokens/calls↓：部署成本。

5.12 Results Deep Dive

  1. IRM Only：Gemini ASR 22.34→14.19%，Llama 50.83→10.37%，证明 trusted invocation validation 本身就很强。
  2. IRM+Binary：两模型增量实验中 ASR 可到0、TPR=100%，但 BU/RCR 明显下降，安全来自粗暴能力删除。
  3. IRM+FFC：Gemini ASR仍0，RCR≈93.21%，相对binary约+16.96pp；Llama RCR≈94.08%，约+14.79pp。
  4. Slack 等 domain 的 RCR 增益可超过27–30pp，说明 fractional restriction 的 utility 恢复不是 Travel 特例。
  5. Flow 安全不单调：Llama Slack ASR 从 binary 8.57→flow 14.29%，换来 RCR 大幅提高，存在明确 security-utility trade-off。
  6. Gemini compositional：SkillGuard BU≈92.27、UA≈54.55、ASR≈14.29；CaMeL≈82.27/75.00/14.00。安全上 SkillGuard 并未赢。
  7. Llama compositional：SkillGuard≈86.82/81.82/8.00，CaMeL≈87.73/71.82/17.50；ASR低约9.5pp、UA高约10pp。
  8. 成本：Gemini compositional CaMeL 延迟约178.62s、42258 extra tokens、7.36 calls；SkillGuard约13.88s、0 extra tokens/calls。
  9. Adaptive attacks：binary 阻断6/8，fractional-flow仅3/8，暴露 parameter-equivalence/canonicalization 弱点。
Strongest result：Llama compositional 中 SkillGuard 同时更低ASR、更高UA、0额外LLM calls。
Weakest：Gemini compositional 中 ASR 不优于 CaMeL，UA 也明显更低。
Failure：fractional-flow 的数学保证依赖 envelope 完整，URL/email 等价表示未覆盖就会重开危险路径。

5.13 Table / Figure Reading

Algorithm 1：pre-check→execute→post-check→commit→contamination→restriction 的时序说明它不能回滚污染识别前已经发生的危险 action，adaptive timing attack 就利用这一点。

Table 1：No Defense→IRM→Binary→Flow 清楚显示模块职责：IRM负责低成本挡显然非法动作；Binary负责强安全；Flow负责恢复 utility。

Table 2：RCR 大幅增加，但部分 ASR 变差，说明 fractional 不是“更安全”，而是把 Pareto 往保留能力方向移动。

Table 5：突出 CaMeL/AttriGuard 的辅助模型成本与 SkillGuard 的0 extra calls。

Table 7：复杂 compositional attack 下 Spotlighting 不稳定；SkillGuard在Llama最强，但Gemini没有全面胜过CaMeL。

Adaptive analysis：binary6/8 vs flow3/8说明真正瓶颈是 policy/envelope semantics，不是 min-cut solver。

5.14 Ablation / Mechanistic Analysis

IRM only 证明 local validation 能显著降低攻击但无法保证 future-path 安全；加 Binary 后 ASR 接近0但 utility/RCR下降，说明 binary 模块承担强 reachability guarantee；Binary→Flow 后 RCR 提升10–30pp，说明 steerability envelope 承担 utility recovery。Adaptive attack 又证明 envelope 本身就是安全边界，而不是无关工程细节。

5.15 Claim vs Evidence

Authors Claim：reachability-based confinement 可在 contamination 后主动限制未来 capability，且无需额外 LLM inference。
Experiments Actually Show：AgentDojo、两个模型、多suite和compositional attacks上明显降低ASR；flow通常保留更多能力；成本低；adaptive test也揭露真实弱点。
What Is Not Yet Proven：开放世界动态工具、真实browser agents、错误 skill summary/signature、自动policy生成、未知forbidden state 等尚未充分验证。

5.16 Contribution

  • New Formalization：contaminated-state→forbidden-state reachability。
  • New Mechanism：SIG + steerability signatures + IRM。
  • New Optimization：binary / fractional / fractional-flow confinement。
  • Security Guarantee：明确假设下的未来路径安全。
  • New Empirical Finding：compositional/adaptive attacks 揭示真实 policy weakness。
  • Engineering：0 extra LLM calls/tokens。

5.17 Limitation & Failure Modes

Authors' Limitation：SIG scalability、复杂 suite 有秒级 overhead、restriction 会伤 utility、需要 policy refinement。
Additional：安全性强依赖 skill summary/signature/B 正确；未写入 B 的攻击不会被处理；late enforcement 不可回滚；fractional envelope 对 canonicalization 脆弱；论文未给官方代码链接；模型只有 Gemini 2.5 Flash 和 Llama-3.3-70B。

5.21 Attack / Verification Lens

最有价值攻击不是继续堆 jailbreak 文本，而是系统探测 restriction scope、timing、parameter canonicalization。对 unlearning，可把“被删知识/skill再次使用”定义为 forbidden state，只要 memory/tool/peer 任一路径可达，就判 closure 未完成。可以定义 Minimum Residual Cut Size：彻底阻止目标能力重新出现，至少还要切断多少 carrier。

5.22 与另外 Top Paper 的关系

UDS 关注内部 representation 到目标知识的恢复路径，SkillGuard 关注系统状态到目标 capability 的执行路径。组合后可以把 representation residual → behavior → tool execution/reacquisition 连成跨层级 causal path。

Cross-Paper Synthesis

两篇共同说明：Local suppression ≠ causal closure。 UDS 问后续 Transformer 能不能从 residual representation 恢复知识；SkillGuard 问后续 skill/tool sequence 能不能从 contaminated state 到 forbidden capability。二者统一成 Residual Reachability：从当前残留状态到禁止结果是否仍存在 causal path。

最适合作 baseline：UDS。
最适合产生 attack：SkillGuard 的 scope/timing/equivalence-class adaptive probes。
最适合产生 benchmark/metric：两者组合。
