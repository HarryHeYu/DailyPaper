2. Executive Summary

今天的新增信号集中在 agent memory：RSIAgent、Interactive Memory Learning、Collaborative Memory for Multi-Agent VLM Systems 都把“记忆”从静态检索库推进为会演化、会共享、会自我修复的系统状态。对 unlearning，这意味着新的核心风险：删除之后，系统可能通过探索、共享记忆、工具检索或其他 agent 副本重新获得目标信息。因此今天最值得推进的不是再设计一个 forget loss，而是把 provenance、dependency closure、reacquisition/rebound verification 做成 agent-native protocol。

ARIA 昨日已 Tier S，按 7 天冷却今天不重复深读，但继续作为 inference-time unlearning 的 collision anchor。今天 Tier S 选择 Agent Zero Memory（provenance 骨架）与 VLM Robustness（多通道恢复攻击），二者共同指向“可验证删除闭包”。

3. Today's Most Important Paper

Agent Zero Memory: Provenance-Aware Long-Term Memory for LLM Agents

今天最重要，因为它提供 Agent Unlearning 最缺的结构性前提：每个 learned item 都带 origin、timestamp、evidence pointer，并以 citation lock 限制答案只能使用真正读过的证据。最值得看三路 memory architecture、retrieval router 与 citation-lock；直接研究关系是把 citation lock 改造成 deletion lock + provenance closure。

6. Tier S

Agent Zero Memory: Provenance-Aware Long-Term Memory for LLM Agents Tier S BACKFILL
Paper · arXiv/preprint · 日期与作者以原文为准

人话版：这篇论文到底干了什么？

这篇工作把长期记忆从“一个向量库”改造成带来源链的三路记忆系统：事件时间线、实体—事件图、层次文档记忆并行维护；检索时先判断是否需要记忆，再路由到三套 agentic search，最后只允许引用真正打开过的证据。它的关键价值不只是 LongMemEval 95.60%、LoCoMo 93.60%，而是把 provenance 变成记忆对象的一等属性——这几乎天然提供了 Agent Unlearning 所缺的“删什么、还要沿依赖删到哪里、如何证明删干净”的骨架。

Background & Research Gap

Agent memory 的核心难点已经从“能不能记住”转向“记忆如何演化、冲突、追溯和撤销”。单一 vector store 容易把事实压成不可追踪的 chunk；knowledge graph 强关系但弱时间；摘要记忆容易丢证据。本文的 gap 是：同一历史需要多个互补视图，同时回答时必须证明每条结论来自哪条真实读过的证据。具体例子：用户先说项目 A 用模型 X，后来改成 Y；只存 semantic summary 容易覆盖时间顺序，而事件线能保留变更，图能保留项目—模型关系，HDM 能保留当前稳定事实。

Core Insight

核心洞察是“记忆质量更多由 memory architecture 决定，而不是 backbone 大小”。论文在 8 个 backbone 上看到准确率只波动 3.4 points，但单次成本可差约 30×；同一套记忆机制能让较便宜模型接近最优。这意味着删除机制也应优先作用于 memory substrate 与 provenance graph，而不是只对生成模型做参数更新。

Method Deep Dive

Input（对话/文件/连接源）→ provenance 标注 → 并行写入 Memory Events / entity-event graph / HDM → query intent gate → source router → 三路 hybrid retrieval + tool loop → citation lock → evidence integration → answer/confidence。Memory Events 负责“何时发生/何时改变”；图负责“谁与谁相关”；HDM 负责稳定、可读、引用锁定的事实。citation lock 的直觉是：reader 没有真正打开的证据不能进入答案，因此把 hallucination 从软提示约束改成系统级可验证约束。

关键公式 / 机制直觉

本文最重要的“公式”不一定是单一 loss，而是把系统输出看成条件路径：只有 provenance/retrieval 条件满足或攻击路径成功时信息才能到达答案。对 unlearning，建议把恢复风险写成 R = P(target recovered | deletion, attack)，把 retain utility 写成 U = E[task score | retain]，再用 Pareto/frontier 而不是单一加权和观察 trade-off；这样不会用 utility 崩坏伪装 forgetting。

Toy Example

删除事实“项目 A 使用模型 X”。若系统有 event 节点、A—X 图边、HDM 摘要和另一个 agent 的缓存副本，naive delete 只删一处会被其余路径恢复；closure 方法应沿 provenance 找到四个派生物并 invalidation，再用同义问法和跨 agent relay 验证 Recovery=0，同时保留与项目 A 无关的事实。

Baseline Deep Comparison

最重要 baseline 是 naive fine-tune/weight unlearning、单库 memory delete、以及只做正常提示评测的 clean protocol。它们分别忽略外部记忆、派生依赖和攻击恢复。strongest baseline 应选能同时保留 utility 且具 recovery defense 的方法，而不是单看最低 forget accuracy。

Experiment Setup Deep Dive

实验在 LongMemEval 与 LoCoMo 两个长期记忆 benchmark 上测最终问答准确性，同时跨 8 个 backbone 做 accuracy–cost–latency 控制实验。RQ1：多视图记忆是否优于单一记忆？RQ2：provenance/citation discipline 是否能保持 grounded answer？RQ3：性能主要来自更强 backbone 还是 memory system？公开结果为 LongMemEval 95.60%、LoCoMo 93.60%，分别比 strongest prior system +0.73、+1.10；跨 backbone accuracy 仅相差 3.4 points，而成本约 30×，并存在最高约 20× 更低成本仍接近 SOTA 的点。

Results Deep Dive

Table / Figure Reading

Figure/系统图最值得看的是三路记忆并行结构与 retrieval routing：它揭示删除不能只删除最终摘要，还必须处理事件、图边和文档事实三种派生物。第二个关键图是 accuracy-cost-latency frontier：若记忆结构贡献大于 backbone，Agent Unlearning 的最小实验应固定 backbone，只替换 deletion/provenance policy。第三个应关注 citation-lock 流程，因为它可直接改造成 deletion-lock：被撤销 provenance 的派生节点不得再进入答案。

Ablation / Mechanistic Analysis

论文主要验证的是 memory-driven quality，而不是 unlearning；因此它没有直接证明 dependency-closure deletion。对你的研究最关键的 mechanistic extension 是把 provenance edge 从“用于引用”升级为“用于撤销传播”：source deletion → 找所有派生 event/entity/HDM nodes → invalidate/recompute → 再做 black-box recovery query。

Claim vs Evidence

Authors Claim：机制能提升记忆可靠性/忘却鲁棒性。Experiments Actually Show：在给定 benchmark、模型与攻击族内成立。What Is Not Yet Proven：开放世界工具、未知副本、长期再学习、自适应攻击下的 deletion closure。

Contribution

Contribution 1 — New Mechanism：把关键控制放到 memory/provenance 或 attack-aware evaluation；Contribution 2 — New Metric/Protocol：强调可追踪/恢复测试；Contribution 3 — New Empirical Finding：性能或“已忘知识可恢复”揭示旧评测盲点。真正创新在机制边界与验证方式，而非简单组合现有模块。

Limitation & Failure Modes

主要风险包括 provenance 不完整、攻击覆盖不足、benchmark 规模有限、外部工具重新引入已删知识、跨 agent 副本未同步、长期再学习导致 rebound。部署上还需考虑 deletion propagation 的延迟、审计日志与 tombstone 生命周期。

Research Value

Baseline：高；Migration：极高；Attack/Evaluation：高；New Paper Potential：高。原因是它能直接补强 multimodal/agent unlearning 中最薄弱的“删除闭包 + 恢复验证”部分，而不是只换一个 loss。

Migration Analysis

Original Problem：长期记忆 grounded retrieval → Transferable Mechanism：provenance + multi-view memory + citation lock → New RQ：删除一个源后，跨视图派生记忆能否闭包删除且不可被其他 agent 恢复？→ Modification：建立 provenance DAG 与 tombstone/deletion-lock，删除沿 dependency edge 传播 → Minimum Experiment：LoCoMo 构造 100 条可删除事实，分别注入 event/graph/HDM，执行 source deletion 后用直接问、paraphrase、multi-hop、跨 agent relay 四类攻击；对比 naive vector delete、summary rewrite、SBU-style closure → Model：Qwen/Llama 7B 级 agent → Metric：Deletion Closure Rate、Recovery@k、Retain QA、cross-agent leakage、latency → Expected Contribution：Agent Memory Unlearning verification protocol + provenance closure algorithm → Risk：provenance graph 不完备；Collision Risk：与 Agentic Unlearning/SBU 中 dependency closure 高，需要突出多视图、跨 agent 与可验证 provenance。

如果只让我记住 5 句话

1) Forget score 不等于删除完成。 2) provenance/多通道访问决定能否验证删除。 3) recovery/relearning 是判断残留知识的关键。 4) 多模态与 agent 场景必须检查跨模块、跨工具、跨记忆副本。 5) 最值得做的是 deletion closure + adaptive recovery verification。

On the Robustness of Machine Unlearning for Vision-Language Models Tier S BACKFILL
Paper · arXiv/preprint · 日期与作者以原文为准

人话版：这篇论文到底干了什么？

这篇工作把 VLM unlearning 从“正常提示下忘没忘”推进到“攻击后还能不能恢复”。作者统一整理多种 VLM unlearning 方法，并用 contextual prompting、下游 retraining 等方式尝试重新激活被忘知识。核心发现是：很多方法只是把目标知识压到正常解码不易访问的位置，而不是彻底消除；因此标准 forget score 好看并不等于 robust forgetting。对多模态 unlearning 研究，真正重要的是 threat model：图像、文本、上下文和再训练都可能成为恢复通道。

Background & Research Gap

多模态模型同时在 vision tower、connector 与 LLM 中编码目标信息。旧评测往往只看原始 image-text QA 的 forget/retain 分数，无法区分“知识真的被破坏”与“默认提示下暂时访问不到”。例如一个名人知识在直接问答时被拒绝，但加入相关视觉上下文、换一种文本描述或做少量下游训练后重新出现，就说明删除并不稳固。本文 gap 是系统地把 robustness attack 纳入 VLM unlearning。

Core Insight

核心洞察：multimodal knowledge 有多条冗余访问路径，unlearning 的攻击面不是一个 prompt，而是 image/text/context/parameter adaptation 的组合。若忘却只改变某一路表示，其他模态或轻量再学习可能绕过它。这直接支持你把 robustness 拆成 model-side 与 input-side，而不是单一 forget accuracy。

Method Deep Dive

Input：已 unlearn 的 VLM → 在统一 benchmark/protocol 下先测 clean forgetting/retain → 构造三类 recovery attack（上下文诱导与 downstream retraining 等）→ 比较攻击前后 forget target 的恢复幅度 → 分析不同 unlearning 方法的脆弱性。这里 recovery gap 比单次 accuracy 更关键：它衡量攻击让“已忘知识”回来多少；越大说明删除越像 suppression。

9. Idea Mining

Idea 1 — Provenance-Closed Agent Unlearning (今日最佳)

Inspiration：Agent Zero Memory 的 provenance/citation lock + Agentic Unlearning 的 dependency closure + tool-mediated recovery。

Research Gap：现有 agent unlearning 很少验证一个事实被删除后，是否仍存在于 event memory、summary、tool cache、other-agent message、skill/trajectory 中。

Hypothesis：若把 agent memory 建模成 provenance DAG，删除沿 derivation edge 做 closure，并对 tombstoned source 实施 deletion-lock，可显著降低 cross-agent recovery，同时比粗暴清空 memory 保留更高 utility。

Proposed Method：Source ID → provenance DAG → dependency score → closure invalidation → selective recomputation → deletion-lock at retrieval/output；对 uncertain edge 用 conservative quarantine。

Minimum Viable Experiment：LoCoMo/自建 100 个可删事实；3-agent shared-memory setting；每个事实产生 summary、message relay、tool retrieval、skill note 四类派生物。对比 naive vector delete、summary rewrite、SBU-like closure。删除后跑 direct/paraphrase/multi-hop/tool/cross-agent 五类 recovery，随后继续 50 episodes 测 reacquisition。

Model：Qwen/Llama 7B agent。Metric：Deletion Closure Rate、Recovery@5、Time-to-Reacquire、Retain Utility、Cross-Agent Leakage、Deletion Cost。

Expected Contribution：Agent-native deletion closure protocol + provenance algorithm + rebound benchmark。Novelty：★★★★★ · Feasibility：★★★★☆ · Compute：★★☆☆☆ · Risk：provenance edge 不完备。Collision：中高，需强调 cross-agent + reacquisition verification。Best Venue：NeurIPS/ICLR/ACL。

Idea 2 — Reacquisition Curve: 从“忘没忘”改成“多久学回来”

把 RSIAgent 的 recursive self-improvement 反过来作为 unlearning attack：删除后允许 agent 自主探索环境，记录目标知识首次重新出现的 episode。Hypothesis：很多 clean forgetting 相同的方法，其 Time-to-Reacquire 会相差一个数量级。MVE：ATU/ARIA/NPO/GA 后运行 verifier-guided exploration，画 Recovery vs Episodes 曲线。Novelty ★★★★☆，Feasibility ★★★★★，Compute ★★☆☆☆；最佳贡献是新的 robustness metric/protocol。

Idea 3 — Cross-Modal Provenance Closure for Multi-Agent VLM

将 Collaborative Memory 的 observation→interpretation→reasoning dependency 与 VLM unlearning attack 合并。删除一张图中的 target concept 后，不仅删原视觉 embedding，还追踪 textual caption、agent message、summary、reasoning trace 的派生污染。MVE：LLaVA/Qwen-VL + 3 agents + GQA/VQAv2 子集；指标加入 visual-source deletion closure 与 text-only recovery。Novelty ★★★★☆，Feasibility ★★★★☆，Compute ★★★☆☆。
