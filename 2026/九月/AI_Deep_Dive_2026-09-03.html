5.2 一句话定位

把 persistent Agent Memory 的 recall / mutation 从“系统自报成功”提升为一个经过 canonical serialization、cryptographic commitment、authorization、provenance 和独立 verifier 共同约束的 portable evidence contract。

5.3 人话版

Agent 的长期记忆会被不断修改、降权、撤销或重写。普通数据库日志只能告诉你“最后值是多少”，却很难证明是谁改的、授权是否有效、旧状态是否对应同一 identity epoch、有没有漏掉不利的 recall result、receipt 是否被伪造。MutMem V2 将一次 recall/mutation 拆成固定结构的 evidence objects，对对象内容、数量、顺序、identity、revocation、authorization、provenance 和 terminal receipt 做交叉约束。对象经过 canonical JSON 和 domain-separated SHA-256 commitment，再进入固定顺序的 Merkle tree；外部 trust anchor 不能由 bundle 自己声明。Mutation 只允许 authorized_transition、signed_noop、occurrence_observation 三类终态。独立 Node/Python verifier 在 72/72 vectors 上 verdict 和 primary reason 完全一致，production-derived corpus 42/42 conformance。对 Agent Unlearning 最有价值的是：它提供了“删除/修改声明是否可信”的证据层。

5.4 Background & Research Gap

传统 Agent Memory 更关注 retrieval utility、compression、conflict resolution。即使系统声明“这条 poisoned memory 已降权/删除”，reviewer 仍需相信生产 DB、运行时和内部对象格式。举例：权重从0.9降到0.1，无法仅从最终 row 判断 old value、actor epoch、revocation、request replay、wrong-memory mutation 或 result omission。本文填的 gap 是 portable mutation verification。

5.5 Core Insight

正确的 memory mutation 不是一个 row update，而是一组跨对象 invariant。 Reviewer 需要同时检查 canonical bytes、membership、order、trust root、identity epoch、revocation、authorization、request parity、provenance、occurrence、Merkle root 和 terminal receipt。第二个关键点是 verification、installation qualification 与 full reproduction 不能混为一谈。

5.6 Method Deep Dive

Recall request → external trust anchor → identity epoch / revocation → effective authorization → canonical request + signed receipt → decision objects → r disclosed results × 5 evidence objects → deterministic ordering → per-object SHA-256 commitment → Merkle root → bundle commitment → terminal receipt → independent Node/Python verifier Mutation → recall commitment → signed outcome → old/new weight + predecessor → authorized_transition / signed_noop / occurrence_observation → mutation commitment → verifier reconstruction

第一步将每个 evidence object 固定为 kind/schema/body，并使用 canonical JSON。第二步强制 membership completeness：固定 13 个 singleton，加上每个 result 的 5 个对象。第三步以固定顺序进入 Merkle tree。第四步使用外部 master fingerprint 破除循环自证。第五步跨对象验证 authority、admission、decision、per-result evidence 与 terminal receipt。Mutation 则明确区分真正状态变化、合法 no-op 与只记录 occurrence 的事件。

5.7 核心公式与数学直觉

o_j = H(D_o || LP4(kind_j) || LP4(schema_j) || BE4(|J(body_j)|) || J(body_j)) N_objects(r) = 13 + 5r L_i = H(0x00 || x_i) T(a,b) = H(0x01 || a || b) B = H(D_b || bundle_id || company_id || master_fingerprint || r || MerkleRoot) B_mu = H(D_mu || J(M))

N_objects(r)=13+5r 是非常强的 completeness invariant：系统不能选择性隐藏 recall result。Merkle root 绑定 membership 与 order；domain separation 防止不同类型 hash 被混用。相较 strongest baseline——V1 native signed receipts——V2 的机制性增量是把 authorization、revocation、result completeness、ordering、provenance 和 terminal 统一进可独立验证的 contract。

5.8 Toy Example

目标 memory 为“Alpha 的部署 token 是 OLDSECRET”，管理员声称将权重900→100。Reviewer 先从外部获得 trust fingerprint，再验证 actor epoch/revocation/authorization。若 recall 返回2个结果，则 bundle 必须有23个对象；若含 OLDSECRET 的第二个结果被省略，membership 直接 fail。随后 verifier 重构旧/新 weight、memory id、predecessor 和 signer epoch。如果数据库实际没发生变化却声称 transition，协议要求它只能是 signed_noop。

5.15 Claim vs Evidence

5.17 Limitation & Failure Modes

协议不证明 semantic truth、availability、confidentiality、universal robustness；external trust anchor 分发不在 scope；单作者自评仍需第三方 replication。对 Agent Unlearning 最关键的额外 limitation 是：raw memory 的 mutation receipt 并不自动覆盖 summary、embedding cache、derived fact、skill 或 cross-agent copy。

5.18 Reproduction View

5.2 一句话定位

把 Agent Harness 的 context assembly 当作权限系统，系统研究低信任 context source 如何被提升到更高 message role 或更持久 scope，并跨 session/project 长期影响 Agent。

5.3 人话版

真实 coding agent 会从 AGENTS.md、CLAUDE.md、GEMINI.md、skills、plugins、project config、global memory、环境变量、Git metadata、runtime-discovered files 等几十种来源构造 context。作者发现这些 source 的 role/scope 分配本身就是攻击面，并提出 Message-Role CPE 与 Cross-Scope CPE。CoRA 先做 LLM 辅助静态 source discovery，再在真实 model endpoint 上插入 hook，通过 random canary 确认 source 真正进入哪个 role、跨多少 scope；之后自动枚举低→高 privilege path，用两轮实验验证 persistent propagation。12 个 harness 中，GPT-5.4-mini 下 1284 条 path loaded，1028 条触发预期行为。作者还展示 RCE、global-memory propagation、PR manipulation 和 cross-agent Git attack。对 Agent Unlearning 最重要：canonical memory 只是众多 carrier 之一。

5.4 Background & Research Gap

AgentDojo/InjecAgent 等主要研究 external content→当前行为；Instruction Hierarchy、Spotlighting 等默认 role 边界本身正确。现实 harness 的底层问题是“哪些东西进入 context、以哪个 role、什么时候加载、作用于哪个 scope”。例如 project instruction 诱导 save_memory(scope=global)，一次恶意 repo 就可能污染未来所有 project。

5.5 Core Insight

Context 是 role hierarchy × source × lifecycle × scope 的权限对象，不是 flat string。每个 source 表示为 S_k=(s_k,ρ_k,σ_k)。M-CPE 发生在 ρ_b>ρ_a，X-CPE 发生在 σ_b>σ_a。静态分析无法覆盖 runtime plugin/MCP/skill discovery，所以最终必须用 endpoint canary 做确定验证。

5.6 Method Deep Dive

Harness source → locate LLM endpoint → static context-source discovery → infer candidate role/scope/lifecycle → instrument outbound model request → generate SourceEnvSpec / RuntimeSpec → insert random canary → launch isolated harness → verify role in actual request → same-project / cross-project differential runs → infer scope → enumerate low→high privilege source pairs → Round 1 propagation → remove low source → Round 2 benign prompt → Loaded? → Verified? → context manifest + attack paths + PoV

CoRA 把 LLM 只用于 candidate discovery 和环境构造，最终 source/role/scope 证据由 deterministic canary 给出。Two-round cleanup 非常关键：它确保第二轮影响来自高权限 persistent carrier，而不是原 malicious source 又被读了一次。

5.7 核心公式与数学直觉

T_i = M(C_i ; T) C_(i+1) = C_i ∪ exec(T_i ; E) S_k = (s_k, ρ_k, σ_k) M-CPE: ρ_b > ρ_a X-CPE: σ_b > σ_a for reachable S_a → S_b

C_i 是多 role context；ρ 是 message privilege；σ 是 session→project→user/global scope。和传统 IPI benchmark 相比，本文先恢复 harness 自己的 privilege map，再测 propagation，因此把攻击面从“恶意字符串”下沉到 context architecture。

5.8 Toy Example

repo/AGENTS.md 是 project scope/user role，~/.agent/memory.md 是 user scope/developer role。恶意 repo 诱导 Agent 把 instruction 保存到 global memory。第一轮后 project→user 发生 X-CPE。随后删除 AGENTS.md，打开完全不同项目，只给 benign task，global memory 仍加载并影响行为——说明原始 source 已消失，但高权限 carrier 仍持续存在。
