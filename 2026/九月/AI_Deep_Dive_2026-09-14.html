5.2 一句话定位

把“unlearning 看起来像 retraining”从经验性准确率比较升级为可证伪黑盒审计：通过猜测哪些 batch 曾进入 forget set，构造真实 unlearning 参数 ε 的数据依赖下界 εLB，直接检验最终模型是否仍暴露训练-删除历史。

5.3 人话版

很多 unlearning 方法只展示 forget accuracy 降了、retain/test accuracy 还不错，然后就说“忘掉了”；但真正 approximate unlearning 定义更强：unlearned model 的分布应该和“从没见过 forget data、只在 retain data 上 retrain”得到的模型近似不可区分。本文做的不是再提出一种 unlearning loss，而是当审计员：它随机决定候选 batch 哪些进入训练后再被要求删除，运行完整 training→unlearning，最后只看 unlearned model，尝试反推出哪些 batch 曾经出现过。如果猜测远高于随机，说明删除前训练影响仍留下可检测痕迹。作者将问题约化到 Local Differential Privacy，利用多 batch 的 balanced sign vector 和 overlap statistic 推出 ε 的下界。结果非常尖锐：真正有适用证明的 Model Clipping 与 Rewind-to-Delete 没被 auditor 明显推翻；而 Hessian、IDA、forget-set ascent、retain fine-tuning 等经验方法可出现几十乃至 142.5 的 εLB。传统 R/F/T accuracy 可能看起来相似，却对应完全不同的 ε 审计结果。

5.4 Background & Research Gap

严格 unlearning 的参考不是“模型不回答”，而是 omission retraining。近似 certified unlearning 常用 (ε,δ)-indistinguishability 表达 unlearned model 与 retain-only reference 的分布距离。问题在于，大量深度网络方法只有 heuristic metrics；普通 MIA 又只判断单点是否在训练集中，不能直接审计“任意 forget subset 删除后都应接近 retrain”的 group-level guarantee。

具体例子：Hessian-based method 的 certification 建立在 convex loss 前提上。若直接搬到 CIFAR-100 非凸 CNN，forget/test 指标仍可能看起来正常，但本文审计得到 uniform split εLB=142.5。研究 gap 因此是：设计一个能对 certified claim 做 falsification 的 auditor，而且输出和 guarantee 同量纲的 ε lower bound。

5.5 Core Insight

Stored behavior不是唯一证据：审计应问“还能否辨认训练-删除历史”。
Subset deletion更像group privacy：因此一次随机选择多个candidate forget batches。
Balanced sign vector：把每轮真实forget subset编码成S，auditor从最终模型反推S。
强unlearning⇒近似LDP channel：若每个S产生的unlearned model都接近同一reference，则S→prediction不能泄露太多。
低lower bound不是成功证明：只能说当前auditor没falsify。

5.6 Method Deep Dive

Dataset D → choose retain set D_r → partition candidate forget pool into m batches → sample balanced sign vector S∈{−1,+1}^m → +1 batches enter training and are later forgotten → run training A → run unlearning U → obtain f_u(S) Calibration: → Γ runs with known S → collect per-example confidence/logit scores → fit included vs excluded likelihoods Audit: → predict Ŝ from new f_u(S) → Instantiation I: batchwise inclusion/exclusion → Instantiation II: joint sign-vector hypothesis → select top-r confident coordinates → compute overlap V(S,Ŝ) → aggregate over L runs → hypothesis test → output ε_LB

大m时联合枚举不可行，用batchwise likelihood；小m时可枚举balanced sign-vector并利用batch间相关性。support r允许auditor对低置信坐标 abstain。核心不是训练一个更强分类器，而是把“预测sign-vector的成功程度”转成有Type-I error控制的ε下界。

5.7 核心公式与数学直觉

Certified unlearning: U(A(D),D,D_f) ≈_(ε,δ) A_bar(D_r) S_m={s∈{±1}^m : #(-1)-#(+1)∈{0,1}} D_f(S)=⋃_{j:S_j=+1} D_{f,j} f_u(S)=U(A(D_r∪D_f(S)), D_r∪D_f(S), D_f(S)) Key reduction for δ=0: certified (ε,0)-unlearning ⇒ auditor mechanism M:S→Ŝ is (2ε,0)-LDP Goal: reject H0: ε ≤ ε_LB at ζ=0.05

2ε来源：S1产生的model ε-close reference，S2也ε-close；transitivity给S1与S2最多2ε。Auditor只是post-processing，因此也受同一LDP限制。m与B：m=|D_f|/B；m大时最大attainable lower bound更高，但每batch信号更弱。r：过小证据bits不足，过大迫使低置信预测进入，实测呈inverted-U。δ限制：δ>0时transitivity引入额外slack，主理论因此集中δ=0。

5.8 Toy Example

  1. 6个candidate forget batches b1…b6。
  2. 随机S=(+1,-1,+1,-1,+1,-1)。
  3. b1/b3/b5先参与训练，随后被unlearn；其余从未出现。
  4. 若unlearning接近omit retrain，两类batch在最终model上的score应难以区分。
  5. Auditor却发现b1/b3/b5的logit score分布系统不同。
  6. 它预测Ŝ并算overlap。
  7. 若多次run持续远高于随机，就能排除很小的ε。
  8. 即使forget accuracy已经“像忘了”，细粒度confidence仍可能暴露训练影响。

5.11 Metrics 教学式解释

ε_LB ↑：表示auditor能证明真实ε至少这么大；不是性能分数。对声称小ε的方法，大lower bound是直接反证。
Overlap V：预测sign与真实sign匹配数，高于随机r/2越稳定，说明training/deletion history越可区分。
R/F/T accuracy：只看任务行为，不等价distributional deletion。
Uniform/Adversarial：测试forget/retain语义支持是否重叠，不能把二者数字直接当同难度。

5.12 Results Deep Dive

  1. Hessian/CIFAR uniform ε_LB=142.5，是最强falsification。
  2. 同一Hessian在adversarial split只有10，表明feature support显著影响auditability。
  3. IDA q=1/2/4时uniform约100.5/100/95.5；adversarial 0/18/66。
  4. Retain FT在CIFAR uniform81.5、adversarial84。
  5. Forget Ascent在CIFAR79.5/86，但Shakespeare仅0.17，明显dataset-specific。
  6. Shakespeare IDA从λ=0.5,E_f=4的13.15降到λ=1.5,E_f=7的0.17，说明更强forget pressure会降低可审计残留。
  7. CIFAR IDA q=1的R/F/T约0.91/0.59/0.54，但ε_LB=100.5，展示surface metric与distributional audit严重脱钩。
  8. Convex Perturbed Newton target ε从5到800时joint lower bound从约0.014升到9.416；Output Perturbation target ε=100时lower bound约11.104，方向正确但仍loose。
Strongest result：非凸CIFAR上的Hessian ε_LB=142.5，直接抓住“theorem前提失效但方法仍被当certified-style使用”的风险。
Weakest：certified deep methods上lower bound很松；没抓到不等于实际ε小。
Failure：Forget Ascent跨Shakespeare/CIFAR差异巨大，说明audit power与dataset geometry纠缠。

5.14 Ablation / Mechanistic Analysis

Pairwise→multi-batch：联合猜多个删除事件提高最大可证明ε。
B sensitivity：heuristic强signal适合小B；certified弱signal需大B。
r sensitivity：abstain能力和统计证据量之间有trade-off。
Mean vs median：结论稳定。
Uniform vs adversarial：uniform通常更易暴露残留；作者将其与shared feature support联系，但这仍是经验解释。

5.15 Claim vs Evidence

Authors Claim：可通过subset-level membership inference得到unlearning ε的可证伪lower bound。
Actually Show：heuristic与错误外推certification的方法出现很大bound，而真正certified controls没有被错误falsify。
Not Proven：ε_LB不tight；δ>0仍难；没有LLM-scale；低bound不能证明成功。

5.2 一句话定位

MUTE先把Multi-Agent policy在“全通信”条件下训练好，再用Counterfactual Message Value识别对joint return不重要的message，并通过L1 communication suppression + per-agent Behavioral Anchoring逐步“忘掉”冗余消息，从而把通信稀疏化问题改成一个return-preserving后处理。

5.3 人话版

过去MARL稀疏通信通常从一开始就同时学两件事：既要学会合作，又要尽量少说话。这样很容易出现目标冲突——为了省带宽，Agent在还没学会协调时就把关键消息关掉；或者用Mutual Information挑“信息量大”的消息，却不保证这些消息真的提高team return。MUTE反过来：先完全不限制通信，把全通信policy训练到收敛；再问“每条消息被拿掉时，joint Q-value会损失多少？”作者把这个量叫Counterfactual Message Value（CMV），再训练一个attention-based Message Value Estimator快速预测每条message的边际价值。低于adaptive threshold的消息进入redundant set，只对这些message generator施加L1稀疏压力；同时用Behavioral Anchoring约束每个Agent的Q_i不要偏离冻结teacher Q_i*。实验覆盖Hallway、Traffic Junction、SMAC/SMAC-Communication、SMACv2等10个场景：Hallway通信减少99%仍100%胜率；MMM2在不到5%通信下达到full-communication MASIA约94%的性能，并在80%额外message dropout时仍约90%胜率。最关键ablation是去Anchoring后胜率会从约95%直接跌到30%以下；去MVE后同等稀疏度只能约50%，而完整MUTE仍约80%。

5.4 Background & Research Gap

partial observability使communication很有价值，但带宽成本要求稀疏。IC3Net类gating、TarMAC/MAIC类attention、NDQ/IMAC类MI regularization往往在训练初期就同时优化“任务return”和“通信成本”，因此可能过早抑制关键message。更关键的是 informative≠return-critical：某条消息可能显著改变receiver动作，却让团队收益更差。SMS用Shapley message value更接近return，但精确计算指数复杂、采样方差高。MUTE的gap是：先学好完整协作，再基于counterfactual return value后处理掉冗余communication。

5.5 Core Insight

先学合作，再学沉默。
消息价值应定义在joint return而不是信息量。
价值依赖其它messages，因此MVE输入joint message set。
稀疏化必须配合Behavioral Anchoring，否则Agent角色会漂移。
L1是连续抑制而非不可逆erase，低价值message若后续重新变重要仍可revive。

5.6 Method Deep Dive

Phase 1 — full-communication MARL τ_i → message generator f_ψ(τ_i) → unrestricted exchange → train MASIA/Q_tot by TD loss for 2M steps → freeze teacher Q_i*,Q_tot* Phase 2 — MVE for each message m_i: → mask m_i for all receivers → resample teammates' actions → evaluate Q_tot* difference → CMV target ΔQ_i → train attention MVE V_φ(m_1,...,m_N) → 0.5M steps Phase 3 — communication unlearning → predict message values → M_red={m_i | V_i ≤ λ μ_MVE} → L_sparse=Σ||m_i||_1 → L_anchor=Σ||Q_i*−Q_i||² → L=L_sparse+βL_anchor → optimize θ,ψ for 1.5M steps → sparse decentralized policy

Phase1故意不做带宽约束。Phase2的sender自身action固定，只重采样其它agents在message被mask后的动作，再用冻结Q_tot*评估差值。Phase3不硬删除message，而是训练sender逐步输出接近0的低价值latent。Behavioral Anchoring在individual Q_i层保持角色稳定，而不是只保全局Q_tot。

5.7 核心公式与数学直觉

Base TD: L(θ)=E[(y_tot-Q_tot(τ,a;θ))²] Return-preserving objective: min_π E[Σ_tΣ_i C(m_i^t)] s.t. J(π*)-J(π)≤ε CMV: ΔQ_i=Q_tot*(τ,a)-Q_tot*(τ,ã) ã=(a_i, ã_-i) ã_-i~π*_-i(.|τ_-i,m\{m_i}) M_red={m_i | V_φ(m)_i≤λ μ_MVE} L_sparse=Σ_{m∈M_red}||m||_1 L_anchor=Σ_i||Q_i*−Q_i||² L=L_sparse+βL_anchor β=10, λ=1.0

CMV：类似COMA的counterfactual advantage，但对象从action变成message。λ：越大删得更激进；theorem里的return bound也随λ和|M_red|增加。β：越大越保teacher behavior，return更稳但可能难以稀疏。Theorem 4.2：在MVE误差≤δ、Q approximation误差≤ε等假设下，return gap由1/(1−γ)放大的估计误差、被删message数量与message norm项控制；因此不是无条件保证。

5.8 Toy Example

  1. 三个交通Agent接近十字路口。
  2. A发“我在左侧准备通过”，但B从自己观测和C消息已足够判断刹车。
  3. mask A后B/C动作几乎不变，joint Q也不变，CMV≈0。
  4. C发“我已经进入路口”，mask后B会错误加速撞车，CMV很高。
  5. MVE学会第一类message通常冗余、第二类关键。
  6. Phase3只对低CMV message施加L1。
  7. Q_i anchor保证B原有right-of-way策略不漂移。
  8. 最终A在冗余状态学会发空message，而关键状态仍保留通信。

MAPPO/QMIX无显式通信0带宽partial observability缺信息保留极少关键message

Strongest baseline：机制上SMS最接近；性能参考上MASIA最关键。MUTE目标是接近MASIA return但通信远低于SMS/attention方法。

5.10 Experiment Setup Deep Dive

Backbone：MASIA value-based CTDE，sender加Linear message generator d_obs→d_obs。
Benchmarks：Hallway/Hallway Group；Traffic Junction Medium/Hard；SMAC MMM2、Corridor；SMAC-Communication 1o_10b_vs_1r、1o_2r_vs_4r；SMACv2 Zerg/Terran 10v10，共10场景。
Training：2M pretrain +0.5M MVE +1.5M unlearning=4M；baselines同样4M。
MVE：500k steps，hidden64，4 heads。
Unlearning：λ=1，β=10，Adam。
Seeds：5，95% CI。
Research Question：RQ1是否降带宽不掉return？RQ2保留下来的message是否真正关键？RQ3 MVE与Anchoring是否必要？

5.11 Metrics 教学式解释

Communication Rate ↓：实际通信比例；不能单独看，因为全沉默也能到0%。
Win Rate ↑：任务成功率。
W_norm ↑：相对无通信与full-communication参考归一化，≥1表示达到或超过full-comm参考。
Dropout–WinRate AUC ↑：训练后继续随机drop保留messages，看win rate曲线面积；越高说明保留下来的通信更value-dense、更robust。

5.12 Results Deep Dive

  1. Hallway：MUTE与MASIA都100% win，MUTE通信减少约99%。
  2. Hallway Group：约100% win，通信减少约90%。
  3. TJ/TJ Hard：通信约5%，TJ Hard匹配最优win rate。
  4. MMM2：<5%通信达到full-comm MASIA约94%性能；TarMAC/SMS还需40–60%带宽。
  5. Corridor：4M win约73%，接近MAPPO77%，MUTE通信约1%。
  6. Zerg10v10：MUTE55% vs MASIA49%，通信约2%，说明稀疏化有时还像regularization。
  7. MMM2 dropout AUC：0.808 vs SMS0.191，超过4倍；80%额外dropout时仍约90%win。
  8. Hallway AUC：0.554 vs MAIC0.178。
  9. w/o Anchoring：win约95%→30%以下。
  10. w/o MVE：同等稀疏下完整MUTE约80%，随机选择约50%。
  11. State+message MVE：Hallway win0.96 vs0.97，但comm0.14 vs0.02，显式state无性能收益且更难稀疏。
Strongest result：MMM2 AUC0.808 vs0.191 + 80% dropout仍约90%win，最能证明保留message确实更return-critical。
Weakest：SMACv2部分setting其它baseline在4M可更高；随机环境减弱通信优势。
Failure / terminology：MUTE不是严格dataset influence erasure；L1允许message revive，更接近communication sparsification/suppression。

5.13 Table / Figure Reading

Figure1：从头限制通信会明显伤performance，支撑“先合作后沉默”。
Figure2：10 benchmark training curves，重点看2M teacher性能和2.5M后unlearning是否保持。
Figure3 + Table2：dropout stress test；10个benchmark MUTE AUC全部第一，是selectivity最强证据。
Figure4：w/o Anchor与w/o MVE核心ablation，分别隔离“保策略”和“选消息”。

5.14 Ablation / Mechanistic Analysis

去Anchoring：灾难性collapse，说明L1不能自动把协作知识迁到local policy。
去MVE：随机删同等比例message明显掉分，说明CMV ranking有效。
加global state：没提高win，反而多通信。
Duplicate messages：两条冗余有用消息单删CMV都可能近0，是典型LOO blind spot；作者认为联合优化会破坏对称并留下一条，但高阶synergy仍是潜在风险。
λ/β：分别承担删得多激进与保teacher多强。

5.15 Claim vs Evidence

Authors Claim：把communication reduction改写为value-guided unlearning，可在return约束下删除冗余message。
Actually Show：多环境中带宽显著下降；dropout AUC、MVE/Anchor ablation支持核心机制；theorem在bounded-error假设下成立。
Not Proven：没有证明message信息从参数中真正忘掉；one-message CMV不是完整coalitional contribution；没有LLM language agents和adaptive attacker。

5.16 Contribution

  • New Mechanism：Counterfactual Message Value。
  • New System：full-communication→MVE→communication unlearning三阶段。
  • New Objective：L1 sparsity + per-agent Behavioral Anchoring。
  • New Theory：bounded-error下return degradation upper bound。
  • New Evaluation Protocol：dropout–win-rate AUC。
  • New Empirical Finding：多个场景80–99%通信削减而保持return。

5.17 Limitation & Failure Modes

Authors'：理论依赖bounded estimation errors；SMACv2随机性强时收益减弱；训练仍需4M steps。
Additional：unlearning术语与data deletion混淆；依赖可用Q_tot*；CMV一次mask一条message，对高阶synergy有风险；无隐私reconstruction attack；低communication不等于敏感信息不可恢复。

5.20 Migration Analysis

Original Problem →MARL latent message通信太多。

5.21 Attack / Verification Lens

可定义 Return-Critical Residual Rate：被系统标成redundant的messages中，counterfactual删除后实际造成显著return loss的比例。对真正隐私删除还应再测message reconstruction / identity recovery，不能只看“现在少发了”。

5.22 与另外 Top Paper 的关系

Auditing论文强调“删除影响是否仍可区分”，MUTE强调“删除后return是否保持”。组合后最自然的是 Return-Preserving + Influence-Audited Communication Deletion：先用CMV找可删项，再用ε-style auditor验证被删message/identity真的无法从最终系统恢复。

5.23 如果只让我记住这篇论文

  1. MUTE先全通信学好协作，再删除冗余通信。
  2. informative message不一定return-critical。
  3. CMV通过mask一条message后joint Q变化估计价值。
  4. MVE快速预测每条message CMV。
  5. 低价值message才被L1压缩。
  6. Behavioral Anchoring让每个Agent Q_i贴近teacher。
  7. Hallway通信可降约99%仍100%胜率。
  8. MMM2 dropout AUC0.808，SMS只有0.191。
  9. 去Anchoring约95%→30%以下，去MVE约80%→50%。
  10. 它更像return-preserving communication sparsification，而不是严格dataset machine unlearning。
