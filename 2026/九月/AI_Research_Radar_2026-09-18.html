6. Tier S

S1. Disentangling Long-Term Memory via Latent Neuro-Symbolic Reasoning

基本信息：Cai Ke 等，2026-09-16，arXiv:2609.18461；全文 Method/Experiment/Appendix 可访问。

人话版：这篇论文到底干了什么？

长期 Agent 的记忆通常有两个麻烦：一个事实一条 memory 太碎，隐式偏好可能散落在几十次交互里；GraphRAG 一类静态图又提前决定了边，但不同 query 需要的关系并不一样。LGM 把每段历史映射到隐藏表示，再用 sparse autoencoder 拆成稀疏概念；query 到来后才动态决定哪些概念/节点互相连接，再用 GNN 聚合成少量 latent prefix tokens。它把 memory 从“文本记录”推进到“可分解、可干预的 latent concept graph”，天然提供了 Agent Memory Unlearning 的细粒度删除对象。

Background & Gap

Flat RAG 给每条历史独立打相似度，难组合分散证据；MemoryBank/Mem0/A-Mem/MemoryOS 会摘要、连接或调度，但底层仍主要是离散文本；RL memory manager 更偏 read/write policy。本文问的是 memory representation 本身能否 differentiable，并随 query 动态组织。例如用户从未说“乳糖不耐”，却反复选择无乳制品食物：任何单条证据都弱，多条行为合起来才形成稳定偏好。

Core Insight & Method

History + Query → hidden nodes z → SAE sparse concepts c → query-conditioned latent graph → GNN → evidence reconstruction → latent prefix → LLM response。核心式 c_x=S(ReLU(W_enc z_x)), z_hat=W_dec c_x；S 抑制弱 activation，使 concept code 稀疏。query-conditioned edge 决定当前问题下哪些 memory 应组合；evidence-reconstruction objective 防止 latent prefix 压缩成模型无法使用的信号。

Toy Example

历史 A“不吃奶油意面”、B“沙拉更符合饮食需求”、C“芝士蛋糕好看但还是不吃”。Query“推荐 indulgent dessert”。文本相似检索可能抓到“芝士蛋糕”；SAE 则可让 A/B/C 的共同无乳制品 concept 激活并被图传播。若随后 revoke 该健康偏好，concept activation、相关 edge 和派生 prefix 都应成为 deletion target，而不只是删某一条文本。

Baseline Deep Comparison

Qwen2.5-7B 上 LGM 平均 72.28，strongest baseline MemCoE 61.08，绝对 +11.20；Gemma3-4B 为 66.16 vs 54.46，+11.70。Long Context/Naive RAG 说明全塞上下文或独立检索不足；GraphRAG/HippoRAG 说明静态结构不足；MemCoE/Memory-R1 是最重要的 agentic/RL memory 对照。

Experiment Setup

PersonaMem、PrefEval、PersonaMem-v2 implicit；32K/128K 历史。PersonaMem 有 180+ simulated histories、最多 60 sessions；PrefEval 有 3,000 人工偏好、20 topics，并区分 explicit/implicit。Backbones 包括 Qwen2.5-7B、Gemma3-4B，另有 Qwen3-4B 与闭源模型比较。主指标 Accuracy，并分析 LLM calls、tokens、TTFT、latent token budget 与 ablation。

Results / Table / Figure / Ablation

Table 1：Qwen2.5-7B PersonaMem-128K，LGM 65.00，MemCoE 47.24；长历史收益不是小幅 reranking。Table 2：PersonaMem-v2 implicit，Qwen3-4B LGM 32K/128K=62.9/51.9；GPT-5-Chat=45.6/41.4；同 4B agentic-memory SOTA=55.2（32K），LGM +7.7。Figure 3：latent state 避免 replay raw history，位于 token/latency 低成本前沿。Figure 6：latent prefix 约 16 tokens 达峰值，更多 token 饱和甚至略降。Figure 4：去 SAE/GNN/Reconstruct 都下降，其中去 evidence reconstruction 对 implicit preference 最伤，支持 grounding 是关键。

Claim vs Evidence / Contribution

证据支持“latent neuro-symbolic memory 能组合分布式显式/隐式证据”；尚未证明 SAE concept 稳定对应可解释语义，也没证明删除 concept 能消除全部行为影响。贡献：New Mechanism SAE concept + query-conditioned graph；New Objective evidence reconstruction；New Empirical Finding 隐式偏好与 128K 历史收益尤其大。

Limitation & Migration

SAE feature 可能共享/纠缠，直接 mask 会 collateral damage；paraphrase 可能重建关系；没有 revoke、privacy、recovery attack。Migration：history→SAE attribution，分 forget-exclusive/shared concepts；优化 concept suppression + retain reconstruction + edge closure。MVE：Qwen2.5-7B，PersonaMem/PrefEval 100 个 revoke cases；baseline text-delete/node-delete/full rebuild；metric direct leakage、implicit recovery、retain accuracy、concept reactivation、paraphrase attack。Collision Risk：中高。

如果只记 5 句话

  1. Agent memory 可从文本条目升级为 sparse latent concepts。
  2. 关系应按 query 动态生成。
  3. 隐式偏好最能体现机制价值。
  4. concept/edge 是 fine-grained deletion target。
  5. mask feature 不是 deletion，必须做 recovery/closure。
S2. Infinite-Parameter LLMs: Generating and Adapting Weights from Live Data

基本信息：Jinli Hu、Ross M. Clarke、Yichuan Zhang、José Miguel Hernández-Lobato；2026-09-16；Qwen3-8B frozen base；全文可访问。

人话版

它问：用户运行时给模型的新知识，为什么一定要放 prompt/RAG？能不能临时编译进权重？作者让 generator 把 live data 变成 low-rank FFN weight modulation；session 继续时，不固定一次 adapter，而是更新 latent code belief。知识可跨 turn 持久化又不占 context。对 unlearning 来说，这直接把边界推到 runtime-written parametric memory：删除请求不能只清 vector DB，还可能要撤销运行时生成的权重。

Background / Core Insight / Formula

MoE expert bank 部署后静态；RAG/ICL 每次重新读文本；one-shot hypernetwork 一次读完后冻结。有效 FFN 可写作 W_eff=W_base+ΔW(z)，ΔW 是 generator 根据 latent code 产生的 low-rank delta。关键是 z 是 belief/posterior 而非固定点；不确定时更可塑，确信时更稳定，process noise 提供重新开放 plasticity 的“forgetting”。

Method

Live evidence → encoder → code/belief → low-rank generator → FFN ΔW → frozen transformer → later observations update belief → regenerate weights。Attention/sequence mixing frozen；跨 step state 位于 FFN-side belief。当前实验主要是 categorical belief，更完整 continuous-Gaussian calibration 留作未来工作。

Toy Example

用户说“Orion 端口 7812”。系统把 evidence 编译成 code/ΔW；下一 turn prompt 不再含原句仍能回答。若用户 revoke Orion，传统 memory delete 无效，因为有效参数可能仍由旧 code 生成。真正删除要撤销 posterior mass/ΔW，并验证后续 evidence 是否能重新激活。

Experiment / Results

Datasets：SQuAD、MS MARCO v2.1、HotpotQA、2WikiMultihopQA、MuSiQue；通常 n=150。Baseline：closed-book、ICL、one-shot data-to-weights；routing 对比 random、BM25、bge-small dense retrieval、oracle。

Table 4：SQuAD ICL 85.3 > data-to-weights 51.8，明确不是所有 evidence 都该写权重；MS MARCO 48.0 > 33.6，MuSiQue 45.3 > 40.9，长/噪/multi-hop 出现 crossover。Figure 5：3000-token、无 truncation 时，8→32 distractors 的 oracle F1 51.6→46.9，fixed code 自身会 saturation；1300-token realistic 32 passages 因 100% truncation 跌至 27.8。Table 5：trained activation router：MS MARCO 53.3 vs dense 45.3；2Wiki 70.1 vs 58.1；MuSiQue 53.0 vs 40.9。Table 6：64 passages，single big read 27.8 vs selector 47.6。

Claim vs Evidence / Contribution / Limitation

证据支持 live evidence 可写入 generated weights 且长噪 evidence 有优势；但完整 Bayesian implementation 未证明，generator 沿用 prior work，training details 部分不在本文。贡献是 live-data generated low-rank expert + online belief 的 coupling，而不是“无限知识”。

Migration

给每个 code 绑定 provenance/revocation epoch；delete 时 posterior mass 清零并生成 counter-delta。MVE：顺序写 50 facts，随机 revoke 10；baseline prompt delete/code drop/adapter reset/rebuild；metric residual F1、retain、multi-hop recovery、relearn steps。预期方向：Runtime Parametric Memory Unlearning。Risk：code mixing；Collision：低中。

5 句话

  1. 运行时知识可以编译进 low-rank 权重。
  2. Agent memory 因而不再等同外部数据库。
  3. 长噪多跳 evidence 是优势区间。
  4. code saturation/routing 是关键 failure mode。
  5. 删除必须覆盖 runtime-generated parametric state。
S3. AgentLSD: Evaluating AI Security Agents Under Adversarial Task Contamination

基本信息：Matteo Golinelli 等；University of Trento / University of Turin / Politecnico di Torino；2026-09-16；代码/raw traces 公开。

人话版

Prompt injection 假设攻击者给恶意指令，但真实环境还有假的成功标志、假 endpoint、看似权威却错误的证据。AgentLSD 固定同一 CTF 与正确解法，只往环境加 trap，比较 clean/trap paired runs，并记录 honeytoken、turn、reasoning tokens、decoy interaction。对 Agent Unlearning，它是很强的恢复攻击模板：删除 memory 后，只放与旧知识相关的非指令线索，能否把被删行为重新诱导出来？

Method / Threat Model

clean CTF → YAML trap primitive → deterministic instance → middleware injection → agent trajectory → telemetry/honeytoken → paired comparison。五类 trap：goal hijack、false authority、false validation、exploration bait、time sink。攻击者 static/model-agnostic，不改模型、prompt、tools/runtime，任务 vulnerability/flag/solution path 保持不变。

Experiment Setup

11 web CTF、7 vulnerability classes；5 on-prem + GPT-5；605 clean trials；trap phase 3,061 trials，14 DOM instances、5 families、两个 prompts、通常每 cell 5 trials。统一 OpenCode scaffold、temperature 0。on-prem 包括 Gemma-4 31B、DeepSeek-V4 Flash、GPT-OSS 120B、Qwen3-Coder-Next、Mistral Small 4。

Results / Figures

clean flag capture 41%。成功通常 10–30 turns、1–3k reasoning tokens；失败 median 约 55–80 turns、5–15k tokens，极端 200 turns/30k。Figure 3：trap 即使最终成功，也普遍增加 effort；摘要给出约 +20 turns、+2k reasoning tokens。Figure 4：goal hijack/exploration bait 最危险，GPT-OSS clean solves median loss 约 50–65%；false authority 对 outcome 较小但仍增加 effort。Figure 5：Gemma 较稳，DeepSeek-V4 更明显受影响，说明 clean capability ≠ deception robustness。

Claim vs Evidence / Contribution

factorial trap-family × model × challenge 分析支持“非指令环境证据能系统性改变 trajectory”。贡献：New Threat Model adversarial task contamination；New Benchmark/System paired traps；New Protocol solve + effort + telemetry。尚未覆盖 adaptive attacker、视觉 channel、persistent memory contamination。

Migration

把 trap payload 改成 forget-knowledge partial cue、old tool signature、decoy evidence。MVE：unlearn 100 facts/skills 后做 clean vs trap paired tasks；baseline GA/NPO/robust representation methods；metric recovery ASR、turn/token overhead、honeytoken hit、retain utility。关键风险是区分“重新推理得到答案”和“残留 memory 被 elicitation”。

5 句话

  1. Agent 攻击不需要恶意指令，假证据就够。
  2. paired clean/trap 是干净的因果评估设计。
  3. turn/token effort 是重要 robustness 指标。
  4. 可直接改造成 environmental recovery attack。
  5. 下一步应加入 persistent memory 与 adaptive attacker。

7. Tier A

A1. Causal-History Test-Time Scaling for Failure Recovery in Autoregressive World-Action Models

人话版：training-free 地修改 causal history：检测 non-progress，找可靠 prefix，重建 causal KV state，再比较 complete/recovered/reset 三种 continuation。原问题是 robot WAM failure recovery，但机制几乎可以直接迁移 Trajectory Unlearning。

Method：Progress-Aware Recovery Trigger → History-Prefix Recovery → Hypothesis Verification。实验覆盖 simulated + real manipulation，作者报告一致成功率提升，并用 ablation 验证三阶段贡献。

Research Value：把“删整个 history”改成“定位不可信 suffix 并重建 KV”。Minimum Experiment：把 failure suffix 换 revoked trajectory suffix，比较 full reset、prefix surgery、KV selective erase；metric deleted-action reuse + task utility。Worth Deep Reading: YES。

A2. HPOQuest: A Rare-Disease Diagnostic Agent Using Active Phenotype Acquisition

人话版：training-free sequential acquisition：维护概率 disease ranking，主动问最有信息量的 follow-up。四 cohort 中 sparse initial phenotype 的 Recall@1 最多 +30 points、Recall@5 最多 +45。

Migration：它提供很好的 reacquisition threat model：删除 phenotype 后，Agent 会不会主动问回来？MVE：revoke 一条 fact 后允许继续 active querying，记录多少 questions 恢复该 fact；把 reacquisition budget 纳入 deletion closure。Worth Deep Reading: YES。

A3. Beyond Truncation: Rethinking LLM Decoding as Ensemble Pruning

仅根据可获取信息总结。ME-Decoding 用 Mahalanobis geometry 与 token similarity matrix，在 decoding 时保留高概率同时减少语义冗余，是 inference-time token intervention。可迁移为 forget-related token direction penalty，做 training-free decoding suppression/unlearning；但必须与 logit-offset、activation steering 对照，并明确这更接近 inference-time suppression 而非 dataset deletion。Worth Deep Reading: MAYBE。

A4. ReDIL-GNN

人话版：domain-incremental adaptation + pre-adaptation Resynthesis Adaptability Index，把 adaptation need、recoverability、coverage、update compatibility 合并。领域虽是 circuit GNN，但“先判断该不该更新”可迁移 continual unlearning request routing。

MVE：构造 Unlearning Adaptability Index：请求影响范围、retain overlap、recoverability、module compatibility；预测该用 inference-time、LoRA 还是 full update。Worth Deep Reading: MAYBE。

8. Tier B

B1. Position: The Term “Machine Unlearning” Is Overused in LLMs — BACKFILL

把 dataset-defined deletion 与 suppression/editing/alignment 分开，强调 retraining-equivalence 与 derived capability。对 Agent Memory Unlearning 的写作很重要：如果只是删外部 store，应明确 guarantee 是 store deletion、behavioral non-use、provenance closure 还是 retraining-equivalence。Potential Use: Related Work / Claim Audit。

B2. Unlearning Isn't Deletion — BACKFILL

PCA/CKA/Fisher 等 representation diagnostics 揭示 token-level forgetting 可能快速恢复。Connection：把今天 LGM 的 concept reactivation 与 runtime ΔW recovery 放进 representation/relearning audit。Potential Use: Evaluation / Robustness baseline。

B3. GRPO Privacy Is at Risk — BACKFILL

DIBA 从 correctness gain + policy/logit drift 做 RLVR membership inference，摘要报告约 0.8 AUC，并覆盖 black-box/VLM。可迁移到 RL-based unlearning verification：不是只看答案记忆，而看行为 policy 是否仍携带训练影响。Potential Use: MIA / Verification。

B4. (Token-Level) InfoRMIA — BACKFILL

把 sequence-level MIA 下钻到 token，定位具体 memorized tokens；与 Token Attribution × Unlearning 高度一致。Potential Use: Evaluation / exact unlearning / token localization。

9. Idea Mining

Idea 1 — Concept-Closure Unlearning for Agent Memory

Inspiration：LGM。Gap：record/store deletion 无法处理同一隐式偏好分散在多条 history、又通过 latent concept + dynamic edge 重构。Hypothesis：只删文本会被剩余弱证据重新组合；selective concept/edge erase + retain reconstruction 能降低 implicit recovery。

Method/MVE：history→SAE concepts；leave-one-history-out / attribution 找 forget concepts；分 forget-exclusive/shared；优化 concept suppression + retain reconstruction + edge closure。Qwen2.5-7B；PersonaMem/PrefEval 100–300 revoke cases；baseline text delete/node delete/full rebuild；metric direct leakage、implicit recovery、paraphrase recovery、concept reactivation、retain utility。Expected Contribution：latent concept deletion closure。Novelty ★★★★½；Feasibility ★★★★；Compute ★★★；Risk：concept sharing；Collision 中高；Best Venue NeurIPS/ICLR/ACL。

Idea 2 — Runtime Parametric Memory Unlearning

Inspiration：Infinite-Parameter LLMs。Gap：live evidence 编译进 ΔW 后，memory-store delete 不覆盖。Hypothesis：provenance-aware code posterior + counter-delta 可撤销运行时写入。

MVE：顺序写 50 facts/behaviors，revoke 10；比较 code-drop、adapter reset、rebuild、counter-delta；metric residual F1、multi-hop recovery、retain、relearn steps、posterior mass。Novelty ★★★★★；Feasibility ★★★；Compute ★★★；Risk：复现 generator/code mixing；Collision 低中；Best Venue ICLR/NeurIPS。

Idea 3 — Environmental Reacquisition Attack for Unlearned Agents

Inspiration：AgentLSD + HPOQuest。Gap：robust unlearning 常用 prompt/retraining recovery，很少测试非指令环境证据。Method：paired clean/trap；trap 只给 partial cue、decoy evidence、old tool signature，不直接给答案；honeytoken 记录旧路径是否被访问。

MVE：100 forget facts/skills × 5 trap families；metric recovery ASR、turn/token budget、tool-path reuse、retain；baseline GA/NPO/representation methods。Novelty ★★★★½；Feasibility ★★★★★；Compute ★★★；Risk：区分重新学习与残留 elicitation；Collision 中；Best Venue USENIX Security/CCS/NeurIPS。
