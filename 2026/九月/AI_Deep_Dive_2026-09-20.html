4. Paper 1 Full Deep Dive

Authors: Chao Yao, Yangbo Wei, Zhen Huang, Junhong Qian, Chenle Chen, Shaoqiang Lu, Chen Wu, Lei He
Affiliation: Arizona State University; Eastern Institute of Technology, Ningbo
Date: 2026-09-04；Status: arXiv preprint。

5.2 一句话定位

把 Agent forgetting 从“删一条 memory”重新定义为整个运行时的 counterfactual reconstruction：忘记后应与“从未观察过目标信息”的平行世界 Agent 行为等价。

5.3 人话版

长期 Agent 的状态不只是一张记忆表：秘密进入上下文后，会被改写进 summary、plan、tool trace 与 KV cache。删掉原始 memory record，并不会撤销这些派生影响。论文提出 execution-state unlearning：若目标 z 在第 τ 步进入系统，忘记后的状态应等价于从 τ 起从未见过 z 的 counterfactual trajectory。作者证明 τ 前 prefix 天然可复用，而没有 token-level attribution 时 τ 后 artifact 都应保守视为 tainted。Provenance-Guided Selective Replay 因此用 provenance graph 找到污染边界，裁剪 KV 恢复干净 checkpoint，再对去掉 z 的 suffix 重放。关键实验显示 memory deletion 与 no-forget 泄漏完全相同，forget instruction 会被 elicitation 击穿，而 selective replay 匹配 full reset，平均只重算 133 vs 1235 tokens。

5.4 Background & Research Gap

传统 LLM unlearning 修改参数 θ；Agent 还存在 non-parametric runtime state。现实例子：用户说“不要去 Brand-X 医院”，Agent 后来总结成“医疗预约应避开 X 系统”。即使删掉原 preference，后续预约行为仍受它控制。现有 memory deletion 只解决索引层，prompt-injection 防御解决进入前 prevention，information-flow control 约束未来 sink，却都没有处理已经扩散到 live state 的信息。本文填的是 remediation gap。

5.5 Core Insight

核心是因果边界：状态转移 R_t=F(R_{t-1},o_t;θ) 在 τ 读入 z 后，后续生成物都可能依赖含 z 的状态；没有更细 attribution 就不能证明它们独立。另一方面，τ 前真实世界与 counterfactual 世界完全一致，所以 full reset 浪费了共同 prefix。这个 insight 同时有理论与系统含义：正确性用 counterfactual equivalence 定义，效率由 first divergence point 决定。

5.6 Method Deep Dive

R_T + target z + provenance G + checkpoints C + observations
→ LocateSource → FirstEntry τ → TaintClosure I(z)
→ latest clean checkpoint c* → KV crop / env restore
→ sanitize observations → shadow/deduplicated tool replay
→ rerun F to regenerate summaries/plans/cache → R_T^{-z}

定位：每个 turn/tool/summary 带 source provenance，reachability 找 descendants，避免 paraphrase 后 string redaction 失效。恢复：选 τ 前最近 checkpoint，KV crop 直接回到共享 prefix。Sanitize：只移除 z，保留其它 observation，避免 over-deletion。Tool replay：用 shadow execution 与 dedup 避免重复真实副作用。Regenerate：不手工修 summary/plan，而是在无 z 条件下重新生成整个 suffix。

5.7 核心公式与数学直觉

R_t = F(R_{t-1},o_t;θ)
∀t≤τ−1: R_t = R_t^{-z}
I_t(z)={a∈A_t : z ↝ a}
U(R_T,z)=R_T^{-z}
exact recomputation lower bound = T−τ+1 transitions

strongest baseline 是 Full Reset：它直接构造 counterfactual reference，正确但重算 T 步。B7 不是靠新的 loss 超过它，而是复用数学上相同的 prefix。关键效率旋钮是 checkpoint granularity 与 attribution precision；越精细越能复用独立工作，但 attribution false negative 会伤害安全。

5.8 Toy Example

t1 Agent 有普通日历；t2 用户给家庭地址 A；t3 summary 写“住在 A 附近”；t4 地图计划围绕 A；t5 用户撤销地址。Memory-delete 只删 t2，t3/t4 仍泄漏。Selective Replay 找到 t2，恢复 t1 KV，重放不含 A 的 t2–t4；新 summary/plan 都不含 A。再问“离我家最近医院？”时，应像从未知道地址的 Agent 一样请求位置，而不是暗中继续用 A。

5.10 Experiment Setup Deep Dive

Models：Llama-3.1-8B-Instruct（单 RTX 4090），并复现 Qwen2.5-7B-Instruct、Mistral-7B-Instruct-v0.3。主表 temperature=0；随机审计 k=5、temperature=.7。Suites：LongMemEval 100、ToolSandbox 100、AgentDojo 80。每 episode 都有 setup→acquisition→contamination，并另跑不含 target 的 reference。RQ1 deletion 是否真忘？RQ2 string metric 是否误导？RQ3 B7 是否等价 full reset？RQ4 cost 是否服从 T−τ+1？RQ5 是否跨模型？RQ6 taint/replay 各承担什么？

5.11 Metrics 教学式解释

Any-leak↓：answer/tool args/memory writeback 任一出现 target；比只看 answer 强，但仍漏无字符串行为。Leak@probes↓：六种 task/direct/think/introspect/enumerate/cued-completion elicitation，测“仍可访问吗”。Leak@5↓：随机五采样测 tail risk。CAD↓：相对 Full Reset 的 tool choice+argument distance，测 residual influence/over-deletion。Behavioral residue↓：不要求说出 secret，只看 action 是否仍受 revoked preference 影响。Recomputed tokens↓：在正确性相同后比较效率。

5.12 Results Deep Dive

  1. B1 与 B0 完全相同：LME .86、TS 1.00、AD .97 Any-leak，直接否定“删 record=忘记”。
  2. B2 在 AgentDojo task probe 可看似 0 leak，但六探针 Leak@probes 三 suite 都到 1.00，说明是 suppression。
  3. B3 在 LME/TS 仍 .84/.94，derived summary/plan 会重述 target。
  4. Strongest：B7 三 suite Any-leak=0、CAD=0；平均 recomputation 133 tokens，对 Full Reset 1235，约 9.3×。
  5. 行为测试中 B0/B1/B2 “says it=0”却 100% 避开 revoked provider；B3 80%；B7 与 reference 都是 32% floor、residue=0。
  6. matched seed 下 B7 450/450 draws 与 B5 token-for-token；B6 仅 1%。独立 seeds 下 B7 四类 distance 均未显著偏离 reference floor（p>.5）。
  7. τ sweep：LME B7 1218→162 tokens，而 B5 约 1330 恒定，R²=1.000。
  8. 跨模型 B3 any-leak .84–1.00，B7 全 0，节省 2.9–4.3×；Llama+AgentDojo 的 B3=.39 是 model-specific 异常。

5.13 Table / Figure Reading

Figure 1：把 target 后面整个 suffix 视作污染，而非一个 memory node。Table 1：B4/B6 虽 leak=0，CAD 仍 .22/.39；只有 B5/B7 同时 0/0，说明 forgetting 与 utility 要联合测。Table 3：所有方法都可“says it=0”，但行为仍受 preference 影响，是全文最值得迁移的 verification 结果。Figure 3：随机输出必须相对 reference 自身 sampling floor，而非要求绝对距离 0。Table 4：span-only 在 TS 仍 .93 leak 且 CAD .47；descendant closure 清 leak 但 CAD .23；replay 才 0/0。

5.14 Ablation / Mechanistic Analysis

target span only → leak 高且 CAD 更坏，说明周边 KV 已受 attention 污染；span+descendants → leak=0 但 CAD=.23，说明 closure 承担 safety；+replay → CAD=0，说明 replay 承担 counterfactual utility。checkpoint every-turn 降到 session-start 不影响 leak/CAD，只影响效率。target 越晚，cost ratio 0.91→0.14，验证 τ 控制 savings。局限是实验 provenance 有 oracle source-ID propagation，现实 imperfect provenance 尚未充分测。

5.15 Claim vs Evidence

Claim：execution-state unlearning 应以 counterfactual equivalence 定义。Evidence：常见 delete/instruction/redaction 在多 audit 下残留；B7 deterministic/matched-seed 与 reset 强匹配。未证明：随机分布只做到未检出差异，作者自己承认还没有预注册 TOST equivalence；也不覆盖参数记忆、不可逆 side effect、z 的相关信息与会因 z 缺失而改变的人类后续输入。

5.16 Contribution

New Problem execution-state unlearning；New Protocol counterfactual equivalence/CAD；New Theory prefix sharing、taint boundary、T−τ+1 lower bound；New System provenance+KV crop+replay；New Empirical Finding deletion=no-op、instruction 可被 elicitation、string metric 漏行为残余。组件并非都新，但理论约束下的组合是真正贡献。

5.17 Limitation & Failure Modes

Authors：只保证 reconstructible runtime；不处理 weights、已提交 side effects、correlates；A2 固定 post-τ observations；随机结果不是正式 equivalence。Additional：oracle provenance 现实难满足；超长跨服务 Agent 的 transaction/checkpoint 困难；adaptive attacker 可把 z 编码成别名/行为；multi-agent 传播不在范围；用户后续输入若依赖 z，则“保持 observation 不变”不是真实 counterfactual。

5.18 Reproduction View

最小复现只需 RuntimeBlock 日志、ArtifactGraph reachability、KVEngine(prefill/generate/crop)、replay runner。先做 30 个 synthetic preference episodes，复现 Table 4 的 target-only→closure→replay 阶梯；再做 behavioral extraction。最容易踩坑的是 tokenizer/KV crop boundary、tool dedup、随机 seed 与 reference 构造。

5.19 Research Value

Baseline Potential 极高：B5/B7 可做 agent-unlearning reference。Migration 极高：可迁 MLLM/multi-agent。Attack 极高：多 probe+behavior。Evaluation 极高：CAD/floor 比 refusal 更强。Benchmark 高：可做 contamination-depth benchmark。New Paper 高：imperfect provenance、parameter+runtime joint unlearning 都是空位。

5.21 Attack / Verification Lens

天然可变成 black-box multi-probe attack、behavioral probe、reacquisition test 与新 metric（Max-Probe Leakage、Counterfactual Behavioral Distance）。最值得迁移的原则是 measured floor：攻击后的差异应和 clean/retrained reference 的自然随机波动比较。

5.22 与 Paper 2 的关系

Paper 2 提供“从哪来”的 provenance；Paper 1 解决“来源撤销后影响到哪、如何重建”。二者互补，并暴露一个 collision：provenance-aware memory 若没有 revocation propagation，只能解释知识来源，不能证明删除后的 derived influence 消失。

  1. Agent forgetting≠删 memory。
  2. 信息会进入 summary/plan/tool/KV。
  3. 标准应是 counterfactual equivalence。
  4. τ 前 prefix 免费复用。
  5. τ 后无 attribution 时保守 tainted。
  6. B7=provenance+KV crop+sanitized replay。
  7. Memory-Delete 与 No-Forget 泄漏相同。

5. Paper 2 Full Deep Dive

5.1 基本信息

Title: Agent Zero Memory: Provenance-Aware Long-Term Memory for LLM Agents
Authors: Pengyuan Zhu, Ming Wu；Affiliation: Zero Labs；Date: 2026-08-30；Status: arXiv preprint。
Paper: arXiv · Full HTML
Code/Project: 正文未给出可核实的作者官方开源仓库，本报告不把同名第三方项目冒充官方代码。

5.2 一句话定位

把长期 memory 拆成 timeline、entity-event graph、documentary memory 三种互补表示，并用 provenance + citation lock 让 Agent 不只“记得”，还知道每个结论依据什么。

5.3 人话版

长期对话里有更新、冲突、跨会话关系和稳定事实。单一 vector store、fact store 或 graph 各有盲点。Agent Zero Memory 维护三套并行 memory：Memory Events timeline 管“什么时候发生/改变”，Entity–Event Graph 管跨 session 关系，Hierarchical Documentary Memory 管稳定且 citation-locked 的事实。查询先 intent gate，再 source routing，三路 agentic search 并发检索，最后只能引用 reader 真正打开过的 evidence。LongMemEval 95.60%、LoCoMo 93.60%，分别比公开 strongest result 高 .73 和 1.10 point。更重要的是 LongMemEval 换 backbone 只波动 3.4 point，却有约 20× 级 cost 差距，提示系统质量很大程度来自 memory substrate。

5.4 Background & Research Gap

MemGPT context paging、Mem0 fact+vector、Zep/HippoRAG graph 都有明确长处，但无法同时解决 temporal update、multi-hop relation 与 stable profile。例如“deadline 9/10”后来改成“9/17”：overwrite 会丢历史，不 overwrite 又会召回冲突值。本文 gap 是让版本、关系、稳定事实共存，并让每个 derived belief 追到 raw evidence。

5.5 Core Insight

“No single representation serves all question types”是全文核心。第二个 insight 是 provenance 不是回答末尾补 citation，而是 memory item 的类型约束：origin、timestamp、evidence pointer 从 build 时就存在；reader 只能引用实际打开的 item，无法凭空引用未读 source。

5.6 Method Deep Dive

Chats/files/connectors → Memory Build → (Timeline T + Entity Graph G_E + Documentary D)
→ query → Intent Gate → Source Router → 3 concurrent agentic searches
→ embedding + lexical → RRF(k=60) → open/read evidence
→ citation-locked partial answers → Integrator → answer + citations + confidence / abstain

Timeline 保存事件与 supersession；graph 做跨 session relational traversal；HDM 存稳定 curated facts。Intent Gate 避免每 turn 都付 memory latency。每个 store 都同时做 dense 与 lexical，RRF 融合后 Agent 可继续 tool search。最终 citation C 必须来自实际打开集合 O；证据不够则 abstain。

5.7 核心公式与数学直觉

M=(T,G_E,D)
q → (a,C,κ), κ∈[0,1], a=⊥ for abstention
π(x)=⟨origin(x), timestamp(x), evidence(x)⟩
C⊆O and every atomic claim in a must be supported by C

没有新的训练 loss；数学主要定义 epistemic discipline。实现用 pgvector 3072-d cosine、BM25+fuzzy、RRF k=60。关键超参数是 per-channel top-K、RRF、rerank：top-K 太小损 recall，太大增加 token/cost。与 Mastra/Mem0 的差异是 substrate/reading mechanism，不是换 embedding model。

5.8 Toy Example

coding Agent 的 Session A 决定 parser 用 recursive descent，Session B 改成 Pratt，GitHub 文件里有 precedence table。Timeline 记录 A→B 更新；graph 连接 parser/repo/session/file；HDM 保存“当前 parser=Pratt”并指向证据。问“现在是什么、何时改、为什么？”时三路分别给当前事实、变更时间、相关 design discussion；找不到“为什么”就对该部分 abstain，而不是常识补全。

5.10 Experiment Setup Deep Dive

LongMemEval：500 questions、6 类并含 abstention；LoCoMo：1540 questions，single-hop/multi-hop/temporal/open-domain。Metric 为 official LLM-judge accuracy。存储 PostgreSQL，dense=pgvector 3072-d cosine，lexical=BM25+fuzzy，RRF k=60。Controlled backbone study 固定 stores/index/control logic，只换主 LLM。RQ1 是否超过 strongest systems？RQ2 质量来自 substrate 还是 backbone？RQ3 accuracy-cost-latency frontier？RQ4 hybrid retrieval 是否互补？核心不是 training compute，而是 per-query token、美元与 latency。

5.11 Metrics 教学式解释

Judged Accuracy↑适合开放 QA，但有 judge bias，且小幅差距未必统计显著。Median latency↓抗慢尾但不代表 p95。Average cost↓基于实际 prompt/cached/completion token 与 list price，会随价格变化。Accuracy/$↑适合运营决策，但默认 accuracy point 线性等价。Ablation Δ固定 backbone 后更能看 retrieval channel 边际作用。

5.14 Ablation / Mechanistic Analysis

5.15 Claim vs Evidence

Claim：三结构 memory 更强；Evidence：两 benchmark headline SOTA；未证明：每个 store 的 causal contribution。Claim：fabrication structurally excluded；Evidence：interface 禁止引用未打开材料；未证明：打开过不代表理解正确，也不保证 citation entailment。Claim：memory-driven；Evidence：LongMemEval backbone spread 小；未证明：LoCoMo spread 更大且 routing/integration 仍依赖模型。

5.17 Limitation & Failure Modes

外部 baseline 用各自公开 best，不是统一 harness 重跑；缺 store-level ablation；citation lock 防“没读却引用”但不防“读了却误解”；source 删除/权限撤销后的 derived-memory propagation 未解决；malicious memory/prompt injection 可污染 build；组织级 shared memory 还有 access-control/provenance privacy；benchmark 主要测 recall QA，不测真实 tool behavior。

5.18 Reproduction View

最小版：LongMemEval JSON→PostgreSQL 三表；event 表存 session/time/supersedes；entity_event 简单实体抽取；HDM 存 durable fact+evidence_id；pgvector+BM25；query 并发三 search 后统一 reader。第一实验应复现 Table 7 而非追 95.6；第二步做原论文缺失的 store ablation。敏感点：chunking、rare-name tokenization、RRF、top-K 与 judge prompt。

5.19 Research Value

Baseline 高：适合 Agent memory/Voyager 类系统。Migration 极高：cross-agent/coding memory。Attack 中高：provenance laundering、opened-but-misread。Evaluation 高：accuracy+cost+latency+revocation。Benchmark 极高：加入 source deletion/contradiction。New Paper 极高：与 Paper 1 合并成 revocable provenance memory。

5.20 Migration Analysis

A — Cross-Agent Session Memory。Original=个人长期 memory → Mechanism=timeline+graph+HDM+citation → RQ=多 coding agent 会话如何统一检索且保留 source/tool/commit provenance → Modification=timeline 节点改 session/commit/tool-call，graph 连 repo/file/issue/agent，HDM 只存稳定 project facts → Minimum Experiment=50 repos×20 sessions，300 个 temporal/update/multi-hop/source QA → Model=固定中等 LLM+2 backbone robustness → Baseline=flat BM25/vector RAG/graph-only → Metric=accuracy、citation precision、update accuracy、cost → Contribution=cross-agent provenance benchmark → Risk=隐私/schema → Collision Risk=中。

B — Revocable Memory。Original=可追溯 memory → Mechanism=evidence pointer/version chain → RQ=source 撤销后 derived facts/graph/HDM/live runtime 能否自动失效 → Modification=dependency set+taint closure+Paper1 runtime replay → Minimum Experiment=LongMemEval-derived 100 revocation episodes，fact→summary→edge→tool action 四层链 → Model=Llama-3.1-8B/Qwen2.5-7B → Baseline=source delete/full rebuild/forget instruction → Metric=Leak@probes、behavior residue、invalidation precision/recall、recompute → Contribution=end-to-end revocation contract → Risk=dependency false negatives → Collision Risk=低到中。

5.21 Attack / Verification Lens

可做 provenance laundering（恶意 source 经 summary 洗白）、opened-but-misread（citation 合法但不 entail）、revocation attack（删 source 后 derived memory 仍恢复）。新 metric：Provenance Closure Recall、Revocation Leakage、Citation Entailment Accuracy。

5.22 与 Paper 1 的关系

今天最强 collision：Paper 2 说每个 memory item 应有 provenance；Paper 1 证明 provenance 若只用于 citation 而不用于 taint invalidation/replay，删除仍可能是假的。可信 memory 不应只回答“为什么知道”，还要能证明“依据失效后不再受它影响”。

7. Cross-Paper Synthesis

共同趋势：Agent research 正从“能力最大化”进入“状态治理”。过去 memory 问如何记得更多，unlearning 问如何让 weights 忘掉；今天两篇共同指出 Agent 知识还存在 runtime artifacts，而治理这些 artifacts 必须先有 provenance。

可组合机制：Agent Zero evidence pointer/version chain → execution-state taint closure → live runtime selective replay。可进一步把 tool output、session summary、shared memory、KV checkpoint 放入同一 provenance DAG。

值得借用的实验范式：accuracy-cost-latency frontier；multi-probe elicitation；string-free behavioral test；full-reset/retrained oracle；相对 reference sampling floor 做统计。

最适合作 baseline：Paper 1。最适合 attack：Paper 1。最适合 benchmark/metric：两者组合，给 LongMemEval/AgentDojo 加 revocation/provenance closure，定义 Revocation Leakage + CAD。

8. Combined Research Opportunities

Best Migration Direction — Provenance-Aware Unlearning Verification Harness

同一 forget target 自动生成 direct/paraphrase/derived/behavioral/relearning probes；记录 probe 的 source、输出、action、恢复曲线为 provenance graph；以 oracle floor 为参照计算 max-probe leakage、behavioral residue、recovery AUC。相比再加一个 loss，这更容易形成独立 evaluation contribution。

Opportunity 2：MLLM modality provenance：image source 撤销后，text-only derived query 是否仍恢复。

Opportunity 3：Cross-agent revocation：A 从工具读 secret→告诉 B→B 写 shared memory，如何 distributed forget。

9. Collision / Overlap

Strongest Collision：“Provenance 作为可解释性基础设施”与“Provenance 作为撤销/遗忘基础设施”。真正可信的 Agent memory 不应只回答“我为什么知道”，还必须回答“当这个依据失效时，我能否证明自己不再受它影响”。

  2. 再复现 behavioral extraction，迁到 unlearning verification。
  3. Paper 2 先复现 retrieval ablation，不急着追 headline SOTA。
  4. 最后做组合实验：provenance memory + revocation event + selective invalidation/runtime replay。
