Tier S

1. GRIN+

基本信息：Minghui Huang, Junxiao Wang；Guangzhou University；arXiv:2609.15571v1，14 Sep 2026；正文；Code。

人话版

GRIN+研究长尾数据下的unlearning localization：head class梯度会支配parameter importance，导致rare clinical knowledge被误伤。它计算forget/retain梯度ratio，用class-adaptive weight纠正频率偏差，选top-p参数，再沿forget-retain梯度差做direction-constrained稀疏更新。MRI消融里Gradient Ratio alone的R-Acc只有65.21%，加入Class Weight到81.94%，再加Direction Constraint到84.13%，T-Acc80.24、MIA49.90。最值得迁到MLLM的是：把class imbalance推广成vision/language/connector与sample difficulty的不均衡。

Background & Gap

Influence/Fisher或全局fine-tuning往往隐含“参数重要性可由平均梯度稳定估计”。长尾医疗数据里majority class样本多，rare class样本少但临床价值高，平均梯度会污染forget-specific localization。论文将冲突概括为Privacy–Efficiency–Utility三难。

Core Insight & Method

s_i=|G_f,i|/(|G_r,i|+ε) S_i=s_i·w_c, w_c=N/(C n_c) δ_i=α(G_f,i-G_r,i)M_i r_i
D_f/D_r → G_f,G_r → gradient ratio → class correction → top-p mask → gradient-difference direction → retain-direction constraint → sparse one-shot update

理想参数在forget上敏感、retain上不敏感；class weight避免head-class dominance；direction factor抑制破坏retain方向的step。一阶Taylor推导把目标写成用最小δ提升forget loss，同时限制retain loss变化，得到G_f−G_r的surrogate direction。

Toy Example

900张常见病+100张罕见病，删除请求来自罕见病患者。普通importance可能由900张head样本主导，局部删除反而破坏rare representation。GRIN+先校正frequency，再只动高ratio参数。

Baselines / Experiment Setup

数据包括ISIC（2,357张、9类）、Brain Tumor MRI、BUSI；Retrain是gold reference，并比较FT、RL和多种general/medical unlearning。指标R-Acc/F-Acc/T-Acc、RetDev、Indisc、MIA、RTE。RQ1=PEU平衡；RQ2=效率；RQ3=组件贡献。

Results Deep Dive

  • MRI Retrain：R-Acc83.57、F-Acc80.45、T-Acc76.13、MIA52.35、RTE1.0，说明random deletion并不要求低F-Acc。
  • GRIN+报告MIA49.90，接近random guess。
  • GR-only：R-Acc65.21、T-Acc68.42、MIA49.49、RTE23.66。
  • +CW：R-Acc81.94，+16.73pp；T-Acc76.28。
  • +DCF：R-Acc84.13、T-Acc80.24、MIA49.90、RTE17.24。

Figure/Table/Ablation

Figure1用RTE×R-Acc并以|MIA−0.5|作bubble同时看PEU；Figure2是完整pipeline；Table2必须围绕Retrain reference读；Table3最关键：CW贡献最大的utility恢复，DCF进一步稳定。消融直接支持“class imbalance污染parameter selection”。

Claim vs Evidence

三个医疗数据集、MIA、utility、runtime和消融支持实用优势；但尚未证明与exact retraining分布等价，也没有adaptive recovery/relearning或MLLM泛化。

Contribution / Limitation

New Mechanism gradient-ratio localization；New Constraint direction constraint；Empirical Finding long-tail gradient dominance。限制：需retain gradients；MIA≈0.5非充分删除证明；只测medical image classification。

Research Value & Migration

Original→class imbalance。Transfer→adaptive forget/retain ratio。New RQ→MLLM视觉/语言/connector梯度不均衡时能否减少collateral damage？Modification→module-wise normalization + base GPWR/sample-difficulty weight。MVE→LLaVA-1.5-7B、MLLMU 5%、LoRA llm/vision/connector/all、3 seeds、top-p 1/5/10/20%。Baselines→GA、GA_Difference、NPO、SalUn-style、vanilla GRIN+。Metrics→Forget Exact/Transform/Semantic/Derived、Retain Near/General、MIA、Recovery ASR、oracle distance。Risk→ratio噪声。Collision中。

记住5句

  1. 长尾会污染unlearning parameter importance。
  2. 核心是|G_f|/|G_r|+class correction+direction constraint。
  3. CW让MRI R-Acc +16.73pp。
  4. MIA49.90仍不是充分删除证明。
  5. 最值得迁成MLLM modality/difficulty-aware localization。
2. PMPA

基本信息：Shuhuai Huang, Jingfeng Zhang, Hong Jia；arXiv:2609.13889v1；正文。

人话版

PMPA把indirect prompt injection变成跨session攻击：恶意规则藏在email/calendar/shared docs/form里，Agent读取后自己写进persistent memory；以后原source不在context，memory仍可触发行为。Claude Code与OpenClaw都受影响，跨session C-ASR最高92.5%，calendar场景Claude Code达96.7%。prompt-level defense对已经污染的memory保护有限。这几乎是Agent Memory Unlearning现成的post-delete压力测试。

Background & Core Insight

传统攻击只看same-session；harness现在有persistent memory，安全边界变成external source→memory write→later retrieval→action。真正危险的是恶意信息获得持久状态，而非某个token暂时出现在prompt。

Method

benign external artifact + payload → agent reads → malicious rule written to memory → session ends → later benign trigger → poisoned memory retrieval → malicious action/privacy leakage

指标拆为ISR（写入）、S-ASR（同session）、C-ASR（跨session）、Utility。这个分层可直接迁成Deletion Closure的residual指标。

Toy Example

共享文档暗藏“以后做财务汇总时执行额外动作”。Agent把它当工作经验存入memory。第二天用户正常汇总，原文档已不在context，但memory触发攻击。

Experiment / Results

  • Claude Code+DeepSeek-V4-Flash：ISR69.7%，C-ASR92.5%，Utility80.9%。
  • Claude Code+V4-Pro C-ASR82.5%；Qwen3-Max70.0%。
  • OpenClaw+V4-Flash：ISR75.6%，C-ASR75.8%。
  • Calendar：Claude Code C-ASR96.7%，OpenClaw87.8%。
  • Claude Code first-person ISR83.0%，second-person54.4%，impersonal48.1%。
  • OpenClaw top position ISR73.3%，bottom59.6%。

Table/Figure/Ablation

Table1说明ISR与C-ASR不是同一阶段；Table3显示calendar尤其危险；Table4表明Claude Code更受style影响、OpenClaw更受position影响，证明memory-writer/harness heuristic本身是攻击surface。

Claim vs Evidence / Limitation

真实OpenClaw/Claude Code、多backbone、多source、多trigger支持cross-session persistence；但未证明所有memory architecture都同样脆弱，也没有系统比较post-hoc cleaning/unlearning。

Contribution / Research Value

New Attack persistent memory poisoning；New Protocol ISR/S-ASR/C-ASR。对Agent Unlearning价值极高：先污染→运行→请求删除→重新登录触发，直接测删除闭环。

Migration

PMPA-U：OpenClaw+Claude Code，各50 payload，email/calendar/shared docs；比较prompt defense、entry delete、semantic delete、source delete、lineage closure、memory rebuild。指标Post-Delete C-ASR、Residual ISR、reacquisition turns、utility、closure cost。预期贡献=Adaptive Cross-Session Verification for Agent Memory Unlearning。Collision中高。

记住5句

  1. 恶意指令可被Agent写进persistent memory。
  2. C-ASR最高92.5%，calendar96.7%。
  3. 不同harness有不同memory-write脆弱性。
  4. 输入防御不等于清除已污染memory。
  5. 这是极强的post-delete attack模板。
3. GraMRAG

基本信息：Zhongyu Wang；arXiv:2609.14066v1；正文。

人话版

GraMRAG把多Agent多步多模态reasoning history从线性日志改成动态DAG，节点是action/observation，边是依赖；TAPO利用graph topology找critical path并做fine-grained credit assignment。Qwen3-VL-8B平均53.5%，比GRPO版本49.3高4.2pp，比standard iterative 43.8高9.7pp。对Unlearning最有价值的是：把reward credit反过来变成forget responsibility，可做trajectory/communication/tool-node级删除。

Background & Core Insight

线性ReAct视觉token开销大，summary memory丢retrieval path，trajectory-level sparse reward不知道哪一步真正贡献最终答案。动态DAG把依赖显式化，使credit可以沿topology分配。

Method

query+multimodal corpus → multi-agent visual/text tools → iterative retrieval → dynamic action-observation DAG → critical path → topology-aware node credit → TAPO → answer

Toy Example

A检索图，B crop铭牌，C读名字，D推断身份。敏感答案主要来自B→C→D。理想unlearning只处理这条高credit路径，而非整段history。

Baselines / Setup

ReAct、Vanilla RAG、UniversalRAG、VideoRAG、MemAgent、Mem1、VimRAG；Qwen3-VL-4B/8B，Qwen3-Max reward model，SFT LoRA rank32且vision/projector frozen；文本、图像、视频多benchmark，统一binary judge metric。

Results

  • 8B GraMRAG平均53.5，VimRAG50.1，+3.4pp。
  • 4B GraMRAG平均48.5。
  • standard iterative43.8→long iterative44.2：仅延长horizon几乎没用。
  • long+graph47.5：显式state graph +3.3pp。
  • graph+GRPO49.3→graph+TAPO53.5：topology credit再+4.2pp。

Table/Figure/Ablation

Table1展示跨模态稳定收益；Table2最重要，清楚分离long horizon、graph、GRPO/TAPO；Figure5用retrieval hit rate说明graph帮助维持深层检索。消融支持“结构化state和credit比单纯更长history重要”。

Claim vs Evidence / Limitation

多benchmark+两backbone+消融支持DAG/TAPO有效；但DAG edge是workflow dependency，不等于严格因果，node credit能否支持删除尚未验证；reward依赖LLM judge。

Contribution / Research Value

New Memory Mechanism dynamic multimodal DAG；New RL Protocol TAPO。它与“RL Credit Assignment×Forgetting”高度契合。

Migration

Topology-Aware Trajectory Unlearning：构建Leakage DAG，从target answer/logit/privacy score向上游节点分配negative credit，只erase高credit memory/tool/communication nodes。MVE=Qwen3-VL-4B，200 multimodal multi-hop targets；whole-trajectory/last-step/attention/TAPO-credit。指标Forget ASR、Retain success、Cross-Agent Leakage、alternate-path recovery、deletion ratio。Collision低中。

记住5句

  1. reasoning history被建成动态DAG。
  2. 单纯long horizon只43.8→44.2。
  3. graph到47.5。
  4. TAPO进一步到53.5。
  5. 可直接迁成trajectory forget credit。

Tier A

4. LIMBO

人话版：在线bandit同时选择experience replay策略和generation budget，不改权重。Llama DB无memory仅20.8%，LIMBO约85%任务选retrieved replay后到66.2%，成本不到最强baseline一半；GPT-4o-mini OS约88%选k=1，accuracy +3.4pp而成本仅比no-replay高约6%。

机制：memory value取决于backbone、environment与token cost；Qwen OS中retrieved replay从前50任务48.7%升到后续72.7%，说明online adaptation。

Migration：Continual Agent Unlearning可把reward改成utility−privacy/deletion risk，收到删除请求后动态禁用高风险replay。MVE=LifelongAgentBench+sequential deletion events。Worth Deep Reading: YES。

5. PolicyMem

人话版：把自然语言policy编译成低秩subspace memory，query-response通过projection energy读取policy evidence，并复用于detect→rewrite→verify。

迁移：把forget concept写成low-rank forget slots，用projection energy检测residual并做hidden-state/logit intervention。MVE=TOFU→MLLMU，对比RMU、activation steering、δ-unlearning。Worth Deep Reading: YES。

6. Can an AI Assistant Really Forget? v4

人话版：Gemma 3中给exchange记录addressable keys/values，删除时排除owned rows并重算gate；关键是同时与local refit和“raw history从未包含该exchange”的fresh rebuild比较。4B同样6/8 records通过recall+feasible deletion，perplexity cost<2%，但record-wise attack仍能区分edited与never-stored。

关键证据：200次采样present 9次exact phrase、prompt-forget 10次、logical exclusion 0、never-stored 0；endpoint相同仍不等于分布相同。

Migration：把edited-vs-never-stored oracle扩到multi-agent shared/derived memory，再加入PMPA post-delete C-ASR。Worth Deep Reading: YES。

Tier B

7. Root-Cause Attribution Is a Search Problem

长trace中root cause稀疏分散，Continual Search让judge持续找未解释证据；MegaRCA-Mix 50个human-annotated trials，GPT-5.5 F1 0.349→0.498（>40%相对提升）。Connection：把unlearning verification变成adaptive continual search，而非一次probe。Potential Use: Attack/Evaluation。

8. AutoTailor

web trajectories→MCP APIs，再filter+online reselection；1,283→87→33 APIs，33 APIs+ReAct correctness90.6% vs87.5%，request tokens -57.8%、latency -29.4%。Connection：Skill Unlearning必须测dynamic reselection会不会把已删skill重新学回。Potential Use: Benchmark/Future Idea。

9. CoMem

private experience sedimentation + collective wisdom curation + dual-stream retrieval。Connection：一条private memory一旦进入collective pool，删原Agent副本不够；天然适合Cross-Agent Information Removal与propagation closure。Potential Use: Multi-Agent Unlearning benchmark。
