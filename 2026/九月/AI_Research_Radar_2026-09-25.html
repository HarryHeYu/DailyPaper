Executive Summary

今天 24–72h 的最强新增集中在 Agent Memory / state editing / executable-agent evaluation，而不是新的 unlearning loss。核心信号有三条：EnSIMem 把长期记忆明确拆成“结构化地址索引”和“原始 source evidence”；AEWM 把 long-horizon agent 的 contaminated reasoning-action state 变成可编辑对象；FDE-Bench 用 pristine rebuild + layered gates 证明 agent 评测应验证可执行后果而不是自述。对 Machine Unlearning，今天用高价值 BACKFILL 补 continual、VLM recovery、attribution、skill 和 agentic unlearning。最佳新方向是 Dual-View Agent Memory Unlearning：Index Closure 与 Evidence Closure 必须同时成立，并把 dense fallback 当成 adaptive recovery attack。

Today's Most Important Paper

EnSIMem: Entity-Structured Indexing for Long-Term Agent Memory

最值得关注的不是 90%+ benchmark 分数，而是 index-as-address, source-as-evidence。每条 record 形如 <entity,type,property,value,episode,provenance>，structured path 负责找地址，dense fallback 保护 recall，最终回到原始 episode 回答。对 Agent Unlearning，这直接产生两个不同的残留面：删 index 不等于删 source；删 source 也不等于 property/value/derived path 消失。优先看 Figure 1、Eq.(3)/(7)、LoCoMo Table 1、LongMemEval Table 2 与 episode-granularity ablation。

Tier SEnSIMem: Entity-Structured Indexing for Long-Term Agent Memory NEW

EnSIMem: Entity-Structured Indexing for Long-Term Agent Memory

基本信息：Xuanyu Meng, Xing Fan, Xinyi Fan, Chenlei Guo, Yixuan Xie, Jiawei Han；2026-09-23；arXiv:2609.27279；Paper；Code。

人话版：EnSIMem 不把长期历史压成一个 summary，而是先切 theme-coherent episodes，再建 [entity][type][property:value] 地址索引；查询先拆 evidence requirements，再按 point/temporal/compositional/aggregation 类型自适应取证，最终从原始 dialogue evidence 回答。它最重要的设计是结构只负责寻址，原始 source 才负责证据。

Background & Gap

Full context 太贵且有 lost-in-the-middle；summary 会丢时间限定、细节与 provenance；anonymous vector chunks 又不知道哪个 entity/property 使片段相关。EnSIMem 在“结构化可寻址”与“保留原始证据”之间取中间路线。

Core Insight / Method

history → theme episodes → entity-property records + provenance → requirement decomposition → structured lookup ∪ dense fallback → coverage stopping → source expansion → grounded answer。Persistent memory M=F(D)；record r=<x,t,p,v,e,π>，π 指向原 evidence。候选 E(q)=Dedup(Structured(I,H(q)) ∪ Dense(T,H(q)))。这意味着 dense fallback 是 recall safety net，也是 unlearning 后潜在 recovery path。

Toy Example

“Caroline took a helicopter to Chicago”可索引为 Caroline/person/travel:Chicago，并指回原 episode。以后问“她怎么去 Chicago？”property alignment 找到 travel，再回源得到 helicopter。若用户要求忘记 helicopter，只删 index 仍可能被 dense source 找回；只删 source，index/value 或后续 summary 仍可能泄漏。

Baselines / Setup

LoCoMo 比 Full Context、RAG、HippoRAG、Zep、Mem0、LangMem、Nemori、MEMORA；strongest published comparison 是 MEMORA(P)。生成使用 GPT-4.1-mini；分别用 GPT-4o-mini 与 Qwen3-32B 做 binary evaluator，不把 judge disagreement 平均掉。

Results Deep Dive

  1. LoCoMo overall 90.6%（GPT-4o-mini judge）vs MEMORA(P) 86.3，+4.3pp；Qwen judge 90.0%。
  2. LoCoMo multi-hop 88.7 vs 78.7；open-domain 70.8 vs 59.4。
  3. LongMemEval overall 92.8% vs MEMORA(P) 87.4，约 +5.4pp。
  4. LongMemEval 最大增益集中 SS-assistant 与 multi-session，约 +13–16pp 区间。
  5. 弱项：LoCoMo open-domain 仍只有约 71–73%，明显低于 single-hop 94%+。

Table/Figure & Ablation

Figure 1 是 offline index / online retrieval 总图；Table 1 看 LoCoMo multi-hop/open-domain；Table 2 看 LongMemEval multi-session；episode-granularity ablation 比 theme-coherent、per-turn、per-session，验证太细丢 anaphora、太粗引噪声。

Claim vs Evidence

Claim：entity-structured indexing + source evidence 提升长期记忆。Actually show：两个 benchmark、两个 judge 均有稳定提升。Not proven：真实持续写入、删除请求、跨-agent replica、恶意 memory 与 privacy closure。

Contribution

New Mechanism：address/source separation；New Retrieval Protocol：requirement-aware stopping；New Empirical Finding：multi-session/multi-hop 显著提升。

Limitation / Research Value

依赖 LLM 做 episode/property extraction；开放式 slice 仍弱；dense fallback 破坏“删 index 即忘记”的假设。它非常适合成为 Agent Memory Unlearning 的 retain baseline、adaptive recovery attack 与双视图 evaluation substrate。

Migration

Original long-term retrieval → Mechanism address/source separation → RQ forget request 是否同时关闭 index 与 evidence paths？→ MVE LoCoMo/LongMemEval 100 facts，比较 index-only/source-only/both/dual-closure；攻击 direct/paraphrase/temporal/aggregation/dense fallback → Model Qwen/Llama 8B + EnSIMem → Baseline vector delete、summary delete、SBU closure → Metric fallback ASR、derived leakage、retain accuracy、closure size → Risk closure 标注成本 → Collision 中高。

只记 5 句话

  1. 结构是地址，不是证据。
  2. record 保留 entity/property/value/episode/provenance。
  3. LongMemEval 92.8%，约 +5.4pp。
  4. dense fallback 是 unlearning recovery surface。
  5. Index Closure 与 Evidence Closure 应分开验证。

Tier SFDE-Bench: Evaluating LLM Agents for Deployment Environment Configuration NEW

FDE-Bench: Evaluating LLM Agents for Deployment Environment Configuration

基本信息：Weihang Ding, Junfei Zhan, Yueting Li, Qirong Guo；2026-09-23；Paper。

人话版：这是部署 benchmark，但对 unlearning 最值得借鉴的是评测哲学：不要相信 agent 自己说完成了什么，把最终 artifact 放进干净环境重建、重放，再按 build→readiness→behavior→conformance 分层验收；还主动测试 do-nothing、抄规格、generic stub 和 adversarial shortcut 能不能刷分。

Method / Formula Intuition

spec+repo → agent artifact → collect → pristine rebuild/redeploy → four gated checks → resolution。Resolution 要求关键 gates 全过；Deployment Score 保留阶段性进度。迁移到 unlearning 可对应 Direct Forget → Adaptive Elicitation → Recovery Resistance → Retain Conformance。

Setup / Baselines

136 tasks，Docker/Compose/Kubernetes，greenfield + diagnose-and-repair；2,145 programmatic checks；7 models / 4 providers，同 four-tool scaffold；release gate 要求 reference solution 可解，并拒绝三类 zero-intelligence shortcuts。

Results

  1. 7 models resolution 52.9–75.0%。
  2. 三种 zero-intelligence floors 0 resolved，mean Deployment Score ≤0.44。
  3. 313 unresolved episodes 中 110 最大失败阶段是 readiness。
  4. repair 比 disjoint greenfield 平均高 30.7pp，每个模型都为正。
  5. 25-task case study：human directing Claude-Sonnet-5 92% vs autonomous 72%。

Figures/Ablation

重点看 four-gate pipeline、7-model grid、failure-stage decomposition。三个 zero-intelligence floors + 三类 adversarial shortcut 实质是 evaluator ablation；vacuous health probe 能过 readiness 却过不了 downstream checks，证明单一指标可被投机。

Claim vs Evidence / Limitation

它证明 artifact-grounded replay 比文本 judge 更可靠，但领域专门化，且 checker 自身仍有 7 个 documented gaps；不是 unlearning 方法。

Migration

把每个 unlearned checkpoint fresh-load，依次跑 direct、paraphrase/multimodal、relearning/quantization、retain utility、adaptive attack；关键 gate 任一 fail 就记录 first-failure stage。你现有 MLLMU checkpoints 基本可离线重算。Expected contribution：artifact-grounded Unlearning Release Gate；collision 低到中。

只记 5 句话

  1. 不要让 agent 自证成功。
  2. artifact 要 pristine replay。
  3. layered gates 定位 failure stage。
  4. shortcut audit 是 benchmark 的一部分。
  5. 可直接迁移为 robust unlearning release gate。

Tier AAgent-Editing World Model: Rethinking World Modeling for LLM Agents NEW

人话版：AEWM 不模拟高熵 tool response，而判断当前 reasoning-action 是 Critical/Exploratory/Noisy；Noisy 时从相同 observed history 重写下一步，再交给真实环境执行。它直接针对错误假设和 stale plan 污染后续 state。

Method：Action Judge + State Revision + EditAct；Search/Terminal/SWE 跨域训练；verified EditAct trajectories 还能用于 AEWM-RFT。

Experiment：Action Judge macro-F1 70.5%，比 strongest frontier baseline +10.6pp；六 benchmarks、三个 Qwen3.5 backbones 上 EditAct average gain +3.2–6.7pp；AEWM-RFT 比 Self-RFT +2.2–2.6pp。强 backbone 上收益缩小是重要 failure signal。

Contribution：New Mechanism：state-editing world model；New Training Protocol：verified revision→RFT。Limitation：本次 primary arXiv 页面正文抽取不完整，因此不升 Tier S；在线 latency/cost 仍需单独量化。

Migration：将 Noisy 改为 Tainted-by-Forget，训练 CLEAN/TAINTED/UNCERTAIN judge；TAINTED 重写，UNCERTAIN 回退 selective replay。Worth Deep Reading: YES。

Tier AForgetting Without Restarting: Execution-State Unlearning for Stateful LLM Agents BACKFILL

人话版：长期 agent 的 forget 不能只删 plaintext memory，因为 summary、pending plans、KV cache 都可能派生自 target。论文要求 forget 后行为等价于“从未见过 target”的 counterfactual world。

Method：provenance graph 找 injection step τ；恢复安全 prefix / crop KV；sanitized replay 重建 suffix。理论上 exact unlearning 至少重算 T−τ+1 transitions，方法达到该 bound。

Results：memory deletion 对 leakage 基本无改善；instruction forgetting 在 elicitation 下 Leak@probes=1.00；source redaction 后 80% episodes 仍受 revoked preference 影响；selective replay 与 full reset indistinguishable，最多 9× fewer recomputed tokens。

Contribution：New Formalization + Mechanism + Evaluation。Limitation：真实 distributed provenance 更不完整，且不解决参数内知识。

Migration：它已强占 execution-state unlearning；剩余 gap 应做 multi-agent propagation、approximate attribution、learned taint editor/self-evolution reacquisition。Worth Deep Reading: YES。

Tier AOn the Robustness of Machine Unlearning for Vision-Language Models BACKFILL

人话版：VLM unlearning 不能只看原 prompt 上的 forget accuracy，因为 text/image/context/downstream retraining 都可能重新激活 target multimodal knowledge。

Method：统一评测已有 VLM unlearning，并加入多种 prompt settings、contextual prompting 与 recovery/retraining attack，问 forgetting 在 intervention 后是否仍保持。

Main Finding：作者报告多种方法在三类 attack 下仍能恢复 target multimodal knowledge，说明 standard forget evaluation 高估 robustness。本次检索未稳定抽取主表逐项数值，因此不编造 method×dataset 数字。

Contribution：New Attack/Evaluation + Empirical Finding。Limitation：attack suite 不是 adaptive upper bound；攻击失败也不能证明 deletion。

Migration：与你现有 Quantization/Relearning/FigStep/Jailbreak/Image-Rephrase/SUA 完全对齐；可加入 module-level subspace/probe 预测 recovery。Worth Deep Reading: YES。

Idea Mining

Idea 1 — Dual-View Agent Memory Unlearning（今日最佳）

Inspiration：EnSIMem。Gap：现代 memory 同时有结构化 address/index 与 source evidence，现有 deletion 常把 memory item 当单一对象。Hypothesis：index-only 会被 dense source recovery 绕过；source-only 会经 property/value/summary 泄漏。

Method/MVE：Address Graph + Evidence Graph 双视图；LoCoMo/LongMemEval 100 facts，比较 index-only/source-only/both/dual-closure；攻击 direct/paraphrase/temporal/aggregation/dense fallback。Model：Qwen/Llama 8B + EnSIMem；Baseline：vector delete、summary delete、SBU closure；Metric：fallback ASR、derived leakage、retain accuracy、closure size。Expected Contribution：New Formalization + Attack + Evaluation。

Novelty ★★★★★　Feasibility ★★★★★　Compute ★★☆☆☆　Risk：closure 标注；Collision Risk：中高。Best Venue：NeurIPS / ICLR / ACL。

Idea 2 — Tainted-State Editor for Agent Unlearning

AEWM × Execution-State Unlearning。训练 CLEAN/TAINTED/UNCERTAIN dependency judge；TAINTED state 从合法 history 重写，UNCERTAIN 回退 selective replay。MVE：三个 tool-agent suites 注入 secret/preferences；比较 full reset、PG replay、judge-only、hybrid。Metric：Leak@adaptive probes、recomputed tokens、task utility、false-clean rate。Novelty ★★★★☆　Feasibility ★★★★☆　Compute ★★★☆☆　Risk：false-clean；Collision Risk：高。Best Venue：ICLR/NeurIPS。

Idea 3 — Artifact-Grounded Unlearning Release Gate

FDE-Bench × robustness。fresh-load 每个 checkpoint，串联 Direct Forget → Paraphrase/Multimodal → Relearning/Quantization → Retain Utility → Adaptive Attack；关键 gate fail 就记录 first-failure stage。可直接离线重算现有 MLLMU checkpoints。Metric：Gate Pass Rate、First Failure Stage、Worst-Case Leakage、Utility Conformance。Novelty ★★★★☆　Feasibility ★★★★★　Compute ★☆☆☆☆　Collision Risk：低中。Best Venue：NeurIPS D&B/TMLR。
