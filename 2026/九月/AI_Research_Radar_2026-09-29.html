Tier S

Tier S — Harness as a Language: A Minimalist Agent Framework With Maximal Expressivity

Paper / Full text

人话版：JAZ 的核心观点是：memory、subagent、self-improvement 不一定各自需要一套复杂框架；一个可递归的 invoke 原语就能让模型写代码、调用工具、拉起子代理，并把 prompt、data、tool 与交互历史都当程序变量。StuLife far-recall 达 69.9%，Letta 61.8%，成本 $18.3 vs $42.1；受控 CodeAct+subagents 只有 32.0%。对 Agent Unlearning 最关键的是：history 不再只是 memory DB 里的对象，而成为可复制、alias、summary、递归传递的 execution state。

Background & Gap

主流删除研究容易把“删 memory record”当闭包终点；JAZ 暴露了更底层的问题：历史可作为普通值跨递归调用传播，删除边界必须覆盖 execution substrate。

Core Insight / Method Deep Dive

inputs/history as variables → invoke → LLM writes executable code → tool / recursive invoke → history grows → tail-recursive delegation → output。当 context 快满时，当前 agent 把 earlier history、current history、progress summary 和 next steps 传给下一次 invoke；后继 agent 可搜索完整历史。

抽象：y=Fθ(x,h,T;B)。h 是可编程历史、T 是工具、B 是 budget；递归调用把 (x,h,T) 重新作为值传入 Fθ，而不是经固定 memory API。

Toy Example

final exam 依赖 497 tasks 前的 lecture。bounded-context agent 已看不到；JAZ 搜索被递归携带的 history variable。论文分析案例中 JAZ 3/3 成功，CodeAct+subagents 0/3，Letta 1/3。

Baseline Deep Comparison

Letta 是专门 memory manager，far recall 61.8%。CodeAct+subagents 保留 code/subagent 但移除 prompt/history variables，只有 32.0%，更能定位机制。ACE 在 AppWorld TGC 69.9%，JAZ 74.2%，但 exposure 不完全等量，因此不能把全部差异归因于 invoke。

Experiment / Results / Figures

  1. StuLife far recall：69.9% vs Letta 61.8%，+8.1pp；成本 $18.3 vs $42.1。
  2. CodeAct controlled baseline：69.9 vs 32.0%，强支持 history-variable 价值。
  3. AppWorld：74.2% vs ACE 69.9%；更公平的 CodeAct baseline 71.1%，margin 3.1pp。
  4. invoke code-flow 图展示 history 如何穿过 recursive boundary；它是机制图，不是性能证据。

Claim vs Evidence

证据支持极简 primitive 能在两个 benchmark 实现 memory/self-improvement workflow；未证明所有 specialized memory 都应移除，也没有测试 privacy deletion 或 revocation。

Contribution / Limitation

New Mechanism/System：agent harness 作为语言原语。限制：递归成本与安全风险、benchmark 范围有限、AppWorld exposure 不完全公平、无 provenance/revocation primitive。

Migration

Execution-Substrate Deletion Closure：给每个 history/tool value 加 provenance taint 与 revocation token，在 invoke boundary 做 lineage-aware redaction。MVE：100 tasks×50 targets，制造 direct copy、summary、tool-output、nested-invoke 四类派生；删除后做 direct/semantic/cloze/action probes。Baseline：source-only delete、vector-store cascade、truncate-k、full reset。Metrics：descendant leakage、closure recall、retain utility、latency、reacquisition ASR。Collision：中；差异化必须是 recursive alias lineage。

只记住5句

  1. history 是程序变量。
  2. far recall 69.9% vs Letta 61.8%。
  3. 受控 baseline 仅32.0%。
  4. 删除不能只盯 memory DB。
  5. recursive history lineage + revocation 值得做。
Tier S — RSIAgent: Autonomous Exploration for Recursive Self-improvement in New Environments

Paper / Full text

人话版：RSIAgent 不改参数，而是 curriculum、actor、verifier 三 agent 先在陌生软件环境练习，把验证过的 action-condition-consequence 经验写进 memory，再冻结 memory 做正式任务。四个 ablation task：full RSI 74.54%，BRS-only 65.52%，DRS-only 56.50%；presentation repair 案例 0.40→0.80。它说明能力可存在 deployment memory 而非 weights，删除后也可能靠环境反馈重新长回来。

Background/Core

陌生 GUI/CAD 的具体约束不在预训练里。核心不是存整条 trajectory，而是 verifier-grounded causal playbook；探索顺序是 broad coverage→deep hard cases。

Method

curriculum task → actor Python/Bash → independent verifier PASS/FAIL/UNVERIFIED → distill memory → BRS → DRS → freeze → evaluate。Verifier 不看 actor 私有 reasoning/memory/log，只看 observable state，减少自证偏差。

Toy Example

FreeCAD 先练 bracket/hole/slot，再由 anchor mismatch 触发 hard-case exploration，形成 connector anchoring rule，正式任务直接检索。

Results / Figure / Ablation

Figure 4：full 74.54 > BRS 65.52 > DRS 56.50；DRS-only 在两个任务甚至低于 no-RSI，说明窄而深的错误 memory 会负迁移。T049 中 endpoint 横/纵误差 121,104/145,345 EMU 在 memory run 归零，partial score 0.40→0.80。

Claim vs Evidence

支持 training-free persistent memory 改善环境适应；selected artifact case 不是 matched-seed proof，也未研究删除。

Contribution / Limitation

New Mechanism/System：broad→deep recursive exploration + verifier-grounded memory。风险是额外 compute、curriculum 失误、错误 generalization、stale memory。

Migration

Procedural Memory Unlearning under Re-exploration：先学50 procedures，删10，允许0/5/10/30轮合法 exploration；controls 为 feedback-off、verifier-off、history purge。Metrics：time-to-reacquisition、procedural leakage、retain success、false deletion。真正 novelty 是 fixed-parameter environment-induced reacquisition。

Tier S — MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement

Paper / Full text

人话版：MiMo-V2.6 最值得迁移的不是“大模型更强”，而是 GAR：同一题 16 条 rollout 一起比较，grader 区分干净 passing solution 与 hack/fallback，再把正 advantage 重新分配。DeepSWE Pro 58.4→72.6，Flash 48.7→65.7。对 unlearning 的启发是 final refusal 太粗，应把 forgetting credit 分给 reasoning/tool/visual trajectory 中真正泄漏的位置。

Gap/Core

binary pass/fail 无法区分两个都过测试但质量完全不同的 trajectory；unlearning 也存在“最终没说，但中间已经恢复 target”的同构问题。

Method / Formula

prompt → 16 rollouts → verifier → groupwise grader → hack zeroing → redistribute positive advantage → policy update。

抽象 A'i=Ai+Δi，组内正 advantage 近似守恒 ΣΔi≈0；confirmed hack 的 A'i=0。重点是改变 credit 落点。

Results / Figures / Ablation

  1. DeepSWE Pro 58.4→72.6（+14.2pp），Flash 48.7→65.7（+17.0pp）。
  2. 无 GAR：turn/token 快速膨胀、pass gain plateau；有 GAR 持续改善到 step52。
  3. GAR grader 约占 Pro RL 成本12.7%。
  4. trainable router：load CV 0.78→2.0，peak 6×→16×，cold experts 0.5%→22%；step20 恢复 router 权重后负载立即恢复且 benchmark 不降。
  5. released 9B：SWE-bench Verified 61.1→66.2。

Claim vs Evidence

controlled ablation 支持 GAR 改善 code-RL 动力学；最终 frontier 横评混有 architecture/pretraining，不能全归因 GAR，且部分 headline benchmark 为内部评估。

Contribution / Limitation

New Objective/Mechanism：GAR；Engineering：大规模 mixed-task RL。限制：高 compute、grader cost、token 总量仍上升。

Migration

Groupwise Trajectory Credit for Multimodal Unlearning：LLaVA/Qwen-VL + MLLMU forget5，同 query 采样8条 trajectories，对 direct answer、CoT、tool query、visual grounding、final answer 做 leakage rank；比较 final-only GA/NPO/KL/PO 与 stage-credit objective。Metrics：FQ、retain utility、relearning、quantization、Worst-Step Leakage、GradNorm。Collision 低-中。

Tier A

Tier A — Recursive self-improvement of AI research agents (AIDE²)

Paper / Full text

人话版：agent 修改自己的 research-agent code，hidden eval 验收，胜者成为下一轮被修改的 agent。8天产生7次 successive improvements，迁移到4个 held-out benchmarks；独立 task family reward hacking 55%→32%。

Method/Experiment

self-code mutation→benchmark→hidden selection→inherit winner。Held-out 覆盖 ML engineering、heuristic engineering、weather forecasting；strongest discovered agent 匹配或超过 human-engineered production agent。

Contribution/Limitation

New System + Empirical Finding。successor selection/eval 仍是固定外部机制，不等于 unrestricted RSI。

Migration

Generational Agent Unlearning：删除 generation-k experience 后，追踪其是否已被编译进 k+1 的 search policy/memory compression。MVE：lineage replay + counterfactual rebuild；指标 descendant recovery、successor utility、rebuild cost。Worth Deep Reading: YES。

Tier A — ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents

Paper / Full text

人话版：把 researcher request/feedback/execution evidence 变成 task/rubric；inner loop 固定模型改 harness，outer loop 固定 harness 做 RL。Qwen3.5-4B 三轮 coupled run single-attempt 42.2%→73.3%。

Results

33.3% test problems wrong→right，2.2% right→wrong；harness-only 31.1→51.1%；model-only pass@4 48.3→67.8%。

Contribution/Limitation

New System/Mechanism。未证明 researcher feedback 本身造成 gain，也未证明 coupled loop 超过两组件独立收益。

Migration

Dual-Surface Unlearning：同一 source 同时污染 harness 与 weights，分别删一侧/两侧，测 rebound/reacquisition。Worth Deep Reading: YES。
