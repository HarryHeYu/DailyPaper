Tier S

1. Forgetting Without Restarting

基本信息：Chao Yao, Yangbo Wei, Zhen Huang, Junhong Qian, Chenle Chen, Shaoqiang Lu, Chen Wu, Lei He；Arizona State University / Eastern Institute of Technology, Ningbo；arXiv:2609.04875v1，2026-09-04；Paper。

人话版

这篇直接定义 Execution-State Unlearning：长期 Agent 不仅有 plaintext memory，还有 summary、过去回答、pending tool plan 和 KV cache；只删 memory record 并不会把这些 derived artifacts 一起删掉。作者把 runtime 写成 deterministic transition system，定义“从未见过 target”的 counterfactual agent 作为 exact reference。target 在第 τ 步进入后，τ 之前 prefix 可复用；没有更细 token attribution 时，τ 之后 suffix 都可能被污染，因此 exact forgetting 至少要重算 T−τ+1 个 transition。Provenance-Guided Selective Replay 通过 provenance graph 找 taint closure、crop KV 到 target 前 checkpoint、sanitized replay 后缀，达到这个下界。三套 Agent 任务里 Memory-Delete 与 No-Forget 泄漏完全一样；Selective Replay 与 Full Reset 等价，却只重算 133 vs 1235 tokens，约 9.3× 更省。

Method Deep Dive

R_T + forget target z → LocateSource(z) → FirstEntry τ → TaintClosure I(z) → latest checkpoint c* before τ → crop KV / restore env snapshot → sanitize recorded observations → shadow-execute & deduplicate tools → regenerate answers / summaries / plans / KV → R'_T = target-free counterfactual state
R_t = F(R_{t-1}, o_t; θ) Minimum exact recomputation = Ω(T-τ+1) Selective Replay recomputation = T-τ+1

Results

  • Memory-Delete LME/TS/AD = 0.86/1.00/0.97，与 No-Forget 完全相同。
  • Source-Redaction 仍 0.84/0.94/0.39。
  • Forget-Instruction 在 adversarial elicitation 三 suite Leak@probes 均 1.00。
  • Selective Replay 三个 suite Any-leak 全 0、CAD=0，与 Full Reset agreement=1.0。
  • 重算 token：B7 133、Full Reset 1235、PrefixCache 202。

Migration

向 Multi-Agent 扩展：Agent×Artifact provenance DAG + 每个 Agent clean checkpoint + distributed replay frontier。关键指标 Cross-Agent Leak@k、Team CAD、Replay Tokens、Closure Rate。

2. TROVE

基本信息：Tianxing Wang, Mingming Zhao, Shuai Huang, Huiyang Xu, Chaoyue Niu, Shengzhong Liu, Fan Wu；arXiv:2609.05019v1，2026-09-04；Paper。

人话版

TROVE 解决“计划后缀变 stale”：离线从 workflow search traces 蒸馏 atomic/composite skills 和 outcome-conditioned transition graph；在线 planner 可提出多步 route，但只 commit 第一个 skill。每次得到 runtime outcome 后，剩余 route 要么 Retain、要么 Insert 局部修复、要么 Replace 失效 suffix。18 个 backbone×benchmark blocks 里 15 个 best/tied-best score、16 个最短 online time。Qwen3-8B HumanEval 完整 TROVE 92.37%；去 offline structure 降 77.86，去 Insert 降 82.44。

Method

Offline traces→atomic/composite skills→transition graph Online query→provisional route → execute only head → observe outcome → RETAIN / INSERT / REPLACE invalid suffix → repeat

Results

  • 18 blocks 中 15 个 best/tied-best score，16 个 shortest time。
  • 对 AFlow 16 settings 提升 score，最多 +31.37pt；时间最多 -86.7%。
  • DeepSeek MATH 74.07→80.86，time 68.88→26.08min。
  • Qwen MATH 8.44→36.42，time 273.35→36.41。

Migration

Forget event 后只 invalidate 依赖 target 的 future skills。与 Execution-State Unlearning 的差异点应放在 semantic/skill route 级别最小修复、以及不可完整 replay 的环境。

3. DCFA

基本信息：Zehao Wang, Lanjun Wang, Shilong Jin, Junjie Chen, Yanghua Xiao；Tianjin University / Fudan University；arXiv:2609.04749v1，2026-09-04；PDF；Code。

人话版

Multi-Agent trace 里“最早看起来不对”不一定是真正决定最终失败的原因。DCFA 先用 Global Causal-inspired Attribution 构建 dependency graph，再用 Local Counterfactual-inspired Enhancement 在局部估计“纠正某 interaction 后最终 outcome 改善多少”。Who&When 上，平均 step-level accuracy 从 32.28→44.79 和 16.67→20.69。

S(τ_i)=Cos(Enc(Y^(i)),Enc(Y*)) ΔS(τ_i)=S(τ_i)-S(τ_{i-1})

Results

  • Algorithm 平均 32.28→44.79。
  • Hand-crafted 16.67→20.69。
  • GPT-5 Algorithm 31.75→47.62，Hand 15.52→24.14。
  • LCE 对长 trace 更有价值，但总成本约 300s/trajectory。

Migration

把“纠正错误”改成“删除 target descendant”，用 ΔLeak 与 ΔUtility 定义 Deletion Credit，从 provenance closure 进一步走向“因果最小删除集”。

Tier A

4. Defense-as-Skill

把 runtime guard 做成可进化 skill。GLM-5 ID ASR 0.482→0.104，OOD 0.606→0.115；adaptive attacker 后总体 ASR 45.1→22.9。可迁 Skill Unlearning：删除后继续 MCTS/evolution，测 target semantics 是否重新进入 skill。Worth Deep Reading: YES。

5. What’s in Your Agent’s Context?

CoRA 分析 12 个真实 harness，发现 role/scope context escalation。1761 candidate paths 中约 58% 被行为验证。对 Agent Unlearning，应跟踪 target 在 tool/user/memory/skill/system-like context 之间的 cross-scope persistence。Worth Deep Reading: YES。

6. ClaimReceipt

把 evidence sufficiency 与 coverage 分开；1,392 历史 records 可 exact replay，11/11 semantic faults 正确检测。可迁为 Unlearning Receipt：预签 forget/retain/recovery manifest，缺 probe 只能 Inconclusive。Worth Deep Reading: YES。

7. Efficient Test-Time Adaptation through Human-AI Interaction

约 20 次普通人类交互就能产生明显 context/weight adaptation。对 Continual Unlearning，应测 normal-interaction reacquisition，而不是只测刚删除后的静态状态。Worth Deep Reading: YES。

Tier B

8. The Safeguard Worked. Is the LLM System Safer?

核心启示：单次低 ASR 不代表系统面对 adaptive attacker 就安全。Unlearning 评估也应从 Leak@1 升级为 Leak@budget、best-of-k、adaptive multi-view recovery。Potential Use: Threat Model / Robust Evaluation。

9. Selective Knowledge Edit Reversal via Gated Singular Vector Shrinkage

对 edit update 做 SVD，并选择性收缩 target-related singular directions。可用于分析 GA/NPO/LoRA update 中 forget 与 retain collateral 是否位于不同低秩方向。Potential Use: Subspace Audit / Repair。

10. Gaussian Core LoRA

Broad concept 是一个 distribution，不是单一 direction。对 MLLM identity unlearning 可把 real/paraphrase/cloze/cross-modal 建模成 target distribution。Potential Use: Multimodal Localization / Concept Erasure Baseline。

Idea Mining

Idea 1 — Distributed Counterfactual Execution-State Unlearning（Best）

Multi-Agent 有多个异步 first-entry 与跨 Agent descendants。构造 Agent×Artifact provenance DAG，求 minimal distributed replay frontier。MVE：5 agents×20 targets×1–3 hops；Metrics=Cross-Agent Leak@k、Team CAD、Replay Tokens、Closure Rate。Novelty★★★★★ Feasibility★★★★☆ Collision 高。

Idea 2 — Causal Minimal-Deletion Credit

Global graph 找候选，local counterfactual deletion 估 ΔLeak/ΔUtility，寻找更小的 delete set。Novelty★★★★★ Feasibility★★★★☆ Collision 中。

Idea 3 — Unlearning Receipts

预签 Forget/Retain/Recovery manifest；每个 probe/seed/checkpoint 产生 typed receipt；缺任何 committed attack 只能 Inconclusive。Novelty★★★★☆ Feasibility★★★★★。

Idea 4 — Normal-Interaction Reacquisition after Unlearning

删除后通过普通 human feedback 自然 relearn。MVE：1/5/10/20 弱相关 sessions，测 Time-to-Reacquire、Behavioral F1、Direct Leak、Retain Personalization。

Collision Detection

⚠️ Deletion Closure HIGH：Execution-State Unlearning 已覆盖 memory/summary/plan/KV descendant closure；剩余空间主要在 Multi-Agent distributed frontier、不可重放环境、parametric+runtime joint deletion、continual re-formation。

⚠️ Multi-Agent causal deletion MEDIUM：DCFA/EDGE/Hindsight 已让 dependency attribution 变拥挤；应证明因果最小删除集显著减少 over-deletion。

⚠️ Skill/Trajectory MEDIUM-HIGH：Repo-To-Skill/MASkills/TROVE/Defense-as-Skill 已覆盖构造、进化、routing、runtime editing。重点应是 targeted revocation + regeneration。

⚠️ Black-box Recovery HIGH：UMPeek/SFRA/Reference-Grafting/LENS-U 等已很拥挤，新攻击必须 adaptive/source-free 或服务 verification。
