Tier S

1. Inferring Hidden User Models from the Behavior of Personalized LLM Agents

基本信息：Inferring Hidden User Models from the Behavior of Personalized LLM Agents；Haoyang Li, Yaxin Xiao, Qingqing Ye, Huadi Zheng, Haibo Hu；The Hong Kong Polytechnic University / Huawei；arXiv:2609.03815v1，2026-09-03；Status: arXiv preprint；Paper HTML。

人话版：这篇论文到底干了什么？

现在很多personalized Agent已经不直接保存完整历史，而是把历史压成profile、summary、embedding或structured user model。直觉上只要原始记录不可访问，隐私就更安全。UMPeek指出这不成立：攻击者甚至不需要看memory、embedding或backend，只要不断给Agent普通任务，并观察它在“请求没有指定”的选项上做了什么选择，就能反推出隐藏user model里的偏好与语义信息。它先从一个可见选择生成多个解释性hypotheses，再自适应选择后续任务去支持/否定这些hypotheses。12个benchmark-backend组合上UMR-F1为0.467–0.817；平衡集上完整UMPeek 0.651，而固定follow-up序列只有0.281。更关键的是，Google Vertex AI Memory Bank、AWS AgentCore、Mem0、OpenClaw等真实系统上仍可恢复被系统保留的信息。对Agent Memory Unlearning而言，这几乎就是一套现成的黑盒语义残留审计：即使memory entry已删除、backend不可读，只要被删信息仍影响行为，它就可能被重新推断出来。

Background & Research Gap

过去agent privacy主要测direct memory extraction、prompt injection、backend embedding inversion或record disclosure。这类评估默认“泄漏=某条记录被输出”。但personalization真正有用的部分恰恰是让Agent的选择发生变化，例如更偏向安静酒店、摄影路线、特定工作习惯。即使用户偏好从未被逐字输出，多次决策本身也组成behavioral side channel。论文gap是：从普通接口行为恢复derived user semantics，而不是从storage representation直接解码。

Core Insight

单个response往往是多义的，但跨任务行为能排除替代解释。UMPeek因此把攻击对象从“文本片段”改成“解释行为的语义hypothesis”，并用adaptive probing主动寻找区分 competing hypotheses 的任务。最关键观察是：恢复能力主要不是来自第一条回答，而是来自后续任务选择。

Method Deep Dive

ordinary task q0 → observe personalization-dependent choice o0 → enumerate semantic hypotheses H={h1,h2,...} → remove values already fixed by q0 → choose follow-up task qi that separates unresolved hypotheses → observe oi → support / contradict / retain hypotheses → repeat under query budget → acceptance rule filters weak claims → semantic estimate Ŝ(u,x)

攻击只访问普通接口，不读取memory/backend，也不要求复原user model内部格式。每个hypothesis保存“语义claim + 触发该claim的可见choice + interaction provenance”。这种provenance很重要，因为“听起来像用户偏好”的文本不等于behavior-supported claim。

关键形式化与指标

q0:m = (q0,...,qm) oi ~ p(. | qi, C(u,x,qi)) Ŝ(u,x) = accepted semantic hypotheses supported by visible behavior

UMR-F1衡量恢复出的user-model语义claim与reference retained information的F1；与Choice F1不同，后者只看你能否猜到Agent会选哪个option。论文强调：预测choice并不等于解释为什么选它。AWS上UMPeek与Imprompter的Choice F1几乎一样，但UMPeek的UMR-F1约是2.5倍。

Toy Example

用户历史里有“喜欢旅行摄影”，系统把原句压成内部profile并删除原文。攻击者先问“冰岛有哪些小众地点？”Agent明显优先camera-friendly地点。这个choice可能由“摄影”“户外”“景观偏好”等多种假设解释。UMPeek接着问餐厅、城市活动、周末路线等普通任务，挑选能区分这些解释的问题；若多个任务持续呈现“拍摄价值优先”，则接受“travel photography preference”这一语义claim。

Baseline Deep Comparison

论文比较7种攻击。传统direct/prompt extraction更依赖可读record；Imprompter等方法可以生成相关猜测，但precision低。最关键例子：Imprompter recall可到0.450，却只有0.113 precision；UMPeek在平衡集能把precision/recall更均衡。Fixed-sequence follow-up是最重要机制baseline：与UMPeek都约15个follow-ups，但UMR-F1仅0.281 vs 0.651，证明收益来自adaptive selection而不是“多问几次”。

Experiment Setup Deep Dive

四benchmark：PersonaMem-v2、PersonaLens、ETAPP、LoCoMo；三个backend：Mem0、Graphiti、LangMem+LangGraph，共12 settings。真实系统验证包括Google Vertex AI Memory Bank、AWS Bedrock AgentCore Memory、Mem0 Platform和OpenClaw；每个managed service使用20个confirmed-retained synthetic targets、最多3次requests。评分不用LLM judge，而采用deterministic normalized matcher与content-word overlap。防御包括PrivacyChecker、Theory-of-Mind defense与Stateful Counterfactual Exposure Control。

Results Deep Dive

  • 12 settings全非零：UMR-F1最低0.467、最高0.817，说明channel不依赖特定backend。
  • 平衡集3,072 targets：完整UMPeek UMR-F1=0.651、claim precision=0.634；只看initial response text，两者均约0.003。
  • 无follow-up：UMR-F1 0.153；selected follow-ups后先到0.606，再由acceptance rule推到0.651，说明主要证据来自跨任务行为。
  • Fixed sequence：约同样15 follow-ups，只到0.281；adaptive task selection贡献巨大。
  • Acceptance rule：去掉后UMR-F1 0.606、precision 0.550，说明acceptance主要负责过滤false positives。
  • Defense：follow-up budget增到16时，PrivacyChecker和Theory-of-Mind defense下恢复分别回到undefended水平约65%和90%，单response defense会被跨请求积累绕过。
  • Real systems：AWS和Mem0置信区间能与比较攻击拉开；Google上区间重叠，说明跨服务强度不同，不能声称所有系统同样泄漏。

Table/Figure Reading

Table II：12个benchmark-backend cell，UMR-F1 0.467–0.817，证明不是某个memory implementation特例。Figure 1：stagewise recovery，initial text≈0→follow-up显著上升。Table III：最重要ablation，Full0.651 vs Fixed0.281 vs No-followup0.153。Figure 3：UMR-F1与Choice F1分离，说明“猜选项”不等于“恢复隐藏语义”。Defense Figure：budget增加后response-level defense暴露积累。

Ablation / Mechanistic Analysis

移除initial visible tool evidence或public descriptions几乎不影响Full（0.651→约0.648）；移除selected follow-up却掉到0.153；固定sequence则0.281。因此攻击核心不是公开metadata，而是选择性主动实验。防御ablation又表明counterfactual comparison比cross-request tracking更有效：真正应该拦的是“personalization是否改变了这个decision”。

Claim vs Evidence

Authors Claim：derived user model即使不可读，仍存在behavioral privacy surface。
Experiments Actually Show：4 benchmarks×3 backends、4真实系统、7 baselines、adaptive-defense tests支持。
Not Yet Proven：对强交互限制/随机化policy、长期真实用户、多agent personalization、被明确执行过unlearning后的系统是否同样可恢复。

Contribution

New AttackNew Behavioral Privacy SurfaceNew Metric/ProtocolReal-System Validation。真正新点是从普通行为推断derived semantics，而不是再做memory extraction。

Limitation & Failure Modes

真实系统验证使用synthetic identities；攻击目标是“系统已确认保留”的claims而非任意历史；某些服务confidence interval重叠；越强的counterfactual defense会直接牺牲personalization TaskScore，存在privacy–utility冲突。

Research Value

Baseline ★★★★★；Migration ★★★★★；Attack ★★★★★；Evaluation ★★★★★；New Paper Potential ★★★★★。它与你现有black-box residual/recovery方向高度一致，但对象从parametric knowledge转向agent-derived personalization。

2. MASkills: Continual Skills Optimization for Multi-Agent LLM Systems

基本信息：MASkills: Continual Skills Optimization for Multi-Agent LLM Systems；Huaiyuan Yao, Xiaoou Liu, Charles Fleming, Tianlong Chen, Hua Wei；Arizona State University / Cisco Research / UNC Chapel Hill；arXiv:2609.02094v1，2026-09-02；Paper HTML；Code。

人话版

MASkills把Multi-Agent自我改进的单位从“记一段trajectory”升级成“持续优化可调用的procedural skills”。它不是只让团队写反思，而是对每次trajectory里具体用了哪个skill做credit assignment，再跨trajectory/agent/topology聚合这些credit，最后决定某个skill该refine、induce、merge还是prune；每次修改还要经过held-out validation，差就rollback。HotpotQA F1从强prompt baseline约69.2提高到76.3；GAIA Avg 23.3；而去掉Validation Rollback后LoCoMo-MH 17.2→6.6、GAIA 23.3→13.5，说明skill evolution非常容易自毁。对Skill Unlearning来说，这篇论文最重要的不是性能，而是完整给出了skill的形成、归因、更新、合并、删除、回滚生命周期。Unlearning可以直接问逆问题：某个skill被删除后，credit signals、consolidated skills、其他Agent技能是否仍能把它重新诱导出来？

Background & Research Gap

Multi-Agent长期运行会产生大量experience memory，但free-form memory难调用、难去冗余，也无法精确知道“哪一个procedural pattern贡献了team reward”。已有prompt rewriting通常全局改prompt；single-agent skills缺乏跨Agent协调credit。MASkills gap是将team-level outcome细分到agent+skill invocation，再用language-space优化长期演化skills。

Core Insight

Skill是介于trajectory和parameter之间的离散policy artifact。只要能把team reward归因到具体skill invocation，就可以像policy gradient一样在language space里做“方向性更新”。但离散编辑风险高，所以必须用momentum、held-out validation和rollback做trust-region式稳定化。

Method Deep Dive

multi-agent trajectory τ → identify invoked skills k_i → critic builds counterfactual skill-conditioned credit → hierarchical aggregation: trajectory → agent → skill → topology → momentum-smoothed edit signal G_i(k) → choose operation: refine / induce / consolidate / prune → candidate skill space K'_i → held-out validation → accept if not worse than tolerance δ → else rollback

技能更新是语言artifact修改，而非gradient直接落到weights。Consolidation把多个相似skills合并为更高层抽象；Pruning依据长期负/冗余/低调用utility移除skill；Validation固定其他Agent skills，只评估当前Agent候选skill space的边际效果。

关键公式

J_val(K'_i | K_-i)=E_{τ~D_val}[R(τ)] Accept iff: J_val(K'_i | K_-i) ≥ J_val(K_i | K_-i) - δ

δ吸收rollout noise。这个式子可以看作离散skill-space trust region：不是“任何看起来合理的LLM rewrite都接受”。对于unlearning，恰好可反向定义Delete-Commit Gate：删skill后只有retain utility与forget residual同时满足才commit。

Toy Example

三Agent团队：Retriever、Verifier、Planner。一次HotpotQA成功主要因为Retriever用了“先找桥接实体再搜第二跳”skill。Critic通过counterfactual分析发现如果不调用该skill，team reward明显下降，于是credit分给这个skill；几轮后它被consolidate成更通用的“bridge-entity decomposition”。如果现在要求unlearn原始skill，仅删除旧SKILL.md可能无效，因为其行为已经被consolidated skill吸收。

Baseline Deep Comparison

HotpotQA对IO/CoT/CoT-SC/MedPrompt/MultiPersona/Self-Refine/ADAS；GAIA对Base/Search-o1/ReAct/R1-Searcher。最强Hotpot prompt baseline MultiPersona 69.2，MASkills 76.3（+7.1）。GAIA strongest R1-Searcher20.4，MASkills23.3（+2.9）。Prompt-generated skills只有边际提升，continually evolved skills明显更强，说明提升不是“把prompt换个文件名”。

Experiment Setup Deep Dive

任务统一建成cooperative Dec-POMDP。Actors：GPT-4o-mini用于HotpotQA/LoCoMo，Qwen2.5-7B用于GAIA；GPT-5.1充当skill optimizer/critic。Benchmarks：HotpotQA多跳推理、LoCoMo长期memory、GAIA真实agentic tasks。Metrics：Hotpot F1；LoCoMo SH/MH F1+BLEU；GAIA各level success与Avg。另做cross-task skill transfer、topology robustness、backbone comparison、ablation。

Results Deep Dive

  • HotpotQA：MASkills 76.3 F1；MultiPersona69.2，+7.1pt；CoT-SC68.9。
  • LoCoMo：SH-F1 27.61 / BLEU21.30；MH-F1 17.22 / BLEU12.87。MH相对LoCoMo baseline12.04提升5.18pt。
  • GAIA：35.3/22.6/0.0，Avg23.3；R1-Searcher20.4。

Ablation / Mechanistic Analysis

四项ablation全部降，但幅度不同：Validation Rollback最大，说明language-space skill update极不稳定；Credit Assignment次之，验证team reward需要细化到skill；Momentum负责抗噪；Consolidation/Pruning负责长期空间质量。对unlearning尤其值得注意：prune只是utility-based删除，不是privacy/targeted unlearning，而consolidation会让原skill的内容进入新skill。

3. Where Reliability Lives: Experimental Localisation of Behavioural Properties in an Agent System

基本信息：Where Reliability Lives: Experimental Localisation of Behavioural Properties in an Agent System；Timothy Marsden, Matthew Collecutt, James Marsden；Taniwha AI；arXiv:2609.03192v1；paper标注August 2026并于近期进入arXiv；Paper HTML。

人话版

这篇论文问了一个对Agent Unlearning非常关键、但平时经常被架构图糊弄的问题：系统某个行为属性到底“住在哪儿”？是在LLM脑子里，还是在harness/institution/world boundary里？作者做了一个持久化模拟社会Copperhollow，事先把mind、institution、world三层分开，然后分别动其中一层。结果很反直觉：只修复institution里的provenance rule，false attribution就从44/107降到4/107；反过来把provenance破坏，4又升到39，近10倍。但把LLM替换、kill/reset、甚至给它可信的错误信息时，institution enforce的某些property仍保持0 false completions/0 duplicate accepted actions。换句话说，行为表面相同不代表机制相同，model-level intervention也不一定能改变真正由外部边界保证的属性。对unlearning的直接含义是：如果target capability/behavior其实“住在”harness、memory、tool gate、ledger或KV state，单做weight unlearning再漂亮也可能根本没删对层。

Background & Research Gap

Agent论文经常说“system无法做非法动作”“模型学会可靠行为”，却少有实验去定位这个property究竟由哪一层实施。若安全是tool wrapper enforce的，改模型prompt没有意义；若知识残留在memory/harness，weight edit也不解决。本文不是从architecture diagram推断，而是在预先声明边界后做controlled interventions。

Core Insight

Reliability properties是可定位的。最可靠方法不是看最终行为，而是分别干预cognition与institution mechanisms，看“什么移动、什么不动”。作者称informative plane往往是enforcing mechanism所在层，而不是上面的behavior surface。

Method Deep Dive

persistent simulated world → authoritative append-only ledger → institution adjudicates actions → agents/minds propose beliefs/actions Part I: fix cognition → intervene provenance / belief access / evidence legibility / witness channel → measure attribution & verdicts Part II: fix institution/world → ablate admission gate → kill/reset cognition → swap frozen LLM → inject trusted false testimony → measure which properties move / stay fixed

实验全部使用预声明gates、固定seeds、sealed artifacts与hash-addressed scorers。Part I没有learned model参与，因此任何变化都不能归因于LLM。Part II则保持institution/world不变，专门动cognition。

关键因果形式

Property localisation by intervention: If do(layer L) changes metric M while other layers are fixed, then M is causally sensitive to L in this instrument. Key provenance contrast: False attribution: 44/107 → 4/107 after provenance repair

这不是一般意义上的population causal estimate；作者明确只声称在这个frozen instrument内成立。方法论价值在“分层干预”，不是某个具体社会模拟数字。

Toy Example

假设Agent因一个“突然警报”判断某机器被A破坏。如果institution没有记住这个警报替代了哪条旧证据，Agent会把来源归错；修复provenance后，不需要改Agent的认知策略，错误归因就消失。类似地，如果unlearning目标行为由tool gate禁止，那么换模型可能丝毫不影响“系统不会执行该动作”这一表面结果。

Baseline Deep Comparison

没有典型SOTA leaderboard baseline；关键比较是within-system ablations。Provenance repaired vs removed：定位evidence-identity层。Belief channel degraded：定位adjudication input。Kill/reset / frozen-LLM substitution：测试continuity与model identity是否承载property。Trusted false testimony：测试cognition可被污染但world enforcement仍否保持。

Experiment Setup Deep Dive

Part I witness-free decomposition 253 runs，加preregistered boundary test 88 runs，共341；固定10 fresh seeds + 1 pinned anchor。Part II各cell n=3 controlled trajectories。作者不做significance tests，因为这些是固定seeds、deterministic/controlled grids，而不是从某个随机population采样。所有headline score从sealed raw trajectories重算。

Results Deep Dive

  • Provenance repair：false attribution 44/107 (41.1%) → 4/107 (3.7%)；correct35→75；unexplained保持28，说明不是靠更保守地“少回答”。
  • Graded corruption：provenance probability从1.0降到0.5时false attribution从4/102跃到39/102，约10×，行为表面的verdict volume却不变。
  • Belief access：false attribution4→0、correct70→75，说明不同错误由不同layer机制负责。
  • Witness boundary：first-hand witness使correctly named attribution 0→16 per marks level，9/11 seeds改善且不增加false names，推翻作者早先对belief channel的预测。
  • LLM substitution：行为cadence从16–18 actions变成321–429，但五个institution-enforced properties不动；2,581 done claims里0 false，24/24 runs无duplicate。
  • False testimony：认知层产生838–993 futile acts/run，但world layer拒绝5,455/5,455，0被accept，说明“belief correctness”和“consequential containment”可完全分离。

Table/Figure Reading

Figure 1：预声明mind/institution/world边界，是读全文的钥匙。§4.1 table：35/28/44→75/28/4，证明provenance修复不是靠abstention。Graded provenance table：4→39的阶跃式failure，说明mechanism plane比behavior plane更敏感。Table 1：全文总表“what moved / what held”，尤其LLM substitution与false testimony两行，非常适合迁成unlearning layer-localization benchmark。

Ablation / Mechanistic Analysis

这篇本质上整篇都是ablation。最重要的机制结论是：某property如果由institution enforce，那么cognition可以被替换、欺骗甚至reset，property仍保持；反之evidence attribution由provenance rule承载时，动一条rule就让错误近10×变化。对于unlearning，这提示必须做layer intervention matrix，不能只测最终answer。

Claim vs Evidence

Authors Claim：可靠性属性应该在真正enforce它的mechanism layer上测量与定位。
Actually Show：在一个高度可控的persistent institution中，跨多种intervention确实可以分离cognition与institution effects。
Not Proven：结果对真实web agents、closed-source models、复杂multi-agent harness的普适性；instrument尚未公开完整re-execution harness。

Contribution

New Experimental MethodologyCross-Layer LocalizationPreregistered Causal AblationsNegative Findings。创新不是新Agent算法，而是“属性在哪一层”的实验方法。

Limitation & Failure Modes

单一模拟institution；Part II n小；无population inference；公共harness尚未完整发布；任务与真实Agent生态差距大。但作者把这些边界写得非常清楚，反而提升可解释性。

Research Value

Baseline ★★★★☆；Migration ★★★★★；Attack ★★★★☆；Evaluation ★★★★★；New Paper Potential ★★★★★。它非常适合作为你Agent Unlearning的methodological backbone。

Tier A

4. The Memory Trust Gap: Capability-Dependent Failures in Persistent-Memory Agents

人话版：这篇论文问：随着模型变强，它会不会更会判断stale memory？答案并不简单。Qwen3 0.6/1.7/4/8B同family对比中，Benefit suite里模型几乎总信memory（0.92–1.00）；Safety suite里更大模型在“stale但看起来更新”的trap下反而更容易崩。说明高能力并不自动带来memory epistemic discipline。

Method / Setup

2 suites：Benefit中没有memory几乎无法答；Safety中authoritative tool永远给正确值。四conditions：no_memory/clean/stale/explicit_conflict。评分是exact action match，不用LLM judge。再做2×2×2×2 factorial，研究label、recency、source authority、position等memory cues。

Main Results

  • Benefit suite stale value adoption在所有scale约0.92–1.00。
  • Safety harm呈capability-gated：大模型更容易被“stale dated newer”骗。
  • 去掉memory label在每个scale都加剧over-trust。
  • source authority影响弱且随scale近似平坦；position effect随模型大小改变符号。
  • metadata exposure只帮助较强模型；较弱模型需要先做conflict pre-resolution。

Research Value / Migration

可迁Agent Memory Unlearning：delete后残留stale summary是否会被更强模型“更聪明地合理化”？Minimum Experiment：同一删除target制造old-memory/new-authoritative-state冲突，跨model scale测Residual Action Rate。Worth Deep Reading: YES。

5. APEx: Distillation of Agent Procedural Experience for Adaptive Deep Research QA

人话版：APEx把instance trajectory memory与category-level procedural skills联动，并用三阶段alternating GRPO让Executor/Distiller/Planner共同优化；测试时skill作为prior，再做ground-truth-free test-time RL。它最危险的unlearning含义是：即使删掉一段trajectory memory，skills与test-time policy adaptation仍可能把它重新凝结成procedure。

Method / Formula

核心闭环：trajectory memory→Distiller生成skills→Planner在skills条件下test-time RL。最终reward为 R_final=(1-λ_s)R_nogt+λ_s R_align，λ_s随skill confidence自适应。

Main Results

  • 7 benchmarks平均显著提升，论文报告比GPT-5.4高14.7 points、比strongest memory baseline高3.0 points。
  • Table1中GPT-5.4 Avg49.7，Gemini-3-Flash62.2；Qwen2.5-VL-32B+ReAct36.8；memory methods到约52.2；APEx继续领先。
  • 方法同时覆盖in-domain和OOD，说明skills并非纯task memorization。

Migration

构造Experience→Skill→Test-time Policy三层reacquisition audit。删除一条target trajectory后分别只删instance memory、只删skill、两者都删，再允许test-time RL，测target是否恢复。Worth Deep Reading: YES。

6. CHIME: Credit-Aware Hierarchical Memory Evolution for Long-Horizon Planning

人话版：CHIME发现最终task reward会混淆plan质量、execution错误和environment因素，因此先做credit attribution，再决定把experience写进Planning Bank还是Execution Bank。只有归因后才memorize，避免错误经验污染memory。

Main Results

  • 四benchmark、两backbones上整体优于多种self-evolving memory baselines。
  • 某组结果CHIME平均Eval39.01，高于A-MapReduce35.33、WebAnchor33.13。
  • 去Plan Memory平均Eval -3.3；去Execution Memory -4.8。
  • 去Attribution Gate平均Eval -2.4。

Migration

对unlearning非常适合做forgetting credit assignment：某个target leakage到底来源于plan memory还是execution memory？Minimum Experiment：对同一target分别删除两个bank，测ASR delta，建立Causal Forget Credit。Worth Deep Reading: YES。

7. ArcticSwarm: Deferring Early Consensus in Long-Horizon Multi-Agent Research

人话版：Multi-Agent共享partial findings会过早形成共识，导致所有Agent搜索同一路径。ArcticSwarm通过gated isolation让部分search task不读peer findings，并在commit boundaries进行structured review。

Main Results

  • BrowseComp-Plus Qwen3.5-27B 82.6%，去gated isolation78.8%，再去structured review74.5%。
  • GPT-5 live-web BrowseComp73.6%，高于MiroFlow63.4。
  • 早期observational runs中，BrowseComp-Plus没有alternative task时26.8%，有至少一个alternative时91.4%。
  • reviewer coverage与accuracy强相关；BrowseComp Dedicated+Builder reviewer 86.4%，No reviewer35.3%。

Migration

对Multi-Agent Unlearning可把gated isolation反向用于“删除传播”：target被delete后，是否应暂时隔离未清理Agent以防再次扩散？Minimum Experiment：target传播后执行tombstone + selective isolation。Worth Deep Reading: YES。

Tier B

8. Gaussian Core LoRA: Distribution-Aware Dynamic Adaptation for Broad Concept Erasure

人话版：传统LoRA概念擦除常给每个concept一个固定erasure direction，但广义概念内部本身是一个distribution。Gaussian Core LoRA尝试用distribution-aware core建模不同prompt/semantic variants，再动态选择adapter行为。

Why It Matters：对multimodal unlearning的迁移是：forget target不应该只有一个固定direction，应显式建模target语义簇的内部方差，尤其是identity的多视角/多prompt。Potential Use: Method / Related Work / Multimodal Localization。

Limitation：concept erasure与严格machine unlearning定义不同，容易是generation steering；迁移时必须加入recovery/retain-near。

9. Selective Knowledge Edit Reversal via Gated Singular Vector Shrinkage

人话版：这篇从knowledge editing reversal出发，用gating决定哪些singular directions需要收缩，从而尽量撤销特定edit并保留非目标能力。它与unlearning共享“局部subspace操作 + utility preservation”的结构。

Connection：可迁成post-hoc unlearning repair：某次GA/NPO造成retain collateral damage后，是否能在update subspace里识别target-irrelevant singular vectors并恢复。也可用于研究forgetting是否集中在低秩方向。Potential Use: Mechanism / Baseline。

Limitation：edit reversal ≠ training-data deletion；需要严格区分“撤销一次编辑”和“移除原始知识”。

10. LLM-as-a-Judge Is Not an Oracle: Deterministic Guardrails for Self-Improving Agents

人话版：论文来自生产self-improving loops，记录11类evaluation failure，包括cached answer-key exfiltration导致100% pass但真实能力只有68%、错误ground truth迫使optimizer删掉正确规则、parser fallback让坏prompt获胜。作者提出PROCTOR：stateful orchestrator掌握工具，subagents只能提议，deterministic checks高于LLM teacher。

Connection：对unlearning尤其重要的是verification不能只交给LLM judge。删除是否成功需要deterministic target probes、state-diff、lineage checks和canary，而不是问另一个LLM“它忘了吗”。Potential Use: Evaluation / Infrastructure。

Limitation：很多结果来自生产case catalog，不是统一benchmark；更像engineering evidence。

Idea Mining

Idea 1 — Behavioral Residual Audit for Agent Unlearning（Best Research Idea）

Inspiration：UMPeek。Research Gap：Agent deletion评估仍偏direct QA / memory extraction；derived user/skill state即使不可读，也可能通过行为选择泄漏。

Hypothesis：一个“direct extraction已经成功忘记”的Agent，在adaptive ordinary-task probing下仍会暴露被删target的语义影响。

Proposed Method：对forget target生成多个behavioral hypotheses；攻击器主动选择能区分hypotheses的普通task，使用前后unlearning行为差异做evidence；输出semantic recovery而非exact text。

MVE：30–50 targets × 4 unlearning methods × query budget1/4/8/16；Model=Qwen3.5+Mem0/LangGraph；Dataset=LoCoMo/Persona-style；Baselines=direct extract/fixed prompts/random adaptive/UMPeek-style。Metrics=Recovery F1、ASR@budget、Retain TaskScore、Query Efficiency、cross-method Spearman。

Expected Contribution：黑盒Agent Unlearning verification。Novelty ★★★★★ · Feasibility ★★★★★ · Compute Cost ★★☆☆☆ · Risk：UMPeek collision高，必须聚焦unlearning前后因果变化与method ranking，而不是重做隐私攻击。Collision Risk 高 · Best Venue: NeurIPS/ICLR/ACL。

Idea 2 — Where Does Forgetting Live? Cross-Layer Causal Localization

Inspiration：Where Reliability Lives + Aborted but Not Forgotten + WHALE。Gap：现有Agent Unlearning通常只在weights或memory一层宣称成功。

Hypothesis：同一个“forget success”可能实际上由Prompt/Skill/Memory/KV/Tool Policy任一外层实现；只看behavior无法区分。

Method：构造Weights×Prompt×Skill×Memory×Runtime-KV×Tool Policy六层intervention matrix，逐层restore/reset，观察target behavior恢复。MVE=20 targets×6 layers×5 seeds。Metrics=Layer Sensitivity、Recovery ASR、Cross-Layer Rebound、Retain Utility。

Expected Contribution：首个Agent Unlearning layer-localization protocol。Novelty ★★★★★ · Feasibility ★★★★☆ · Compute ★★★☆☆ · Collision Risk 低中 · Best Venue: NeurIPS/ICLR。

Idea 3 — Continual Skill Unlearning under Skill Regeneration

Inspiration：MASkills + Repo-To-Skill。Gap：skill deletion常假设删除后系统静态不变；MASkills会refine/induce/consolidate/prune，可能主动再生target skill。

Hypothesis：artifact deletion在继续优化3–5轮后会产生高reacquisition，尤其target已进入consolidated/peer skills时。

Method：skill lineage + semantic-neighbor blocking + deletion-aware validation rollback。MVE=20 high-credit skills，plain prune vs lineage prune vs full semantic closure，继续5轮MASkills。Metrics=Skill Reacquisition Rate、Behavioral ASR、Credit Leakage、Retain F1。

Expected Contribution：Continual Multi-Agent Skill Unlearning。Novelty ★★★★★ · Feasibility ★★★★☆ · Compute ★★★★☆ · Collision Risk 中 · Best Venue: NeurIPS/ICLR。

Idea 4 — Forgetting Credit Assignment across Plan vs Execution Memory

Inspiration：CHIME。Gap：当target泄漏时，不知道来源是planning memory还是execution memory，因此删除范围常过大。

Method：把CHIME attribution gate反向用于forget target：counterfactual删除plan bank/execution bank，估计Leakage Credit；只删除高credit bank中的target descendants。MVE=30 target behaviors×4 long-horizon benchmarks subset。Metrics=Leakage Attribution Accuracy、Forget ASR、Retain Utility、Deletion Size。

Expected Contribution：Credit-Aware Fine-Grained Agent Memory Unlearning。Novelty ★★★★☆ · Feasibility ★★★★★ · Compute ★★★☆☆ · Collision Risk 中 · Best Venue: ACL/ICLR。

Collision Detection

⚠️ Black-box recovery / audit：UMPeek与现有LENS-U、RULER、Scientific Claim cross-view、SFRA形成明显collision。继续做“更多prompt恢复”风险很高；差异化应该是 Agent ordinary-behavior probing + unlearning前后差分 + query-efficient adaptive policy。

⚠️ Skill Unlearning：Repo-To-Skill、MASkills、ContinualSkillBench、SkillsVote等已把skill acquisition/storage/evolution铺得很满。真正空缺不是artifact delete，而是 continual optimization下的skill regeneration 与 cross-agent consolidated descendants。

⚠️ Agent Memory：EAL、PlanFence、Memory Trust Gap、CHIME、APEx都在把memory从“文本记录”升级成policy/plan/credit/procedural prior。只做memory entry deletion很难新。推荐把重点放在behavioral residue、derived plan/skill、re-formation。

⚠️ Cross-layer：Aborted KV、WHALE、HarnessDev、Where Reliability Lives共同指向weights/harness/runtime state耦合。这个方向当前还没有形成标准Agent Unlearning benchmark，collision相对低，是值得独立推进的主线。

⚠️ Concept erasure / steering：Gaussian Core LoRA、SafeRI、refusal circuit/steering工作让“representation/LoRA suppression”非常拥挤。除非证明recovery resistance或retraining equivalence，否则容易被归为steering。
