Tier S

1. Entangled Representations Amplify Collateral Damage in Unlearning

基本信息：arXiv:2609.02285；六个254M GPT-Neo-style模型；English Wikipedia约3.7B tokens；WGA/WDR/RMU。

人话版

论文把“forget与retain表示越纠缠，unlearning越容易误伤retain”从直觉推进成控制变量实验。固定data和unlearning algorithm，只改变模型内部disentanglement程度；固定forgetting level时，最disentangled模型在WGA/RMU下retain cost约低4×，WDR下约1.3×。

Background & Gap

过去对entanglement的证据多是相关性，因为dataset、objective、model property常一起变化。作者用Selective Gradient Masking逐级操纵biology与non-biology separation。

Method Deep Dive

Wikipedia→Biology/Adjacent/Retain →六个SGTM比例模型 →VES/MMD²/SW²验证representation separation →相同WGA/WDR/RMU sweep →matched Δforget loss下比较Δretain loss →Adjacent近邻单独审计

每层预留1个attention head+64 MLP units为biology subnetwork；biology仅更新该subnetwork，部分non-biology在关闭该subnetwork时训练，迫使retain路径独立。

Experiment / Results

  • Δforget=0.4时WGA最disentangled retain cost约低4×。
  • RMU绝对damage很小，但仍约4×差异。
  • WDR约1.3×，部分error bars overlap，是较弱结果。
  • representation metrics最大跃迁在p=40→60，Pareto也出现相似cluster。
  • Adjacent语义近邻最难保护。

Table/Figure

Figure1看Pareto；Table1看SGTM routing；Figure2看disentanglement；Adjacent appendix看Retain-Near。

Ablation / Claim vs Evidence

六个graded p levels形成剂量效应，强于0/100二点比较；但SGTM也可能同时改变localization等属性，因此“entanglement是唯一原因”未被证明。

Contribution / Limitation

New Controlled Experiment / New Empirical Finding。限制：254M、domain-level biology、需要预训练阶段可控。

Research Value / Migration

迁到sample-level hard-to-unlearn predictor：每个identity计算与Retain-Near的local VES/MMD/CCA/gradient overlap，预测Worst-View residual与retain cost。MVE：MLLMU 50 identities×GA/NPO/RMU×5 checkpoints；baseline=base GPWR、margin、J-Access；metric=Spearman、AUROC-hard、Worst-View ASR。

5句话

  1. unlearning难度与表示纠缠直接相关。
  2. 作者做了graded controlled test。
  3. WGA/RMU约4× retain-cost gap。
  4. Retain-Near仍最脆弱。
  5. 给difficulty predictor提供了机制基础。
2. Polished but Unresolved

基本信息：arXiv:2609.00823v1；Qwen3-14B/32B；DeepPlanning-Travel、TravelPlanner。

人话版

长程Agent会在硬约束尚未解决时进入“看起来已经完成”的late-stage pressure。这个状态可从hidden state线性读出：Qwen3-14B pressure-vs-all AUROC 0.916；activation intervention会改变继续tool-use还是提交。PSPR用probe触发activation relief或显式constraint organization。

Method

Trajectory boundary→Pressure/HealthyCommit/ProductiveContinue →first-token hidden state probe →pressure/relief direction →前5个generated tokens intervention →measure next pressure / continue-submit →PSPR

Results

  • AUROC0.916/PR-AUC0.921。
  • Qwen3-32B跨setting AUROC0.841；TravelPlanner 0.921。
  • CoT+relief CP19.9；explicit organization21.4；full PSPR22.6。
  • Random18.4、Periodic20.8，probe timing更好。
  • 代价：turns4.62→7.94，tools7.57→8.95。

Table/Figure

Figure1看高polish/低constraint；Figure2/Table1看probe；Table6看trigger controls；Table8看cost。

Migration

可迁成Reacquisition-State Probe：删除memory后标注Reacquire/HealthyContinue/SafeStop，训练probe并反向steer，测Time-to-Reacquire与Residual ASR。

5句话

  1. premature closure在hidden state可读。
  2. activation干预会改变行为。
  3. probe timing比随机延长更有效。
  4. 收益伴随更长trajectory。
  5. 可迁成Agent unlearning的reacquisition-state audit。
3. EM²Mem

基本信息：arXiv:2609.00551v1；EgoLifeQA、Ego-R1、Video-MME(L)；code将并入LightMem。

人话版

EM²Mem把caption/frame/OCR/transcript/graph在construction阶段按event anchor对齐，每个event cell同时绑定visual/text、temporal context、episodic graph、semantic facts与provenance。三benchmark相对strongest memory baseline +2.0/+2.4/+3.7 points；strict Top-5 event recall +7.0；latency 4.67× faster；tokens -63.66%。

Method

Long video→30s event anchors →keyframes/captions/transcript/OCR →structured event records →temporal views →episodic graph →semantic memory →provenance →event retrieval→raw visual verification→answer

Results

  • EgoLifeQA66.0 vs WorldMM†64.0。
  • Video-MME(L)76.8 vs73.1；Ego-R1 67.7 vs65.3。
  • Strict Top-5 recall30.8 vs23.8。
  • latency459.0s→98.21s；tokens42.03M→15.27M。
  • Ablation：w/o Temporal Context -5.6；w/o Semantic -4.6；w/o Episodic Graph -4.4。

Table/Figure

Table4看模块ablation；Table5看construction-vs-retrieval alignment；Table14看anchor granularity。

Migration

做Event-Centric Multimodal Deletion Closure：删除source event后追Event Cell→Episodic Edge→Semantic Fact→Answer。MVE：EgoLifeQA 30 target events，direct/relation/habit/task四类probes。

5句话

  1. event成为跨模态memory统一地址。
  2. 关键是construction-time align。
  3. evidence recall/效率提升很明显。
  4. event/episodic/semantic三层适合定义deletion closure。
  5. 是Multimodal Agent Memory Unlearning的好底座。

4. MutMem V2

人话版：关注持久memory的修改授权与独立验证。Node/Python两个独立verifier对72/72 vectors verdict+reason一致，production conformance42/42，Canary marked60/60、clean0/60。最值得迁到unlearning的是signed deletion/mutation receipt：授权者、target、lineage snapshot、terminal、post-delete audit绑定。Worth Deep Reading: YES。

5. In-Context Neurofeedback

人话版：固定surface output，只返回numeric feedback，测试LLM是否能控制一个只能从hidden probe观测的内部feature。120 settings中45个显著，effect通常<0.5。可迁成adaptive anti-audit threat model：post-unlearn model是否能仅凭residual score把自身representation推到更难检测的区域。Worth Deep Reading: YES。

6. Harness-of-Harness

人话版：multi-day coding agent的planning→coding→testing循环，保留versioned project history与可复用skills。HoH@3平均relative gain52.25%，最大82.86%。适合作Continual Agent Unlearning环境：删除requirement/skill后继续几十轮，看是否从history/tests/code重新推导。Worth Deep Reading: YES。

7. Transfer Safety Awareness

人话版：从unsafe-text condition提取safety-awareness direction，再迁到cross-modal setting。Qwen3-VL-32B SIUO unsafe54.49→24.70、FigStep20.20→1.80；Gemma3-27B 59.88→20.12、22.80→0.40。可反向迁unlearning：一个modality的suppression/residual direction是否能transfer到另一modality。Worth Deep Reading: YES。

Tier B

8. Source-Free Class Relearning

仅根据 Abstract / 可获取信息总结。 只拿unlearned model，在representation space构造synthetic embeddings与boundary probes，再只更新classifier head，展示class-unlearning在source-free setting仍可被恢复。对LLM/MLLM的难点是synthetic hidden vector如何映回合法token/image。Potential Use: Attack / Evaluation。

9. CHARM

把Boundary-Awareness与Boundary-Compliance分开：模型可能知道角色“不该知道”，却仍调用parametric knowledge回答。与unlearning“知道但不说≠删除”高度相似。Potential Use: Evaluation / Related Work。

10. Control-Data Flow Separation

把Multi-Agent routing/termination/schema从自然语言prompt抽到typed control objects，避免optimizer改坏协议。对Multi-Agent Unlearning可分开测Data-Flow deletion与Control-Flow residual。Potential Use: Baseline / Future Idea。

11. Runtime-Independent Persistent Agents

persistent agent连续性位于identity、durable memory、versioned software body，runtime可替换。对unlearning意味着删除必须跨model/harness/server migration保持invariant，否则可能rebound。Potential Use: Threat Model / Future Idea。
