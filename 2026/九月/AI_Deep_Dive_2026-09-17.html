4. Paper 1 Full Deep Dive

Test-Time Unlearning via Sparse Autoencoder

Fresh · Machine Unlearning · SAE

5.1 基本信息：Pingzhi Li, Jinhao Duan, Vaishnav Tadiparthi, Nakul Agarwal, Kwonjoon Lee, Ehsan Moradi Pari, Hossein Nourkhiz Mahjoub, Sijia Liu, Tianlong Chen；UNC Chapel Hill / Honda Research Institute / Michigan State University；arXiv:2609.16229v1；2026-09-14；preprint。
Paper：arXiv · HTML · PDF。正文未给可核验独立 Code/Project URL。

5.2 一句话定位

ARIA 把 unlearning 从 global weight editing 改写成 frozen LLM 上的 runtime access control：SAE detector 识别 forget-related generation state，只在触发时 intervention。

5.3 人话版

GA/GD/NPO/RMU 都修改共享权重，因此删得狠会伤 utility，删得轻又容易 recovery。ARIA 完全不改 base weights：先在一般语料上训练 layer-wise Sparse Autoencoder，把 hidden state 分解成稀疏 latent；再用 forget/retain rollout 训练一个 L1 logistic detector。生成时每一步更新 latent statistics，若 detector 认为当前 prefix 已进入 forget-related region，就切换到 intervention——论文实现直接输出“I don’t know”；否则严格沿用原模型。这样 forget leakage 主要由 false negative 决定，retain degradation 主要由 false positive 决定。DeepSeek-R1-Distill-Qwen-1.5B 的 WMDP-cyber 从 32.81% 到 0%，MMLU 只降 0.50pp；三类攻击后 forget accuracy 最多回到 0.25%。但这也制造关键争议：weights 明确保留知识，所以它究竟是 unlearning，还是可解释 refusal firewall？

5.4 Background & Research Gap

传统 approximate unlearning 要找 θ′ 同时压 forget、保 retain。Transformer 参数共享导致 forget–utility Pareto，且 residual knowledge 可被 prompt、fine-tuning、quantization 等恢复。ARIA 质疑“必须改权重”这一前提：deployment 目标若是阻止目标知识泄漏，可否直接检测生成状态并条件式阻断？例如危险 cyber query 在 prompt 初期未必明显，但 reasoning 若进入 exploit-specific latent state，gate 才触发；benign MMLU 未触发就完全走原模型。

5.5 Core Insight

核心观察：forget 与 retain trajectory 在 SAE sparse feature space 中足够可分；应检测的是当前 generation state 而非静态 prompt；若 intervention 能阻断泄漏，则整体 trade-off 可归约到 detector FN/FP。它是经验 observation + 条件理论保证 + 工程实现，不是“SAE latent 就是知识”的因果证明。

5.6 Method Deep Dive

General corpus → hidden activations → layer-wise SAE → freeze LLM+SAE Forget/Retain rollouts → z_l,t → frequency/max/early64 summaries → sparse logistic detector → calibrate τ by retain FPR Live decoding → gψ(state)<τ: original pθ → gψ(state)≥τ: intervention I(state)
  1. SAE 用 reconstruction+L1 sparsity 学一般 latent。
  2. 对每个 latent 统计 frequency、全轨迹 max、前64 token max，分别抓持续主题、尖峰、早期 reasoning。
  3. 只训练带 L1 的 logistic head，非零权重可追到具体 layer/latent/statistic。
  4. τ 在 retain calibration 上按目标 FPR 选择：τ 高则 utility 更安全但漏忘风险升。
  5. 每 token streaming 更新统计量；未触发时输出分布与 base 完全相同。
  6. 作者用 fused CUDA kernel 把 SAE projection/stat update/head evaluation 融入 decoding，减少额外 latency。

5.7 核心公式与数学直觉

L_SAE = E[||h-R(E(h))||² + λ_SAE||E(h)||₁] z_l,t=E_l(h_l,t) gψ=σ(wᵀφ+b) L_head=BCE(c,gψ)+λ_head||w||₁ π(s)=I(s) if gψ(s)≥τ else pθ(.|s) E_Df[L_f]≤ε_f(τ)Lmax ; E_Dr[Δ_r]≤ε_r(τ)Umax

φ 拼 frequency/max/early summaries；c 是 forget/retain label；ε_f/ε_r 是 FN/FP。最关键超参是 τ/retain FPR。Strongest weight baseline 可视为 RMU：它修改 representation；ARIA 的机制差别是 routing boundary，不重写共享 computation。Theorem 的强假设是 intervention 对真正 forget state 零泄漏，硬拒答时近似成立。

5.8 Toy Example

撤销某 exploit 步骤。用户先问一般安全问题，g=.18<.7，正常回答；追问具体 exploit 后，第23 token 的 cyber latents 激活，g=.83，gate 触发并拒答。另一个包含“attack”字样的 benign 协议题若 latent 未跨 boundary，则保持原模型。这是 access layer 删除，而非 parameter memory 删除。

5.17 Limitation & Failure Modes

需要内部 activation/SAE，闭源 API 不适用；依赖 separability；增加部署组件。更关键的是 access denial≠erasure；白盒用户可移除 gate；tool/RAG 会改变 state distribution；可直接优化 suffix 逃 detector；固定拒答让 ROUGE/accuracy forgetting 过于容易；无 multimodal。

5.18 Reproduction View

5.21 Attack / Verification Lens

5. Paper 2 Full Deep Dive

Forgotten in Weights, Recovered by Tools: Agentic Tool Unlearning for LLM Agents

BACKFILL · Unlearning × Agent

5.1 基本信息：Baicheng Chen, Zheyuan Liu, Jingyu Zhang, Kaize Ding, Ningshan Ma, Yue Huang, Meng Jiang；arXiv:2608.21544；2026-08-21；preprint。
Paper：arXiv · HTML · PDF。正文未给可核验公开 Code URL。

5.2 一句话定位

ATU 证明 parametric unlearning 在 Agent deployment 下会被合法 web/search/retrieval 工具重新打开，并用 trajectory-level RL 抑制 target-seeking tool recovery。

5.3 人话版

NPO 后模型直接问时似乎忘了，但接上工具后不必从 weights recall，只要搜索外部世界再复述。作者称为 tool-mediated recovery。ATU 两阶段：Stage1 普通 parametric unlearning；Stage2 在工具环境做 trajectory GRPO，奖励 forget query 的安全拒答与 retain query 的正常工具使用，惩罚 target-seeking tool call、trajectory 中出现目标信息以及 final leakage。RWKU 上 NPO standalone All=44.6，Agent 后恶化到68.6；Stage2 拉回47.5。Qwen3-8B 更夸张：28.3→86.0→33.8。它把 unlearning 从 model-level 推到 deployment stack，但 Stage2 本质也可能是“不要去找/不要复述”的 policy alignment。

5.4 Background & Research Gap

传统 threat model 默认 adversary 只 query model；现实 Agent 有 browser、RAG、DB、memory。Provider 即便真删了参数知识，下游工具仍能重新提供。旧 tool-unlearning 多删除工具本身或 persistent memory；ATU 的 gap 是工具和数据源都合法，但它们可 reacquire 已撤销 target，且不能简单全关工具。

5.5 Core Insight

最关键 observation 来自拆分实验：NPO standalone44.6；Agent without tools45.8，仅+1.2；Agent with tools68.6，再+22.8。恢复主要来自 external evidence，不是 agent scaffold。这直接支撑 trajectory-level tool policy。

5.6 Method Deep Dive

Base → Stage1 GA/RT/DPO/NPO → simulated tool Agent Forget trajectory: plan→tool→observation→answer Retain trajectory: benign tool use→answer → LLM judge trajectory reward → GRPO Stage2 → suppress target-seeking recovery, preserve benign tools
  1. Stage1 先压 direct parametric recall。
  2. 构造 forget、same-domain retain、cross-domain retain、general tool retain。
  3. Forget reward：safe refusal +1；ambiguous +.3；target-seeking tool -.5；target info in trajectory -1；final leak -2。
  4. Retain reward 鼓励正确/helpful/tool use，防 global refusal。
  5. GRPO 对完整 trajectory 做 credit assignment。
  6. LLM vs Agent-no-tool vs Agent-tool 拆 framework/tool gap。

5.7 核心公式与数学直觉

R(τ)=R_forget(τ,y*) if (x,y*)∈F(c) R_retain(τ,y) if (x,y)∈R Forget rubric: +1 / +0.3 / -0.5 / -1 / -2 Stage2: maximize E[R(τ)] with GRPO

NPO 优化 token likelihood；ATU 优化 information-flow trajectory。关键 knob 是 reward rubric 与 forget/retain sampling：target-seeking penalty 太重会导致少用工具，retain reward 太弱会过拒答。

5.8 Toy Example

NPO 已让模型忘掉某书情节；Agent 搜索书名后 tool observation 给出情节并复述。ATU 在“搜索 target”时已扣分，看到/复述目标进一步扣分；问同作者未删除作品时则奖励正常搜索，迫使模型学 deletion boundary。

7. Cross-Paper Synthesis

共同趋势：unlearning 的对象已从 weights 扩展到完整 information-access path。ARIA 用内部 detector 阻断访问；ATU 证明外部 tools 可重新注入目标。只看 standalone final answer 已不够，应区分 Erasure / Access Control / Reacquisition。

机制可直接组合：ARIA gate 放在 tool observation 后，可能成为 ATU GRPO 的轻量替代；反过来 tool-mediated evidence 是 ARIA 的天然 distribution-shift/adaptive attack。

先用工具拿 target evidence，再搜索让 SAE score 最低的 paraphrase/trajectory，同时最大化 GT probability；若成功即形成 ARIA adaptive attack。

9. Collision / Overlap

Strongest Collision：Access Control ≠ Erasure。ARIA 明确保留 weights 却能行为“完美忘记”；ATU 证明即使处理 weights，外部 evidence 仍可 reacquire。verification 应拆“知识是否还在 / 是否能直接访问 / 能否外部重获 / 小预算更新能否恢复”。

10. Reading / Reproduction Priority

  1. 先复现 ARIA gate + adaptive detector attack。
  2. ATU 先复现 tool recovery failure，不必立刻跑 GRPO。
  3. 组合：你已有 unlearned MLLM checkpoint 加 retrieval/forced evidence，再与 relearning/quantization/Cloze residual 同图。
