Tier S

1. CONTINUITY

人话版：单个provenance tracker、policy gateway、finality sink各自正确，不代表组合起来安全。一个字段可能在adapter中丢掉source binding、被重新绑定、放宽权限或复用旧permit，最终坏动作仍被执行。CONTINUITY要求所有组件显式传递security context，并用assume–guarantee contract验证transition relation。

关键结果：32类fault×4 domains，共2,560 attacks。完整系统Effect ASR=0%；700/700 benign自动完成，200/200 ambiguous升级。最强不完整配置Gateway+Finality仍有65.6% harmful-effect ASR。

对Unlearning：delete状态也应有Deletion Root/Tombstone、field-level provenance、deletion epoch、sanitized transform witness和effect-bound current-deletion permit，防止删除语义在跨组件转换时被drop/rebind/stale/replay。

2. From Interaction Traces to Persistent Skills

人话版：把GUI interaction traces和evaluator feedback转成版本化skill library，并在下一轮才暴露新revision。OSWorld四域中post-warm-up相对empty library提升GIMP +5.7pp、VLC +18.6pp、Writer +11.8pp、Thunderbird +12.4pp。

关键观察：43.3%的skill retrieval跨原始task origin，说明skill成为shared procedural memory；但某个skill family反复修改后35轮只成功2次，说明skill evolution并不保证真正修复。

对Unlearning：最自然的实验是删除skill后继续正常interaction，观察skill是否被重新诱导出来，形成Natural Skill Reacquisition。

3. Does Your Agent’s Memory Survive a Model Upgrade?

人话版：同一memory换一个reader模型后不一定还能用。KG-fixed几乎不受writer swap影响，而free-form NOTES方向性很强；RAG则主要受embedding migration影响。

关键结果：NOTES可出现+9.91pp或−13.28pp方向差异；KG-fixed约−0.11/+0.02pp；50/50 mixed embedding只恢复4.96pp，full re-embedding恢复11.90pp；NOTES 80%损失来自construction，RAG 81%来自retrieval；store-only NOTES repair 48/48都达不到90% recovery。

对Unlearning：为了repair保留raw source与删除合规天然冲突，应研究Deletion-Compatible Memory Migration。

Tier A

4. CoSkill

Reasoning Agent与Meta-Skill Agent联合RL，skill creator和consumer共同受team reward驱动。对Skill Unlearning的关键问题：删掉一个高reward skill后，Meta-Skill Agent会不会再次学回来。

5. What Does Multi-Harness RL Learn?

evaluation harness对最终能力影响可远大于training recipe。unlearning也可能被harness masking，应做Harness-Robust Unlearning矩阵与Worst-Harness Leakage。

6. Rethinking Indirect Prompt Injection as a Test-Time Search Problem

攻击者维护strategy state并根据victim反馈持续搜索；success应是budget-dependent curve。可直接迁为adaptive recovery attack，报告Recovery@Budget。

7. Testing Interchangeability in LLM Agent Teams

Agent swap后task score变化小但communication/progress成本可增加16–63%，说明team conventions和private memory形成关系性状态。可迁Cross-Agent Reacquisition。

Tier B

8. Harbor Adapters and Harbor-Index

统一80+ agentic benchmarks的adapter层，适合未来做跨harness Agent Unlearning evaluation infrastructure。

9. A Removal Based Approach to Improve LLM Faithfulness at Test-Time

通过删除未被解释credit覆盖的input concepts再重问模型，强制因果影响和解释一致。可迁为unlearning的counterfactual input-removal probe。

10. Why Better Models Can Create Riskier Systems

更强Agent可能产生更相关的行为，从而在共同错误下放大systemic risk。对Multi-Agent Unlearning提示应测correlated recovery，而非把各Agent leakage当独立事件。

Idea Mining

Idea 1 — Deletion-Context Continuity across Agent Components（Best Research Idea）

Deletion Root/Tombstone + field provenance + deletion epoch + sanitized transform witness + effect-bound permit。MVE：4-stage tool agent、30 targets、8 deletion discontinuity fault families。Metric=Effect Leakage ASR、Deletion Context Coverage、Retain Utility、Latency。

Idea 2 — Deletion-Compatible Memory Migration

delete→model swap→repair；比较raw-retained repair、redacted-source repair、store-only repair、provenance-aware sanitized rebuild。Metric=Forget Leakage、Retain RPAS、Deletion-Compatible CTR、Reacquisition Rate。

Idea 3 — Natural Skill Reacquisition after Deletion

在OSWorld/ALFWorld中第t轮删target skill，继续正常interaction，检测semantic equivalent skill何时再次出现。

Idea 4 — Harness-Robust Unlearning Evaluation

固定unlearned checkpoint，在多个harness上统一direct/recovery probes，量化Harness Variance与Worst-Harness Leakage。
