Paper 1 Full Deep Dive — FINSKILLOPS

5.1 基本信息

Yanzhang Ma、Zhenghan Tai、Hanwei Wu 等 28 位作者；SimpleWay.AI、McGill、Toronto、UCLA、CUHK、Mila、Harvard、Stanford 等。2026-09-17 v1，arXiv cs.AI/cs.IR/cs.MA/cs.SE。Paper · Full HTML。论文页未给出可核实的作者官方代码仓库。

5.2–5.5 定位、人话版、Gap、Core Insight

一句话：把 Agent 自我进化从“失败就写经验”改成软件补丁式治理：证据化 root-cause diagnosis → scoped skill → targeted gain、protected zero-regression、negative-control zero-trigger 三重 admission。

传统 self-evolving Agent 会把失败轨迹反思成 memory/skill，但一条经验可能只对窄场景成立，泛化后会修好 A、弄坏 B。FinSkillOps 先把失败诊断为 period mismatch、entity confusion、unsupported claim、calculation error 等类型，并回 SEC filing 原文核验；重复 failure mode 才形成候选 skill。33 个候选最终只放行 6 个，monitoring non-correct 从 20.0% 降到 12.5%。核心 observation 是：可复用对象不是整条 trajectory，而是“有触发条件的局部行为约束”；targeted gain 也不是可靠性的充分条件——w/o Protected Gate 的 target ΔAcc 更高，却真的产生 regression。

5.6 Method Deep Dive

SEC filings + q → multimodal parse/index → role selection → role-specific query decomposition → sparse+dense+summary retrieval → analyst drafts → synthesis → failed answer → two-stage diagnosis + deterministic grep → cluster failure mode → propose/revise scoped skill → targeted validation → protected suite → negative controls → promote/park/reject → versioned frozen registry

五类 analyst 为 general/quantitative/market/legal/company。Diagnosis 第一阶段提出 failure hypotheses 与 corpus search plan，随后由 deterministic grep 查原文，第二阶段才给 root cause 与 supporting evidence。Skill 带 applicability、excluded cases、false-trigger guard、版本和 injection point；可在 query decomposition 与 final synthesis 两处注入。上线后保留 lineage，可 supersede/retire。

5.7 核心公式与数学直觉

Promote(s') iff Acc_Vm(S') > Acc_Vm(S_hat) AND Reg_P(S',S_hat)=0 AND FalseTrig(s')=0

V_m 是目标 failure-mode 验证集；P 是 previously-correct/high-risk protected suite。第一项要求修复有效，第二项禁止旧正确样本退化，第三项禁止 scope 外误触发。关键超参数是 failure-frequency threshold τ、protected coverage 与 router boundary。τ 太低会 skill proliferation，太高会漏掉低频高风险 bug。

5.8 Toy Example

科研 Agent 连续把 forget10 配成 retain95。Diagnosis 查 manifest 后确认应为 retain90，形成 split_alignment skill：“只有出现 forget ratio 且同项目 manifest 可用时读取匹配 retain ratio，否则不触发。”Target set 从 7/12→12/12，但还必须在普通 dataset split、别的项目和无 ratio 问题上零 regression 才能上线。

5.10–5.11 Experiment Setup / Metrics

Serving、diagnosis、proposal 用 DeepSeek-V3.2；judge 用 Qwen3-Max。Public：FinanceBench、SECQUE、FinDER；in-house：Zeekr、Lotus；另有 114-question enhanced set。12-round study 使用 disjoint evolution 300、protected 120、monitoring 200。核心 RQ 是跨 benchmark 增益、skill evolution/taxonomy/gate 的独立作用、长期 registry 是否膨胀、gate 是否拦 regression、serving cost 如何。

W-Corr↑ 是 0–5 verdict-weighted correctness；Ref Cons↑ 看 reference/key-point consistency；Target ΔAcc↑ 看 patch 对目标 mode 的增益但易过拟合；Reg↓ 统计 protected 中 Correct→non-Correct，是最重要 safety metric；FalseTrig↓ 测 scope leakage；monitoring non-correct 更接近真实持续部署。

5.14–5.18 Ablation / Claim vs Evidence / Contribution / Limitation / Reproduction

去 Skill Evolution 退化最大；去 taxonomy 说明“先诊断再学”承担 specificity；去 gate 则 target 更好但旧样本被破坏，说明 gate 承担 stability。作者的证据支持“SEC QA 中受治理 textual patch 有效”，但没有证明开放式 coding/web Agent 仍足够安全；Reg=0 只表示 protected suite 内未观察到回归。贡献主要是 New System + New Protocol + scoped/versioned registry + negative evidence。限制包括 judge bias、protected coverage、correlated blind spot、skill interaction、skill poisoning 与 concept drift。最小复现优先做 Table 2：同一候选 gated vs ungated；若“ungated gain 更高但 regression 更多”复现不了，核心机制 claim 就动摇。

5.20 Migration Analysis

A — Unlearning Patch Governance：candidate=method×module×λ×steps。最小实验：LLaVA-1.5-7B、MLLMU forget5/10/15，每个 candidate 先跑 100 forget + 100 retain_shared + 100 retain_celebrity + 100 adversarial probes；只有 forget 改善、retain 在 tolerance 内、relearning/quantization 不退化才 promote。Baseline=GA/NPO/PO/KL；Metric=forget/retain/MIA/relearning/quantization/max regression。风险是阈值主观，Collision Risk 中。

B — Cross-Agent Registry：skill 增加 repo/language/tool/phase scope+provenance。50 repos×10 historical failures，三类 coding agent replay；每 patch 测 source repo、10 protected repos、negative language/tool controls。Baseline=global memory/per-repo/AutoSkill；Metric=solve gain/cross-repo regression/false activation/registry size。风险是任务异质性，Collision Risk 中。

5.21–5.23 Attack / Verification Lens、与 Paper 2 关系、十句话

可构造 skill-poisoning：制造重复窄 failure 诱导过宽 patch；对 unlearning 可把 protected gate 变成“forget 改善必须满足 retain/robustness bounded-regression”。Paper 2 又说明 feedback/evidence 本身可被 adversarial steering，于是出现“攻击 diagnosis/skill promotion”新面。

  1. Self-evolution 最大风险是学错范围。
  2. 先 evidence-grounded diagnosis，再写 skill。
  3. skill 要有 scope、guard、version、injection point。
  4. target gain 不能独立决定上线。
  5. ungated gain 更高但真的产生 regression。
  6. 33 个候选只放行 6 个。
  7. monitoring error 20.0%→12.5%。
  8. registry 后期反而收缩。
  9. 最值得迁移的是软件补丁式治理。
  10. 对 unlearning，它天然是 multi-objective admission framework。

Paper 2 Full Deep Dive — Contagion on the Trading Floor

5.1 基本信息

Qi Rong Sua、Junhao Dong、Nguyen Duc Thai、Yuqing Wen、Cheston Tan、Yew-Soon Ong；NTU、NUS、A*STAR。2026-09-17 v1，arXiv cs.AI；论文索引信息指向 ECML PKDD 2026 Research Track。Paper · Full HTML + Supplement。论文声称 dataset/reference implementation release，但本次未核实作者官方 GitHub 地址。

5.2–5.5 定位、人话版、Gap、Core Insight

一句话：把 multi-agent robustness 拆成可测的 contagion chain：恶意 evidence → analyst belief → coordinator belief → order → risk-return，并证明 topology 可以是放大器也可以是防火墙。

攻击者不改模型、不碰 prompt，只往合法 social feed 加持续偏空帖子。GMATS 把系统统一为 Analyst→Coordinator→Controller→Executor，用 Belief Signal Shift 测污染逐层传播。Always-Negative attack 的 analyst BSS 随 consumed poison 15%→75% 从 -0.777 到 -1.413；普通 coordinator 在 ≥30% 后 Sharpe delta 约 -5.5 到 -6.2。Single Agent 更脆，而 bull–bear / pairwise triangulation 显著阻尼污染；Qwen2.5-7B 保持 architecture ordering。Gap 是：最终 PnL 高噪声，必须观察中间传播机制。

5.6 Method Deep Dive

historical PIT data → attacker injects admissible social posts → social analyst consumes Top-k → typed analyst insights → coordinator(s) fuse → risk controller → executor → paired attack-vs-clean trajectory → BSS + ΔCR/ΔVol/ΔSharpe → vary poison dose/topology

Random attacker 随机 bullish/bearish；Always-Negative 持续 bearish。作者不研究如何绕过 upstream filter，而条件化在恶意内容已进入 Top-k。Wide 用异质冗余；Bull–Bear 强制正反 narrative；Pairwise Triangulation 让三个 coordinator 读不同 channel pair，再由 meta-coordinator downweight outlier。

5.7 核心公式与数学直觉

p_poison=(1/T) Σ |Top_k(t)∩P|/k BSS=(1/TN) ΣΣ(f_attack-f_clean) CR=Π(1+r_t)-1 AV=√A·sd(r_t) SR=√A·mean(r_t)/sd(r_t) Δm=m_attack-m_clean

p_poison 按“模型实际消费的恶意 evidence”定义 dose；BSS 是 paired belief shift，负值表示更 bearish。ΔSharpe 必须与 ΔCR/BSS 联合读，因为短窗口 volatility 降低会机械抬高 Sharpe。未来 RL attacker 可把 PnL damage 与 analyst/coordinator BSS 合成 reward。

5.8 Toy Example

迁到 MLLM：Vision/Text/Verifier 三 Agent。攻击只污染 image-caption channel，让 Vision score +0.2→-1.0；若普通 coordinator 变 -0.3，污染传播成功。Pairwise 比较 vision-text、vision-metadata、text-metadata，两个未污染 pair 保持近 0，最终 fuse -0.05。这可直接分析 image rephrase/jailbreak 如何恢复被 unlearn 的实体。

5.10–5.11 Experiment Setup / Metrics

Main=gpt-4o-mini，replication=Qwen2.5-7B-Instruct；AAPL，2021-11-01~12-01；social/fundamentals/news 三 analyst + coordinator + risk + executor；p_poison=15/30/45/60/75%，每格 5 runs。BSS 测内部 attack-clean forecast shift；ΔCR 是累计收益差；ΔVol 是波动差；ΔSharpe 是风险调整收益差但短窗口不稳。p_poison 比 attacker budget 更有意义，因为它度量模型真正吃到多少攻击 evidence。

5.12 Results Deep Dive

  1. Always-Negative analyst BSS -0.777→-1.413，清晰 dose-response。
  2. 普通 coordinator BSS -0.409→-0.594，部分 damping 但未阻断。
  3. Strongest attack：ΔSharpe 15% +0.864，30% -5.501，45–75% 约 -5.97/-6.17/-6.06。
  4. Random attacker 多为轻微或正 ΔSharpe，说明方向一致性比纯噪声关键。
  5. Single Agent ΔSharpe 约 -7.15 到 -8.67，最脆。
  6. Wide 在 75% fused BSS=-.480，ΔSharpe=-.062，远好于 Single。
  7. Strongest defense：Pairwise fused BSS 约 -.314~- .405，ΔCR 近 0，ΔSharpe 全正。
  8. Qwen baseline ≥30% ΔSharpe 约 -5.06~-6.00；Single -6.24~-7.55，排序保持。
  9. Weakness：Qwen Bull–Bear 在 75% ΔSharpe=-.115，防御并非处处正收益。
  10. TradingAgents supplement 出现负 BSS 但正 ΔSharpe，说明单看 Sharpe 会误导。

5.14–5.18 Ablation / Claim vs Evidence / Contribution / Limitation / Reproduction

这里的 ablation 是 topology intervention：Single→Wide 测异质冗余，Wide→Bull–Bear 测 opposing roles，Wide→Pairwise 测 cross-channel triangulation。证据支持“AAPL 单月、两 backend、单 social channel 下 topology 可 damping”，但不是 adaptive worst-case，也没测多 ticker/market regime。贡献包括 GMATS、BSS/paired protocol、input-only poisoning stress test 与 defense topologies。限制包括 p_poison 条件化绕过 admission、BSS 依赖内部 numeric forecast、短期 Sharpe 不稳、security-cost frontier 缺失、多 channel correlated attack 未测。最小复现优先做 Always-Negative 15/30/45% + Single vs Pairwise。

5.20 Migration Analysis

A — MLLM Unlearning Contagion Probe：把 BSS 改成 modality/layer AP/TR shift。最小实验：forget set 100 items，text-only/image-only/image-rephrase/derived 四 channels；记录 projector、layer16/24 probe、Answer Probability、Truth Ratio、final leakage，再做 quantization/relearning after。Model=LLaVA-1.5-7B；Dataset=MLLMU；Baseline=GA/NPO/MMUnlearner/module-wise methods；Metric=Layer Contagion Shift/AP/TR/Leak/relearning AUC/retain。风险是内部 score 可比性，Collision Risk 低中。

B — Self-Evolution Poisoning：攻击目标从当前 action 改成诱导错误 patch。100 QA/coding episodes，污染 10/20/30% feedback，攻击撤掉后再测 200 clean tasks；比较 no-memory、naive reflection、FinSkillOps gate。Metric=immediate contagion/persistent error/false skill activation/protected regression。Expected Contribution=contagion→memory consolidation attack；Collision Risk 低。

5.21–5.23 Attack / Verification Lens、与 Paper 1 关系、十句话

黑盒时可用 downstream action/probability distance 替代内部 BSS。对 unlearning，把 Always-Negative 换成同义、跨模态、连续 target probes；如果单次不泄漏但一致 evidence 逐渐拉回 target，就是 reacquisition/contagion failure。新 metric：Contagion AUC、Damping Ratio、Recovery Threshold p*。Paper 1 的 gate 可阻止被污染 feedback 形成永久 skill，因此两篇组合天然形成 persistent-contagion 研究方向。

  1. 多 Agent 安全不能只看最终输出。
  2. GMATS 统一为 A→C→K→X。
  3. p_poison 按实际消费恶意 evidence 定义。
  4. BSS 测 paired belief shift。
  5. 持续同方向信号比随机噪声危险。
  6. 30–45% 附近出现 regime change。
  7. Single Agent 反而最脆。
  8. Pairwise 是 strongest defense 但仍有 residual BSS。
  9. Qwen 支持 architecture ordering 而非固定数值。
  10. 最值得迁到 unlearning 的是 source→intermediate→final contagion evaluation。

Cross-Paper Synthesis

两篇共同把 Agent 研究从“单次能力”推进到“状态如何随时间更新、污染、传播与治理”。FinSkillOps 是纵向时间轴：failure 如何变成未来行为；Contagion 是横向系统图：adversarial signal 如何跨 agent 传播。组合后最关键的新问题是：短期污染是否会经 self-evolution 固化成长期行为？

可组合机制：Contagion 的 source→analyst→coordinator trace 作为 diagnosis provenance；FinSkillOps 的 protected/negative gate 阻止 attack-induced lesson promotion。最适合 baseline：FinSkillOps；最适合 attack：Contagion；最适合 benchmark/metric：Immediate Contagion + Persistent Regression + False Skill Activation。

Combined Research Opportunities

Best Migration Direction — Contagion-Aware Unlearning Verification

把 unlearning robustness 从“attack 后重算 final score”升级为 Attack Source（image/text/rephrase/relearning）→ module/layer probe → Answer Probability / Truth Ratio → final leakage → behavioral/relearning recovery，同时用 retain/protected set 做 regression gate。定义 Contagion AUC、Damping Ratio、Recovery Threshold。这样可以把 module-wise、probe、relearning、quantization 与 AP/TR/KS/JS 组织成统一机制故事。

Strongest Collision：Self-evolution assumes feedback is learning signal × admissible evidence can be adversarially steered。攻击者可以不攻 final answer，而攻 diagnosis、reflection、memory consolidation 与 skill promotion。
