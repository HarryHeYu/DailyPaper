1. Executive Summary

今日最强信号不是又一个普通 forget-loss，而是三条机制线开始汇合：representation selectivity / recovery robustness、provenance & dependency closure、closed-loop inference-time control。RepSelect 把“为什么 relearning 能恢复”推向子空间机制；Agent Zero + PlanFence + MEME 则把 agent 删除问题从 memory item 扩展到 derived memory、plan、action 的闭包；LQR activation steering 给出了可做 adaptive inference-time suppression 的控制论工具。

对当前多模态 unlearning 研究最值得立即实验的是：把已有 Relearning/Quantization/Probe robustness 数据与模块级 PCA/CKA/gradient-subspace overlap 接起来，判断 vision/projector/LLM 哪个模块保存了“可恢复残留”。这比继续增加一个行为指标更可能产生机制贡献。

RepSelect: Robust LLM Unlearning via Representation Selectivity

5. Tier S

Tier SRepSelect: Robust LLM Unlearning via Representation Selectivity

Paper

人话版：这篇论文到底干了什么？ 许多 unlearning 方法让模型“暂时答不出来”，但少量 fine-tuning 或 few-shot prompt 就能把知识拉回来。RepSelect 把问题定位到表示空间：现有更新同时碰到了 retain 共享表示与攻击者可恢复子空间，所以既伤 utility，又容易恢复。它试图只打掉 forget-specific、且与可恢复方向分离的表示成分。

Background & Gap

传统 GA/NPO/RMU/UNDIAL 多从输出概率、偏好或表示扰动出发，但“forget accuracy 下降”不等价于训练影响真正消失。近期 recovery/relearning 研究表明，浅层输出抑制可快速反弹。RepSelect 的关键 gap 是：为何某些方向一方面造成 collateral damage，另一方面又最容易被 relearning 找回？答案被表述为子空间重叠问题。

Core Insight & Method Deep Dive

Pipeline：Forget/retain gradients → 分析梯度表示的 principal components → 折叠/去除与共享或可恢复结构相关的主成分 → 在更 selective 的剩余方向执行 unlearning update → 用 relearning 与 prompting 攻击验证。PCA 在这里不是“降维画图”，而是把梯度矩阵中解释最大方差的正交方向找出来；若最强方向同时承载通用能力和攻击者最容易重新学到的结构，直接沿它更新会同时造成 utility loss 与可逆性。RepSelect 的机制假设是：真正适合删除的信号位于更具选择性的成分。

关键公式直觉

可把梯度矩阵写成 G≈UΣVᵀ。SVD/PCA 的 V 给出参数更新空间中的主方向，Σ 表示各方向能量。RepSelect 的核心不是把最大能量方向当作“最重要删除方向”，而是先 collapse 顶部 principal components，再对剩余梯度执行更新。与普通 GA 的区别在于：GA 直接最大化 forget loss；RepSelect 先对“允许更新的方向”做结构约束。

Toy Example

假设“生物危险知识”与普通生物常识共享一个强主方向 v1，而更细粒度的危险步骤还依赖 v3。直接沿 v1 反向会连普通知识一起损坏，且攻击者用少量生物数据很容易重建 v1；若先去掉共享 v1，再主要破坏 v3，则可能得到更小 collateral damage 和更高 recovery cost。

Baseline Deep Comparison

GradDiff/GA 直接改变 forget likelihood，简单但容易过删；NPO/SimNPO 用 preference-style negative objective 稳定 forgetting；RMU 在表示层把危险概念推向目标表示；UNDIAL 用反学习/保持约束平衡 retain。论文报告的比较覆盖五类常用强基线，因此最有价值的不是单点 forget score，而是 post-relearning 与 few-shot attack 下的差距。

Experiment Setup & Research Questions

覆盖 biohazardous knowledge 与 abusive tendencies，两种 forget 类型；四个模型家族包括 Llama 3、Qwen 3.5、Gemma 4 E4B、DeepSeek V2 Lite，并覆盖 dense 与 MoE。RQ1：selective representation 是否改善 forget/retain trade-off？RQ2：relearning 后是否仍保持 forgetting？RQ3：few-shot prompting 是否能绕过？RQ4：机制是否跨架构。

Results Deep Dive

论文摘要报告：相对五个基线，RepSelect 在 post-relearning answer accuracy 的下降幅度上达到 strongest baseline 的 4–50×，并对 few-shot prompting 达到接近完全的鲁棒性。这里“4–50×”说明优势主要体现在 recovery resistance，而不是普通 before-attack forgetting。跨四模型家族仍出现优势，支持机制并非单一架构 trick。最强结果是 relearning robustness；最弱证据是公开摘要没有给出每个 dataset/model 的完整 utility 数字，因此不能把“deep erasure”直接等同于 retraining-equivalence。

Table/Figure Reading

优先阅读主结果表中 Before/After relearning 两列：真正关键的是攻击后 forget accuracy 是否反弹，同时 retain/MMLU 是否稳定。其次看 representation/PCA 分析图：若作者主张“selectivity 是因”，应看到 forget-specific 与 recoverable/shared subspace 的几何分离，而不只是最终分数更低。第三看跨模型表，确认 MoE 与 dense 是否一致。

Ablation / Claim vs Evidence

最关键 ablation 应是“不 collapse top PCs”“改变 collapse 数量/比例”“去掉 retain selectivity”。若去掉 PCA filtering 后恢复攻击显著增强，就直接支持机制。现有证据支持“representation selectivity 能显著提高 recovery robustness”；尚未证明信息在所有 black-box extraction、量化、跨语言、多模态路径上不可恢复，更未证明严格数据删除。

Contribution / Limitation

New Mechanism: selective representation unlearning；New Empirical Finding: dominant/shared directions可能正是可恢复性的来源；Evaluation: 把 relearning 与 prompting 放到中心。限制：需要白盒梯度；PCA/SVD 成本随参数与样本增长；攻击覆盖仍有限；representation destruction 与法理上的 data influence removal 不是同一保证。

Research Value & Migration

Original Problem LLM recovery-robust unlearning → Transferable Mechanism gradient/representation subspace selectivity → New RQ MLLM 中视觉、connector、LLM 三模块的“可恢复子空间”是否不同？→ Method Modification 分模块收集 forget/retain gradient，比较 top/minor components 与 relearning overlap → Minimum Experiment LLaVA-7B，MLLMU forget5，分别对 vision/projector/LLM 做 PCA-filtered LoRA unlearning；攻击用 1/5/20-step relearning + 4-bit quantization → Baseline GA/NPO/RMU/UNDIAL + 原模块 LoRA → Metric Forget、Retain、Relearning After、Quantization After、CKA/PCA overlap → Expected Contribution multimodal recoverability map → Risk 梯度低秩统计不稳定 → Collision Risk 中高。

只记住 5 句话

  1. 浅层 forgetting 的核心问题是“能被重新学回来”。
  2. RepSelect 把 recovery failure 定位为表示子空间重叠。
  3. 它先 collapse 顶部梯度主成分，再做 selective update。
  4. 核心优势出现在 relearning/few-shot attack，而非只看 before score。
  5. 对 multimodal unlearning 最值得迁移的是“模块级 recoverable subspace”诊断。
Tier SLocal Linearity of LLMs Enables Activation Steering via Model-Based Linear Optimal Control

Paper

人话版：这篇工作把 activation steering 从“加一个经验向量”升级成控制系统。作者发现 Transformer 虽然整体非线性，但在一次生成附近、逐层传播可被局部线性模型近似，于是把 layer 当作时间步，用 Jacobian 描述扰动如何传播，再用 LQR 做闭环反馈，让 hidden state 追踪目标语义而尽量少施加控制。

Background & Gap

普通 steering vector 通常在固定层加 αv，属于 open-loop：它不知道扰动经过后续层会被放大、旋转还是抵消，也没有 error feedback。对 unlearning 来说，这意味着 inference-time suppression 很容易“力度不足则泄漏、力度过大则伤 utility”。本文提供了一个可迁移的闭环框架。

Core Insight / Method

Input → 选定 semantic feature/setpoint → 在当前 hidden state 附近计算 layer-wise Jacobian → 构造局部线性时变系统 xₗ₊₁≈Aₗxₗ+Bₗuₗ → LQR 求每层反馈 uₗ=-Kₗ(xₗ-rₗ) → 逐层注入 → 根据新状态继续反馈。Jacobian 表示“当前层输出对输入微小变化的敏感度”；LQR 的目标是同时最小化状态偏离目标与控制能量，避免粗暴 steering。

关键公式

典型目标 J=Σ[(xₗ-rₗ)ᵀQ(xₗ-rₗ)+uₗᵀRuₗ]。Q 越大越强调语义目标，R 越大越惩罚干预幅度。与固定 α steering 的本质差别是 Kₗ 根据动力学 Aₗ/Bₗ 决定，而且误差变化会反馈到后续层。论文还给 setpoint tracking error bound，使“能否跟踪目标”从经验现象变成可分析对象。

Toy Example

若忘记目标是某个敏感实体，probe 在第 14 层检测到敏感特征 0.8，目标 setpoint 设为 0.1。固定 steering 可能一次压到 -0.5 并破坏其它语义；LQR 会考虑第 15–20 层自身会衰减该特征，因此第 14 层只施加较小控制，后续层按残余误差补偿。

Baselines

对比对象是常见 open-loop activation steering / contrastive vector 类方法。它们合理之处是零训练、部署简单，但忽略 layer dynamics；本文新增的是 model-based feedback，而非单纯换一个 steering vector。

Experiments / Results

论文覆盖多个模型、尺度与任务，目标包括 toxicity、truthfulness、refusal 和 arbitrary concepts，并报告超过 baseline steering 的控制效果。最值得核验的三类结果是：①局部线性拟合误差是否在不同层/模型都低；②同等 utility/control-energy 下 semantic target 改善多少；③setpoint 与控制强度变化时是否稳定。论文声称 minimal computational overhead、无需 offline training，并给 tracking-error 理论界。最强证据是跨行为类型的统一控制；最弱点是“控制住输出”不等价于删除训练影响。

Table/Figure / Ablation

优先看 local-linearity 图：真实层输出与 Jacobian 线性预测的误差决定整个控制建模是否成立；再看 fixed steering vs LQR 的 Pareto 图，重点不是最高 refusal，而是同等行为改变下 utility/control norm；最后看 feedback/setpoint ablation，验证提升来自闭环而非更大扰动。

Claim vs Evidence / Contribution

New Mechanism: LQR closed-loop activation steering；New Empirical Finding: LLM layer dynamics 在局部可线性近似；Theory: tracking bound。证据足以支持“更精细的 inference-time behavior control”，但不能支持严格 machine unlearning。

Limitation

需要白盒 activation/Jacobian；长生成中局部线性区间可能漂移；semantic feature/setpoint 如何构造仍是关键依赖；adaptive jailbreak 可主动把状态推离控制区；每 token/layer 反馈的 latency 需要部署验证。

Research Value & Migration

Original inference-time alignment → Mechanism closed-loop state control → New RQ 能否做“inference-time reversible unlearning firewall”？→ Modification forget attribution probe 作为状态观测，retain probe 进入 Q/R penalty，多模态时分别控制 projector/LLM layers → MVE LLaVA-7B + 100 个 forget entities；比较 fixed steering、abstention、LQR steering；FigStep/Jailbreak/Image Rephrase/SUA 攻击 → Metrics Forget leakage、Retain utility、attack recovery、control norm、latency → Expected adaptive inference-time unlearning baseline → Risk 仍是 suppression → Collision 中。

只记住 5 句话

  1. Activation steering 可以被视作控制问题。
  2. 逐层 Jacobian 提供局部动力学。
  3. LQR 用反馈而非固定向量控制 hidden state。
  4. 它很适合做 inference-time unlearning baseline，但不能冒充 deletion。
  5. 最值得迁移的是“forget state + retain penalty + adaptive feedback”。

Tier AAgent Zero Memory: Provenance-Aware Long-Term Memory for LLM Agents

Paper

人话版：它不是 unlearning 论文，而是今天最重要的 Agent Memory 迁移源之一：把长期历史同时存成事件时间线、实体—事件图和分层文档记忆，并强制每条派生记忆带 origin/timestamp/evidence pointer，回答只能引用真正打开过的证据。

Background & Gap：单一 vector store 擅长相似检索，却弱于更新、时间和多跳；覆盖式 update 又会丢历史。作者把“记忆可信度”变成 provenance discipline。

Method：Build 阶段 preprocess→双索引→extract events/HDM→connect entity-event graph；Read 阶段 intent gate→source router→三路并行 agentic search→citation-locked integration。Provenanced item π(x)=〈origin,timestamp,evidence〉；citation lock 要求引用集合必须来自本次实际打开的 item，否则 abstain。

Experiment：LongMemEval 95.60%，LoCoMo 93.60%，分别比 strongest reported system +0.73/+1.10；8 个 backbone 的 accuracy 仅相差 3.4 points，但 query cost 约 30×，小模型配置可在接近 SOTA 时降至约 1/20 成本。作者还比较 embedding 与 lexical channel 的互补性。

Table/Figure：Table 1 最值得看：Mem0 的 overwrite/delete 会丢 provenance，Zep 用 temporal invalidation，Agent Zero 用 append/non-destructive + citation lock。架构 Figure 1 则直接提示 unlearning 应从单条 memory delete 升级为 provenance closure。

Contribution：New System/Engineering + formal provenance protocol + empirical memory result。Limitation：它追求“永不破坏历史”，这与 GDPR-style deletion 天然冲突；多存储副本使 deletion closure 更难；benchmark 是 recall，不是删除验证。

Migration：把每个 forget request 映射到 evidence pointer，沿 timeline/graph/HDM 求 dependency closure；逻辑失效后做 raw-source purge，再测试 cross-store retrieval、derived answer、agent plan 是否仍泄漏。Minimum Experiment：在 LoCoMo/MEME 人工插入 50 个可删除事实，比较 naive delete、graph closure、provenance closure，指标为 direct leakage、derived leakage、cross-agent propagation、retain recall、closure size。

Research Value：对 Agent Unlearning 是“数据结构与验证协议”级价值，Worth Deep Reading: YES。

Tier AFresh Memory, Stale Plans: Dependency-Scoped Validation for Distributed LLM-Agent Memory

Paper

人话版：共享记忆已经更新，不代表 Agent 正在执行的计划也更新。PlanFence 要求 plan 明确引用它依赖的 public records，执行外部动作前只验证真正影响该动作的依赖；若依赖变了就 replan/block。

Gap：传统同步只保证“读到新状态”，没有证明“旧计划仍有效”。这正对应 unlearning 的 deletion closure：删掉 memory 后，缓存计划、trajectory、tool arguments 仍可能携带被删信息。

Method：plan→dependency citation→action 前 scoped validation→依赖未变则执行；变化则一次 replan；无法验证则 block。它把 provenance 从“回答引用”推进到“行动授权”。

Experiment：30 个受控 live workflows 中，post-plan revision 后 freshness-only executor 在每个任务都执行 obsolete plan；PlanFence 30/30 无 invalid action。Replay 显示低 churn 时 proactive sync coordination stall 更低，而 churn 增大时 PlanFence 避免重复 update-path coordination；keyspace 变大时它也不必验证无关状态。

Contribution：New Protocol / New Empirical Failure Mode。Limitation：作者明确说这是 controlled safety/system-cost result，不是 general task-accuracy gain；依赖标注本身可能漏边。

Migration：Deletion request 后，不只删 memory，而是把 provenance 指向被删节点的 pending plans 标为 invalid。MVE：多 agent web workflow，计划后注入删除/修订；比较 memory-only delete、global replan、DeletionFence（dependency-scoped）；测 stale action rate、replan cost、task success、cross-agent leakage。

Worth Deep Reading: YES。对 Multi-Agent Unlearning 的价值非常直接。

Tier AUnlearning Isn't Deletion: Investigating Reversibility of Machine Unlearning in LLMs

Paper

人话版：这篇工作追问“模型答不出来，是删掉了还是暂时压住了？”它用受限 relearning 加 representation diagnostics 把 forgetting 分成可逆/不可逆、灾难/非灾难四种 regime。

Method：PCA similarity 看主表示方向是否保留；PCA shift 看 activation centroid 漂移；CKA 看样本间表示几何是否仍一致；Fisher Information 看参数对 loss 的敏感度是否结构性变化。Mean PCA distance 把跨层漂移压成标量。

Results：十种 unlearning 算法在 single-request 时常能降低 forget accuracy 且 retain 基本不掉，但 PCA similarity 仍接近 1、CKA 稳定，并能在与 |D_f| 匹配的 relearning budget 内快速恢复；continual/aggressive setting 才更容易进入不可逆或 catastrophic regime。高学习率约 3×10^-5 时出现更强 representation fracture，但 utility 风险同步上升。作者找到过 brittle 的 irreversible/non-catastrophic 区域，但依赖精细超参。

Contribution：New Evaluation/Empirical Finding。Limitation：representation drift 仍不是法律意义删除证明；relearning attacker 的数据/预算定义会影响结论。

Migration：直接把 PCA/CKA/Fisher 加到 multimodal robustness suite，并分别在 vision/projector/LLM 测 before→unlearn→relearn 的几何轨迹；与现有 Relearning/Quantization/Probe 指标形成机制层证据。

Worth Deep Reading: YES，尤其适合作为 robust-unlearning evaluation 理论支撑。

Tier AMEME: Multi-entity & Evolving Memory Evaluation

Paper

人话版：MEME 证明 Agent Memory 的难点不是“能不能搜到一条旧消息”，而是多个实体、更新、依赖、删除同时发生后还能否推导正确状态。

Method/Benchmark：六类任务覆盖 multi-entity × evolving 两个轴，特别加入 Cascade、Absence 与 Deletion。Cascade 检查一个更新是否沿依赖链传播；Absence 检查系统能否正确推理“某依赖不存在”；Deletion 检查移除后的状态，而不是仅看 retrieval hit。

Experiment：6 个 memory systems、3 种 memory paradigms、100 controlled episodes。默认配置下 Cascade 平均 accuracy 仅 3%，Absence 仅 1%；prompt optimization、更深 retrieval、减少 filler noise 与大多数更强 LLM 都无法补齐。只有 file-based agent + Claude Opus 4.7 部分缩小差距，但成本约 baseline 的 70×。

Contribution：New Benchmark + New Failure Finding。Limitation：受控 episode 与真实长期组织记忆仍有 gap；“Deletion”是 memory-state benchmark，不等于 parametric unlearning。

Migration：把 MEME 的 Cascade/Absence/Deletion 改造成 Agent Unlearning benchmark：删除源事实后检查 derived memory、plan、skill、其他 agent replica 是否闭包删除。MVE 可先 100 episodes，不训练模型，只比较 memory architectures。

Worth Deep Reading: YES。

7. Tier B

Tier BCURaTE: Continual Unlearning in Real Time with Ensured Preservation of LLM Knowledge

Paper

人话版：CURaTE 不改 LLM 参数，而训练 sentence embedding gate 判断 prompt 是否命中不断增长的 forget requests；命中就拒答，因此更新快、utility 几乎不累积损伤。

Background/Method：Continual unlearning 最大痛点是 sequential updates 累积破坏模型。CURaTE 把问题外置为“forget-request retrieval/classification”，用相似度形成 sharp boundary，再 answer/refuse。

Main Finding：作者报告其 forgetting 优于既有方法，并因不改参数而在任意更新次数下维持近乎完整知识保存，同时支持 real-time continual requests。

Contribution：New System/Protocol；真正创新点是把 continual deletion latency 与 parameter preservation 解耦。Limitation：这更接近 access control/refusal，不是 retraining-equivalent unlearning；paraphrase/jailbreak 与 embedding collision 是核心攻击面。

Why It Matters / Connection：适合作为 continual/inference-time baseline，并提醒论文术语必须区分 suppression 与 deletion。Potential Use: Baseline / Attack / Evaluation。

Tier BEffective Skill Unlearning through Intervention and Abstention

Paper

人话版：作者发现不同技能在 FFN pre-activation/key space 中形成可分区域，于是提出 Neuron Adjust 与 Key Space Detection 两个 training-free 方法：前者干预神经元，后者检测到目标技能请求就 abstain。

Core Method：关键对象是 FFL key-space activation；同技能 query 聚类后用 hypercube 做区域检测。它把“skill”从抽象能力变成可被局部 activation geometry 检测的对象。

Main Finding：覆盖数学、Python、comprehension 和 7 种语言；Key Space Detection 在多数任务上让目标技能相对性能下降超过 80%，同时其它技能和 MMLU 相对下降小于 10%。论文已被 NAACL 2025 main 接收并公开代码。

Contribution：New Mechanism + training-free control。Limitation：abstention 可被视为路由防护而非删除；hypercube 对分布外 prompt、组合技能和 adaptive attack 的稳定性关键。

Connection：非常适合迁移到 Agent Skill Unlearning：把 tool/skill invocation 的 trajectory activation 做 key-space detection，再与真正的 skill-library deletion 比较。Potential Use: Baseline / Future Idea。

Tier BCrystalMem: Elastic Memory for Self-Evolving LLM Agents via Knowledge Crystallization

Paper

人话版：CrystalMem 研究 agent memory 在预算缩小再恢复时为何能力回不来，并称这种现象为 memory hysteresis。它指出简单 delete/one-way compression 会丢掉未来重建所需材料，因此提出可降级、可恢复的 crystallized memory。

Core Method：不是把条目简单 keep/drop，而是把知识在不同精度层级间 demote/promote，保留重建结构。理论上，纯 keep/drop policy 存在 residual-deficit floor。

Main Finding：可获取摘要明确报告 squeeze-and-recover 后普通策略存在能力缺口；CrystalMem 的目标是通过知识结晶减少这种 hysteresis。由于本次只获得摘要级可访问信息，本条按“仅根据 Abstract / 可获取信息总结”，不虚构表格数字。

Contribution：New Memory Mechanism + New Empirical Phenomenon。Limitation：它优化可恢复性，而 unlearning 恰恰可能要求不可恢复；因此两者形成有价值的反向碰撞。

Connection：可把 crystallization 当作 unlearning attacker：删除后是否还能从低精度晶体重建敏感知识？Potential Use: Attack / Future Idea。

8. Idea Mining

Idea 1 — Recoverable Subspace Atlas for Multimodal Unlearning

Inspiration: RepSelect + reversibility diagnostics。Gap: MLLM unlearning 常只知道“哪个模块训了”，不知道“哪个模块留下可恢复残留”。Hypothesis: vision/projector/LLM 的 forget gradients 与 relearning gradients 存在不同 principal-subspace overlap，overlap 能预测 recovery。

Proposed Method: 对每 checkpoint 在三模块采样 forget/retain/relearn gradients；低秩 SVD 得 U_f/U_r/U_re；定义 overlap = ||U_fᵀU_re||²/k 与 selectivity = 1-||U_fᵀU_r||²/k；用它预测 Relearning After/Quantization After。

MVE: LLaVA-7B，MLLMU forget5，GA/NPO/RMU/UNDIAL + 现有 module-LoRA；先 20 个代表 checkpoint。Metric: Forget/Retain、After relearning、After quantization、CKA、subspace overlap、Spearman ρ。Expected Contribution: 首个 multimodal recoverability map，并可导出 selective update。

Novelty ★★★★★　Feasibility ★★★★★　Compute Cost ★★★☆☆　Risk：梯度采样噪声/LoRA rank 限制。Collision Risk：中高（RepSelect/MCU），差异化必须放在 multimodal module decomposition + attack prediction。Best Venue：NeurIPS/ICLR。

Idea 2 — DeletionFence: Provenance-Closed Multi-Agent Unlearning

Inspiration: Agent Zero provenance + PlanFence + MEME。Gap: 删除 memory item 后，derived memories、pending plans、tool args、其他 agent replicas 仍可携带信息。Hypothesis: deletion 必须成为 dependency-scoped invalidation protocol，而非单库 delete。

Method: 给 memory/plan/trajectory/tool-call 建 provenance DAG；forget request 从 source node 做 typed dependency closure；删除原始证据，invalidate derived nodes，并在 action 前做 deletion-fence validation。

MVE: 100 个多 agent web/file workflows，计划形成后触发 deletion；baseline = naive vector delete / global flush / graph closure；metric = direct leakage、derived leakage、stale action rate、cross-agent propagation、retain task success、closure cost。

Novelty ★★★★☆　Feasibility ★★★★☆　Compute Cost ★★☆☆☆　Risk：与 Agentic Unlearning 的 dependency closure 高碰撞。Collision Risk：HIGH；差异化必须聚焦 plan/action/trajectory/tool side-effects，而不是再做 parameter+memory dual update。Best Venue：ICLR/ACL/System workshop。

Idea 3 — Closed-Loop Inference-Time Unlearning Firewall

Inspiration: LQR activation steering。Gap: fixed steering/abstention 在 paraphrase 与 jailbreak 下不自适应。Hypothesis: forget-attribution probe 可作为状态观测，retain feature 作为控制代价，形成 adaptive feedback。

MVE: 100 forget entities；固定 steering vs Key Space Detection vs LQR；攻击 FigStep/Jailbreak/Image Rephrase/SUA；测 leakage、retain utility、control norm、latency、attack recovery。

Novelty ★★★★☆　Feasibility ★★★☆☆　Compute Cost ★★★☆☆　Risk：仍属于 suppression，不应声称严格 deletion。Collision Risk：中。Best Venue：ACL/EMNLP/ICLR。

9. Collision Detection

⚠️ Collision Warning: YES

Agent Unlearning：Agentic Unlearning (SBU) 已明确联合 parameter 与 persistent memory，并在 memory path 做 dependency-closure unlearning；因此“参数+记忆双路闭包删除”本身已不是空白。剩余 gap 是 plan/trajectory/tool/action side-effect closure、跨 agent replica propagation、provenance-verifiable deletion certificate。

Robust Unlearning：RepSelect、Minor Component Unlearning、Unlearning Isn't Deletion 已把 relearning/recovery 与 representation geometry 推到前台。若做“representation-based robust unlearning”，必须在 multimodal/module-level、attack prediction 或新 verification protocol 上形成明确差异。

Inference-time：CURaTE、skill abstention、offset/logit steering 已覆盖 refusal/router/black-box 方向；新工作应明确是 deployment-time suppression firewall，而不是宣称 retraining-equivalent machine unlearning。
