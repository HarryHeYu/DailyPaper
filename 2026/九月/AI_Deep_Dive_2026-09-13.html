5.2 一句话定位

多个Agent互相冲突时，作者不再从forward答案池内部找多数或judge，而是构造一个Bayesian reverse posterior作为不同因式分解的共享锚点，用cross-path consistency决定相信谁、如何加权以及是否把reverse信息直接融入最终posterior。

5.3 人话版

Multi-Agent系统常用多数投票、Borda/IRV等选举规则或LLM judge解决分歧，但这些方案大多仍沿“证据→标签”的forward path：如果五个Agent共享相似先验，三个同时错到同一个疾病，多数票与judge很可能继续放大这个共同错误。本文额外构造一条反向路径：把输入拆为上下文a和额外证据e，显式估计P(e|d)与P(d|a)，再通过Bayes得到R(d|x)∝P(e|d)P(d|a)。R本身常常是更弱的单独分类器，却因为错误结构与forward pool更不相同，反而非常适合作为anchor。作者用JS divergence衡量每个F_i与R的距离，提出MinJS硬选择、FwdJS软加权、LogLin对数线性融合。DDXPlus、五个backbone上，LogLin在All和真正有冲突的Disagree子集都稳定最好，后者相对最强forward-only electoral baseline高1.2–4.7pp。最重要的机制证据不是这几分本身，而是R与forward consensus同时错误时撞到同一个错误label的概率显著更低。

5.4 Background & Research Gap

投票缺外部reference；LLM judge仍读forward traces且有position/verbosity/self-enhancement bias；多轮debate成本高并可能形成conformity。即使额外加入一个neutral forward agent，本质仍是同一factorization。作者认为真正缺的是一个“结构上独立的参考分布”。例如五个医疗Agent都看到同一症状，三票A两票B；若A是共享先验导致的共错，任何forward consensus机制都很难自救。Reverse path改问“假设疾病d成立，这些证据e出现的可能性多大”，从另一个条件方向近似同一后验。

5.5 Core Insight

第一，关键不是多一个Agent，而是多一个inference factorization。第二，anchor standalone accuracy不是主要目标：R在All上比MeanF低7.8–26.4pp，却作为FwdJS/LogLin anchor始终更好。第三，cross-path consistency可成为routing信号。第四，error collision比accuracy更能解释“为什么这个anchor有用”：forward plurality与R同时错时同label碰撞仅0.196–0.413，而forward–forward可达0.680–0.829。第五，最稳方法是routing和reverse mass同时使用，因此LogLin通常优于MinJS/FwdJS。

5.6 Method Deep Dive

Input x → 5 heterogeneous forward agents → F_i(d|x) → split evidence x=(a,e) → reverse construction: P(d|a) + P(e|d) → R(d|x) ∝ P(e|d)P(d|a) → D_i = JS(F_i,R) → MinJS: choose argmin D_i → FwdJS: w_i ∝ exp(-τD_i), weighted forward mixture → LogLin: P ∝ P_FwdJS^(1-w_R) · R^(w_R) → optional labeled calibration of reverse anchor → final label

Forward pool由ToT、few-shot MedPrompt、vanilla CoT、common-bias、rare-bias五种agent组成。Reverse每个case只构造一次，由两个LLM elicitation step加Bayesian replay得到。MinJS只让R排序，不让R进最终posterior；FwdJS将D_i变成soft weights；LogLin再让R以小权重直接修正posterior。校准阶段只拟合reverse maps、temperature和一个marginal correction，不微调underlying LLM。

5.7 核心公式与数学直觉

R(d|x) ∝ P(e|d) · P(d|a) D_i = JS(F_i,R) = 1/2 KL(F_i||M_i)+1/2 KL(R||M_i) M_i=(F_i+R)/2 MinJS: i*=argmin_i D_i FwdJS: w_i = exp(-τD_i)/Σ_j exp(-τD_j), τ=5 P_FwdJS=Σ_i w_i F_i LogLin: P(d) ∝ P_FwdJS(d)^(1-w_R) R(d)^(w_R), w_R=0.2

JS对称且有界，适合“两个分布都不是ground truth”的情况。τ越大越接近硬选择，过高会放大R偶然误差；过低则趋向uniform average。w_R=0.2之所以较小，是因为FwdJS已经通过JS间接用了R。与Range/Borda/IRV的本质差异不是更复杂的投票，而是加入不同factorization的证据源。

5.8 Toy Example

  1. 五个Agent在A/B/C疾病中三票A、两票B。
  2. Plurality直接选A。
  3. Reverse path计算“若A/B/C成立，这些症状出现的可能性”。
  4. R本身top-1可能甚至是C，不保证单独正确。
  5. 但R与两个B-Agent的分布更近，JS更低。
  6. MinJS可选择一个B-Agent。
  7. FwdJS让两个B-Agent权重更高。
  8. LogLin再用R轻量抑制A、修正最终posterior。
  9. 价值来自错误结构独立，而不是R本身更准。

5.11 Metrics 教学式解释

GTPA@1↑：最终posterior argmax是否为gold pathology。Disagree accuracy：只看真正需要仲裁的case，比All更敏感。Label-collision rate π↓：两个预测都错时是否错到同一label，衡量错误独立性但不等于accuracy。JS-rank accuracy：按JS距离排序Agent后看rank-1到rank-5准确率，衡量routing signal。

5.14 Ablation / Mechanistic Analysis

R换成MeanF后LogLin不再超过最强electoral baseline，说明收益不是log-linear operator本身。R换成GenF也系统退化，说明额外forward Agent无法替代不同factorization。likelihood-only和prior-only多数弱于完整R，说明两部分互补；Llama prior-only略强是机制边界。MinJS→FwdJS→LogLin逐级改善，说明“软加权+直接reverse mass”比硬选更稳。

5.15 Claim vs Evidence

Authors Claim：Bayesian backward reasoning提供label-free、结构不同的anchor。
Experiments Actually Show：DDXPlus五backbone同forward pool下，LogLin稳定领先，reverse error collision更低，替换anchor会退化。
What Is Not Yet Proven：未证明任意任务都能构造好reverse likelihood；开放文本、多轮Agent、真实临床都未覆盖。

5.16 Contribution

  • New Mechanism：Bayesian reverse posterior作为MAS conflict anchor。
  • New Metric/Protocol：JS cross-path consistency做Agent routing。
  • New Operator：FwdJS与LogLin。
  • New Finding：weak standalone anchor可以是strong aggregation anchor。
  • New Mechanistic Finding：reverse与forward错误同label碰撞显著更低。

5.17 Limitation & Failure Modes

Reverse posterior本身可能misspecified；数据是合成医疗closed-label；不同backbone的rank曲线不都单调；R需要显式a/e分解与likelihood elicitation；没有完整成本/latency表；没有恶意Agent、collusion、memory poisoning或多轮通信。

5.21 Attack / Verification Lens

Anchor Collision Attack：让forward pool和reverse anchor一起被诱导到同一个错误label，专门破坏“错误独立性”假设。可定义Cross-Path Collision Rate与Anchor Independence Gain：相同accuracy下，error collision越低的anchor越适合作verifier。

5.2 一句话定位

论文把“模型会回答一个事实”拆成parameter-retrieval routing、target knowledge content、object selection三个不同功能，并用layerwise删除/反转干预证明：可读性、自然强度、对答案的因果作用、对后续知识的作用并不在同一层同时出现。

5.3 人话版

“模型内部能读出Kenya→Africa”并不说明它当下真的依赖这条信息。作者用country–continent任务做了很细的机制分解：routing负责“当前问题请求哪条参数知识”，content负责“被检索出的Africa/Asia/Europe事实内容”，selection负责“多个可用候选里最终选谁”。他们不仅训练线性probe，而是删除、反转这些方向，并与八个等实际长度random interventions比较，看答案margin和后续层知识score是否发生specific变化。最关键结果是：Qwen的pair-conditioned request方向从很早就可读，但删除它直到约28–36层才显著影响答案，峰值32；后面target content仍持续具有因果作用，而一种global request direction的作用会衰减。可这个“handoff”不是统一stage：在同一任务中把global方向换成pair-conditioned方向，晚层effect又强烈出现；Gemma只部分重叠，Llama没有持续routing window。Target content的跨表达结果更稳：noun-derived变化能迁移到adjective，却很少迁移到任意code。对unlearning最关键的提醒是：representation residual可读≠仍被使用；输出被压制≠内容已经删掉。

5.4 Background & Research Gap

knowledge localization常回答“知识存在哪些层/参数”，mechanistic probing常回答“能否从某层读出事实”，activation intervention则回答“改这个state会不会影响输出”。这些证据经常被混成“模型在这里检索知识”。但同一个state component可能是事实内容，也可能只是控制“去取哪条事实”。例如Kenya/China问题的hidden-state差异同时包含country token、request identity、目标continent等多种成分。本文的gap是把retrieval拆成routing、content、selection，并严格区分readability与causal use。

5.5 Core Insight

第一，readability可以早于causal dependence很多层。第二，representation strength也不等于downstream causal effect。第三，content通常比某些routing representation更持久。第四，“routing handoff”强烈依赖方向定义，global方向晚层失效不代表所有request information消失。第五，content跨自然表达可迁移但对arbitrary codes大多失败。第六，object selection不是跨模型统一stage。

5.6 Method Deep Dive

Question x → record question-end hidden state h_x^l at every layer A. Parameter-Retrieval Routing → fit pair-conditioned/global request directions → remove content overlap → delete / reverse request component → measure answer margin + later content B. Object Selection → marker task supplies both candidate markers → fit first-vs-second selection direction → transfer to factual questions → test answer change / two-continuation restoration C. Target Knowledge Content → fit Africa/Asia/Europe means → SVD → 2D orthonormal content basis U^l → P^l=UU^T → delete content projection → matched random controls → transfer noun-derived shift to adjective/code D. Layerwise comparison → held-out countries + fit/seed/repeated-deletion controls → model-specific conclusions

所有状态都取question-end位置。Routing方向先剔除fitted content overlap，尽量避免把请求与答案内容混在一起。Selection先在“marker已直接供应”的任务校准，避免把selection与stored knowledge混为一谈。Content空间由Africa/Asia/Europe三个centered means做SVD得到二维subspace。每次真实干预都和八个actual-length-matched random directions比，而不是只看raw damage。

5.7 核心公式与数学直觉

h_x^l = H_x^l[n_x,:]^T μ^l = average_x h_x^l μ_k^l = average_{x in continent k} h_x^l V^l=[μ_Africa-μ, μ_Asia-μ, μ_Europe-μ] U^l = first two right singular vectors P^l = U^l(U^l)^T z_x^l = P^l(h_x^l-μ^l) F^{l,route}=(1/N)Σ_x 1[σ_x α_x^l>0] Δh_transfer = κ_alt^(name)-κ_target^(name)

SVD/Projection：三个continent centered means最多张成二维空间，P只表示该task中拟合的continent content，不是“全部知识空间”。F_route：只看route coefficient sign是否指向被问country，属于readability。Deletion/Reversal：删除去掉component，反转主动朝错误request推。Matched random：控制“改hidden state本身就会伤模型”，是因果解释关键。

Interventions：route delete/reverse、selection edit、content delete、cross-format shift。
Controls：8 matched random、repeated deletion、fit omission、multi-seed。
Research Question：routing何时可读/因果？是否改变后续content？selection能否分离？content是否跨表达？跨model是否有统一handoff？

5.11 Metrics 教学式解释

Answer margin：正确candidate sequence log-prob减paired alternative，连续反映偏好。Corrected answer effect：真实干预damage减八个random中最大平均damage；>0才支持specific causality。Knowledge score：hidden state在2D content space中更接近correct还是alternative reference，不能跨model比较绝对值。Correct pointing fraction：route sign是否指向被问对象，只测readability。Pass gate：要求screening和两个validation split一致，而不是单一均值。

5.14 Ablation / Mechanistic Analysis

Delete vs reverse让作者区分“移除路由”与“主动错误路由”；content projection deletion证明content不仅可读而且被使用；matched random控制通用扰动；repeated deletion降低“后层迅速重建所以单删看不到”的解释；noun→adjective/code transfer给语义抽象边界；fit/seed sensitivity显示content结论比routing更稳。特别是Qwen layer31→32，true route damage从0.8021降到0.0104，而random damage反而0.25→0.4167，说明corrected decline主要是真route作用下降。

5.15 Claim vs Evidence

Authors Claim：知识回答可功能性区分routing、selection和content。
Actually Show：country-continent及少量capital任务上，Qwen/Llama/Gemma存在可复现差异，Qwen最清楚。
Not Proven：不存在跨模型统一stage；pair-conditioned/global差异大；selection不普遍；线性方向只捕捉部分机制。

5.21 Attack / Verification Lens

可直接形成三级verifier：Readable Residual ≠ Causal Residual ≠ Recoverable Residual。先线性读出，再做specific deletion看answer damage，再看是否改变后续content。若只有第一项，不应直接叫privacy leakage；若第二、三都成立，才更接近“模型仍在使用该知识”。

5.22 与另外 Top Paper 的关系

第一篇创造系统级forward/reverse路径独立性；本篇提供单模型内部routing/content/selection独立性。组合后可构造mechanistic multi-agent verifier：各Agent不是简单换prompt，而是读不同功能路径，然后用error collision/JS决定谁更可靠。

Best Migration Direction — Cross-Path Mechanistic Unlearning Verification

Unlearned target → forward behavioral probes: direct/paraphrase/cloze/prefix → internal mechanistic probes: routing/content/selection → reverse-consistency probes: target→expected evidence → measure probe accuracy + error collision + JS → intervene: delete/reverse routing; delete content projection → test downstream recovery → aggregate only path-diverse evidence → classify: forgotten / residual-routing / residual-content / output-only suppression / unresolved
