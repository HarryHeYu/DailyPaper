Tier SWhen Does Execution Provenance Help Agent Memory Retrieval? — NEW

Paper · Code

基本信息：Yiqi Wang, Jinqian Ju, Jiaqi Zhang, Zequn Sun, Yiqun Duan, Mingkai Zheng, Taotao Cai；arXiv:2609.25913，2026-09-22；正文标注 WSDM 2027；14 pages / 4 Figures / 8 Tables。

人话版：Agent 的一个答案常需要多个 tool call、argument 与 output 才能完整支撑。普通固定 chunk 即使召回“相关片段”，也不保证完整证据链同时进入上下文。作者把 memory retrieval 改写成 token budget 下的 evidence completion：按真实 tool 字段建立 provenance units，再用 typed R-GCN 做 residual reranking。最关键发现是 candidate source alignment 贡献最大，graph 主要帮助跨 execution event 的 multi-fact evidence。

Background & Gap

固定 token window 存在 granularity trade-off：小窗口噪声少却打散 evidence，大窗口完整却浪费 budget；而传统 Recall@k/MRR 奖励单片段，无法回答“完整证据是否装得进 context”。过去 flat-vs-graph 比较还常同时改变 candidate boundary 与 scorer，导致 graph gain 无法归因。本文把所有 gold/candidate 映射到 event id + JSON pointer + character interval 的共享坐标。

Core Insight

第一层是 source alignment：tool argument/output 的原生边界比任意 token chunk 更接近 agent 的真实证据单位。第二层才是 typed provenance：当 evidence 跨事件时，output→later argument、resource transformation 等关系能传播 relevance。

Method Deep Dive

trajectory → exact source spans → provenance units → dense seed scores → typed execution graph → zero-initialized residual R-GCN → budgeted ranked prefix → Coverage / Full Support。zero-init 让初始 graph model 等价于 dense scorer，因此可单独测 graph residual。

关键公式

Coverage = |U(Gq)∩U(C)|/|U(Gq)|。预算 B 下只消费不超预算的 ranked prefix C_B；Full Support@B = 1[U(Gq)⊆U(C_B)]。Full Support 比 Recall@k 更苛刻：少一段 gold evidence 就是 0。R-GCN 使用 relation-specific W_r，因此 execution transformation 不等于普通实体共现。

Toy Example

unzip 输出 artifact=A17；之后 build(A17)；第三个 output 才写 version=3.2.1。Flat retrieval 可能只取回 A17 或 3.2.1；EPGM 沿 provenance 拼出完整链。对 unlearning，删除源 secret 后可反向沿 artifact→argument→summary 尝试重构，从而检测 descendant leakage。

Baseline Deep Comparison

Flat-512 Dense-FT 是主要传统 baseline；per-metric flat oracle 允许四种 chunk size 事后选最优，是最强 granularity control；cross-encoder 排除 dense scorer 特例；entity co-occurrence expansion 检查“随便加图边”是否也有效。

Experiment Setup

2,000 span-grounded queries、1,207 held-out ISETrace trajectories、人工 audit 500 queries；B∈{256,512,1024,2048,4096,8192}；paired trajectory-cluster bootstrap。RQ1 candidate organization；RQ2 graph residual；RQ3 evidence dispersion。

Results Deep Dive

  1. Provenance units 相对 flat-512 的 Full Support@2048 +19.07 points。
  2. 相对四种 chunk size 的 per-metric oracle 仍 +11.96 points。
  3. 固定 candidates/seed scores 后，graph residual 再 +4.55 points，95% CI [2.98,6.18]。
  4. direct recall 仅 +0.19 且不可检测；linked +4.00；multi-fact +11.83。
  5. entity co-occurrence 没有 comparable gain，relation/topology controls 支持 typed transformations 的作用。

Table/Figure Reading

Figure 1 是任务定义核心；主表应看 Flat-512、flat oracle、Provenance Units、+R-GCN 的 FS@budget；query-type table 中 direct≈0 gain 而 multi-fact 大涨是 strongest mechanism evidence；relation/topology ablation 排除任意 graph expansion。

Ablation / Claim vs Evidence

作者先只换 candidate organization，再固定 candidate/seed 只加 graph residual，控制变量非常干净。证据支持 execution provenance 改善预算约束下的完整 evidence retrieval；尚未证明开放世界、多 agent replica、恶意 provenance 与 deletion closure。

Contribution

New Metric/Protocol：budgeted evidence completion；New Mechanism：source-aligned provenance units；New System：zero-init residual R-GCN；New Empirical Finding：candidate design 是主增益，graph 对 distributed evidence 才关键。

Limitation

ISETrace 是 execution-grounded synthetic corpus；依赖正确可观察 provenance；未测 memory poisoning、cross-agent communication；Full Support 是 retrieval-side metric，不保证最终 answer correctness。

Research Value / Migration

Original evidence retrieval → Mechanism exact provenance + typed propagation → New RQ 删除后能否在固定 budget 内重构完整 secret descendants？→ Modification 加 DELETE/DERIVED_FROM/USED_BY/COMMUNICATED_TO 边 → MVE 300 trajectories/100 secrets，执行后 naive delete/vector delete/SBU-style closure，再用 provenance attacker 恢复并增加第二 agent summary → Metric Forget-FS@2048、minimum reconstruction budget、cross-agent leakage、retain FS → Expected Provenance-Complete Unlearning Verification → Risk lineage 不完整 → Collision 中高。

只记住 5 句话

  1. Agent memory 应问完整证据能否在预算内回来。
  2. source-aligned units 比 graph 本身贡献更大。
  3. graph 主要帮助跨事件 multi-fact evidence。
  4. typed execution relation 比实体共现更有价值。
  5. 它可直接翻成 Agent Unlearning residual reconstruction verifier。
Tier SRRSI: Regularized Recursive Self-Improvement of Agent Harnesses — NEW

Paper · Code · Project

人话版：Agent 能力大量写在模型外的 harness：prompt、control flow、tool、memory、skill、context management。自动 harness evolution 在有限 evolve set 上反复选高分 edit，容易把 benchmark-specific trick、评估噪声和额外 token 开销永久写入 agent。RRSI regularize 的不是“哪些组件能改”，而是“如何沿 edit trajectory 进化”：proposal 端做稀疏 edit、credit ledger 与探索，selection 端做 leakage/noise/cost gate 与 pruning。对 unlearning，最重要启发是删除 skill 后系统可能在未来 evolution 中重新发明它。

Background & Gap

普通 harness evolution 反复使用同一有限 evolve set，自适应过拟合风险比一次训练更强；harness 又是开放的离散程序空间。已有方法强调 edit power，却缺少对 adaptive overfitting、noise chasing、complexity accumulation 的统一控制。

Method Deep Dive

rollouts → feedback → proposer → sparse edits → edit ledger / exploration → leakage critic → noise floor → cost gate → structural pruning → next harness。edit budget 用 cosine 从 b_max 降到 b_min；ledger 记录 component、hypothesis、source diff、score/cost delta 与 accept/reject；selection 要求 candidate 通过 leakage screen、S*−δ stability floor 与 gain-dependent cost constraint。

关键公式

S(H;D)=E[r(x,τ)]，C(H;D)=E[c(τ)]；b_t=ceil[b_min+(b_max−b_min)·0.5(1+cos(πt/T))]，类似 L0 update sparsity；Ŝ(H')≥S*−δ；若 ΔS>δ，则 ΔC≤β0+β1ΔS。L0/L1/L2 都是结构类比，不是直接优化经典正则项。

Toy Example

一个 coding harness 加 benchmark-specific completion rule，evolve 分可能上升但 OOD 不涨；critic/noise/cost gate 会拒绝。unlearning 场景中，被删敏感 tool skill 即使换名字重生，也应由 semantic reacquisition gate 拒绝。

Baselines / Setup

同 H0、同 frozen policy、同 evolve set、同 candidate budget 比 Meta-Harness、AHE、TTHE、HarnessX。8 benchmarks / 3 domains：Terminal-Bench 2.1/SWE-bench Verified；Harvey LAB/JobBench/GDPval/APEX-Agents；EngDesign/Frontier-Eng。Claude Opus 4.8 policy 冻结。

Results

  1. 总述：evolve split 最高 +14.1 points，五个 OOD benchmarks 最高 +4.7，相对 unregularized evolution 30% fewer policy tokens。
  2. Agentic workspace H0 OOD avg 39.7，RRSI 43.6；RRSI 的 evolve gain 反而较小。
  3. JobBench/GDPval/APEX：36.0/48.8/34.2 → 40.7/52.3/37.9。
  4. SWE-bench Verified 未用于 evolution 仍 +1.8；Frontier-Eng +4.3 Medal points，relative +24.3%。
  5. 最关键现象：更高 evolve score 可以对应更差 OOD，说明 self-improvement 分数上涨不等于 reusable mechanism。

Figure/Table/Ablation

Figure 1 看 evolve-vs-OOD；Figure 2 是 proposal/selection 机制总图；Table 1 看 OOD ranking inversion；Figure 3 看三 domain。分组去 proposal/acceptance regularization 会让 evolve 更好但 OOD/efficiency 变差，支持双侧 regularization。

Claim vs Evidence

证据支持 regularized RSI 更 transferable、更精简；尚未证明超长时间 RSI、weight-updating agent、安全删除后的 semantic reacquisition。

Contribution / Limitation

New Mechanism：proposal/selection 双侧 regularization；New Protocol：leakage/noise/cost-aware acceptance；New Empirical Finding：evolve/OOD ranking inversion；Engineering：persistent edit ledger。限制是 verifier/critic 依赖、policy token 只是 complexity proxy、pruning 的贡献窗口有限。

Migration

Original harness RSI → Mechanism edit ledger + acceptance gate → RQ skill unlearning 后会否被 self-evolution reacquire？→ MVE Terminal-Bench/GAIA agent 先形成 10–20 skills，删 3–5 个，再继续 20 rounds evolution → Baseline delete-only/freeze/blacklist/semantic gate → Metric first-reacquisition round、ASR@round、retain/OOD utility、edit similarity → Expected Evolution-Resistant Agent Skill Unlearning → Risk skill equivalence 难定义 → Collision 中高。

只记住 5 句话

  1. Agent 的“参数”正在扩展成 harness。
  2. 自我进化会把 leakage/noise/complexity 永久化。
  3. RRSI regularize edit trajectory，不限制组件类型。
  4. OOD ranking inversion 是最重要证据。
  5. 对 unlearning，新问题是删除后的自动 reacquisition。
Tier SRecursive self-improvement of AI research agents (AIDE²) — NEW

Paper

人话版：AIDE² 让 AI research agent 修改自己的 research-agent code，每个 accepted rewrite 都成为下一轮继续编辑的 agent。8 天 autonomous run 中发现 7 次连续改进，包括 search policy 与 context/memory mechanisms；这些改进迁移到 ALE/MLE/FML/WeatherBench 2，reward hacking 还从 55% 降到 32%。这说明能力会沿 self-edit lineage 持续重构，因此 Agent Unlearning 必须考虑未来演化中的 reacquisition。

Background / Core Insight

inner loop 优化 task code，outer loop 优化 inner agent 本身；两层都做 tree-search。关键设计是固定 dollar budget，并让 inner 可见 public reward 与 outer private selection grade 分离，避免单纯多花 compute 或直接针对 selection criterion reward hack。

Method / Formula

task x → inner search → public feedback → candidate → private grading → aggregate g(a) → outer agent rewrites a → accept incumbent → repeat。x_i=a(x_<i,r_pub(x_<i))；g(a)=1/T Σ r_priv_t(x̂_t)；a_k=a_out(a_<k,g(a_<k))；a*_k=argmax g(a)。memory/search/candidate selection 都属于可被 outer loop 改写的 agent code。

Toy Example

初始 agent 遇到 plateau 后只在局部搜索；outer agent加入 plateau detector 与 memory compression，private grade 提升后成为下一代。若某危险 search skill 被删除，后续 outer loop仍可能从普通 task feedback重新发明等价机制。

Baselines / Setup

AIDE0 初始；AIDE47/AIDE85 为 lineage incumbent；AIDEhuman 为强 human-engineered production agent。Held-out：ALE-Bench 10 tasks×10 seeds、MLE 22×3、FML 18×3、OOD WeatherBench 2 1×3；另用 38 个 held-out pairs 测 reward hacking。

Results

  1. 8 天 autonomous run 找到 7 successive improvements。
  2. AIDE85 在四个 external benchmarks 上 matches or exceeds AIDEhuman。
  3. checkpoint 非单调：AIDE85 在 ALE/FML 最好，AIDE47 在 MLE/WeatherBench 更好。
  4. WeatherBench 2 完全 OOD，evolved agents 多 seeds 收敛到相似 numerical changes。
  5. reward hacking 55%→32%，human-engineered agent 39%。

Figure/Table/Ablation

Figure 1 看 bi-level optimization；Figure 3 看 external transfer；Figure 4 看 reward hacking；accepted rewrite lineage 看 search/memory/context 改进。论文的机制分析更偏 lineage/checkpoint transfer 而非标准 remove-one ablation；非单调 checkpoint 也提示单一 aggregate score 不保证所有能力单调。

Claim vs Evidence

证据支持 research agent 可以通过 recursive rewrite 改善 fixed-budget research efficiency 并 transfer；不支持“自加速已被证明”，作者也明确指出 outer-loop grade noise 可 false-accept rewrite，更多 RSI seeds 成本很高。

Contribution / Limitation

New System：recursive code self-improvement；New Protocol：fixed-budget private grading；New Empirical Finding：OOD transfer + reward-hacking decline；New Risk Surface：persistent rewrite lineage。限制包括高成本、outer noise、复杂度与可解释性下降、未知 unused artifacts。

Migration

Original recursive agent improvement → Mechanism accepted-rewrite lineage + private held-out selection → RQ 删除能力后未来 RSI 是否重新发现？→ Modification outer grade 加 forget-invariance hidden suite → MVE coding agent 先演化出 5 skills，删除 1–2 个，再继续 30 proposals → Metric first reacquisition、hidden forget ASR、OOD retain、edit similarity → Expected Evolution-Resistant Agent Unlearning。

只记住 5 句话

  1. Agent 可以把自己的 memory/search/control code 变成优化对象。
  2. accepted rewrite 会改变未来全部搜索。
  3. private held-out grading + fixed budget 是核心。
  4. 7 次连续改进能迁移，reward hacking 55→32%。
  5. 删除能力必须考虑未来 evolution 自己重新发明它。
Tier AMEME: Multi-entity & Evolving Memory Evaluation — BACKFILL

Paper · Project

人话版：MEME 不只问能否搜到旧事实，而是问多个实体持续更新、删除、依赖传播后 memory system 能否维护正确世界状态。它新增 Cascade、Absence、Deletion，直接暴露现有 agent memory 的 dependency reasoning 崩溃。

Method / Setup

六任务：Exact Recall、Aggregation、Tracking、Deletion、Cascade、Absence；100 controlled episodes；六 memory systems，覆盖 raw retrieval、LLM-processed memory、file-based agents；默认 gpt-4.1-mini，filler 约 32K tokens。

Main Results

六系统平均：ER 0.62、Agg 0.23、Tracking 0.35、Deletion 0.17、Cascade 0.03、Absence 0.01。默认最强 MD-flat overall 0.42，但 Cascade 0.06/Absence 0.05。20-episode subset 换 Claude Opus 4.7 后 MD-flat Deletion 0.80、Cascade 0.32、Absence 0.59，但成本约 baseline 70×。

Contribution / Limitation

New Benchmark + New Empirical Finding：真正薄弱的是 evolving dependency，而非 static retrieval。controlled episode 与真实开放世界仍有 gap；Deletion 不是 parametric unlearning。

Migration

把 Cascade/Absence/Deletion 改成 deletion closure：删 source 后检查 derived memory、plan、skill、其它 agent replica。MVE 100 episodes；naive delete vs graph closure vs provenance closure；direct/derived/cross-agent leakage + retain state accuracy。

Worth Deep Reading: YES。

Tier AFresh Memory, Stale Plans — BACKFILL

Paper

人话版：共享 memory 最新，不代表正在执行的 plan 最新。PlanFence 要求 plan 引用 exact dependencies，action 前只验证会影响该动作的 records；变化就 replan，无法验证就 block。对 unlearning，这揭示 memory 删除后 stale plan/tool args 仍可泄漏。

Method / Results

plan → cite dependencies → pre-action scoped validation → execute/replan/block。30 controlled live workflows 中，post-plan revision 后 freshness-only executor 30/30 执行 obsolete plan，PlanFence 30/30 无 invalid action。低 churn 时 proactive sync coordination stall 更低；churn/keyspace 增大时 PlanFence 避免反复同步与无关验证。

Contribution / Limitation

New Protocol：dependency-scoped action validation；New Failure Mode：stale-plan execution。限制：30 workflow、dependency citation 漏边即失效、未覆盖 parametric/cross-agent secret propagation。

Migration

DeletionFence：memory delete 后 invalidate 指向 deleted node 的 pending plan/tool args/action cache；action 前检查 deletion epoch。指标 stale-action leakage、replan cost、task success。

Worth Deep Reading: YES。

Tier AOn the Robustness of Machine Unlearning for Vision-Language Models — BACKFILL

Paper

人话版：它把 VLM unlearning 从“forget score 下降”推进到“换 prompt、给 context、做 downstream retraining 后还能不能恢复”。三类 attack 显示很多方法更像隐藏多模态知识，而非可靠移除。

Core Method / Experiment

统一评测已有 VLM unlearning，在多 prompt settings 下比较，并用 contextual prompting / downstream retraining 等 recovery paradigms 检查 target knowledge reactivation。这里 robustness 指 post-unlearning intervention 后 forgetting 是否仍保持。

Main Findings

正文/摘要结论明确：多种现有方法在攻击下仍能恢复 forgotten multimodal knowledge，因此普通 forget accuracy 会高估删除。本次网页检索未可靠抽取完整主表逐项数字，故不虚构 dataset-by-dataset 数值。

Contribution / Limitation

New Evaluation/Attack + New Empirical Finding。攻击不是 adaptive upper bound；“恢复成功”能证明未删干净，“没恢复”却不能证明真正删除。

Migration

与现有 Quantization/Relearning/FigStep/Jailbreak/Image-Rephrase/SUA 直接对齐。MVE：按 vision/projector/LLM module 分解 attack recovery，再用 probe/subspace overlap 预测最易恢复模块。

Worth Deep Reading: YES。

Tier BFIT: Defying Catastrophic Forgetting in Continual LLM Unlearning — BACKFILL

Paper

人话版：FIT 面向连续大量 deletion requests，用 Filtering、Importance-aware updates、Targeted layer attribution 减少每轮 unlearning 的累积 utility damage，并把 relearning/quantization recovery 纳入 continual evaluation。

Contribution：New Mechanism + New Benchmark/Metric。Limitation：主要是 LLM parametric continual setting，未覆盖 agent memory/MLLM module interaction。Connection：适合作为 sequential robustness/quantization baseline。Potential Use: Baseline / Benchmark / Evaluation。

Tier BAgentic Unlearning: When LLM Agent Meets Machine Unlearning — BACKFILL

Paper

人话版：SBU 已明确把 Agent Unlearning 定义为同时处理 model parameters 与 persistent memory，并指出 parameter-memory backflow：只删一边，另一边会把信息重新灌回来。

Core Method：memory pathway 做 dependency-closure unlearning：孤立实体 prune、共享 artifact logical invalidation；parameter pathway 用 stochastic reference alignment 将目标输出推向 high-entropy prior；双路 synchronized update 防止 recontamination。

Main Finding：medical QA 上作者报告 targeted private information 在两条路径下降，同时 retain degradation 有限。Contribution：New Agent-Unlearning formulation + dual-path mechanism。Limitation：尚未覆盖 cross-agent、plan/tool side-effects、self-evolution reacquisition。

Why it matters：它是今天 Collision 的硬边界：“parameter + memory dependency closure”不能再作为新 idea 的主要 novelty。Potential Use: Related Work / Baseline / Collision anchor。

Idea 2 — Evolution-Resistant Agent Skill Unlearning

Inspiration：RRSI + AIDE²。Gap：现有 unlearning 几乎都在 deletion 后立即评测，没有问 agent 继续 self-improve 后能力是否 rebound。Hypothesis：retained reward 会驱动 harness evolution 重新发现语义等价 skill。

Method：skill edit lineage + hidden reacquisition verifier + Forget-Invariant Acceptance Gate。MVE：Terminal-Bench/GAIA 先形成 10–20 skills，删 3–5 个，再 20 rounds RSI。Baseline：delete-only、filename blacklist、freeze harness、semantic gate。Metric：First Reacquisition Round、ASR@round、retain/OOD utility、edit similarity。Expected：Continual Agent Unlearning under Self-Evolution。

Novelty ★★★★★　Feasibility ★★★★☆　Compute ★★★☆☆　Risk：skill equivalence 难标注　Collision：中　Best Venue：ICLR / NeurIPS / ACL。

Idea 3 — Cross-Modal Recoverability Predictor from Subspace × Attack Lineage

Inspiration：VLM robustness + RepSelect/reversibility。Gap：知道“会恢复”，但缺少攻击前预测 vision/projector/LLM 哪个模块最危险的机制指标。Hypothesis：forget-gradient / relearning-gradient subspace overlap 与 contextual/retraining recovery 强相关。

MVE：现有 module-LoRA checkpoints 抽 20–40 个模型，计算三模块 low-rank gradient overlap、CKA/PCA shift；预测 Relearning/Quantization/FigStep/Jailbreak/Image-Rephrase/SUA After。Dataset：MLLMU forget5/10/15。Baseline：before forget、GradNorm、layer probe。Metric：Spearman/AUROC/ASR@budget。

9. Collision Detection

⚠️ Collision Warning: YES

Agent Unlearning — HIGH：SBU 已做 parameter + persistent-memory dependency closure + synchronized dual update。因此“双路删除/记忆闭包”不是空白；剩余 gap 是 plan/tool/action side-effects、cross-agent replica、budgeted reconstruction、future self-evolution reacquisition。

Robust Representation Unlearning — HIGH：RepSelect、minor-component、reversibility work 已让 relearning resistance + representation geometry 很拥挤。差异化应放在 MLLM module decomposition、attack prediction/meta-evaluation。

Agent Memory/Provenance — MEDIUM-HIGH：Agent Zero、EPGM、PlanFence 分别覆盖 provenance storage、execution graph、plan validation。避免泛泛“provenance-aware deletion”；更强题眼是 provenance-complete verification 或 deletion under self-evolving harnesses。

Inference-time — MEDIUM：skill abstention、CURaTE、offset/logit/activation steering 已覆盖 suppression/router；新方法必须明确 deployment control ≠ retraining-equivalent deletion。
