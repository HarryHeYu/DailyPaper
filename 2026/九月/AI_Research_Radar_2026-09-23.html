1. Executive Summary

本轮先按 unlearning、reasoning leakage、relearning robustness、continual deletion、multimodal forgetting、agent memory、multi-agent memory、provenance/lineage、memory poisoning、inference-time steering、token attribution 等方向广搜，建立 38 篇 Candidate Pool，再统一筛选。近期真正“新且直接”的 unlearning 论文并不多，因此没有硬凑正式篇数；最终深度收录 9 篇，其中 2 篇 Tier S、3 篇 Tier A、4 篇 Tier B。最新高价值项是 9 月 18 日提交的 GUARD；Agent 侧 9 月的 PlanFence 与 EAL-Bench 则进一步把“memory correctness”推进到“plan validity / authorization lineage”。

今天最明显的研究趋势有三条。第一，unlearning 正从 answer-level 转向 trajectory / representation / token-level：GUARD 直接管 CoT 与 answer 的完整轨迹；TokenUnlearn/ATWU 关注 token 贡献；MCU/FRAG 则关注 representation 几何和更新结构。第二，robustness 不再只是 jailbreak：relearning、continual forgetting reversal、black-box/API-only、training-free prompt suppression 都成为“是否真的忘了”的必要压力测试。第三，Agent memory 的 provenance 正在变成安全边界：Agent Zero Memory、MemLineage、TMA-NM、PPMF、EAL-Bench 都在不同层面说明“内容看起来可信”远远不够，必须追踪 origin、derivation、timestamp、authority 与 downstream action。

5–8. Formal Papers

Tier S GUARD: Natural Forgetting in Large Reasoning Models via Guided Answer-Reasoning Distillation

Zeyu Yan, Guanghao Zhou, Minghui Qiu, Ming Gao, Cen Chen · East China Normal University + unaffiliated · 2026-09-18 · arXiv cs.AI · Paper · Code

人话版：这篇论文到底干了什么？

以前给 reasoning model 做 unlearning，常见做法是让敏感答案概率下降、让最终答案学会拒答，或者把相关 hidden representation 推走。但 reasoning model 在真正输出答案前会先生成一大段 CoT：敏感事实可能已经在里面泄漏；更糟的是，如果只“破坏原轨迹”而不告诉模型忘掉之后应该怎么继续，它会胡编替代事实、重复、断掉 </think> 边界。GUARD 的核心是先给模型造出一条“自然忘记”的完整替代轨迹：推理中逐步转向不确定/不可披露，最后稳定拒答；再把这种轨迹蒸馏进参数。论文还提出 NFRS，专门测忘掉之后的生成是不是仍然自然、完整、没有幻觉替代。

Background & Research Gap

传统 unlearning 默认输出是一个 answer，因此“forget”常被写成降低目标答案 likelihood、增加 refusal preference，或让 forget representation 偏离原空间。LRM 改变了问题：输出实际是 reasoning r → boundary </think> → answer a → EOS。如果只监督 a，r 仍可能写出隐私；如果粗暴改 r 的表示，autoregressive decoder 的后续 token 分布会被级联扰乱。论文用具体 failure family 把 gap 拆成三类：GA 的 probability-mass redistribution 会把被压下去的敏感 token 质量转移到“看似合理的替代词”；PO 出现 CoT/answer refusal mismatch；R²MU 的 representation redirection 会造成 downstream drift amplification。

Core Insight

忘记不是“把原 continuation 删掉”这么简单，而是一个 conditional trajectory replacement 问题。若目标轨迹未被指定，语言模型仍必须在每个位置归一化出下一个 token，于是被压掉的概率会流向别的 token；这解释了为什么 suppression 很容易变成 hallucination。GUARD 因此把 safe exit 当成一个需要被显式学习的 attractor，而不是副作用。

Method Deep Dive

Pipeline：Forget query → base LRM 生成原始泄漏 trajectory → frontier LLM 离线改写成 natural-forgetting trajectory → 冻结 base model，仅优化 continuous guidance tokens（GTA）→ 得到稳定 guided teacher → 用 LoRA 做 Answer-Reasoning Distillation（ARD）→ 部署时不再需要 guidance token。

第一阶段保留原模型的 reasoning cadence，只把敏感语义改成“自然转向不确定/拒答”的轨迹。第二阶段 GTA 不直接改参数，而是把 guidance sequence 当作一个低风险搜索变量，寻找能让 forget 轨迹进入 safe-exit basin、同时 retain 轨迹保持原行为的 teacher。第三阶段再把这个 teacher 的分布蒸馏进 LoRA，因此最终模型没有 runtime prompt 依赖。

关键公式与直觉

L_GTA = L_fg + λ_rt L_rt

L_fg 对 reasoning block 与 answer-side block 各占 1/2，避免长 CoT token 数量压过真正关键的拒答边界与答案；L_rt 用 Top-K forward KL，让 guided model 在 retain token 的高概率候选上接近 base model。这里 KL 的直觉是“忘记时允许改，但在 retain 上不要把原分布推乱”。Top-K=1000 过滤低概率尾部噪声。ARD 再最小化 guided teacher 与 deployable model 的 Top-K KL。

Toy Example

假设问题要求回忆某虚构作者的私人地址。GA 可能把“上海”压低后改答“北京”；PO 可能 CoT 先推理出地址，最后说“抱歉不能回答”；representation redirection 可能出现重复句。GUARD 目标则是：CoT 先识别“该问题涉及受保护私人信息→不应继续检索具体地址→转向说明限制”，随后正常闭合 </think>，答案稳定拒答。关键是“安全轨迹”本身被监督。

Baseline Deep Comparison

GA/GD/KL：强在简单直接，但只约束概率，不约束替代轨迹；PO：能学拒答 answer，却可能让 CoT 与 answer 脱节；R²MU：更直接干预 reasoning representation，但可能过度扰动 decoder。GUARD 相比 strongest reasoning baseline R²MU 的机制差异不是多一个 regularizer，而是把 destructive disruption 改成 constructive trajectory specification。

Experiment Setup & Research Questions

模型是 DeepSeek-R1-Distill-LLaMA-8B 与 14B。隐私 forgetting 用 R-TOFU 1%/5%/10%；安全 forgetting 从 STAR-1 setting 产生 230 条 unsafe reasoning traces，并用 Llama-Guard-3-8B 过滤；SQuAD 作 retain anchor；MMLU 测 general utility，MATH500/BBH/GPQA 测 reasoning preservation。RQ1：是否比 GA/PO/R²MU 更少泄漏？RQ2：是否避免“忘掉但生成坏掉”？RQ3：是否保持通用 reasoning？RQ4：guidance length、retain weight、checkpoint 如何影响 forget-retain equilibrium？

Results / Figures / Ablation

Figure 1–2 是最有价值的诊断：GA 的敏感 token 概率下降后，alternative token mass 在 CoT 与 answer 附近上升；PO 的 CoT refusal-match 与 answer refusal-match 不形成理想对角相关；R²MU 的 distributional drift 会从 intervention layer 向 late-CoT、boundary、answer 扩散。这三组现象直接支持“under-specified replacement”而非单纯“forget strength 不够”。Figure 3 展示 GTA→ARD 的完整 pipeline；Figure 4 则把 epoch、guidance-token length、λ_rt 对 forget-retain 平衡的影响显式化。论文报告 GUARD 在 R-TOFU 与 STAR-1-derived setting 上同时降低 privacy/unsafe disclosure，并保持更好的 NFRS 与 reasoning utility；这里最重要的不是某一个百分点，而是 leakage metric 与 generation-quality metric 同时改善。

Strongest result：方法在两类 forgetting 场景都能避免“安全答案 + 泄漏 CoT”的分裂行为。Weakest / 未完全证明：当前主要是 8B/14B distilled LRMs，safe trajectory 由外部 frontier LLM 重写，尚不能证明对更大 closed LRM、adaptive extraction、relearning attack 仍稳健；NFRS 本身也依赖评估协议，仍需与人工标注、攻击恢复率交叉验证。

Claim vs Evidence

Claim：自然 forgetting trajectory 比 destructive suppression 更适合 LRM unlearning。Evidence：failure diagnostics + 双场景实验 + reasoning utility + NFRS 支持该结论。Not proven：没有证明参数中的原知识被“物理删除”；也没有覆盖强 relearning、quantization、probe、black-box adaptive attack，因此更准确说是更自然、更完整的 behavioral/trajectory unlearning。

Contribution

① New Mechanism：trajectory substitution + guided teacher + distillation；② New Objective：reasoning/answer block-balanced forgetting + retain Top-K KL；③ New Metric/Protocol：NFRS 衡量结构稳定、流畅与 unsupported substitute；④ New Empirical Finding：GA/PO/R²MU 的失败可分别由 probability redistribution、trajectory mismatch、drift amplification解释。

Limitation & Failure Modes

依赖外部 rewriter；对“拒答式忘记”较自然，但对必须给出替代合法事实的 editing/unlearning 边界还不清楚；未验证 multimodal reasoning leakage；没有把 recovery/relearning、MIA、activation steering extraction 纳入主评测；对 safe-exit trajectory 的风格依赖可能产生可检测的 unlearning signature。

Research Value & Migration

Original Problem LRM reasoning leakage → Transferable Mechanism 显式替代轨迹 + block-balanced distillation → New RQ MLLM unlearning 是否也需要“visual evidence → multimodal reasoning → answer”的完整 safe-exit trajectory？→ Modification 在 image-text forget 样本上同时约束 visual-token attribution 与 reasoning/answer trajectory → Minimum Experiment：LLaVA/Qwen-VL，MLLMU forget5/10/15；比较 GA/NPO/PO/R²MU/现有 multimodal baseline；新增 image-rephrase、FigStep、relearning、quantization；Metric 用 forget/retain + NFRS-like multimodal trajectory quality + MIA AUC → Expected Contribution：Multimodal Natural Forgetting Trajectory → Risk：外部 rewriter 可能泄漏 target；Collision Risk：中等，需强调 cross-modal trajectory 与 robustness，而非仅复制 GUARD。

只记住 5 句话

  1. LRM unlearning 必须管 CoT，不只是 final answer。
  2. 压掉敏感 token 不等于教会模型“忘了之后怎么继续”。
  3. GUARD 把 forgetting 改写为 safe trajectory substitution。
  4. NFRS 补的是 replacement quality，而不是又一个 leakage score。
  5. 最值得迁移到 MLLM 的是“完整生成轨迹 + robustness”而非 guidance token 本身。
Tier S · BACKFILL Robust LLM Unlearning Against Relearning Attacks: The Minor Components in Representations Matter

Zeguan Xiao et al. · 2026-05-12 · arXiv cs.CL · Paper

人话版

很多 unlearning 方法第一次测看起来忘得很好，但稍微用 forget 数据重新 fine-tune，知识就迅速回来。MCU 问的是：为什么？作者从 representation spectrum 入手，发现常规 unlearning 主要改 dominant components，而 minor components 基本保留；relearning 时 dominant 方向又容易被拉回，所以知识“复活”。相反，minor components 对逆转更抗，因此 MCU 故意把 unlearning 作用集中到这些低能量方向，以提高 relearning resistance。

Background & Gap / Core Insight

传统 robustness 常看参数距离或 sharpness，但“离原模型远”不保证忘得稳：随机破坏也能很远。MCU 的 insight 是更新方向的几何结构更重要。把 representation 做 spectral decomposition 后，dominant component 承载大方差、任务主方向，优化器最容易重新利用；minor component 虽能量小，却可成为更难被短程 relearning 逆转的删除载体。

Method Deep Dive

Input forget/retain representations → 分解主/次成分 → 选择 minor subspace → 把 forget update 投影/集中到该子空间，同时约束 retain utility → 得到 MCU model → 用 relearning attack 验证恢复速度。关键数学对象是 representation covariance 的 eigen/singular directions。若 H=UΣVᵀ，大 singular value 对应 dominant directions，小 singular value 对应 minor directions；MCU 的目标是让“删除痕迹”落在后者，而不是只沿最大梯度/最大方差方向。

Toy Example

把表示想成二维：x 轴是模型最常用的通用语义方向，y 轴是弱但稳定的细节方向。常规 unlearning 把 x 改很多；relearning 只需几步就把 x 拉回。MCU 则把删除约束编码到 y，攻击者只按常规 loss 更新时不容易精确恢复 y 上的结构。

Baseline & Experiments

论文在三个数据集上比较常规 unlearning 与包括 sharpness-aware 思路在内的强 baseline，核心 RQ 是：minor component 是否真的更难逆转、MCU 是否在相似 retain utility 下延缓恢复、这种现象是否跨数据集成立。作者报告 MCU 对 relearning attack 的抵抗显著优于 SOTA，包括 sharpness-aware baseline。最关键的图应读“不同 representation component 的改变量/恢复量”与“relearning steps–forget performance 曲线”，因为它们分别验证机制与最终 robustness。

Ablation / Claim vs Evidence

真正有说服力的不是 MCU 最终分数，而是 dominant/minor component 在 unlearning 与 relearning 两阶段呈现相反可逆性。它支持“minor directions matter”。但尚不能推出 minor subspace 对所有攻击都稳健：adaptive attacker 若显式估计该 subspace、用 layer-wise probe 或低秩恢复，可能绕过优势。

Contribution

① New Empirical Finding：dominant updates 易被 relearn，minor updates 更抗逆；② New Mechanism：Minor Component Unlearning；③ New Robustness View：从 update structure 而非 global distance 解释 relearning。

Limitation

relearning threat model 仍是有限攻击族；representation decomposition 有额外成本；minor direction 可能与 rare retain knowledge 重叠；尚未直接覆盖 MLLM 的 vision/projector/LLM 三模块以及 cross-modal leakage。

Migration Analysis

Original LLM relearning robustness → Transfer minor spectral subspace → New RQ MLLM 的 robust forgetting 是否应分别在 vision/connector/LLM 的 minor subspace 编码？→ Minimum Experiment：对 LLaVA LoRA 的 vision/projector/LLM hidden states 分层 SVD，做 dominant-only vs minor-only unlearning；随后统一 relearning、quantization、linear probe；Dataset=MLLMU forget5/10/15；Baseline=GA/NPO/PO + module-wise LoRA；Metric=forget/retain + relearning recovery area + probe AUC → Expected 找到 cross-modal robust deletion 的 module×spectrum map → Risk minor subspace 噪声大；Collision 中高，必须加入 multimodal/module-level 新问题。

只记住 5 句话

  1. “忘了”要看能不能被快速学回来。
  2. global weight distance 不是 robustness。
  3. dominant representation update 容易被 relearning 逆转。
  4. minor components 可能是更耐恢复的删除载体。
  5. 对 MLLM 最有价值的是 module×spectral robustness 分解。
Tier A · BACKFILL Agent Zero Memory: Provenance-Aware Long-Term Memory for LLM Agents

Ming Wu, Pengyuan Zhu · 2026-08-30 · arXiv cs.CL · Paper

人话版

它不是 unlearning 论文，但对 Agent Unlearning 很关键：作者把长期记忆拆成三套并行系统——事件时间线、实体-事件图、带引用锁的层级文档记忆。每个 memory item 都带 origin、timestamp、evidence pointer；回答只能引用 reader 真正打开过的证据。LongMemEval 达 95.60%，LoCoMo 93.60%，分别比 strongest prior +0.73/+1.10；8 个 backbone 的准确率只差 3.4 点，但单 query 成本可差约 30×。

Gap & Method

单一 vector store 会把“何时变化”“实体关系”“长期稳定事实”混在一起。Agent Zero Memory 通过 Intent Gate → Source Router → 三路并发 agentic search → cited integration。对 unlearning 最关键的是 provenance：删除请求不再只是删文本，而可以沿 evidence pointer / event graph 找派生记忆。

Experiment / Results

两个公开长期记忆 benchmark 的 SOTA 数字说明系统结构而非单纯更大 backbone 能显著提升 memory QA。更值得注意的是成本实验：backbone 变化导致成本约 30×，准确率只 3.4 点，说明 memory substrate 本身贡献很大。

Contribution / Limitation

New System/Engineering + New provenance discipline。限制是它主要优化“记得准”，没有系统测试删除闭包、poisoning、revocation 或 cross-agent propagation；三存储也意味着删除时要做多副本一致性。

Research Value / Migration

Minimum Experiment：在 LoCoMo/LongMemEval 上人工注入 50 个需删除事实，构造其 summary、graph edge、derived preference 三类派生物；比较 naive delete、source-delete、lineage-closure delete。Metric：direct recovery、paraphrase recovery、derived-action recovery、utility、deletion latency。若 lineage closure 显著降低 derived recovery，可形成 Agent Memory Unlearning benchmark/protocol。

Worth Deep Reading: YES — provenance schema 是后续 deletion closure 的直接基础。

Tier A · BACKFILL Poison Once, Exploit Forever: Environment-Injected Memory Poisoning Attacks on Web Agents

Wei Zou et al. · 2026-04-03 · arXiv cs.CR · Paper

人话版

eTAMP 证明攻击者甚至不需要直接写 agent memory：只要让 web agent 看一次被操纵页面，污染观察就可能被存成 trajectory memory，之后在别的网站、别的 session 被重新触发。VisualWebArena 上 ASR 最高达到 GPT-5-mini 32.5%、GPT-5.2 23.4%、GPT-OSS-120B 19.5%；当 agent 遇到掉点击、乱码等“挫折”时，ASR 可上升最多 8×。

Method / Experiment

攻击链是 environment observation → trajectory storage → future retrieval → malicious instruction reactivation。研究问题不是“prompt injection 能否当场成功”，而是一次污染能否形成跨 session 持久后门。它用不同模型与 web 场景验证，并额外加入 environmental stress，发现性能更强的模型并不自动更安全。

Contribution

New Attack：environment-injected persistent memory poisoning；New Empirical Finding：frustration exploitation；New Threat Model：跨 site/session、无需 direct memory access。

Limitation / Research Value

主要集中 web agent，且攻击触发依赖 memory policy。对 Agent Unlearning 的价值非常高：删除机制必须证明能清掉 poisoned observation 的所有 summary/skill/plan derivatives，而不只是原始 memory row。

Migration / Minimum Experiment

做“Poison-Unlearn-Reattack”：先 eTAMP 污染→执行 selective memory unlearning→跨站重新触发。Baseline：exact delete / semantic delete / lineage delete；Metric：post-delete ASR、benign utility、derived-memory residual、reacquisition rate。Worth Deep Reading: YES。

Tier A · BACKFILL Robust Continual Unlearning against Knowledge Erosion and Forgetting Reversal (SAFER)

Eun-Ju Park, Youjin Shin, Simon S. Woo · 2026-04-21 · Paper mirror

人话版

现实删除请求不是一次性的。SAFER 观察到连续做 unlearning 会出现两个相反问题：retain accuracy 一轮轮掉（Knowledge Erosion），而以前已经忘掉的样本又在后续轮次被认出来（Forgetting Reversal）。它用 retain representation stability + forget negative-logit margin 同时控制两端。

Method / Results

直觉上，retain stability 负责“不越删越坏”，negative margin 负责让旧 forget target 维持在决策边界外。论文的价值主要在问题定义：continual unlearning 不能只汇报最后一轮平均 forgetting，而要同时画 forward forgetting、backward reversal、retain erosion 随 phase 的曲线。

Contribution / Limitation

New Empirical Finding：erosion + reversal；New Mechanism：SAFER regularization。限制是该方向仍需在 LLM/MLLM、LoRA、reasoning trace 与 repeated deletion overlap 上验证。

Migration

MLLMU 可直接做 sequential forget 5→10→15 或按 identity/semantic cluster 分批删除，测每轮旧 forget 的 rebound、retain-shared/celebrity erosion、relearning robustness。Worth Deep Reading: YES，因为它可直接变成 continual MLLM unlearning protocol。

Tier B · BACKFILL Unlearning What Matters: Token-Level Attribution for Precise Language Model Unlearning

人话版：sequence-level unlearning 把一句话所有 token 一视同仁，但真正承载 target knowledge 的通常只是少数 token。TokenUnlearn 用 knowledge-aware masking + entropy-aware signal 得到 token importance，再做 hard selection 或 soft weighting。

Core Method：先估每个 token 对目标知识的重要性，再把 GA/NPO 等 unlearning gradient 只施加在关键 token，减少无关梯度噪声。Main Finding：论文报告 token-level 版本能改善 forget-retain trade-off；机制上最值得关注的是 attribution 是否真的对应 causal knowledge carrier，而非只是高 entropy token。

Contribution：New Mechanism（token attribution → selective unlearning）。Limitation：importance estimator 可能被 paraphrase / reasoning path 改写绕过。Connection：与 visual-guided key-token、MLLM token attribution 高度相容。Potential Use：Baseline + Future Idea。Paper

Tier B · BACKFILL Divergence Decoding: Inference-Time Unlearning via Auxiliary Models

人话版：不改 base checkpoint，而是在 decoding 时用小辅助模型把 logits 从待忘知识方向推开；之后如果需要，也可把这个 steered distribution 蒸馏回 base。

Core Method：base logits + auxiliary divergence signal → inference-time reweight/steer → forgotten output distribution。它把 unlearning 从 training-time parameter surgery 转成 runtime control。Main Finding：作者报告在多种 model/data scale 上优于 SOTA，并强调成本低。

Contribution：New Mechanism（inference-time unlearning）。Limitation：若攻击者绕过 decoder/controller 或拿到 raw weights，删除并不成立；因此更适合 API/service threat model。Connection：可与 KV-cache steering、activation steering、black-box API unlearning 对照。Potential Use：Baseline/Future Idea。Paper mirror

Tier B · BACKFILL CBD: API-Only LLM Black-Box Unlearning through Controlled Behavioral Divergence

人话版：如果模型只有 API，参数和 logits 都拿不到，怎么 unlearn？CBD 用两个辅助模型估计输入与 forget target 的相关性，然后把疑似需要 unlearn 的请求从 target LLM 路由走，实现 black-box behavioral unlearning。

Core Method：auxiliary divergence → unlearning relevance score → routing。Main Finding：价值在 threat model：把 black-box unlearning 明确成服务层行为控制，而不是假装改了不可访问参数。

Contribution：New Mechanism / System。Limitation：这是 routing-based suppression，不等价于模型内部删除；adaptive paraphrase 可攻击 relevance detector。Connection：非常适合作为“API-only unlearning” baseline，与真正 parametric unlearning 区分。Potential Use：Baseline/Evaluation。Paper page

Tier B · BACKFILL Memory Provenance Laundering in LLM Agents: A Non-Amplification Firewall for Persistent Memory

人话版：危险不只是“恶意 memory 被存下来”，而是它在 summary/consolidation 后可能看起来像用户自己说过的话，原始低信任来源被洗掉。PPMF 强制 provenance 与 action authority 不得在记忆加工中凭空升级。

Core Method：platform-maintained provenance + risk label + action gate；高风险 tool call 必须有足够 authority 的 action-relevant memory 支撑。Main Finding：文中 schema-grounded evaluation 中 vulnerable consolidated memory 的 ASR 可到 1.000；保留 provenance、confirmation 与 risk labels 后，评测中的未授权高风险 action 无一通过，同时目标低风险 memory use 仍可执行。

Contribution：New Security Mechanism / provenance non-amplification。Limitation：依赖平台可信 provenance 与固定 risk policy。Connection：Agent Unlearning 可把“删除”定义为撤销 source authority 并沿 derivation closure 传播，而不是文本 erase。Potential Use：Attack/Evaluation/Future Idea。Paper

9. Idea Mining

Idea 1 — Provenance-Closed Agent Unlearning (PCAU)

Inspiration：Agent Zero Memory + MemLineage/PPMF + eTAMP。Gap：现有 agent memory 论文重“记忆正确/防毒”，unlearning 论文重“删目标内容”，但缺少对 derived summary、plan、skill、tool-history、cross-agent copy 的删除闭包定义。Hypothesis：如果每个 memory/plan/skill 都维护 source→derivation DAG，那么 unlearning 可被定义为对 target source 的 transitive influence closure 做 revoke/recompute，而不是语义搜索删除。

Proposed Method：为每次 memory write 记录 provenance edges 与 influence weight；删除请求触发 backward source match + forward closure traversal；对高 influence descendants 删除，对混合来源节点做 re-summarize/recompute；tool policy 在 closure 完成前阻断依赖被撤销源的 action。

MVE：LoCoMo/LongMemEval + WebArena 小规模 100 条任务；注入 30 个可追踪事实并让 agent 产生 summary/plan/skill；比较 exact delete、embedding delete、lineage closure。Model：Qwen3-8B / GPT-class API agent。Metric：direct recovery、derived recovery、action recovery、utility、closure precision/recall、deletion latency、reacquisition。Expected Contribution：Agent Unlearning 的 deletion-closure 定义 + benchmark + baseline。Novelty：★★★★★ Feasibility：★★★★☆ Compute：★★☆☆☆ Risk：lineage attribution 不准。Collision：中；与 provenance security 重合，但“deletion closure + recomputation + unlearning metrics”仍有明显空位。Best Venue：NeurIPS/ICLR/ACL。

Idea 2 — Multimodal Natural Forgetting Trajectory (M-NFT)

Inspiration：GUARD + MLLM unlearning。Gap：现有 multimodal unlearning 多测 answer-level forget/retain，却很少验证 visual evidence 是否仍能在 hidden reasoning 或 image rephrase 后泄漏。Hypothesis：对 image→reasoning→answer 的完整轨迹做 safe-exit distillation，比仅在 LLM token loss 上做 GA/NPO 更能减少 cross-modal leakage。

Method：用 visual attribution 找 forget-relevant patches/tokens；构造不泄漏视觉身份的 safe reasoning trajectory；对 reasoning/answer 分块 CE + retain Top-K KL；再加入 visual-token consistency penalty。MVE：LLaVA-7B，MLLMU forget5/10/15，1000 GQA/VQAv2 general；Baseline GA/NPO/PO/MIP-Editor/VG key-token；Metric forget/retain、image rephrase、FigStep/jailbreak、relearning、MIA、trajectory-quality。Expected：第一套 multimodal trajectory unlearning + reasoning leakage protocol。Novelty：★★★★☆ Feasibility：★★★★★ Compute：★★★☆☆ Risk：可能被认为是 GUARD 直接迁移。Collision：中高，必须用 cross-modal leakage 和 attack suite 做出机制差异。Best Venue：CVPR/NeurIPS。

Idea 3 — Spectral Module Routing for Robust MLLM Unlearning

Inspiration：MCU + module-wise LoRA unlearning。Gap：没人系统回答 robust deletion 应该写进 vision tower、connector 还是 LLM，以及每个模块的 dominant/minor subspace 对 relearning/quantization/probe 哪个最稳。

Method：对三模块 hidden/update 做 SVD，构造 module×spectrum grid；以 robustness harmonic mean 选择最小干预组合。MVE：同一 forget split 跑 3 modules × dominant/minor × 2 methods；攻击只需 relearning + quantization + layer probe。Metric：forget、retain、recovery AUC、quantized recovery、probe AUC、update norm。Expected：“where to forget”与“which spectral direction to write deletion”统一。Novelty：★★★★★ Feasibility：★★★★☆ Compute：★★★★☆ Risk：SVD 代价与 layer choice。Collision：中。Best Venue：NeurIPS/ICLR。

10. Collision Detection

⚠️ Collision Warning: YES

Token-level Unlearning：TokenUnlearn（2605.00364）与 ATWU（2606.06320）已经把“token importance × unlearning”做得很直接，因此若新工作只是“给 token 加权再做 GA/NPO”，撞题风险 高。剩余 gap 应转向 multimodal token provenance、reasoning-token leakage、attack-aware attribution 或 learned causal attribution。

Inference-time Unlearning：Divergence Decoding 与 CBD 已覆盖 auxiliary-model steering / API-only routing；仅做 decoding steering 撞题 中高。更值得做的是可验证的 deletion guarantee、KV-cache/hidden-state attack robustness，或“inference-time controller → distillation → parametric closure”的完整链。

Continual Unlearning：SAFER 与 Plasticity Collapse 已明确 repeated deletion 的 erosion、reversal、forward/backward failure。新工作必须至少进入 LLM/MLLM、overlapping deletion、reacquisition 或 adaptive sequence，而不能只在图像分类重复 continual setting。

Agent Memory / Provenance：Agent Zero Memory、MemLineage、TMA-NM、PPMF、EAL-Bench 已快速占据 provenance/authority 方向。仍值得继续，但差异化应是 unlearning-specific deletion closure：撤销源后，所有 summary/plan/skill/tool action/cross-agent copies 是否同步失效，以及如何最小化 utility collateral damage。
