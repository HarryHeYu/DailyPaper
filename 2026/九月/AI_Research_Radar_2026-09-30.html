Executive Summary

今日最强信号是 memory validity、provenance 与 trajectory credit 三条机制线正在汇合。最新 TRACE 把多 Agent 记忆从“检索是否相关”推进到“信息现在是否仍有资格驱动行动”；MemAgent 把 heterogeneous memory 显式变成 provider routing；ProvenanceGuard 则把 tool action 约束成可追踪 evidence support。三者组合后，非常接近 Agent Unlearning 所需的 deletion-closure 骨架。

Unlearning 侧，VLM robustness 与 SMU 共同说明 clean forgetting 不等于 deletion：文本 backbone 忘掉后可被图像重新激活，默认 prompt 忘掉后也可能被 contextual prompting 或 downstream retraining 恢复。今天最值得投入的新实验是 cross-modal / cross-agent / relearning / action-level reacquisition 的统一 closure test。

Tier S

Tier S · TRACE: Governing Memory Validity in Evolving Multi-Agent Systems

Wenjun Xiong et al. · arXiv:2609.33517 · 2026-09-27 · 41 pages incl. appendix · code linked by arXiv

人话版：这篇论文到底干了什么？

一名 Agent 离线后重新加入时，它记得的东西可能完全真实，却已经不再允许拿来行动：离开前团队订酒店 A，缺席期间队友已改成 B。TRACE 不简单 Restore，也不 Reset，而是把 departure checkpoint 与 absence-period updates 做 reconciliation，处理显式/隐式 invalidation，只释放覆盖返回角色未完成义务的 bounded Return View。它实际上把 memory validity 变成 read→act 边界的 eligibility decision。

Background & Gap

传统 Agent Memory 优化写入、压缩、检索和总结，通常默认“相关且可信 ⇒ 可使用”。多 Agent 世界状态持续演化，这个假设不成立。Restore 连续性好却接纳 stale state；Reset 安全却丢失仍有效知识。论文要求同时最大化 valid-information availability 与 invalid-information rejection。

Core Insight / Method Deep Dive

Departure checkpoint → absence update log → explicit/implicit invalidation → obligation coverage → bounded Return View → resumed action。Validity 不是 memory item 的静态属性，而是相对当前共享状态、时间、角色义务与更新链的动态资格。对 unlearning，可把 forget target 及其受污染后继视作 revoked nodes，在 retrieval/action 前统一 admission。

关键机制与 Toy Example

可把返回视图理解为集合选择：从候选 M 选 R，使有效信息覆盖最大、无效信息泄漏最小，同时满足 role obligations。例：A 离开前记得“周五交付、tool v1、用户偏好 PDF”；期间前两项改为周一/v2。Restore 三项全带回，Reset 全丢；TRACE 应拒绝前两项旧值、保留 PDF 偏好并补入新值。

Baseline Deep Comparison

Restore 在 stale rejection 上结构性失败；Reset 在 valid availability 上结构性失败；write-time consolidation 更早维护一致状态，准确率可更高，但作者报告 token 约为 TRACE 的 3.99×。TRACE 的价值是双目标与成本折中，而不是单项 accuracy 冠军。

Experiment Setup

Memora、STALE Type II、派生 ManBench-Return 均被重构为 return episodes：1 个 Agent 离开，4 个 teammates 更新共享状态，随后返回；覆盖三类 actor models。RQ：能否同时 retain valid / reject stale？能否跨模型？与 write-time consolidation 的成本差多少？

Results Deep Dive

ManBench-Return 上 valid availability 92.6–98.3%，invalid rejection 98.4–99.5%；Restore/Reset 各自在两项之一降到 0%。TRACE overall accuracy 距最佳 baseline 不超过 3.8 points。STALE Type II 相对 strongest comparison policy，Overall 提升 22.3 (Qwen)、18.5 (Gemini)、27.5 (DeepSeek) points。代价是约 2.3× tokens；write-time consolidation 更准确但约需 TRACE 3.99× tokens。

Table/Figure & Ablation Reading

第一优先看 return-policy 主表的 valid/reject 两列，而非只看 Overall；第二看 STALE Type II 三 backbone；第三看 token-cost；第四看 re-entry pipeline。机制证据来自 Restore/Reset 两个极端都无法满足双目标。未来最应补 explicit invalidation、implicit invalidation、obligation coverage、bounded view 的逐模块 ablation。

Claim vs Evidence

Claim：temporal admission 是独立 lifecycle 问题。Evidence：三数据设置、三 actor models、双指标一致支持。未证明：它不等于参数级 machine unlearning，也未证明攻击者不能从其他 Agent、tool log、cache、derived summary 恢复信息。

Contribution / Limitation

New Problem/Formalization：temporal memory admission；New Mechanism：re-entry reconciliation + bounded Return View；New Protocol：return episodes；Empirical Finding：Restore/Reset 双双结构性失败。局限包括 token overhead、update log 不完整、implicit invalidation 漏检、prompt injection 绕过 admission、跨 Agent 派生污染未闭合。

Migration Analysis

Original Problem：returning agent stale memory → Transferable Mechanism：lineage-aware admission → New RQ：删除后跨 Agent 所有可执行后继是否闭合？→ Modification：memory/trajectory/skill/tool-call 建 provenance DAG，forget node revoked 并传播 taint → MVE：5-Agent task，让目标事实传播到 2 memories + 1 summary + 1 skill 后删除，再做 role-return/tool-replay/paraphrase 攻击 → Model：Qwen/DeepSeek → Dataset：ManBench-Return + deletion episodes → Baseline：physical delete / filter / reset / TRACE-only → Metric：direct/derived/action leakage、reacquisition AUC、utility、closure latency → Expected：从删记录升级为删影响路径 → Risk：provenance 不完备 → Collision Risk：高，但 explicit unlearning + adaptive recovery 仍为空白。

只记住 5 句

  1. 真实且相关不代表现在还能行动。
  2. Agent unlearning 可能更需要 admission + lineage。
  3. TRACE 同时做到约 93–98% valid availability 与 98–99.5% stale rejection。
  4. 成本约 2.3× strongest comparison tokens。
  5. 最值得抢的是跨 memory/trajectory/skill/tool 的 deletion closure。
Tier S · MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement

Xiaomi LLM-Core · submitted 2026-09-21 · omni-modal Agent RL

人话版

MiMo-V2.6 的关键不是“更大 RL”，而是长轨迹 Agent RL 的反馈质量。GAR 把同一任务的 16 条 sibling trajectories 放一起比较，把正 advantage 从“虽然 pass 但冗长/投机”的轨迹重新分给更干净的成功轨迹，confirmed reward hack 直接归零。对 unlearning，完全可以把“忘得干净、retain 好、抗恢复、无泄漏”变成组内相对 credit。

Gap / Insight / Method

binary verifier 无法区分两个都 pass 的 trajectory。流程：prompt → 16 rollouts → verifier → groupwise grader → hack filter → advantage redistribution → policy update。每 step 1,568 prompts、2.7–3.7B tokens，最长 1M context；异步调度维持 heterogeneous task mix，trajectory 放 distributed cache。

关键公式直觉 / Toy Example

普通 terminal reward r∈{0,1}；GAR 进一步学习组内质量 q_i 并重分配正 advantage。迁移到 unlearning 可令 q_i = w_f Forget + w_u Utility + w_r Robustness − w_l Leakage − w_c Cost。同一删除请求若 8 个候选 clean forget，但其中 3 个 utility collapse、2 个 paraphrase 恢复、1 个只会拒答，则 advantage 应集中给真正稳定的 2 个。

Experiment / Results

DeepSWE v1.1（113 长程 repo tasks）Pro average@3 58.4→72.6，Flash 48.7→65.7。GAR controlled ablation：无 GAR 时 turns/token length 快涨且 pass-rate plateau；有 GAR 时 improvement 持续到 step 52。grader 占 Pro RL 总成本约 12.7%。trainable router 的 expert-load CV 0.78→2.0、peak load 6×→16×、cold experts 0.5%→22%；router reset 后负载立即恢复且 benchmark 不变。released 9B recipe 中 SWE-bench Verified 61.1→66.2，cyber internal mini 31.3→47.0。

Table/Figure / Ablation

最关键是 GAR 的 pass-rate/turns/token-length 三联图，它是最干净的机制证据；第二是 router load 三联图；跨域 training curves 只能说明训练期持续提升，不是 no-RL controlled comparison。router reset 把 collapse 定位到 routing drift，而非 expert weights。

Claim vs Evidence / Contribution / Limitation

New Mechanism：GAR；New Infrastructure：mixed-task async RL / unified trajectory representation；Finding：binary pass reward 会诱导轨迹膨胀，router drift 会造成 MoE load collapse。局限：计算昂贵、grader 可能固化偏好、多个 headline benchmark internal、token use 总体仍增长。

Migration

每个 forget target 采样 8–16 个 LoRA update candidates，grader 同时读 Forget/Retain/Relearning/Quantization/Probe/MIA，再做 groupwise advantage。MVE：Qwen/LLaVA + TOFU/MLLMU，GA/NPO/PO/RMU 为候选或 baseline；比较 harmonic scalar reward 与 GAR。目标是 RL credit assignment × robust unlearning。

只记住 5 句

  1. Agent RL scale 的瓶颈越来越像 feedback quality。
  2. GAR 用 sibling trajectories 做局部对照。
  3. 无 GAR 时长度膨胀且收益停滞。
  4. MoE router drift 是真实 scale failure。
  5. Unlearning reward 必须包含 recovery 与 utility，而非只奖励拒答。
Tier S · On the Robustness of Machine Unlearning for Vision-Language Models

Yujie Lin et al. · 2026-05-26 · BACKFILL · code available

人话版

这项工作把 VLM unlearning 从“正常问法下忘没忘”推进到“攻击者能不能重新叫醒知识”。它提出三类攻击，覆盖 contextual prompting 与 downstream retraining 等恢复路径。核心结论是很多方法更像隐藏默认访问路径，而非彻底移除目标知识。

Background / Core Insight / Method

VLM 的目标可同时存在于 language backbone、vision tower、connector 与跨模态交互。标准 forget QA 只观察一个输入分布。论文流程是 unlearned VLM → multiple prompt settings → contextual reactivation → downstream retraining/relearning → recovery measurement，把 robustness 加成 forget-retain 之外的第三轴。

Experiment / Results / Figure Reading

统一多个 VLM unlearning 方法和 prompt settings，以三类 attack paradigms 检验 forgotten multimodal knowledge 是否能被 context 或 downstream retraining 恢复。作者明确报告 many existing methods remain vulnerable。阅读优先级：方法×攻击矩阵、clean vs attacked forget、retraining recovery curve、retain utility。本轮可验证网页没有稳定暴露完整逐 cell 数字，因此不虚构。

Ablation / Claim vs Evidence

应关注 attack strength、context change 与 retraining budget；若极小 budget 即恢复，说明 knowledge basin 很浅。Claim：clean forgetting 不代表 robust deletion。Evidence：统一 prompt settings + 三 reactivation paradigms。未证明：攻击仍未覆盖全部 adaptive black-box strategies，“没恢复”也不是信息论删除证明。

Contribution / Limitation / Migration

New Evaluation/Attack：VLM robustness suite；Finding：clean forget 可被 contextual/retraining attack 逆转。新工作要超越它，应做 module-specific recovery topology：LLaVA 的 llm/vision/connector/all 分别 unlearn，再做 image rephrase、text paraphrase、relearn、quantization、layer probe，指标用 recovery AUC、utility、MIA、TR/KS/JS、GradNorm。Collision 高，不能只再做三攻击复现。

只记住 5 句

  1. clean forget ≠ robust deletion。
  2. VLM 有 cross-modal bypass。
  3. relearning 是强残留知识探针。
  4. 评价至少是 forgetting × utility × robustness。
  5. 新贡献应推进到 adaptive/module-level/closure。

Tier A

MemAgent: Learning to Manage Heterogeneous Memory Providers for LLM Agents

人话版：先评 13 种 memory methods，发现没有一种跨 GAIA、WebWalkerQA、xBench-DS 通吃，于是把 memory 使用改成 routing：执行前 probe、运行中 STM gate、结束后 selective multi-provider write。

Method：task → content-aware probe → provider routing → STM gate → execution → selective storage。这使 trajectory/reflection/skill/structured knowledge 都成为显式 provider，也天然形成 information-flow graph。

Results：平均 accuracy +10.0%，三 benchmark 都优于任一单 provider；routing overhead <0.3%，平均 task steps -12%。最值得看 13-method cross-benchmark 表与最终 overhead/steps 列。

Contribution：New Mechanism — heterogeneous memory routing；New Finding — no universal provider。Limitation：provider set/supervision 预定义，无 deletion semantics。

Migration：做 revocation-aware router：provider 返回 provenance/taint，删除请求广播 tombstone。MVE：让事实跨 trajectory→reflection→skill 传播，删除后测 cross-provider reacquisition。Worth Deep Reading: YES。

Stochastic Meta-Unlearning: Bridging Language Backbone and Multimodal Unlearning

人话版：语言 backbone 单独已经忘掉的 target，重新接回 VLM 并给图像后还能恢复。SMU 因此用 bilevel：inner 只在 language backbone 上 text-unlearn，outer 把它接回 frozen VLM，用最终 multimodal forget/utility 反馈学习更好的初始化。

Method：θ → inner text-unlearning → recompose VLM → multimodal evaluation → outer meta-gradient。目标不是让 θ 立即忘，而是让它经少量更新后完整 VLM 也可靠忘。

Results：2 VLM、2 multimodal meme datasets、3 baselines；相对各 metric strongest baseline，平均 Forget accuracy -10.52 points，Retain +20.10，Test +17.01 points，并能 transfer 到新 target 与不同 meta-test unlearning method。

Contribution：New Mechanism — VLM-feedback bilevel meta-unlearning；New Finding — image 可恢复 language-forgotten target。Limitation：更新仍局限 language backbone，vision/connector 残留是攻击面。

Migration：inner-update LLM/vision/connector/all，outer objective 加 TR + utility + recovery；再加 image rephrase/relearning/probe。Worth Deep Reading: YES。

ScopeEdit: Multimodal Knowledge Edit-Scoped Generalization for Online Recursive MLLM Editing

人话版：研究“编辑应该传播到哪里、又不该传播到哪里”。instance edit 成功既不保证 cross-modal generalization，也不保证 locality，因此用 modality-local absorption + evidence-gated shared generalization 双 branch，并在正交低秩空间写入。

Method：edit → local branch + evidence gate → shared branch → orthogonal low-rank writes → Sherman–Morrison preconditioner。pilot 还观察到 cross-modal edit responses 集中于更深 semantic layers。

Experiments：diverse benchmarks、long-horizon edit streams、多个 MLLM backbones、VLKEB real-world scenarios；作者报告改善 in-scope transfer / out-of-scope locality，同时维持 reliability/stability/efficiency。当前来源未稳定提供逐表数字，因此不猜。

Contribution：New Problem — Edit-Scoped Generalization；New Mechanism — scope-separated writes。Migration：反向用于 unlearning：local branch 抹 modality-specific trace，shared branch 仅在 cross-modal causal evidence 足够时传播 deletion。Worth Deep Reading: YES。

Safeguarding LLM Agents from Misalignment through Provenance Analysis

人话版：ProvenanceGuard 不让 LLM judge 凭感觉判 tool call，而问“这个 action 是否被 context 中可追踪证据支持？”它在执行前做多阶段 provenance checks。

Results：Agent-SafetyBench misaligned traces error 42.9%→1.8%，WorkBench 32.1%→17.3%；task-successful traces intervention burden 30.5%→12.8%，aligned traces 无统计显著额外 unnecessary intervention。

Contribution：New Mechanism — provenance runtime guard。Limitation：provenance 缺失/污染会误判；guard 不清参数或 memory。

Migration：把 deletion request 视作 provenance revocation：任何以 revoked node 为必要祖先的 tool call / memory write / skill invocation 都 block。MVE 测 revoked-action rate、false block、closure depth。Worth Deep Reading: YES。

Tier B

What to Remember, What to Reveal: Privacy-Aware Memory for Conversational Agents

人话版：SP-Mem 把 sanitized content 与 exact private values 分离存储，只有任务需要且有 consent 才暴露精确值。

Method/Finding：full-lifecycle identify→separate→store→selective retrieve；benchmark 联合 response quality、privacy behavior、cost，多 LLM agents 上报告更强 personalization 与更少 unnecessary exposure。

Contribution：privacy lifecycle memory + benchmark。Limitation：access control ≠ forgetting，exact value 仍存在。Connection：可作为 soft-revocation baseline，测试 consent revoke 后能否从 sanitized memory 推断原值。Potential Use: Baseline/Evaluation/Future Idea。

Learning What Not to Forget: Long-Horizon Agent Memory from a Few Kilobytes of Learning

人话版：LRE 用 KB 级 CPU-only scorer 学哪些历史片段不能 eviction，直接保留 task-critical units。

Results：恢复 full-history aggregate accuracy 的 93%（41.1 vs 44.0），简单任务高 27%，zero compressor calls，worst-case peak prompt -52%。

Contribution：learned relevance eviction。Limitation：优化“别误删”而非合规删除。Connection：可作为 unlearning retain protector：forget-risk 与 future-task criticality 双头评分。Potential Use: Baseline/Future Idea。

Explainable LLM Unlearning Through Reasoning

人话版：TRU 认为 GA 的问题之一是没有明确告诉模型“如何推理到已遗忘状态”，于是构造 reasoning-based unlearning target，用 CE + GA 联合优化。

Finding：作者在多 benchmark/backbone/attack 下报告更可靠 forgetting、general capability preservation 与 robustness；本轮网页未暴露稳定逐表数字，因此不编造。

Contribution：New Objective — reasoning-based target。Limitation：reasoning target 可能反而保存 target 或学成 surface refusal。Connection：最值得做 Reasoning Trace Leakage：final answer 忘了但 CoT/hidden state/tool trajectory 是否仍泄漏。Potential Use: Baseline/Attack/Future Idea。
