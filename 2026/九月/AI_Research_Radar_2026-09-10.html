Executive Summary

今天最值得追的不是一个新 unlearning loss，而是三条 evaluation / lifecycle 机制：MERIT 把 Agent Memory 从“问答记忆”升级到“是否真正改变 tool action”；SCAFFOLD 显示 skill 会递归组合并最终蒸馏回 weights；EdgeMem 则证明高可靠 memory 往往依赖保留原始 evidence。它们分别对应 Agent Unlearning 的 behavioral verification、Skill Deletion Closure、evidence-preserving memory 与 deletion compliance 冲突。

另外，Reasoning-Aware Compression 说明 module vulnerability 强烈 task/model-dependent，ARC-Bench 说明 closed-loop success 会掩盖内部 ranking defect；这两点都适合迁到你当前 module-level / cross-layer unlearning evaluation。

Tier S

1. MERIT — When Does Memory Help?

基本信息：Shweta Mishra, Shashank Mishra；Independent Research；arXiv:2609.05441v1；Paper；Code/Traces。

人话版

MERIT 认为 LoCoMo/LongMemEval 只测“能不能回答旧历史”不够，因为真实 Agent 要把 memory 用进 tool call。它构造 Customer Support、IT Ops、Personal Assistant 三类 episodic tool-use 环境，用 easy/medium/hard(updated fact) 梯度、controlled stale corruption、Memory Utilization Rate(MUR)、Ignore Rate、Stale-Memory Harm(SMH)、Cost-Adjusted Marginal Utility(CAMU) 来判断 memory 是否真正帮到行动。23,440 个 scored episodes 中，无 memory 的 dependent tasks 严格为 0；embedding retrieval 到 updated-fact hard tier可掉到 0.35–0.70，而正确最新值已经在 context 中时，Agent 仍有约45%不把它用于 tool argument。

Background & Gap

旧 memory benchmark 的三个 blind spots：QA ≠ action；memory 被默认当成 benefit、很少测 stale harm；cost 只报 token 不报边际收益。MERIT 用 mutable world end-state 作为 task success，并用 leak check 确保 probe episode 没有 gold fact。

Core Insight

Retrieval、presence、utilization、final action 是四层不同问题。一个 memory system 可以把最新值正确召回，但 Agent 仍执行旧值；因此 memory quality 不能只用 retrieval accuracy。

plant fact → optional update → later probe omits fact → memory read → agent receives memory → tool execution → world-state checker → value tracing → TSR/MUR/Ignore/SMH/CAMU
MUR=P(gold values appear in tool args | gold values present in memory) Ignore=1-MUR SMH=TSR(clean)-TSR(corrupted) CAMU=ΔTSR/Δcost

Experiment & Results

  • No-memory dependent cells 全部 0.000；independent tasks 0.83–1.00。
  • hard tier C2 retrieval 0.35–0.70；C1 replay 0.95–1.00；C4 fact store 0.75–1.00。
  • Hybrid 在 hard tier 三个 domain 都比其 C4 组件差，说明“更多 memory”可重引入 stale state。
  • C2 hard tier中55个正确最新值已被召回的probe，只有30个真正进入tool args，Ignore≈0.45。
  • stale corruption ρ=0.3 时 Hybrid SMH +0.25，Holm-adjusted p=0.030。
  • Full replay 从不在 CAMU 上最经济；per-domain best 的 utility/$ 高约2.7–3.9×。

Table/Figure Reading

Table1/Figure1把updated-fact差异拉开；Figure2显示 starter→real implementation 可让同架构移动多达60pt；Figure3显示“memory在但没用”；Figure4 stale harm；Figure5 accuracy和cost-efficiency排序不同。

Ablation / Mechanism

Starter→real swap 是最关键诊断：LLM summarization把 hard tier 从接近floor拉到1.00/0.70/1.00；LLM extraction在IT Ops medium反而1.00→0.40；embedding retrieval升级只小幅改善，说明根因是缺 recency arbitration 而不是 retrieval 质量。

Claim vs Evidence

Authors Claim：Agent Memory需要action-level、cost-aware、corruption-aware evaluation。
Actually Show：多domain、programmatic action score、跨model replication支持。
Not Proven：原生商业memory产品、超长真实用户历史、多Agent shared memory。

2. SCAFFOLD

基本信息：Bowei He, Xiaokun Zhang, Meng Ding, Xue Liu；Accepted by EMNLP 2026；arXiv:2609.05511v1；Paper。

人话版

SCAFFOLD把Web Agent skill library升级为可递归组合、可压缩、最终还能蒸馏回weights的技能体系。它从成功trajectory中做multi-instance skill induction，高层skill可调用低层skill，再用MDL做library compaction和behavioral equivalence validation，最后周期性把skill-augmented trajectories蒸馏进参数。WebArena/VWA/held-out OM2W达到42.7/36.3/43.5%，比SkillRL高11.1/13.6/17.2pp。对Skill Unlearning而言，最大风险是skill不只存在文件库里，还会被递归组合并internalize进weights。

Method

successful trajectories → multi-instance induction → recursive skill hierarchy → MDL compaction → behavioral equivalence → skill-augmented rollouts → distillation into weights → next iteration

Results & Ablation

  • WebArena 42.7%，比SkillRL +11.1pp。
  • VWA 36.3%，+13.6pp。
  • OM2W-X 43.5%，+17.2pp。
  • 去distillation：WebArena -8.0pt，最大单项ablation。
  • 去recursive composition：WebArena -6.3pt，OM2W-X -7.4pt。
  • 去multi-instance induction、holdout validation分别约 -4.6、-3.7pt(WebArena)。

Table/Figure

Table1为三benchmark主结果；Table2拆四项核心创新；self-improvement曲线显示连续5轮单调提升且library未collapse。

Claim vs Evidence

证据支持recursive skill + parametric distillation提升Web Agent，但尚未证明skill lineage穿过distillation后可被可靠追踪，更没研究targeted deletion。

Migration

New RQ：删skill file后，低层skill composition或weights能否恢复target behavior？
MVE：10 target skills；file-only / hierarchy-delete / weight-only / joint delete。
Metrics：Skill ASR、Cross-Level Recovery、Parametric Residue、Retain SR、Reacquisition Iterations。

记住5句话

  1. Skill可递归组合。
  2. Skill最终可蒸馏回weights。
  3. 三benchmark比SkillRL高11.1–17.2pp。
  4. 去distillation是最大ablation。
  5. Skill Unlearning必须跨library和参数层。
3. EdgeMem

基本信息：Zeyang Cui, Jiannong Cao, Zhiyuan Wen, Bo Yuan, Junlan Feng, Shengyuan Chen；arXiv:2609.05553v1；Paper。

人话版

EdgeMem反对写入时就让LLM压缩历史，因为未来需要什么信息未知。它保留原始interaction turns，用episode、co-occurrence、time三类anchor组织成multi-anchor hypergraph，construction/retrieval不用生成式LLM，只在最终回答时使用LLM。LoCoMo统一prompt下Strict Judge 61.01，对strongest reproduced baseline CompassMem 58.70；从flat BM25 49.74加入episode/co-occurrence/time后逐步到61.01。对unlearning的矛盾很直接：高faithfulness依赖保留raw evidence，但合规删除要求部分raw evidence真正消失。

Method

raw turns → episode/co-occurrence/time anchors → multi-anchor hypergraph → query matching → retrieve source turns → evidence-only reader → answer/abstain

Results

  • LoCoMo SJ61.01 vs CompassMem58.70。
  • flat BM2549.74 → +episode58.18 → +co-occurrence60.43 → +time61.01。
  • evidence-only reader在1,540个answerable questions中28.0% abstain，约损8个judge points。
  • Full History在LongMemEval-S约103,137 tokens/question，结构化retrieval显著降低read cost。

Table/Figure

Table1统一比较生命周期cost与LoCoMo answer quality；Figure3(a)是accuracy-token Pareto；Figure3(b)/Table3是anchor ladder；Table4是LongMemEval-S。

Migration

New RQ：删除一个source turn后，哪些anchor/neighbor仍形成residual access path？
MVE：LoCoMo标50个targets，source-only delete vs edge-delete vs connected-component purge vs selective causal closure。
Metric：Worst-Anchor Leakage、Retain SJ、Deletion Size。

记住5句话

  1. EdgeMem保留原始turn而非先压缩。
  2. LoCoMo SJ61.01。
  3. episode anchor贡献最大。
  4. evidence-only有明显abstention代价。
  5. source preservation与真正删除天然冲突。

Tier A

4. AutoFyn Technical Report

AutoFyn冻结模型，每轮fresh session，仅通过persistent memory files、reports和repo state把verified knowledge带到下一轮。它把Expert Iteration搬到non-parametric state：多Agent提出候选→grounded verifier→更优incumbent写回persistent state。IMO 2026中，同一模型换AutoFyn harness后均不差于provider agent；GPT-5.6 Sol +2分，GLM5.2 +11.3分。对Unlearning的关键：fresh session≠fresh policy，只要persistent state还在，能力仍会延续。MVE：删某role memory rule后继续expert iteration，测是否从verifier feedback重新写回。Worth Deep Reading: YES。

5. When and What to Teach

在线Web Agent teaching把预算分成“什么时候问teacher”和“哪些turn值得训练”。solvability-aware gate决定when，score/log-probability guided trimming决定what。MiniWoB/TimeWarp上teacher calls平均-22.6%，student compute -52.1%，first-pass success基本保持。迁到Continual Unlearning：只对高reacquisition-risk episode触发re-unlearn，再用turn attribution缩小更新范围。Worth Deep Reading: YES。

6. Reasoning-Aware Compression

逐个扫描196–224个(layer,projection)模块的INT4脆弱性，再只保护Top-K。ProofWriter上R1-Qwen-7B Top-10%达到84%，比FP16 72%高12pp且energy -9.7%；但FOLIO/Qwen、ProofWriter/Llama等组合里ranking跨split不稳定。迁到module-level unlearning：对每个模块测Forget ASR delta与Retain Utility delta，做稳定性/跨view验证，而不是只画一张saliency map。Worth Deep Reading: YES。

7. The Failure Happens Before the Drift

1,200 personas、约4,000 conversations、15 topics、三模型中，超过50%的persona从一开始就没忠实表达assigned values，而真正长期drift只有2–7%。对Unlearning非常重要：如果base target access本来就弱，post-unlearning“下降”没有意义。建议加Precondition Gate：base accessibility达阈值的样本才进入forget effectiveness统计。Worth Deep Reading: YES。

Tier B

8. CriticGen

针对每个question-answer生成sample-specific rubric，再统一输出score→reason→executable suggestion→rewrite。Relevance/Coverage 3.33/4.03→3.97/4.24；Spearman最高0.956；73.17%答案改进，non-degradation93.28%。对Unlearning可迁为adaptive evaluator/attack generator：针对每个forget target生成不同泄漏维度和可执行probe。Potential Use: Evaluation / Adaptive Attack。

9. Damage-Aware Bandit Pruning

把attention heads/MLP channel groups作为bandit arms，临时mask后观测paired loss damage，在固定候选预算内选低损伤结构单元。迁到Unlearning时可把reward改成高forget gain、低retain damage，用于budget-aware module search。Potential Use: Module Selection / Attribution。

10. ARC-Bench

closed-loop replanning会掩盖latent action ranking本身已经坏掉：第一步候选排序很差，但频繁replan可把最终success救回来。对Agent Unlearning同理：closed-loop最终不泄漏可能只是guard/planner纠偏，不能证明底层忘记。建议同时测open-loop first-decision leakage与closed-loop success。Potential Use: Cross-Layer Evaluation。

Collision Detection

⚠️ Agent Memory Unlearning HIGH：Execution-State Unlearning已覆盖runtime descendant replay，MERIT又补上action-level evaluation；新工作不能只做memory delete+QA。

⚠️ Skill Unlearning HIGH：Repo-To-Skill、MASkills、Persistent Skills、SCAFFOLD已覆盖skill induction/evolution/composition/internalization。真正空间是cross-layer deletion closure与normal-interaction reacquisition。

⚠️ Module Localization MEDIUM-HIGH：Reasoning-Aware Compression说明module sensitivity高度task/model-specific且跨split可能失效；module-level unlearning必须做稳定性验证。

⚠️ Cross-Layer Evaluation MEDIUM：ARC-Bench、Where Reliability Lives、WHALE都说明harness/closed-loop会掩盖底层能力；建议双报open-loop和closed-loop leakage。

⚠️ Evidence-Preserving Memory LOW-MEDIUM：EdgeMem的source-retention与deletion compliance的直接冲突尚未被充分解决，值得继续。
