4. Paper 1 Full Deep Dive

CERA-MoA: Co-Evolving Routing Mechanisms with Continually Learning LLM Agents

FRESH · Multi-Agent · Continual RL

5.1 基本信息：Jiaxuan Jiang, Liyuan He, Zhixuan Fang；IIIS, Tsinghua University / Shanghai Jiao Tong University / Shanghai Qi Zhi Institute；arXiv:2609.18779v1；2026-09-16；preprint。
Paper：arXiv · HTML · PDF。正文未给可核验官方 Code/Project URL。

5.2 一句话定位

把“谁来做题”的 router 与“每个 agent 学成什么样”的 post-training 从两个静态模块改成闭环共演化系统。

5.3 人话版

传统 MoA 要么固定 agent 能力再训练 router，要么固定 workflow 再 fine-tune agent；但 RL 过程中 agent 能力不断变化，静态 router 很快拿着“旧地图”分配 query。CERA-MoA 用 frozen backbone 的中层 hidden states 表示 query，每个 agent 配 predictor head 与随机冻结 target head，把相对表现转成几何 familiarity；训练 routing 时加入 UCB 与历史 entropy 防止早期赢家吞掉全部样本，再用 cumulative threshold 只激活“累计 competence 足够”的最小 agent 子集。被选 agent 用 DAPO+GSPO 更新，router 再根据相对 reward 更新 familiarity。Qwen3-4B 的 ID Avg 63.2、OOD 72.8；强 baseline AT-GRPO 分别 61.0、71.5。更关键的是 adaptive routing 367.77 tokens 几乎匹配 fixed Top-2 的性能，而后者 666.37 tokens。真正值得迁移的是 competence-aware continual routing，而不是“又一个 MoA”。

5.4 Background & Research Gap

ICL-Router、LinUCB、RouteMoA 主要优化固定 agent 的 orchestration；MAPoRL、AT-GRPO 会训练 agent，但 workflow 预定。两条线之间缺反馈环。若四个同源 agent 均匀吃数学、代码、指令数据，它们趋同；若只把数据喂给当前赢家，又会 starvation。论文同时瞄准 router stale 与 agent homogeneous / starved。

5.5 Core Insight

绝对 reward 在 policy 持续变化时是非平稳信号；作者把同一 query 上的相对 advantage 映射成 predictor-target 的几何 pull/push。中层 hidden state 又比 final layer 更保留任务语义，因此更适合 competence routing。Table 3、Figure 2、Table 10 支持这一工程观察，但没有证明 hidden-state distance 就是因果意义上的 competence。

5.6 Method Deep Dive

q → frozen mid-layer h(q) → per-agent distance d_i → familiarity f_i → training-only UCB + entropy exploration → rank agents → minimum prefix with cumulative f ≥ τ → selected agents sample G completions → verifier reward → DAPO + GSPO update LoRA → relative advantage updates familiarity head → next routing step tracks evolved competence → inference removes exploration; adaptive subset + aggregation

Step 1：拼接约 L/2 与 3L/4 层 hidden state；backbone 冻结，避免 router feature 自身漂移。Step 2：每 agent 一对 trainable predictor / frozen orthogonal target head；表现好就拉近，表现差就推离 margin。Step 3：训练 score 加 UCB 与历史 entropy，防 policy starvation。Step 4：按 score 排序，但 cutoff 看 familiarity 累计和；简单题少 agent，难题多 agent。Step 5：各 agent 用 LIFO buffer、task verifier、DAPO+GSPO 更新。Step 6：router 用参与 agent 的 relative reward 同步更新。Step 7：确定性任务 familiarity-weighted majority vote；open-ended 直接取最熟悉 agent，这也是明显 limitation。

λ 控制 familiarity 对距离敏感度；τ 控制需要多少累计 competence；m 是负样本 separation margin；β 约束 agent 偏离 reference。Strongest baseline AT-GRPO 的核心是固定 tree MoA 上做 GRPO；CERA 的机制差异在于 sample allocation 本身参与学习闭环。最关键 knob 是 τ：高则多 agent/高成本，低则趋近 Top-1。

5.8 Toy Example

动态规划 query 到来，四 agent familiarity 为 .55/.18/.12/.08，τ=.7，于是只选前两名。两者各 rollout 8 次，Agent3 reward=.875、Agent1=.375；相对 advantage 使 Agent3 对这类 query 的 distance 继续缩小，Agent1 被推远。下一批 DP 更偏 Agent3；长期没选的 Agent2/4 又因 UCB 得到探索机会。于是 specialization 是 routing 产生的，而 specialization 又重写 routing。

5.11 Metrics 教学式解释

各 benchmark accuracy/pass rate 越高越好；Avg 方便跨域，但会隐藏单项退步。Avg Tokens 越低通常越省生成成本，却不是 latency/energy。ID+OOD 同看才能判断 specialization 是否过拟合。Familiarity 不是 calibrated success probability，累计 familiarity 也只是 learned routing criterion。

5.14 Ablation / Mechanistic Analysis

去 geometric familiarity→ID/OOD 下降；Top-1 省但弱；Top-2 强但贵；去 exploration 产生 starvation；final-layer 同时伤 accuracy 与 cost。t-SNE 不能证明因果，下一步应做 routing counterfactual：固定 query，强制交换 specialist，看 reward 是否按 familiarity 排序。

5.17 Limitation & Failure Modes

5. Paper 2 Full Deep Dive

Verifiable Social Reasoning for LLM Assistants

FRESH · Multi-Agent Simulation · Evaluation

5.1 基本信息：Amir Taubenfeld, Zorik Gekhman, Avigail Grinstein-Dabush, Itay Laish, Ariel Goldstein, Marian Croak, Avinatan Hassidim, Yossi Matias, Amir Feder；Google Research 等；arXiv:2609.17496；2026-09-15；preprint。
Paper：arXiv · HTML · PDF · Code/Data：official Google Research。

5.2 一句话定位

Fuse 用带隐藏真实 motive 的 multi-agent simulation，把“通常没有客观答案”的社会推理变成可验证 benchmark，并控制 user mediation、framing bias、detail 与 multi-turn。

5.3 人话版

现实用户问“同事是真支持还是想抢位置”，模型只看到主观叙述，研究者也不知道对方真实动机。Fuse 先在模拟世界偷偷设定 target motive，再让多个 agent 演出社会互动；之后 user agent 凭自己的记忆向被测 assistant 复述。ground truth 因此已知，同时可以只改 bias/detail 而保持底层事件不变。作者生成1,200个 multi-agent simulation、21,600条 user message，并用24k人类标注验证。raw event 的 assigned motive 有97% human majority 一致；first message 人类88% correct/MSR89.8，而12个模型无一超过MSR83.7。bias 让模型平均掉7.7分，人类只掉3.6；更多 detail 缩小差距，但更多 turn 在第4轮后常 plateau/下降。对研究最有价值的是 controlled mediation：固定 reality，只干预 observation channel。

5.4 Background & Research Gap

SocialIQA/ToM 给“上帝视角”完整事件，ground truth 清楚但不贴近 assistant；真实咨询有 subjective report，却没有可验证 latent truth。Fuse 将二者分层。例如 Caleb 真心支持，但 user 把“尊重方案、愿意对齐”描述成“过度奉承、可能夺权”。同一底层事件只改 framing，就能分离 reasoning failure、information loss 与 sycophancy。

5.5 Core Insight

assistant 的输入不是 reality，而是 user-mediated reality。只要先生成有 latent truth 的 world，再把 world→user report 与 report→assistant 分开，就能对中介层做 intervention。97% raw-event human validation 与88% first-message solvability说明模型 gap 不能简单归因于任务无解。

5.6 Method Deep Dive

ATOMS mental-state categories → scenario template + two candidate motives → assign hidden ground-truth motive → Concordia multi-agent simulation generates objective events → simulated user forms subjective report → intervene on bias × narrative detail → evaluated assistant predicts motive → judge: Correct / Incorrect / Abstain → human validation → Observer / Bias / Detail / Multi-turn analyses

Step1 保留 desire/intention/belief/emotion/knowledge 五类。Step2 每 template 定义 personas、episodes、两个对立 motive。Step3 同 motive 采多个 realization。Step4 simulation 与 debrief 隔离，assistant 看不到 raw events。Step5 bias 有 default/opposite-ground-truth，detail 三档。Step6 judge 只判 Correct/Incorrect/Not Attempted。Step7 人类不逐条创造标签，而验证生成机制是否 faithful、first message 是否可解。

5.7 核心公式与数学直觉

MSR(d)=(|Correct| + d·|Not Attempted|) /(|Correct|+|Incorrect|+|Not Attempted|) paper: d=0.75

Correct=1、Incorrect=0、Abstain=d。d=.75 表示谨慎优于随机二选一但不如正确。最关键风险是高 abstention 会被奖励，所以 MSR 必须与三种 outcome rate 一起看。d 越高，Claude/Gemma 这类高 abstention 模型可能排名更好。与普通 accuracy 相比，它显式建模 safety–utility trade-off。

5.8 Toy Example

ground truth：Caleb genuinely supportive。Observer 看 raw events，发现他尊重既有方案、主动学习。Default user 正常复述；biased user 只多加“我担心这是策略性夺权”，事件不变。若模型把同一“对齐”解释成 ingratiation、map relationships、identify levers，就发生 framing-induced failure。这比随机换一个 adversarial prompt 更干净，因为 latent world 固定。

5.18 Reproduction View

B — Minimal Framing Attack / Bias Surface

Original→7.7 MSR bias gap；Transfer→paired intervention；RQ→多少 fact-preserving framing token 能翻转判断？Minimum→Fuse1k paired，0/1/2/4/8 edits，constrained rewrite+entailment checker；Model GPT-OSS/Gemma/Mistral；Baseline default/opposing/generic paraphrase；Metric flip rate、MSR drop、edit distance、fact preservation、Bias Surface AUC；Expected 连续 robustness curve；Risk 事实保持验证难；Collision中。

5.21 Attack / Verification Lens

Fuse 天然是 black-box probe。可定义 minimum fact-preserving framing edit、Mediation Robustness Gap、Bias Surface AUC、Clarification Recovery Rate。迁到 unlearning 后还能区分“模型自身 recall”与“外部叙述重新提供证据后的 reacquisition”。

5.22 与 Paper 1 的关系

Fuse 给 CERA 一个重要反例：semantic similarity 不等于 robust competence。router 应把 framing susceptibility 纳入 competence，而不是只学平均 task accuracy。

7. Cross-Paper Synthesis

共同趋势：Agent 能力不能再用静态 base-model score 描述，而必须同时考虑 capability drift 与 evidence/framing drift。CERA 处理 agent 在训练中变了；Fuse 处理 world 没变但 observation channel 变了。可组合成 robust competence routing：familiarity 不只预测 reward，还预测 neutral/biased/partial evidence 下的稳定性。

8. Combined Research Opportunities

Top — Robust Competence Routing for Unlearning Agents

把 competence 定义成 retain utility、forget leakage、recovery robustness、mediation robustness 四维。CERA-style router 跟踪 unlearning 后 competence drift；Fuse-style paired intervention 测同一 forget fact 在不同叙述/tool/image evidence 下是否 reacquire。可与你现有 relearning、quantization、Cloze residual、MIA 直接并表。

9. Collision / Overlap

Strongest Collision：Semantic Familiarity ≠ Robust Competence。CERA 的 mid-layer semantics 足以提升平均 routing，但 Fuse 证明同一 underlying reality 只改 framing 就能系统性改变 reasoning。下一代 router 应识别“谁懂”与“谁在这种 observation channel 下仍可靠”两个维度。
