05 · RL Highlights

重点变化：Credit 估计从“多采样”走向“控制反事实噪声”。 TWICE 使用共享 Gumbel noise 在相同后续随机性下比较动作；AOPD 尝试用现有 student rollout 估计 teacher action advantage，避免额外反事实 rollout；Generative Reward Models 的实验提醒：静态 judge accuracy 更高不保证优化出的 policy 更强。

必须追踪的 RL 链条： Trajectory → terminal reward → turn-level counterfactual credit → advantage-weighted update。本期已明确 TWICE 的 sparse exact-match reward、组内优势与 twin advantage；AOPD 和 GenRM 的训练效率数字尚未从正文核验，不能写成已验证加速。下一步应比较同等 rollout tokens 下的最终成功率、credit sign error、KL、训练稳定性和 reward hacking。

06 · Agent / Multi-Agent Highlights

重点变化：Memory 的目标从“记得住”走向“该不该用、用了有什么后果”。 AMV-Guard 把 memory premise、行动后果和 VOI 放在同一个决策门；Memory-Aware Reward Modeling 用真实用户偏好否定“记忆越多越好”；Subgoal-aware Memory Graph 把 GUI 经验组织到可复用的意图层；EpiSEM-Bench 测试工具漏掉关键事实后的危险执行。

信息流与长时稳定性： Muffin（异步共享 buffer）和 Herding/Cascades（群体从众）值得做 related work，但仅有消息共享不等于信息贡献可归因。10/100/1000-step 的稳定性与跨 Agent 传播错误，本期绝大多数工作尚未充分证明，不能把短任务成功率外推到长期系统。

07 · Video Acceleration Highlights

两个不同的“快”： Direct Forcing 让训练流程从继承数千次初始化更新变成 250 次联合更新，推理仍是四步；CAVC 是推理执行中的 training-free 分支缓存，实测 1.10–1.35×。两者不应混成一个 speedup 数字。Direct Forcing 的 20.63 FPS 与其他四步模型相同；CAVC 缺少完整 FLOPs/峰值显存绝对数值，已按 Not Reported 处理。

值得扩展的技术线： 长视频 Query-aware 选择、可恢复性驱动缓存、跨帧 KV reuse、事件级压缩、少步生成与 chunk continuity。优先做真实 GPU latency、显存、token/帧数与质量的同配置对照；对生成任务同时看 VBench Total、Semantic 与时序断裂，不允许用单一平均分掩盖质量损失。

Tier SRL2026-10-22 v1 · arXiv

Same Luck, Different Choice: Twin-World Credit Assignment for Agentic Reinforcement Learning

论文正文 HTML · PDF · Code：未核实，勿视为已开源

Basic Information / 人话版

作者与机构：Zeropy Surio（University of Sheffield）、Tobias Engel（Carnegie Mellon University）、Mei-Lin Chou（University of Michigan）、Anika Raman（University of Michigan）、Samuel Okafor（Carnegie Mellon University）。日期：2026-10-22 首版；Venue：未核实会议录用，按 arXiv preprint 处理；Project / Code：未核实。

Agent 做一连串搜索时，通常只知道最后答案对不对，却不知道哪一步查询真正帮了忙。传统反事实方法会换掉其中一步，再让后续模型重新随机生成；这样得到的成绩差异既包括“换动作”的影响，也包括“后来运气不同”的影响。TWICE 的想法是：换动作，但尽可能让两个世界后续使用同一份随机性。它用按轮次、行号和 token 位置索引的 Gumbel 噪声，构造配对轨迹，用终局奖励之差估计该步优势。Qwen2.5-3B 的七任务平均 Exact Match 从 GRPO 的 37.4 升到 42.7；7B 从 42.0 升到 46.5。最重要的不是再加一个奖励，而是把 credit 的统计方差真正降下来。

Background & Research Gap：把动作效果与随机运气分开

设搜索 Agent 先决定“搜论文标题”还是“搜作者主页”，之后继续搜索并作答。GRPO 给整条成功轨迹同一优势，容易奖励无效步骤；PPO 的价值网络面对长工具历史也难准确估计。VinePPO、CRR 和 tree-based 方法通过补充 rollout 细分信用，但后续随机采样不一致。假设同一查询动作本来只提高 5% 的成功概率，重新采样后续回答的波动可能比这 5% 更大，单次比较容易把正贡献判为负贡献。论文将其明确化为方差问题，而不是再设计一个启发式过程奖励。

Core Insight 与 Method Deep Dive

Input → 采样事实轨迹 → 在某轮选择替代动作 → 固定后续噪声运行 twin → 计算配对 outcome 差 → 按成本选取值得分叉的轮次 → 更新 actor → Output。

第一步：可复现但仍正确采样。 事实轨迹中每个 token 通过 argmax_v(logit_v/temperature + Gumbel_v) 采样。随机数不依赖全局 token 计数，而用 (episode, turn, line, position) 作 key。这样替代查询比原查询多写几个字，也不会把下一轮的随机流全部错位。论文报告 keyed sampler 增加约 2% 生成时间。它不把两个世界强行生成成相同文本，只是让“相同随机冲击”进入不同策略分布。

第二步：配对反事实优势。 对访问过的状态 s_t 和动作 y_t，重新从旧策略抽一个替代动作 y'_t，后续复用事实轨迹的噪声 key，得到 U'_t。定义 D_t=U-U'_t，其条件期望等于该动作相对于策略平均动作的 advantage。若两个动作完全相同，直接得到零差值；若检索到相同证据，则可少跑一部分后续步骤并作概率重加权。这是减少辅助 token 的工程关键。

第三步：把分叉预算用在有信息的步骤。 分叉概率为 q_t=clip(λ√(η̂_t/c_t),q_min,1)，其中 η̂_t 是预测 twin 结果不同的概率，c_t 是补充 rollout 的 token 成本。使用逆概率加权修正选择偏差。直觉是：不要在明显无影响或极昂贵的步骤上反复试错，而要优先看“便宜且可能改变结果”的节点。

第四步：不更换主体训练器。 每轮 token 的优势由 GRPO 的 trajectory advantage 与标准化 twin advantage 组合；PPO/GRPO 的 clipping、KL 和工具返回 token masking 保留。twin 只用于训练估计，部署仍是单 actor。Reward 是终局 exact match（稀疏、规则型），并未依赖人工逐步打分；credit 是对动作的反事实贡献，而非奖励模型生成的过程分数。

公式 / Toy Example / RL Formulation

公式核心是 E[D_t | s_t,y_t]=Aπ(s_t,y_t)；配对方差 Var(D_t)=(1-ρ_t)Var(D_ind)，ρ 越高，同等样本数下噪声越低。Toy example（示意，非论文实验）：事实世界先搜 A 后搜 B，答对得 1；替代世界把第一步改搜 C，在后续随机性相同的条件下答错得 0，则 A 相对 C 的一次配对信用为 +1。若两个世界都答对，则差为 0，避免把偶然成功误当动作贡献。

RL 定义：State 为问题与搜索历史；Action 为模型写出的推理与检索/回答；Policy 为 Qwen2.5 actor；Trajectory 为多轮工具交互；Reward 为最终 Exact Match；Advantage 为组内轨迹优势加 twin turn advantage；Objective 为原 PPO/GRPO clipped surrogate；KL/Entropy 沿用基线配置；Exploration 通过采样替代动作；Credit 用共享噪声配对差分。可能的 reward hacking 来自检索证据污染或 grader 只检查最终字符串；论文没有证明真实网页变化下的同样收益。

Experiment Setup / Research Questions

作者在 Qwen2.5-3B、7B 上测试七个 QA benchmark：NQ、TriviaQA、PopQA、HotpotQA、2Wiki、MuSiQue、Bamboogle；主指标 Exact Match，报告三种随机种子平均。比较 PPO、GRPO、GRPO×2、IGPO、GiGPO、Tree-GRPO、AT²PO、VinePPO、CRR。RQ1：是否提高最终正确率？RQ2：是否真正改善每轮 credit 的符号与相关性？RQ3：共享噪声、行级重新同步、预算分配分别有多大贡献？RQ4：额外生成成本是否抵消收益？

Claim vs Evidence / Ablation / Limitation

Authors Claim：共享噪声使反事实 credit 低方差、无偏，改善长轨迹训练。Experiments Actually Show：在确定性/缓存检索环境及两种 Qwen 规模上，credit 审计和 QA EM 同向改善；独立 twin、单一 episode seed、均匀分叉都明显变差。What Is Not Yet Proven：真实浏览器、非确定性工具、多人同时操作和开放世界 Agent 是否保留高 ρ；多任务训练总 wall-clock 是否优于所有强对手；该 credit 是否真能追溯长期 memory 写入。论文明确依赖可重放工具和噪声对齐，分叉成本也随 horizon 增长。

Contribution 1 — New Mechanism：token 级可重放随机性形成 twin-world 对照；2 — New Objective/Estimator：无偏 turn-level advantage 与预算重要性修正；3 — New Empirical Finding：错误 credit 符号可从 21.7% 降至 6.9%。Baseline Potential 很高：可与既有 GRPO/Search-R1 系统对接。System Value 在可复现工具环境高，在开放网页环境需先做 tool snapshot。Benchmark/Attack Value：可将“某步是否真改变结果”做成因果归因评估。New Paper Potential：跨 session 的记忆/技能写入 credit 仍是明显空白。

When Is a Memory Safe Enough to Act On? Action-Conditioned Verification for Long-Lived Agents

论文正文 HTML · PDF · Code：未核实，勿视为已开源

Basic Information / 人话版

作者：Yiqi Wang、Yifei Wang、Jiaqi Zhang、Zhangkai Wu、Yiqun Duan、Taotao Cai、Mingkai Zheng；机构：未从已核验页面完整确认；日期：2026-10-22 v1；Venue：arXiv preprint，未核实录用；Code/Project：未核实。

一个 Agent 记得某个收件地址，不代表它应该直接把高价值包裹寄过去。同一条记忆，能否使用取决于下一步行动的后果。 这篇论文把长期记忆的使用从“检索到了就用”改成“先看该动作依赖哪些记忆前提，再决定继续、核验、重规划还是拒绝”。AMV-Guard 用价值信息（VOI）选择最值得核查的前提。在 ToolSandbox，和同输入静态策略相比，验证成本从 1.843 降至 1.219，安全放行召回维持 100%，Gate harmful 维持 0%，可放行覆盖率从 38.83% 提升到 44.17%。但 AppWorld 的迁移并非全面胜利：成本下降的同时成功率也下降。

Background & Gap：记忆正确性不等于行动安全

传统 Agent Memory 主要研究怎么写、压缩、检索、更新、去冲突。即使一条旧地址有 90% 可信度，寄一份普通宣传册与寄一份昂贵证件的风险容忍度也不同。错误概率是 memory 的属性；可接受的风险是 action 的属性。 只做 memory freshness 排序无法回答“现在是否需要再问用户一次”；全部核验又可能耗尽工具调用预算。作者把问题提升为带后果成本的序贯停止决策。

Core Insight / Method Deep Dive

Input：候选行动与相关记忆 → 抽取行动前提 → 为每个前提估计可信度和依赖关系 → 计算执行风险与核验 VOI → 选择核验/继续/拒绝/重规划 → Output。

Step 1：Premise extraction。 从行动的前置条件抽取可核验的事实，例如“账户仍有效”“地址未变更”“收件人授权”。这些前提可能是 AND/OR 依赖，不能把整段记忆压成一个平均 confidence。作者使用 LLM+Graph、反事实过滤等构造依赖结构；在未知 schema 下，前提抽取误差是关键风险来源。

Step 2：Consequence-aware risk。 对候选行动 a、前提后验 b，计算预期损失 R(b,a)=E[L(Proceed(a),z)] 和损失超过阈值 δ 的概率 Hδ(b,a)。只有当风险屏障满足阈值、且执行成本不超过 abstention cost κ，才允许放行。相同记忆在低风险动作中可直接通过，在高风险动作中需要查证，极高风险且无法验证时直接拒绝。

Step 3：Value of Information。 不对所有前提平均核验，而是比较“做某次检查后，最终决策预期损失能否减少”与检查费用 λC(q)。每次工具返回后重新更新 posterior 与 VOI。单步贪心不足时，允许受限两步前瞻，以捕获互补证据：例如单查订单或地址都不够，但两个一起查才能改变决策。若证据推翻关键前提，返回 ReplanRequired，而不是继续执行旧动作。

Step 4：Failure ownership。 把 Gate 阶段的错误放行与上游 planner 误解意图、下游工具错误分开统计。这点非常重要：0% Gate harmful 并不意味着整条 Agent 工作流零伤害。

Objective / Toy Example / Agent Architecture

作者：Haojun Xu、Jie Huang、Xin Lu、Mingchen Zhong、Zihao Fan、Linjiang Huang、Si Liu；机构：Beihang University / JD Future Academy（按论文 HTML 标注）；日期：2026-10-22 v1；Venue：arXiv preprint，未核实录用；Project/Code：未核实。

流式视频生成想做到低延迟，通常要把双向扩散模型改成逐段生成、每段仅去噪几步。旧训练流程常先花大量更新做 ODE 初始化，再用分布匹配或蒸馏修正生成质量。Direct Forcing 发现：一段真实视频既提供“给定历史应该接什么”的配对监督，也提供“生成视频整体应该像什么”的分布监督，没必要把两件事分两阶段训练。它将 Causal Continuation Alignment（CCA）与 Rollout Distribution Matching（RDM）联合优化，并动态平衡梯度，从 Wan2.1-1.3B 出发只用 250 次更新训练四步自回归生成器。VBench Total 84.63、Quality 86.01；但同类四步模型的推理速度相同，论文最强证据是训练路径更短，不是同等四步下 wall-clock 更快。

Background & Gap / 具体例子

例如让模型连续生成一个人从厨房走到客厅的 10 秒视频。只看某一段的静态质量，可能在两个 chunk 边界突然换了衣服；只做 teacher-forcing 的连续性监督，模型在真实 rollout 中又会逐渐积累误差。Self Forcing / Causal Forcing 使用 ODE 初始化再 DMD；ViRDM / Elastic Forcing 虽然转向 MMD，标准流程仍继承初始化阶段。作者的问题不是“如何再减少一个 diffusion step”，而是“能否跳过冗长初始化，直接联合学习因果连续性与生成分布”。

Core Insight / Method Deep Dive

Input：双向预训练 Wan2.1 + 视频-文本训练集 → 构造 reference-history CCA 分支 → 构造 self-rollout RDM 分支 → 用冻结表征计算 paired loss 与 population loss → Dynamic Gradient Balancing → 共同更新 causal generator → Output：四步流式生成器。

CCA 分支： 把参考视频切成时间块。当前 noisy chunk 只允许看之前的 clean reference chunks 与自己的 noisy tokens，使用块因果 attention mask；预测 clean endpoint 后，在冻结 VideoMAE 特征空间与对应真实 chunk 做逐位置 cosine 对齐。公式 L_CCA = E[(1/P) Σ_p (1-〈f_p,f*_p〉)]。它解决“在给定正确历史下，下一段是否接得对”，而非自由生成时的分布漂移。

RDM 分支： 模型按自身生成的历史逐块 rollout，用 KV cache 保存前面块的条件；在四个去噪评估位置中采样一个训练 exit，对完整生成视频提取冻结 VideoMAE/DiT 表征。以文本嵌入为条件构造核函数，用 MMD²(P_generated,Q_reference) 对齐生成样本与参考样本的联合视频-文本分布。这里的监督来自真实视频的统计分布，不需要在线 diffusion-score teacher。只做 RDM 会出现边界不连续，因此 CCA 不能完全去掉。

Dynamic Gradient Balancing： 两个损失的数值尺度不代表对参数更新的贡献。先将 CCA 梯度 norm 与 RDM 梯度对齐，再按 CCA 当前拟合残差缩放它的贡献：r_t=r_min+(1-r_min)min(ℓ_t/ℓ_1,1)，g_t=g_RDM+r_t·ḡ_CCA，其中 r_min=0.1。早期重视连续性，后期逐渐把优化能力分配给自由 rollout 的分布质量。这是可迁移到 Video RL / Agent World Model 的机制。

Agent 记得用户的很多事情，并不代表用户希望每次回答都用这些记忆。论文收集 87 名参与者的约 1,000 个真实成对偏好判断，比较使用个人记忆与不使用记忆的回答，发现“更个性化”并不稳定地更受欢迎。现成自动评测器也比真人更偏爱带记忆的回答。作者因此训练 memory-aware reward model，报告偏好预测准确率 72.8%。它把 Memory 评价从“能否记住/检索到”推进到“使用这条记忆是否真正符合用户偏好”，对于 Agent Memory RL 和长期交互非常关键。

Background & Gap / Core Insight

现有 memory benchmark 往往测 recall、QA 或 personalization score，但这不等于用户效用。例如用户问一道数学题，系统突然提到过去的个人生活细节，虽然记忆准确，却可能是明显的负体验。作者强调 memory access、memory appropriateness、response quality 是不同维度。核心观察来自真人对照偏好与自动 evaluator 的系统性差异，而不是从论文标题推测。

Method：Input → Output

Input：用户原始问题、可用个人记忆、两条候选回答 → 真人成对偏好标注 → 记忆适当性与回答属性的 rubric/特征 → 学习 rubric 权重与偏好映射 → 输出偏好概率或 reward。 数据收集包含个人上下文、成对回答构造、偏好标注、一致性分析；方法比较 off-the-shelf judge、rubric-based evaluator 与学习型组合。论文正文设有专门的 feature ablation、不同 generator 对照和高置信子集分析。这里的 reward 是人类偏好监督，不是终局任务成功率，也不是 RL 训练已经证明成功；将其用于 RL 仍是未来工作。

Experiment Setup / Results / Evidence

Participants：87；Judgments：约 1,000 对；任务：参与者自己的查询与记忆；主要指标：偏好预测准确率与评价器/用户一致性。RQ1：记忆是否必然提高用户偏好？结果：否，部分用户明确偏好无记忆回答。RQ2：自动评价是否可靠？结果：自动评价器比用户更频繁偏爱 memory-conditioned 回答，存在评测偏差。RQ3：能否学到更贴近用户的 reward？结果：memory-aware 模型达到 72.8% 偏好预测准确率，并优于论文中的基线。注意：约 1,000 是标注规模、87 是参与人数，不能伪装成三项模型性能数字；完整 baseline 逐项分数未在本次核验材料中提取，因此不编造。

When to Follow the Teacher: Advantage-Based On-Policy Distillation

论文正文 HTML · PDF · Code：未核实，勿视为已开源

人话版

Online Policy Distillation（OPD）让学生模型在自己采样到的状态上模仿老师，通常比单纯离线 SFT 更贴近真实部署分布。但老师偏好的动作不一定对当前学生有帮助：老师可能在学生暂时处理不了的状态下给出过难策略。AOPD 不盲目模仿，而按“老师动作相对于学生自身策略能提高多少预期回报”加权。论文给出的关键机制是用学生 rollout 的终局奖励与教师 importance weight 构造优势监督，避免每一步额外试多个老师动作并重新 rollout。

Background / Method

Input：student 采样的 trajectory、teacher 对这些动作的概率、终局 reward → 计算 importance-weighted advantage signal → 加权蒸馏 loss → 更新 student。 它不是直接将 teacher score 当 reward；它把 teacher 选择与 student 能否从该选择获益分开。对 RL for Agent 的意义在于：可把工具策略、技能建议、memory 写入建议视为“teacher actions”，只在它们确实改善学生回报时才学习。

Experiment / Main Finding

仅根据 Abstract / 可获取信息总结：摘要明确提出无额外 rollout 或 reward evaluation 的无偏估计器，但本次没有核验完整实验表格、模型、数据集和量化收益，不能写“优于 GRPO X 点”。值得检查正文理论条件：importance ratio 的方差是否在长轨迹放大？teacher 与 student support 不重叠时是否仍可用？是否存在 reward hacking？

Contribution / Limitation / Connection

贡献：New Objective（优势加权 on-policy distillation）和 New Estimator（仅用学生 rollout 估计）。局限：重要性权重可能高方差，且没有本次核验的端到端数值。Potential Use：在可复现搜索 Agent 上比较 OPD、SFT、AOPD 的最终正确率、rollout token、训练稳定性；与 TWICE 结合可测试更低方差的教师动作优势，但需警惕撞题。建议：READ THIS WEEK；先查 Method/理论证明与 Experiments。

人话版

GUI Agent 记忆常有两个极端：存单个点击动作，太碎；存整个任务轨迹，太粗。论文将连续执行同一意图的一段动作定义为 subgoal，例如“打开设置并定位到蓝牙页面”，再把这些片段存成可合并、扩展、检索的图结构。相比直接保存整条轨迹，子目标节点更容易跨任务重用。作者在 SPA-Bench 报告相对基线成功率提升 11.11%，但摘要未提供绝对成功率，不能把相对提升误写成百分点。

Background / Method / Experiment

Input：历史 GUI trajectory → 根据共同意图分割 subgoals → 将子目标经验合并到 memory graph → 根据当前屏幕/环境状态检索节点 → 指导后续动作。 研究核心是记忆粒度：单动作成功不代表任务进展，而整条轨迹又不利于局部复用。仅根据 Abstract / 可获取信息总结：实验确认使用 SPA-Bench 和 11.11% 的改进，但具体模型、图构建消融、token 成本与失败例没有本次核验，不编造。

Contribution / Limitation / Connection

贡献：New Memory Representation（subgoal graph）与可复用经验组织方式。限制：子目标切分错误会污染多个未来任务；图合并可能把表面相似但环境前提不同的经验混为一谈；100-step 以后记忆冲突与长期漂移尚需独立验证。Potential Use：和 TWICE 的 turn credit 结合，估计“哪一个子目标经验真正提升后续成功”；与 AMV-Guard 结合，在高后果 GUI 操作前核验旧子目标前提。最小实验：SPA-Bench 中对比 action memory、full-trajectory memory、subgoal graph，在相同 token/检索预算下测 success、错误复用、latency。

Agent 的安全问题不一定来自恶意指令：工具返回的每句话都是真的，但少返回一条关键事实，也可能让 Agent 错误执行禁止动作。EpiSEM-Bench 把这个现象做成可执行测试，覆盖六个领域的 300 对匹配安全/不安全任务，系统地隐藏关键事实，观察 Agent 是否主动找回证据、停止危险动作并继续完成允许任务。它直接挑战“没有检测到恶意文本就安全”的评测假设。

Collision 1：I1 vs TWICE / AMV-Guard / Memory-Aware Reward Modeling。 TWICE 已解决动作级共享噪声 counterfactual credit；AMV 已解决动作后果条件下的 memory premise 核验；Memory-Aware RM 已解决部分偏好监督。重合：反事实贡献、记忆选择与核验。剩余 Gap：跨 session 的记忆写入/删除是否造成长期效用变化，如何同时优化风险与用户偏好。差异化：必须提供 memory intervention benchmark、credit variance 审计与真实 policy improvement 三件证据；若只是“TWICE + AMV 两个模块串联”，不值得单独投稿。

Collision 2：I2 vs Cache Locally, Recompute Selectively for Streaming Video Understanding（arXiv:2610.29229）/ CAVC / 视觉 token pruning。 已有 streaming cache、选择性重算、异构可恢复性。剩余 Gap：查询改变、长时事件证据不可恢复的条件下，是否仍有可证明的 accuracy–latency 前沿。差异化：固定实际 GPU wall-clock 和峰值显存，加入 evidence-loss oracle 与 query shift stress test；只报告 token 降低会被认为重做旧工作。

Collision 3：I3 vs Muffin / Herding / 既有 MARL difference reward。 异步消息交换和多智能体 credit 本身均不是新问题。剩余 Gap：在可复现事件调度下对单条消息做因果干预，并将信息贡献直接反馈给通信 policy。差异化：构建消息级 oracle、反从众对照与 100+ step 的错误级联评价；没有这些证据建议只作为系统 feature。

额外风险：Direct Forcing × DRILL（2610.30814）：若新 Idea 声称“训练世界模型以提高下游 policy”，必须先核实 DRILL 已解决的任务级目标；仅将 VBench loss 替换为 policy loss 不够新。
