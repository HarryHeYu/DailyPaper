12.2 一句话定位

VETO 把视频 VLM 的 token reduction 从“只压空间或只压时间”改成有顺序的双轴压缩：先把每帧内部 token 合并，再做跨帧相似性合并，从而同时降低最终 attention 长度和 temporal matching 自身的开销。

12.3 人话版

长视频喂给 VLM 时，真正可怕的不是“帧多”本身，而是每帧有数百 visual tokens，64 帧很快就变成四万多个 token，LLM attention 的成本近似随总 token 数平方增长。已有方法往往只做 spatial token pruning/merging，或者只做 frame selection；前者在 FlashAttention 等优化后真实 latency 收益可能被 kernel 吞掉，后者又必须在未压缩的高维 frame features 上先做昂贵匹配。VETO 的关键不是发明一种更复杂的 selector，而是利用视频冗余的不对称性：空间冗余大、时间事件更脆弱，所以先在每帧内较激进地合并，再较保守地合并帧。默认 k=2、frame retention=0.75 时，理论 attention FLOPs 约降 7.1×；实际端到端在 EgoSchema 上可降 40% latency 且精度持平，在 LLaVA-OneVision-7B 的 VideoMME 上精度 58.9% 不变、H100 latency 降 15%。

12.4 Background & Research Gap

设视频有 T 帧，每帧 N 个视觉 token，视觉前缀长度约 TN。标准全注意力的核心二次项是 O((TN)^2)。例如论文 VideoMME 设置 T=64、N=729，总长度 46,656；仅视觉 attention 的 pairwise interaction 已经巨大。传统路线有两类：一类如 ToMe/VisionZip/FastV 在空间轴减少 N；另一类如 frame selection/temporal memory 在时间轴减少 T。问题是二者都只吃到一个维度的冗余。

更隐蔽的 gap 是：压缩算法自己也要花时间。如果先做 temporal matching，你必须先拿每帧完整的 N 个 token 形成比较对象；即使最后删掉很多帧，前面的相似度计算已经付费。相反，如果先把 N 压到 N/k，再做 T×T frame similarity，matching 的输入已经小得多。VETO 因此把“compression ordering”本身当成系统设计变量，而不是把 token count 当唯一指标。

具体例子：64 帧 × 729 token。只做 k=2 空间压缩得到 23,360 tokens，attention FLOPs 约 0.25×；只保留 75% 帧得到 34,992 tokens，约 0.56×；双轴组合得到约 17,520 tokens，attention 约 0.141×，即约 7.1× reduction。关键是这两个 reduction 是乘法叠加，而不是二选一。

12.5 Core Insight

核心 observation 有两层。第一层是冗余不对称：同一帧里的天空、墙面、纹理等 patch 高度重复，因此空间 token 可以非常激进地压；但跨帧的状态变化、动作转折、因果事件往往只出现短暂几帧，时间压缩过猛会直接删掉不可恢复的信息。论文消融中 spatial retention 从 50% 降到 20%，VideoMME 仍在 58.4–59.0 间；而 frame retention 从 0.75 降到 0.125，精度从 58.9 掉到 52.1。第二层是系统级顺序效应：先空间压缩会让后续 temporal matching 更便宜。这个 insight 同时是经验观察和工程复杂度分析，不是纯理论定理。

12.6 Method Deep Dive

Video → Frozen Visual Encoder → Intra-Frame Compressor → Spatially Compressed Memory → Inter-Frame Compressor → Shorter Spatio-temporal Token Sequence → Frozen LLM → Answer

Step 1 · Visual memory bank

视觉编码器输出 M∈R^{B×T×N×C}。VETO 不改 encoder，也不改 LLM，插在二者之间，所以零训练版本是纯 tensor transform。这一点对部署很重要：收益不是靠重新训练 backbone 换来的。

Step 2 · Intra-frame compressor

对每帧 X_t∈R^{N×C}，按 modulo-k 均匀划分 destination anchors 与 source tokens。destination 大约 N/k 个；其余 source 计算与所有 anchors 的 cosine similarity，每个 source 指派给最相似 anchor，再用 size-weighted average 合并。均匀 anchor 的目的不是“最聪明”，而是保证空间覆盖，同时避免额外 O(N²) 的 saliency selection。

Step 3 · Inter-frame compressor

对压缩后的每帧做 spatial mean pooling 得到 F_t∈R^C，再计算 T×T cosine matrix G。贪心选择最相似且不重叠的 frame pairs，按各自已聚合的 compression size 加权平均，直到剩余 T′ 帧。这里 temporal stage 已经在 N′=N/k 的 feature bank 上运行。

Step 4 · Frozen LLM inference

压缩后的 T′×N′ tokens 直接作为视觉前缀进入 LLM。无需自定义 CUDA kernel；论文强调兼容 FlashAttention。系统收益来自减少 sequence length，而不是仅仅减少某个 Python-side preprocessing。

12.7 核心公式与数学直觉

目标：L = E_V[D(F(M), F(f_inter(f_intra(M))))]

F 表示下游任务行为，D 表示语义损失。它表达的不是实际训练时一定显式优化的 loss，而是“压缩后任务语义尽量不变”的设计目标。

S_ij = cos(X_src,i, X_dst,j), idx_i = argmax_j S_ij

这是 intra merging 的核心。不是按 attention score 删除 token，而是把 source 的信息转移到最相似 anchor，因此更接近 information aggregation。k 是最关键 spatial hyperparameter：k 越大，保留 1/k token，计算更省；但理论上空间细节风险上升。论文的意外结果是 k=2→5 几乎不伤 VideoMME，说明 spatial redundancy 很强。

G_ij = cos(F_i,F_j), F_t = mean_n M'_{t,n}

temporal stage 用 frame-level pooled representation 找冗余。G_ratio 是更敏感的超参数：0.75 基本安全，0.5 开始掉，0.25 以下明显恶化。这与 Core Insight 的“时间事件比空间纹理更不可替代”一致。

C_VETO = O(TN²/k + T²C + G²T²N²/k²)；attention speedup ≈ (k/G)²

默认 k=2、G=0.75 给出约 7.1× attention FLOPs reduction。但注意：7.1× 不是 7.1× wall-clock。端到端还包含视觉编码、projection、sampling、LLM 非 attention 层和 kernel overhead，因此实际报告最高约 45% faster。这恰恰是本论文比很多“只报 FLOPs”的 acceleration paper 更值得看的地方。

12.8 Toy Example

假设一个 8 帧厨房视频，每帧 16 个 patch token。问题是“厨师在加盐前做了什么？”先 k=2，把每帧 16 token 合到 8：墙、台面、背景等相似 patch 合并，而手、锅、盐罐等独特区域因 cosine feature 不同被保留。随后每帧 mean-pool，发现帧1/2几乎一样、3/4一样、6/7一样，于是从 8 帧合到 6 帧，但包含“拿起盐罐”和“搅拌”的转折帧相似度较低而留下。最终 token 从 128 降到 48。LLM 仍能看到关键动作链，但 attention pair 数从 128² 降到 48²。若反过来先 temporal matching，算法必须先在完整 16-token frame 表示上做跨帧比较；而若 temporal retention 压得太狠，可能把“搅拌”那一瞬间删掉。

14. Experiment Setup Deep Dive

Models：LLaVA-OneVision 0.5B/7B、InternVL-2.5 1B、LongVA 7B；监督实验还用 InstructBLIP/Vicuna-7B 体系。Benchmarks：VideoMME、LongVideoBench、EgoSchema、MovieChat-1K，另有 MME/MMMU image benchmarks、BreakFast/COIN/UCF-101 action recognition。零样本默认 64 frames、k=2、G=0.75；MovieChat-1K 为 40 frames、G=0.5。监督任务 100 frames、k=2、G=0.32、20 epochs，只训练 lightweight linear adapter。

Latency protocol：batch size 1，端到端包含 visual encoder + compression + LLM inference。主结果对 7B backbone 用 H100 + FlashAttention-2；部分小模型用 V100，并明确标注。这个 protocol 的价值是直接回答“理论 FLOPs 是否落到真实 latency”。

15. Metrics 教学式解释

Accuracy：任务正确率，高越好，但不同 benchmark 不能横向直接比较。Normalized latency：Vanilla=1.00，0.85 表示端到端时间约少 15%；比 FLOPs 更接近部署价值，但 batch=1 不能代表高并发 serving。Token retention：保留视觉 token 比例，越低越省，但不是质量指标。Attention FLOPs：理论二次 attention 计算量，适合解释机制上限，却可能被 encoder、MLP、memory bandwidth 和 kernel overhead 稀释，因此必须与 latency 配对看。

16. Results Deep Dive

  1. VideoMME / LLaVA-OV-7B：58.9→58.9，H100 latency 1.00→0.85。精度零损失、端到端快 15%，直接支持 deployment claim；但远小于理论 7.1× attention reduction，说明 attention 不是全部 wall-clock。
  2. EgoSchema：60.2% 持平，latency 1.00→0.60，40% reduction；ToMe 0.78、HERMES 0.82。是最强 wall-clock 结果之一。
  3. LongVA-7B：VideoMME 54.0 vanilla →53.5 VETO，但 latency 0.90；LongVideoBench 52.9→53.0 且 0.86。说明跨架构成立，但并非所有任务都“精度提升”。
  4. InternVL-2.5-1B：VideoMME 49.2→48.1，V100 latency 0.81。19% 加速换 1.1 point accuracy，是明确 trade-off，不能说 universally lossless。
  5. MovieChat-1K：80.6，超过同 backbone HERMES 78.6 两点，是 strongest quality result；但这是不同于零样本 latency表的 setting，不能把 2-point gain解释为纯压缩必然带来的提升。
  6. Temporal sensitivity：G=0.75 时 58.9；0.5→57.9；0.25→56.1；0.125→52.1。证明 temporal compression 是主要 failure axis。
  7. Token starvation 10%：VETO 55.7 > VFlowOpt 54.9 > VisionZip 52.6 > FastV 47.9。优势存在但对 strongest baseline 只有 +0.8 point，因此这是稳健性胜利，不是碾压。
  8. Ordering：以 intra-first latency=1.00，inter-first 1.07–1.09、inter-only 1.16、intra-only 1.10–1.14；相同思想的“先后顺序”产生真实系统差异，是最有研究迁移价值的结果。

Strongest result：EgoSchema 40% latency reduction with matched 60.2% accuracy。Weakest/failure：InternVL VideoMME -1.1 point；极端 temporal compression G=0.125 掉 6.8 points。Trade-off：空间轴几乎免费，时间轴不是；实际 wall-clock 远小于理论 attention FLOPs reduction。

18. Ablation / Mechanistic Analysis

去掉 inter，只做 intra：压缩仍有，但 latency 比完整 VETO 高 10–14%，说明 temporal stage 不只是删帧，还让最终 LLM sequence 显著变短。去掉 intra，只做 inter：最慢到 1.16× VETO，说明 temporal matching 在完整空间特征上有明显 overhead。改成 inter-first：即使最终两轴都压，仍慢 7–9%，这最接近因果式组件验证。空间 k 从2到5几乎不掉精度，支持“spatial redundancy abundant”；时间 G 降到0.125则明显崩，支持“temporal events fragile”。不过 qualitative visualization 只说明相关性，不足以证明被保留 frame 真的是 causal keyframe。

19. Claim vs Evidence

Authors Claim：双轴、intra-first、hardware-agnostic，且现代 fused attention 下优势更大。
Experiments Actually Show：在 H100/V100、数个 VLM/benchmark 上有一致 latency gain，顺序消融支持 ordering；极低 budget 优于几类 baseline。
What Is Not Yet Proven：没有覆盖高 batch serving、不同 GPU 世代/TP topology、真实 streaming pipeline；“hardware-agnostic”目前是跨两类 GPU + complexity argument，而非全面系统验证。没有证明 frame mean-pooling similarity 对所有动作密集视频都可靠。

20. Contribution

Contribution 1 — New Mechanism：严格 intra→inter 的 dual-axis compression，是真正核心创新。Contribution 2 — New System/Engineering：无需 custom kernel、直接插在 encoder/LLM 间，工程价值高。Contribution 3 — New Empirical Finding：空间冗余远比时间冗余耐压，且 ordering 影响真实 latency。没有新 benchmark，也没有全新 metric。

21. Limitation & Failure Modes

Authors' Limitation：temporal compression 太激进会损伤关键事件；mean-pooled frame representation 对细粒度动作可能不够。Additional：batch=1 latency 不能推出 serving throughput；没有 TTFT/TPOT 分解；没有 GPU memory/KV memory 表；压缩后 visual token 数降低理论上会减 KV，但未系统量化；对 streaming video，当前全局 T×T similarity 需要改成 causal/windowed；query-agnostic compression 可能删掉“对当前问题重要但视觉上不显著”的瞬间；VLM encoder 成本若占主导，LLM-side token reduction 的收益会进一步受限。

22. Reproduction View

最小复现只需实现两个 PyTorch 模块：intra cosine matching + scatter/weighted merge；inter mean-pool + T×T cosine + greedy pair merge。先固定 LLaVA-OneVision-7B、VideoMME 64 frames，跑 Vanilla / Intra-only / Inter-only / Inter-first / Intra-first 五组，记录 accuracy、视觉 token 数、compression ms、LLM ms、end-to-end ms。最敏感超参是 G_ratio，其次 k。第一优先复现 Table 4a，因为它能最快验证论文最核心的“ordering 而非单纯 token budget” claim；第二优先 Table 1 的 H100+FlashAttention-2 latency。

23. Research Value

Baseline Potential：很高，适合作为 video token compression baseline。Migration Potential：很高，可迁到 streaming、agent perception、query-aware compression。Systems Potential：高，因为有真实 latency。Attack Potential：可构造 temporal-critical-frame stress test。Evaluation Potential：可把 speed-quality curve 拓展为事件保真曲线。Benchmark Potential：可建立“相同 token budget，不同冗余结构”的 acceleration benchmark。New Paper Potential：最高价值不是再做一个 merge rule，而是做 adaptive budget allocation：根据 query/trajectory 动态决定 spatial vs temporal budget。

26. Attack / Verification Lens

可以反向做 Temporal Needle Attack：在高度冗余视频中只插入 1–2 帧决定答案的事件，测 compression 是否把它误合并。可定义 Critical Event Retention Rate、Compression-induced Answer Flip Rate，以及 Speedup-at-Fixed-Event-Recall。黑盒 probe 可以通过逐渐缩短事件持续时间，估计系统的 temporal retention threshold。

28. 如果只让我记住这篇论文

  1. VETO 的创新重点是双轴压缩的顺序，而不是单一新 pruning score。
  2. 先压空间，再做时间匹配，可以同时降低最终 attention 和 temporal matching 自己的成本。
  3. 视频空间冗余很强：每帧只留 20–50% token，VideoMME 几乎不掉。
  4. 时间冗余更危险：frame retention 低于 25% 后性能明显崩。
  5. 默认 k=2、G=0.75 的理论 attention FLOPs 约减少 7.1×。
  6. 真实端到端加速远小于 7.1×，但在 EgoSchema 可到 40%，VideoMME H100 为 15%。
  7. 最重要的消融是 inter-first 比 intra-first 慢，即使最终也做双轴压缩。
  8. VETO 不需要改 LLM/encoder，也不需要 custom CUDA kernel，因此 baseline 价值很高。
  9. 它的弱点是 query-agnostic 和离线全局 temporal matching。
  10. 最值得迁移的是 query-aware / streaming dual-axis compression，而不是再发明一个普通 token merge heuristic。
Paper 2 — Finetuning with Sampling: SFT Learns Better Than You Think

Aayush Karan, Sitan Chen, Yilun Du · Harvard · arXiv v1 · 2026-10-01 · Preprint

Paper · HTML Full Text · Official Code

12.2 一句话定位

这篇论文把“RL 为什么比 SFT 更 generalize / 少 forgetting”的一部分优势归因于训练数据更 on-policy，并提出用 MCMC 把 off-policy expert traces 投影成“信息仍正确、但更像 base model 自己会说的话”的训练数据，让普通 SFT 获得接近甚至超过 on-policy RL 的性质。

12.3 人话版

传统说法是：SFT 用专家答案，容易把模型拉离原分布，所以会过拟合和灾难性遗忘；RL 用模型自己的 rollout 更新，更 on-policy，因此泛化更好、旧能力掉得少。但 RL 有个尴尬点：真正的新能力恰恰是模型不会的，模型采样 100 次都错时，reward 没有方差，GRPO/PPO 也学不到。本文不改 SFT loss，而是先“翻译数据分布”：从专家轨迹出发，用 base model 提议语义等价的新写法，再通过 Metropolis–Hastings 风格采样逐步提高这些轨迹在 base model 下的 likelihood。最终 SFT 看到的仍是正确 expert information，却更接近模型自己的表达/推理分布。Qwen2.5-3B 的 hard MATH 上，Sampling SFT 0.495，超过 GRPO 0.457 和 UFT 0.470；MATH500 更达到 0.582，而 GRPO 只有 0.313。它还显著减少 prior capability forgetting，并能作为 RL 更好的初始化。

12.4 Background & Research Gap

SFT 的优点是可以直接学习“模型自己根本采不到”的专家轨迹；缺点是 expert policy q 和 base model p 差得太远，最大似然训练会产生大分布移动。On-policy RL 的优点正相反：数据来自当前 policy，所以 update 更贴近已有行为；缺点是必须先采到 reward variation。对 hard problem，如果所有 rollout reward 都是 0，group-relative advantage 也近乎 0。

因此真正的 gap 不是简单“RL objective 比 cross-entropy 更先进”，而可能是：什么样的数据分布最适合这个 learner？本文把问题写成 information projection：在所有仍保留 expert information 的轨迹分布中，找 KL 距离 base model 最近的那个。于是目标不再是把模型硬拉向 q，而是先把 q 的样本搬到 p 的可学习区域。

具体例子：专家化学解答可能使用模型很少见的符号组织、句式和推导顺序。vanilla SFT 强迫模型复现这些 off-policy surface forms；projection sampling 则让模型在“答案/知识必须等价”的约束下，改写成自己高概率的 reasoning trace，再拿这些 trace 做 SFT。

12.5 Core Insight

作者的关键 observation 是：RL 的优势未必完全来自 policy gradient，本质上还来自数据与当前 policy 的分布对齐。如果我们能保留 off-policy expert 的 privileged information，同时把 trajectory 的 surface distribution 拉回 base model 附近，就可能同时获得 SFT 的“能学新东西”和 RL 的“少分布漂移”。论文用两个证据支撑：一是 boosted traces 在 base model 下 sequence likelihood 显著更高；二是把为 Olmo 采样的数据拿去训 Qwen，Chemistry 只到 57.33%，甚至低于 vanilla SFT 61.8，说明“对哪个 learner on-policy”非常关键，而不只是改写质量更好。

12.6 Method Deep Dive

Expert Dataset → Define Information-equivalence Set C → Base-model-conditioned Proposal → Blockwise MCMC / Metropolis-Hastings → Boosted More-On-Policy Dataset → Standard SFT → Optional RL

Step 1 · 定义等价集合 C

对每个 expert trace，定义所有“仍然正确/保留同一信息”的 trajectories 集合 C。数学题可用正确性约束，开放式 medical 则依赖 grader/semantic preservation。这个 C 是整套方法最重要也最容易被忽略的假设：如果 preservation 判断错，采样会把 expert information 一起洗掉。

Step 2 · 目标 distribution

在 C 内，不是均匀采样，而是按 base model p(x) 重新加权：base model 越自然的等价解越应该被选。于是 target 是 p restricted to C。

Step 3 · Proposal

给 base model 当前 partial trajectory + expert solution，让它生成保持信息的新 continuation。这样 proposal 本身就利用 privileged expert context，解决 base model 独立 rejection sampling很难采到正确 hard solution 的问题。

Step 4 · Blockwise MCMC

长序列不是一次全部重写，而是按 block 逐步演化。Metropolis–Hastings 根据 target/proposal likelihood 决定是否接受 candidate。实际实现为了省成本有近似：当 candidate likelihood 更高时直接替换等工程 shortcut，因此理论 stationary guarantee 与实际 finite sampler 要区分。

Step 5 · Standard SFT + optional RL

采样是一次性 preprocessing；训练本身仍是普通 SFT。之后还可以在 Sampling-SFT checkpoint 上继续 GRPO，论文中这一组合在 math 上是整体最强。

12.7 核心公式与数学直觉

p_C(x) = p(x)·1[x∈C] / Σ_{x'∈C} p(x')

这是最核心公式：把 base model distribution 截断到“正确/信息等价”集合 C 上再归一化。它是所有满足信息约束的分布里，KL(π || p) 最小的唯一解。直觉：既然必须正确，那就在正确答案里尽量“像自己”。

min_{π∈P_C} KL(π || p)

与 vanilla SFT 最大区别：SFT 直接拟合 expert empirical q；这里先寻找最接近 p 的等价数据 distribution，再做相同 cross-entropy。与 on-policy RL 区别：RL 通过 rollout+reward 在 p 附近找成功样本；projection sampling 则借 expert privileged information 进入 p 本来很难命中的成功区域。

E_cost ≈ |D| · N_MCMC · T² / (4B)

预处理成本随 trajectory length T 近似二次增长，随 block size B 增大而下降。B 是关键 efficiency/approximation trade-off：小 B 修改更细、更接近理想 MCMC，但采样成本更高；大 B 更省但 proposal 粗。

12.8 Toy Example

假设一个 agent 要学会调用新工具 solve_chemistry。专家轨迹是：“parse molar ratio → derive stoichiometric coefficient → normalize integers → answer”，但 base model 平时喜欢先写已知量、再列方程。直接 SFT 会逼它学专家罕见的轨迹风格。Projection sampling 先固定“最终配平必须正确、关键化学关系不能丢”的 C，然后让 base model 根据 expert trace 提议一个更自然的版本：“先列元素守恒 → 解系数 → 化最简整数”。若新 trace 在 base model 下 likelihood 更高且仍满足 C，就接受。反复若干步后得到既正确又更 on-policy 的 trace。SFT 学它时参数不必为模仿陌生 style 大幅移动；如果之后做 RL，初始 policy 已经能更频繁地产生成功 trajectory，reward 不再全 0。

13. Baseline Deep Comparison

Baseline合理性失败点本文差异
Vanilla SFT直接吃高质量 expert traces，最简单。off-policy distribution shift，泛化/retention 弱。objective 不变，先改数据分布。
Rewrite SFT让 base model 一次性改写 expert，低成本。没有逐步 MCMC refinement；Chemistry 明显弱于 full sampling。多步 projection 而非一次 rewrite。

Strongest baseline：Math 上 GRPO/UFT 是最重要的 strongest baselines，因为它们直接代表“on-policy RL generalizes”的主张；Chemistry 上 OPSD 是关键 baseline，因为 reward 混合格式更难写。

14. Experiment Setup Deep Dive

Tasks：Chemistry 使用 SciKnowEval Chemistry L-3，2400 problems（1800 train/600 test），expert traces 由 GPT-5 生成；Math 使用 MATH Levels 3/4/5，8230 train/1024 test，自带 expert solutions；Medical 使用 HuatuoGPT-o1 SFT 19,704 questions，测试从 RL set 随机取 1000 unseen questions。Models：Chemistry Qwen2.5-7B-Instruct、Olmo-3-7B-Instruct；Math Qwen2.5-3B；Medical Qwen2.5-7B-Instruct。

Evaluation：全部主要 benchmark 用 single-shot accuracy；Medical correctness 用 GPT-5-mini grader。Retention 用 MMLU、GPQA、AMC、MATH500、GSM8K 等未针对新任务训练的能力。官方代码给出的 SFT recipe 包括 learning rate 5e-5、2 epochs、batch size 16（Chemistry/Math）。

Research Question A：Sampling SFT 能否比 vanilla SFT 泛化更好？
B：能否达到/超过 on-policy RL，同时更少 forgetting？
C：收益来自简单 rewrite 还是多步 MCMC？
D：数据必须针对 learner 本身投影吗？
E：Sampling SFT 能否成为 RL 更好的 initialization？

15. Metrics 教学式解释

Single-shot accuracy：每题一次生成的正确率，适合测真实 policy 的典型行为，不会被 best-of-N 掩盖。Prior capability average：多个旧任务 accuracy 的简单平均，用于测 forgetting；缺点是各 benchmark 难度和重要性被等权。Sequence log-likelihood under base model：越高表示 boosted trace 越“像 base model 会生成”；它是 distribution alignment proxy，不等于能力。Information preservation accuracy：boosted dataset 自身正确率，越高越好；Chemistry/Math/Medical 约 94–96%，说明仍有 4–6% preservation failure，不能忽略。

16. Results Deep Dive

  1. Chemistry：Qwen Sampling SFT 66.0%，vanilla SFT/OPSD 均 61.8%。对 base 34.3 是大幅新能力提升；相对 strongest OPSD +4.2 points。
  2. Chemistry retention：Sampling SFT prior avg 58.6%，base 59.7%，只掉 1.1 point；vanilla SFT 52.0，说明 distribution alignment 与少 forgetting 强相关。
  3. Hard MATH：Qwen2.5-3B Sampling SFT 0.495，GRPO 0.457、UFT 0.470、base 0.315；说明不靠 policy gradient 也能超过两种 on-policy baseline。
  4. MATH500 OOD：Sampling SFT 0.582，GRPO 0.313、UFT 0.297，差距巨大，是论文 strongest result；但需要警惕训练 expert solutions 与 benchmark family 的结构相关性。
  5. Sampling SFT + RL：MATH(3,4,5) 0.545、MATH500 0.652、GSM8K 0.830，是整体 strongest model，说明 sampling 与 RL 不是替代关系，更像更好的 policy initialization。
  6. Medical weakness：Sampling SFT 45.8%，OPSD 46.6%，任务本身并未赢 strongest baseline；优势主要在 prior avg 51.6 vs OPSD 50.1。说明 open-ended/LLM-judge setting 下新能力 gain 不稳定。
  7. Cross-model mismatch：用为 Olmo boosted 的数据训 Qwen，Chemistry 57.33%，低于 vanilla SFT 61.8；这是非常强的 mechanism evidence：boosted data 不是普遍“更高质量”，而是 learner-specific。
  8. Preservation：boosted dataset accuracy Qwen chemistry 94.33%、Olmo 93.94%、math 95.33%、medical 95.86%。这既支持 preservation 大体成立，也暴露方法并非无损。

Strongest result：MATH500 0.582 vs GRPO 0.313；再接 RL 到 0.652。Weakest result：Medical task accuracy 45.8 < OPSD 46.6。Failure case：cross-model boosted data 57.33 < vanilla 61.8。Trade-off：训练阶段省掉 RL rollout 不代表总 compute 更低，MCMC preprocessing 也可能很贵，尤其长 trajectory。

Table 1：最关键不是单个新任务分数，而是“New Task Domain + Prior Capabilities”并列，这迫使方法同时回答 learning 与 forgetting。Math 部分 Sampling SFT 在 MATH500 的跃升最异常、也最值得复现。Figure 3：boosted traces 的 base-model likelihood 分布右移，是机制链条第一环：采样确实让数据更 on-policy-like；但它不能单独证明 likelihood 提升导致泛化。MCMC step scaling figure：随着 steps 增加 KL/likelihood改善，accuracy总体上升但中间有波动，说明不是单调因果。Appendix Table 2：Olmo 上 Sampling SFT chemistry 58.3，低于 OPSD 59.7，但 prior avg 61.7 最高；说明“泛化全面超过 RL”不能跨模型绝对化。Cross-model mismatch experiment：虽不是主表最显眼项，却是最强机制验证之一，因为它排除了“只是 rewrite 变好”的简单解释。

18. Ablation / Mechanistic Analysis

Rewrite SFT 相当于 0-step MCMC：去掉 iterative projection 后效果下降，说明多步采样有额外价值。把 boosted/original 50/50 混合，Qwen Chemistry 62.14%，介于 vanilla 与 full boosted 之间，呈现 distribution interpolation。把 Olmo-targeted boosted data 给 Qwen，性能崩到 57.33%，说明 projection 必须绑定 learner。Dataset likelihood histogram 验证“更 on-policy”这一中间变量，但严格因果还缺 compute-matched、likelihood-matched synthetic controls。

19. Claim vs Evidence

Authors Claim：sampling 是通用 post-training primitive，可让 SFT 泛化更好、忘得更少，并可帮助 RL hard examples。
Experiments Actually Show：在 Chemistry/Math/Medical 三类任务、Qwen+Olmo 上，learner-specific projection 多数 setting 改善 SFT；Math 上可超过 GRPO/UFT；retention 普遍较强。
What Is Not Yet Proven：没有证明在 frontier-scale models 上仍成立；没有完整 compute-matched 对比 MCMC preprocessing vs RL rollouts；Medical 依赖 GPT-5-mini judge；理论 MH stationary target 与实际近似实现存在 gap；“sampling 可普遍替代 RL”并未被证明。

20. Contribution

Contribution 1 — New Objective/Formulation：把 expert-data adaptation 表述为 KL information projection。Contribution 2 — New Mechanism：blockwise MCMC projection sampling，把 off-policy expert traces learner-specifically on-policy 化。Contribution 3 — New Empirical Finding：SFT 的弱泛化有相当部分可通过数据分布而非 loss 修复。Contribution 4 — New Post-training Composition：Sampling SFT→RL 的组合明显强于单独 RL。不是新 benchmark。

21. Limitation & Failure Modes

Authors' / inherent：需要定义 information-equivalence C；开放域只能依赖 grader；MCMC 有额外预处理成本。Additional：专家本身错误会被 preservation 约束固化；GPT-5 生成 expert traces 引入 closed-model dependency；T²/B cost 对长 agent trajectory 可能迅速膨胀；base-model likelihood 高不一定代表 reasoning mechanism 更正确，可能只是语言风格更像；若 projection 过强，可能把稀有但真正新颖的 expert reasoning“同化”掉；医疗评估的 LLM-as-judge bias 明显；没有直接测 calibration、diversity collapse 或 reward hacking。

22. Reproduction View

官方代码已公开。最小复现建议不要一上来跑全部三域：先 Qwen2.5-7B-Instruct + Chemistry。四组：SFT、Rewrite SFT、Sampling SFT、OPSD。固定同样 1800 train / 600 test，SFT lr=5e-5、2 epochs、batch=16；记录 Chemistry accuracy + MMLU/GPQA/AMC/MATH500/GSM8K retention。然后做最关键 mechanism test：把 Olmo-targeted boosted data 喂给 Qwen。如果能复现“learner-specific data 显著更好”，核心 claim 就站住一半。第二阶段再做 MCMC steps × block size 的 compute-quality frontier。

23. Research Value

Baseline Potential：高，尤其 post-training/continual learning。Migration Potential：极高，可迁到 agent trajectories、tool-use RL、multimodal reasoning。Systems Potential：中等，关键是 preprocessing compute scheduler。Attack Potential：可攻击 equivalence checker，让错误 trace 被高 likelihood 接受。Evaluation Potential：可建立“capability gain vs prior retention vs projection compute”三维评估。Benchmark Potential：可构造 base policy 零成功率但有 expert trace 的 hard-task benchmark。New Paper Potential：非常高：把 projection sampling 用于 long-horizon agent credit assignment，是最自然的下一步。

24. Migration Analysis

方向 A：Projection Sampling for Long-Horizon Agent RL

Original Problem →hard agent tasks 上 rollout 全失败，terminal reward 无学习信号。Transferable Mechanism →从 expert successful trajectory 出发，投影到 current agent policy 附近。New Research Question →能否在不依赖 dense critic 的情况下生成 learner-native successful trajectories？Method Modification →把文本 equivalence C 改成 environment-verified state/action constraints；每个 block 是若干 tool actions；proposal 可看到 expert trajectory，但 acceptance 同时检查环境可执行性和 policy likelihood。Minimum Experiment →Qwen3-8B agent；WebShop/ALFWorld；挑 base pass@1<10% 的 hard subset；比较 SFT expert、GRPO、OPSD/SRPO 类方法、Projected-Trajectory SFT、Projected SFT→GRPO；固定 environment steps budget，记录 success、rollouts-to-first-success、prior benchmark retention、sampling tokens。Metric →success rate、sample efficiency、trajectory KL、retention、cost。Expected Contribution →解决 zero-reward hard regime。Risk →trajectory equivalence 很难，环境 stochastic。Collision Risk →中高，需要仔细对比 hindsight relabeling / privileged distillation。

方向 B：Multimodal Projection Sampling for Video Reasoning

Original Problem →video reasoning expert traces 与小 VLM 自身 reasoning distribution 差距大。Transferable Mechanism →信息约束下的 learner-specific projection。New Research Question →能否把 GPT-级视频 CoT 转成小 Video-VLM 可学习的 reasoning trace，同时不丢 temporal evidence？Method Modification →C 同时约束答案正确 + evidence timestamps/frame IDs 保持；proposal 只改 reasoning text 和 evidence ordering。Minimum Experiment →LLaVA-OneVision-7B；VideoMME/EgoSchema；构造 expert CoT；比较 vanilla SFT、rewrite、projection SFT；测 accuracy、evidence-frame recall、MMLU retention。再与 VETO 组合测试压缩后 evidence 是否仍保留。Expected Contribution →把 post-training distribution alignment 与 video acceleration 联起来。Risk →evidence annotations 成本。Collision Risk →低到中。

25.1 RL Deep Dive

RL Formulation（作为对照）：state 是 prompt/partial reasoning，action 是 next token/segment，policy 是 LLM，trajectory 是完整 solution，reward 多为 correctness，GRPO 用 group rollout 的相对 reward 构造 advantage。本文自身不是 policy-gradient RL，而是在 RL 最弱的“成功 trajectory 不可达”区域，用 expert-conditioned MCMC 生成更接近 policy 的成功数据。Reward Analysis：最大价值是减少对 reward design 的依赖；Chemistry 混合 multiple-choice/free-form，RL reward 更麻烦。Credit Assignment：本文没有真正解决 token-level credit assignment，而是绕开它：把整条成功 trajectory 搬近 policy。Reward hacking：转化为 equivalence/grader hacking 风险。Training Efficiency：论文给出 preprocessing cost 近似 |D|N_MCMC T²/(4B)，但没有足够完整的 GPU-hour/wall-clock compute-matched RL 对比，因此不能直接断言更便宜。

26. Attack / Verification Lens

可以做 Equivalence Boundary Attack：寻找语义已改变但 grader 仍判 equivalent 的 candidate，让 MCMC 偏向高 likelihood 错误轨迹。也可做 black-box probe：测不同 base model 对同一 expert trace 的 projection divergence，作为“learner-native distance”指标。对 continual learning，可定义 Projection Retention Curve：新任务 gain 相同条件下，projection KL 越小是否旧能力越稳定。

28. 如果只让我记住这篇论文

  1. 论文挑战的不是 RL 本身，而是“RL 优势全部来自 objective”这个解释。
  2. 它认为 on-policy data distribution 是 RL 泛化和少遗忘的重要来源。
  3. 核心做法是在保持 expert information 的约束下，把轨迹投影到 base model distribution 附近。
  4. 数学目标是 base model 在等价集合 C 上的条件分布，也就是 KL 最近的正确分布。
  5. MCMC/Metropolis–Hastings 是把 off-policy expert trace 逐步搬过去的工具。
  6. Math 上 Sampling SFT 可超过 GRPO/UFT，MATH500 的差距尤其大。
  7. 它并不总赢：Medical task accuracy 低于 OPSD，Olmo Chemistry 也不是 task-score 最强。
  8. 最有说服力的机制证据是 learner mismatch：为 Olmo boosted 的数据拿去训 Qwen 会明显变差。
  9. Sampling SFT 再接 RL 比单独任何一个都强，说明二者更像互补而非替代。
  10. 最值得迁移到 Agent 的方向，是用 expert trajectory 帮 zero-reward hard tasks 构造 learner-native successful rollouts。

Cross-Paper Synthesis

两篇论文表面一个讲 video token，一个讲 post-training，但共同趋势非常清楚：不要只优化最终对象，要优化“中间表示与后续计算/学习者之间的匹配关系”。 VETO 不是单纯把 token 数变少，而是先把空间表示变成适合 temporal matching 的形态；Sampling SFT 不是单纯换 loss，而是先把 expert data 变成适合当前 learner 的形态。

它们都体现“ordering / distribution alignment > brute-force objective”。VETO 的 intra-first 比 inter-first 更快；Sampling SFT 的 learner-specific boosted data 比跨 learner 数据更好。两者都告诉我们：同样的信息量、同样最终预算，路径和接口分布会决定效率与稳定性。

最适合作 baseline 的是 VETO，因为 plug-in 清晰且系统指标完整；最适合产生新 training idea 的是 Finetuning with Sampling；最适合形成 benchmark/metric 的交叉点，是“在压缩/投影后，关键 evidence 是否仍可达”。

Combined Research Opportunities

机会 1：Learner-aware Video Compression

VETO 当前根据视觉 feature similarity 合并，但 Sampling SFT 提醒我们“最好的表示不是全局最好，而是对当前 learner 最可学习”。可以把 compression objective 从 feature reconstruction 改成 LLM-native likelihood / answer-preserving projection：候选 merge 若让当前 VLM 的 evidence-conditioned answer distribution 偏移太大就拒绝。最小实验：固定 25% token budget，在 VideoMME 上比较 cosine VETO 与 learner-aware acceptance VETO，测 accuracy、latency、KL(output distribution)、critical-event recall。

机会 2：Compressed-Trajectory Agent RL

对长 horizon agent，先把 trajectory 做结构化 compression（类似 VETO 的“先局部、后全局”），再用 projection sampling 把 expert compressed trajectory 搬到 current policy 附近。局部先合并重复 tool observations，时间轴只保留 state-changing events；之后 MCMC 重写 reasoning/action chunks。目标是同时减少 context cost 与 zero-reward problem。

Collision / Overlap

Strongest Collision：Compression / Projection 是否真的 preservation？ VETO 假设 cosine-similar token/frame 可以合并而不伤任务；Sampling SFT 假设语义等价轨迹可以重写而不伤 expert information。两者的共同薄弱点都是 preservation oracle：一个用 representation similarity，一个用 correctness/grader。新研究可以统一为 Task-Conditional Preservation under Budget：给定 compute/token budget，最大化下游任务不变性，而不是仅最大化 feature similarity 或 likelihood。
