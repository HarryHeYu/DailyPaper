Tier S Learning What to Skip: Counterfactual Credit Assignment for Efficient Multi-Agent LLM Workflows — RL × Multi-Agent × Efficiency

Paper

人话版 / Background / Core Method / Main Finding

把工作流组件是否执行改写为反事实 credit assignment：完整轨迹给 factual reward，受控 skip intervention 给 counterfactual outcome，再训练 action-specific safety model。关键价值是把 Agent workflow efficiency 从静态删模块变成 state-conditioned causal decision。论文覆盖数学推理、选择题 QA、代码生成和两个 instruction-model family；可获取摘要明确报告 token cost 下降且 aggregate accuracy 持平或改善，并指出 shared-error 使“多 Agent 一致”不足以成为安全跳过依据。最值得迁移：把 component-level marginal utility 下沉到 token/KV/tool-call 级。

Depth Audit

Method：见上面的机制链；Experiment：仅使用可核验公开信息，不猜未报告数字；Claim vs Evidence：摘要支持核心机制与主结果，但未获取到的逐表数字标为未报告。Contribution：机制/系统层创新；Limitation：跨模型、长 horizon、真实 serving 分布仍需核验。Migration：均给出可执行交叉实验，优先测 wall-clock、memory、quality，而非只看 FLOPs。

Tier S Just-In-Time Agent Memory with Runtime Agentic Research — Agent Memory × RL

Paper

人话版 / Background / Core Method / Main Finding

JAM 反对 Ahead-of-Time 的 query-agnostic memory 压缩：Memorizer 保留完整 raw history 到层次 page-store，Researcher 在请求到来后迭代 retrieve/inspect/integrate。Memory-Gym 覆盖 6 domains、9 task types；Researcher 先 verified-trajectory SFT，再 Hint-guided GRPO。核心迁移点是让 memory retrieval policy 与 KV budget 联合优化。风险是 raw history storage 仍在、online research 增加 TTFT，summary/navigation 错误也会传播。

Tier S ASPIRE: Asynchronous Batched Self-Speculative Decoding for Long-Context LLM Inference — Inference Acceleration

Paper

人话版 / Background / Core Method / Main Finding

ASPIRE 针对 long-context decode 的 KV-read/memory-bandwidth 瓶颈。它用 unified mixed forward 让 drafting 与 verification 共存于同一 batch；per-request scheduler 根据 acceptance rate 与 batch-aware cost 独立决定何时 verify；intra-draft refresh layer 降低 sparse-context staleness。3 models、5 reasoning/long-context benchmarks 上，相对 AR decode throughput speedup 1.70–4.58×，相对 strongest prior self-spec baseline 平均 speedup 再提升约 27%。最值得迁移到 tool-interrupted Agent serving。

Depth Audit

Method：见上面的机制链；Experiment：仅使用可核验公开信息，不猜未报告数字；Claim vs Evidence：摘要支持核心机制与主结果，但未获取到的逐表数字标为未报告。Contribution：机制/系统层创新；Limitation：跨模型、长 horizon、真实 serving 分布仍需核验。Migration：均给出可执行交叉实验，优先测 wall-clock、memory、quality，而非只看 FLOPs。

Tier A Spexis: Speculative Lookahead Scheduling for LLM Inference — Inference Acceleration

Paper

人话版 / Background / Core Method / Main Finding

把 speculation 变成 multi-GPU serving 的新并行轴，并用 lookahead scheduler 预测 speculation quality 与未来 memory pressure；基于 vLLM，在多 GPU 配置下相对最优 pipeline+tensor parallel baseline 最高加速 34%。摘要未给完整 TTFT/TPOT，不能把 throughput speedup 等同于所有 latency 指标都改善。

Research Value & Migration

建议复现核心机制并补齐真实 latency/throughput/memory 曲线；与 Agent workload 或动态 budget controller 结合。Worth Deep Reading: YES。

Tier A Unified Spatiotemporal Token Compression for Video-LLMs at Ultra-Low Retention — Video Acceleration

Paper

人话版 / Background / Core Method / Main Finding

把两阶段时空压缩改成 global token pool allocation：attention 衡量贡献、semantic similarity 衡量冗余，未选 token clustering merge/refill，LLM 内再 text-aware merge。约 2% visual-token retention 保留 90.1% baseline performance，FLOPs 约为 2.6%；作者同时报告 end-to-end latency 和 memory 下降，因此不只是 FLOPs-only。

Tier A Fast Autoregressive Video Diffusion and World Models with Temporal Cache Compression and Sparse Attention — Video Generation Acceleration

Paper

Tier A Flow caching for autoregressive video generation — Video Generation Acceleration

Paper

人话版 / Background / Core Method / Main Finding

每个 autoregressive video chunk 维护独立 caching policy，再用 importance-redundancy KV compression 控制固定内存。MAGI-1 2.38×、SkyReels-V2 6.7× speedup；VBench 分别 +0.87 与 -0.79。它的价值在于报告真实 wall-clock speedup，而不是只报 FLOPs。

Research Value & Migration

Tier B ReasonAlloc: Hierarchical Decoding-Time KV Cache Budget Allocation for Reasoning Models — Reasoning × Inference

Paper

人话版 / Background / Core Method / Main Finding

离线 layer-wise Reasoning Wave + 在线 head-wise utility allocation。MATH-500/AIME 2024 上优于 uniform R-KV、SnapKV、Pyramid-RKV，优势在 128–512 token 小预算最明显。训练免费、可插拔。

Tier B CompressKV: Semantic-Retrieval-Guided KV-Cache Compression for Resource-Efficient Long-Context LLM Inference — Inference Acceleration

Paper

人话版 / Background / Core Method / Main Finding

用 Semantic Retrieval Heads 做 token retention，并按 layer eviction error 分预算。LongBench QA 用 3% KV 保留 >97% full-cache performance；Needle-in-a-Haystack 用 0.7% KV storage 达 90% accuracy。摘要未给 wall-clock speedup，因此不能把 cache reduction 当作 latency reduction。

Connection / Potential Use

适合作为 baseline、evaluation 或机制迁移参考；优先验证真实系统收益与质量 trade-off。

Tier B Hierarchical Control in Multi-Agent Games: LLM-based Planning and RL Execution — RL × Multi-Agent

Paper

人话版 / Background / Core Method / Main Finding

LLM 做 centralized high-level strategy controller，RL skills 做 low-level reactive execution。2v2 King of the Hill 中 LLM+RL win rate 46.4%，behavior tree 51.5%，p=0.103；二者均显著优于 Flat RL。n=15 用户研究中 60% 认为 LLM+RL 最像人，p=0.027。

Connection / Potential Use

适合作为 baseline、evaluation 或机制迁移参考；优先验证真实系统收益与质量 trade-off。
