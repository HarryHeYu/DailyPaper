RL Highlights

MemPilot 的 prefix marginal utility、TROPIC 的 compositional verified path、PrisMem 的 capability-level search共同指向结构化 credit assignment。值得追踪 reward 是否真对应最终能力、是否可被 shortcut，以及 rollout/sample efficiency。

Agent / Multi-Agent Highlights

Memory 设计明显从 AOT summary → JIT retrieval → learned orchestration → self-evolving program 演进。raw history 的保留提高 fidelity，也把 privacy、storage、deletion closure 拉回核心系统问题。

Video Acceleration Highlights

RealtimeWAM 报告约 25× H100 end-to-end speedup 且性能下降小于 1%；VETO 报告最高 45% faster inference。今天这两篇都提供真实速度信号，优先级高于只给 FLOPs reduction 的工作。

Inference Acceleration Highlights

DeferKV 改“何时删”，Behavior-Preserving KV 改“按什么标准删”，TaSQ 改“如何极低比特存”。三者机制正交，值得做组合与统一 TTFT/TPOT/throughput/quality benchmark。

Tier S — MemPilot: Orchestrating On-Demand Multimodal Memory Curation for LLM Agents Agent + RL + Multimodal

Paper

人话版

把 query-time memory 使用建模为多步 RL：policy 在压缩 memory bank 与 raw multimodal history 之间选择 Retrieve/Curate，并决定证据量、curation 指令、后端 LLM/VLM 与视觉访问。核心创新是 objective-wise advantage decoupling 与 prefix-based marginal utility，用于 quality/cost/latency 多目标和逐步 credit assignment。最值得迁移到“reasoning/tool/memory 统一 test-time compute router”。
