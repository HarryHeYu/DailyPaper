02 · Paper 1 — Decoupling Exploration from Optimization in RLVR

基本信息：Saif Punjwani、Micah Goldblum；Columbia University（计算机科学/电气工程）；arXiv:2610.10536v1，2026-10-07 UTC 首次提交；截至本报告检索时为预印本，未核实正式 Venue。
论文：全文 HTML / PDF；代码：JAX/Flax 实现；检查点：Hugging Face。
方法名：Exploration-Distillation（ExpDis）；任务：RL with Verifiable Rewards（RLVR）。

12.2 · 一句话定位

解决“在 LLM 推理强化学习中，增加探索多样性会同时污染最终模型”的结构性冲突：让探索者大胆试错、让学生只接收可验证的高质量发现。

12.3 · 人话版（约 330 字）

假设你在训练一个数学推理模型：普通 RL 只奖励答对，模型很容易反复使用少数熟悉的解法；你给它加“新奇度奖金”，它就更愿意尝试新思路，但也可能变得啰嗦、跑题、甚至遗忘原来擅长的知识。作者的办法不是寻找一个神奇的 reward 权重，而是干脆不要让探索模型成为最终交付模型。先让一个或多个 explorer 带着 novelty bonus 做 RL，收集各式推理轨迹；用数学答案校验、长度限制、重复循环检测筛掉差样本，并对每道题保留一条最短正确解；然后从相同基座出发的 student 先做 SFT 吸收这些解法，再只用正确性 reward 做 DAPO。这个流程还能多探索者并行、多轮循环。在 Qwen3-4B 上，五个主评测的平均 pass@1 从 DAPO 的 62.58 提升至 66.50，pass@64 从 81.14 提升至 87.63。关键不是“越新奇越好”，而是探索与可靠部署之间建立了一道可审计的轨迹过滤接口。

12.4 · Background & Research Gap：为什么直接鼓励 novelty 会失败？

RLVR 通常从已训练的 LLM 出发，对一道数学题采样 G 条回答，用程序或规则检查最终答案是否正确，再根据组内相对优势更新 token 概率。GRPO、Dr. GRPO、DAPO 等优化器解决了不同的稳定性与长度偏置问题，但奖励大多是“答对/答错”。这类 reward 并不覆盖模型的通识知识、指令遵循、逻辑推理甚至代码能力。模型可以在数学训练集上得分更高，却同时丢失训练奖励没检查到的能力。

具体例子：对“求满足某条件的整数 n”这一题，模型习惯代数变形。增加 novelty 后，它可能试数论同余、图论构造、暴力枚举，也可能生成很长但毫无意义的推理。只按最终正确性训练会抑制稀有但有价值的解法；只按 novelty 奖励又可能鼓励“新奇垃圾”。这不是单纯的优化器问题，而是单个策略同时承担发现与稳健输出两个目标造成的目标耦合。作者把探索策略 μ 与学生策略 π 分离，并只传递经验证的成功轨迹；这样学生不必继承探索者的坏参数更新。

与 ReST/STaR 自训练的区别在于：普通自训练从同一模型筛正确样本，主要扩大正确解监督；ExpDis 刻意训练一个不同目标的 explorer，使它去搜寻基座当前不常生成的解法。与 R²PO/ICE 等共享权重或共享主体的探索方法相比，这里的参数隔离更彻底。与 Go-Explore 的思想类似之处是“先发现，再可靠复现”，但任务对象是 LLM 的完整 reasoning trace，而非经典环境中的状态轨迹。

12.5 · Core Insight：风险不是 novelty 本身，而是奖励施加位置

作者首先观察到：直接在 DAPO 上叠加 RND novelty，确实能提高词汇多样性和 token entropy，但数学正确率并没有同步提高，且知识/指令遵循等先前能力可低于基座。这个结论来自同一训练预算下的模型对照、Figure 5/6 和附录 Table 6/7。它属于实验发现，不是一般性的收敛定理。第二个观察是：经过正确性和质量筛选的 explorer 轨迹可以提升 student，说明探索者中的“可迁移发现”与“探索造成的参数损害”可以被部分拆开。

为什么成立？student 的梯度只来自两部分：筛过的成功轨迹的交叉熵、正确性 RLVR；它不会因为 explorer 自己的高熵或奇怪输出而直接接受参数更新。这个机制同时留下两个重要假设：① verifier 的正确性足以筛出有用样本；②最短正确解能代表有价值的 reasoning。两者在数学上较合理，在开放式 Agent、代码修复和多模态推理中就未必成立。

12.6 · Method Deep Dive：逐步从 Input 到 Output

Base π₀ + 训练题库 D → Explorer μ（DAPO + 正确时 novelty bonus） → 采样多条 reasoning trajectories → Verifier + 长度/循环过滤 → 每题只保留最短正确轨迹，单轮最多 500 条 → Student SFT → Student correctness-only DAPO → π₁ → 可选 K 个 explorer 并行；R 轮迭代（πᵣ 进入下一轮） → 部署 Student πᴿ

Step 1：初始化与探索者 RL

将基座 π₀ 复制为 explorer μ；训练输入是 DAPO-Math-17K 中不放回抽取的题目，输出是包含中间思考与 \boxed{} 最终答案的 completion。每次 RL 更新采 4 道题、每题 16 个 rollout。explorer 使用 DAPO clipped objective，但 reward 在答对时额外加 novelty。注意论文的 novelty 不是任意输出都奖励：必须 r_correct=+1 才启用；这样错误且新奇的回答不会轻易靠刷 bonus 反超正确回答。失败模式仍包括 reward 仅检查最终答案、verifier 错判，以及 novelty 特征被表面重写欺骗。

Step 2：RND 从隐藏表示估计“没见过”

在模型约四分之一、二分之一、四分之三深度的中间层，对 completion token 的隐藏状态取均值，送进固定随机目标 MLP 与可训练预测 MLP。若预测器很难拟合当前轨迹特征，误差大，就把它当作相对新颖的轨迹。每层网络为三层 MLP、宽度及输出 512；预测器在每个 policy update 后更新，目标网络冻结；每个 explorer/round 重新初始化 RND 网络。RND 的本质是“当前预测器的熟悉度”，不是语义上的真正新发现，因此作者又额外测 semantic diversity。

Step 3：可审计过滤而不是全量知识蒸馏

对每条 explorer rollout 检查最终 boxed answer 是否正确、是否在 32,768 token 限制内结束、是否存在重复循环。通过后，每道题只留一条最短的正确轨迹；单轮最多 500 条。这里“最短”减少冗长噪声，也防止容易题因为生成了很多正确解而过度主导 SFT。但它可能丢失长而有启发性的证明，也可能筛掉新颖但暂时不能通过 verifier 的方法。过滤器是整篇论文真正的可靠性边界。

Step 4：学生先吸收，再自我强化

学生从 π₀（多轮时从上一轮 πᵣ₋₁）出发，在过滤集上做 completion-only cross-entropy SFT 两个 epoch，再执行标准 DAPO，reward 仅包含正确性与 overlong penalty，不含 novelty。为什么需要两个阶段？SFT 将低概率但正确的轨迹引入学生分布；随后的 on-policy RL 把这种启发转化为学生自己能稳定采样的策略。Table 8 表明缺一不可。

Step 5：两个扩展维度

并行宽度 K：相同起点、不同随机种子训练 K 个 explorer，汇总轨迹后统一过滤。多个 explorer 可以在固定总更新预算下并行运行，论文强调不增加其设置中的 wall-clock，但这依赖足够硬件并行资源，不等于 GPU/TPU 总消耗必然不变。迭代深度 R：把训练题拆为不重叠的 R 份，每轮从上一轮学生继续探索/过滤/SFT/RL；四轮的 novelty 权重按 0.75→0.50→0.35→0.25 退火。主实验的总 explorer 更新 200、student 更新 100，在各 explorer/round 间切分，非每轮额外增加 300 次更新。

12.7 · 核心公式、变量、方向与直觉

rexplorer(τ) = rcorrect(τ) + λ·rnovelty(τ)·𝟙[rcorrect(τ)=+1] + roverlong(τ)

τ 是一条完整 reasoning trajectory；r_correct∈{−1,+1}；λ≥0 控制探索偏好；r_novelty≥0；r_overlong∈[−1,0] 惩罚过长。最大化 explorer 的期望回报意味着偏好“正确且表示新颖”的轨迹；学生不优化此目标。主单轮实验 λ=0.5，多轮采用退火。若 λ 太小，探索者接近普通 DAPO；若过大，虽然 bonus 只给正确轨迹，但对训练稳定性、成功轨迹分布和学生可学性仍可能造成影响。Table 7 中 λ=2 时 explorer 词汇多样性最高而 student 最差，直接否定了“新奇越大越好”。

rnovelty(τ) = (1/|L|) Σℓ∈L (1/√d) ‖f*ℓ(hℓ(τ)) − fθ,ℓ(hℓ(τ))‖₂

L 是选定的中间层集合；hℓ 是 completion 平均隐藏特征；f* 为固定随机目标，fθ 为训练预测器；d 是输出维度。RND 与常见的语义 embedding 距离不同，它奖励的是预测器对当前隐藏状态的拟合误差。因 predictor 会学习，reward 非平稳；同时均值池化可能掩盖少量关键 token 的局部创新。可复现时必须保证 predictor 更新频率与训练 rollout 采样策略一致。

LSFT = − Σ(x,τ)∈Dfiltered Σi log πstudent(τi | x,τ<i)

学生 SFT 最小化正确轨迹 token 的负对数似然；随后的 DAPO 使用组内 advantage 与 asymmetric clip（ε_low=0.2、ε_high=0.28）强化正确采样，论文设置 KL β=0。它与只用 DAPO 的 strongest baseline 最大差异不在最终 RL objective，而在 RL 之前额外引入了来自另一策略的成功轨迹分布。论文采用 Dr. GRPO 的固定归一化以避免长度偏置，且使用 dynamic sampling、overlong filtering。

pass@k = (1/N) Σi=1…N [1 − C(n−ci,k) / C(n,k)]

n 是对一道题生成的样本数，cᵢ 是正确样本数，k 是从中无放回抽取的次数。pass@1 接近单次成功率，pass@64 衡量有足够多尝试时能否至少解对一次；它们不是“同一个准确率换个写法”。如果某题 64 次里仅 1 次正确，则该题 pass@1 估计为 1/64，pass@64 为 1。大 k 指标容易被高采样成本掩盖，必须与 token budget、延迟一起看。

12.8 · Toy Example：四道数学题的探索—蒸馏

设学生基座对题 A、B、C、D 的单次正确率分别是 0.8、0.6、0.1、0。普通 DAPO 常在 A、B 上反复得到成功轨迹，而 C 很难碰到新解。我们复制两个 explorer：第一个对 C 试“分类讨论”，第二个试“构造不变量”。每个 explorer 为 C 生成 4 条轨迹，假设其中只有两条答对，长度分别 780 与 430 token；其余有答案错误或 2000 token 重复循环。过滤后只保留 430-token 正确轨迹，D 仍无合格轨迹。学生 SFT 学会 C 的解法，再用自己的 rollout 做 DAPO。如果 C 的正确率由 0.1 提到 0.35，说明发现被吸收；若 B 的正确率从 0.6 降到 0.3，说明过滤/SFT 仍可能有副作用，不能因为 C 提升就声称全面安全。

这是假设性手算示例，不是论文实验数据。它解释为什么要统计 per-problem 覆盖率、accepted ratio、轨迹长度分布以及未监督任务能力，而不能只看最终均值。

15 · Metrics 教学：测什么、怎样误导？

pass@1 ↑：一次回答正确的概率估计，是用户最直接感知的能力，但对随机种子和题目难度敏感。pass@64 ↑：64 次尝试至少成功一次的概率估计，体现潜在可搜索能力；不等于 64 次 majority vote，也不意味着 64 次生成在生产环境可负担。Token entropy ↑/↓：下一 token 分布的不确定性，越高表示采样更分散，但高熵可由无意义内容造成，不能简单认为越高越好。InterDistinct-4 ↑：所有生成的不同 4-gram 数量/总 4-gram 数，测词汇多样性，但可被换词、换标点轻易提高。Semantic diversity ↑：利用推理策略分类 embedding 对生成聚类，归一化簇数，试图捕捉不同解法；但依赖额外分类器，不能当作无误差真值。AnswerDistinct@n ↑：不同最终答案数量，错误答案越多也可能越高。Reasoning faithfulness ↑：中间推理是否支持最终答案；作者发现探索者可能牺牲它，所以仅有正确答案不足以证明过程可靠。

19 · Claim vs Evidence

Authors Claim / Actually Show

分离探索和优化可在三个基座、七个数学评测上提高准确率及 pass@k；固定训练更新预算下效果优于 DAPO。附录还证明筛选、学生 RL 都很关键；直接 novelty 奖励可能损伤旧能力。

Not Yet Proven

没有证明真正创造了预训练中不存在的算法；没有证明任何开放式 verifier 都能可靠过滤；没有证明对更大模型、真实 Agent、非数学任务、不同硬件成本核算普遍成立；也没有证明永不遗忘。

Contribution 1 [New Mechanism]：用独立权重的 explorer 与 student 进行目标隔离，靠过滤轨迹传递发现，这是本文最清楚的机制贡献。Contribution 2 [New System / Engineering]：并行 explorer + 多轮退火 + 预算切分，使探索宽度和深度可控，属于已有训练部件的系统性新组合。Contribution 3 [New Empirical Finding]：直接加 novelty 可伤害 prior capabilities，且词汇多样性不保证 student 收益。Contribution 4 [New Evaluation Protocol 的局部实践]：同时报告 pass@k、语义/词汇多样性和未监督能力；指标本身不是原创。

24 · Migration Analysis：两个不同方向

Migration A：Agent / Multi-Agent 的验证式经验迁移

Original Problem：探索模型为获得新策略损伤部署能力。Transferable Mechanism：双策略隔离 + verifier 过滤轨迹 + student SFT/RL。New Research Question：在真实工具链任务中，独立探索者是否能让 Agent 学到可复用 skill 而不增加错误调用？Method Modification：把数学答案 verifier 换成可执行单元测试、文件系统状态断言、工具调用安全检查；每个 task 保留成功且成本低的 trajectory，并加入失败恢复记录。Minimum Experiment：用 300 个可重复软件修复任务，按 200 train/50 dev/50 test 固定拆分；3 seeds；每题 explorer 8 rollout、最多 12 tool steps；对照 single-agent GRPO、novelty-on-policy、self-training、ExpDis；训练更新/工具调用数匹配；记录 trajectory lineage。Model：Qwen3-4B 或同量级 coding agent。Dataset：从 SWE-bench Verified 中筛可本地运行的 300 项，若资源不足先用 100 项。Baseline：ReAct+GRPO、直接 novelty GRPO、仅 SFT。Metric：resolved rate、tool calls、time-to-fix、test pass、回归失败率、cost/solved。Expected Contribution：验证“经验隔离”是否提升 Agent learning 的真实泛化。Risk：测试脚本不稳定、奖励稀疏、运行成本大。Collision Risk：与 Expert Iteration、Go-Explore、ReST、共享权重多探索者已有思想重叠；新意必须是可测的隔离与审计协议。

Migration B：RL reward hacking 的隔离审计与安全验证

Original Problem：单一策略可能为 novelty/奖励作弊而污染通用能力。Transferable Mechanism：将探索奖励与部署奖励分开，并记录筛选失败样本。New Research Question：哪些 verifier 漏洞会穿透“只传成功轨迹”的防线？Method Modification：构造真假混合的 verifier：允许正确 final answer 配错误中间过程、允许工具输出伪造成功标志；过滤层新增过程一致性和独立执行校验。Minimum Experiment：200 道数学/代码混合任务，每题 16 rollouts，设 0/5/10/20% 的 verifier false-positive；比较原 ExpDis、双 verifier、过程验证、无过滤；三随机种子，绘制错误经验被 student 吸收的曲线。Model：Qwen3-1.7B。Dataset：MATH500 子集 + HumanEval 可执行任务。Baseline：DAPO+novelty、普通 rejection-SFT。Metric：污染率、真实 pass@1、旧能力 retention、verifier disagreement、attack success。Expected Contribution：提出探索经验“可验证传递”的失效边界和新的污染指标。Risk：人为 verifier 错误分布可能不真实。Collision Risk：与 reward hacking、process reward verification、data poisoning 工作重叠，需做独立威胁模型。

25 · RL 专用分析：State / Action / Reward / Advantage

State：数学 prompt、已生成前缀及当前策略参数；Action：下一 token（整条 rollout 是 trajectory）；Policy：explorer μ 与 student π；Reward：程序 verifier 的 ±1 正确性、正确时的 RND novelty、soft overlong；Trajectory：完整 reasoning token 序列；Advantage：同 prompt 的 16 个 rollout 组内相对奖励形成训练信号；Objective：DAPO clipped policy optimization，KL β=0；Credit Assignment：终局 reward 通过 policy gradient 归因到生成 token，并没有真实逐步证明正确性标签。Reward Hacking：潜在路径包括伪造 boxed 格式、偶然答对但错误推理、通过 RND 预测器弱点刷 novelty。Training Efficiency：论文严格给出更新数、rollout 配额与 TPU 拓扑，但没有证明总美元成本或每个成功解所需实际能耗最低。最关键理解：student 的 reward 与 baseline 一样，改进来自数据分布与训练架构，不是部署时新添 reward。

26 · Attack / Verification Lens

可以定义 Filtered-Trajectory Poisoning Rate：被过滤接受但过程有错误的轨迹占比；Discovery Transfer Efficiency：学生新增正确解覆盖 / explorer 成功轨迹 token 成本；Old-Capability Delta：在未训练能力集合上的准确率变化。攻击者可用“正确答案 + 虚假步骤”绕过仅最终答案校验，或利用冗长/格式异常诱导过滤器错误。black-box probe 则固定同一道题生成 1、8、64 次，测新解法簇数量与 pass@k 曲线，识别只是概率 sharpen 还是搜索覆盖扩大。以上是本报告提出的验证设计，非论文已证明结果。

28 · 如果只记住这篇论文（9 句话）

  1. RLVR 的正确性 reward 只监督一小部分能力，不能保护整个 LLM。
  2. 直接奖励 novelty 可能提高熵，却同时降低正确率和旧能力。
  3. ExpDis 用独立 explorer 和 student 分担探索与优化。
  4. 探索者只在答案正确时获得 RND 新颖性奖励。
  5. 学生只接收通过 verifier、长度与循环检测的最短正确轨迹。
  6. 学生必须先 SFT 再 correctness-only RL，缺一效果变差。
  7. 多轮迭代主要改善 pass@1，并行探索者主要增加候选覆盖。
  8. 三种模型在主表的 pass@1 和 pass@64 均超过 DAPO。
  9. 最值得迁移的不是 RND 公式，而是“高风险发现→可靠过滤→稳健吸收”的接口。

03 · Paper 2 — MORCA: Offline-to-Online RL for Adaptive Cache Reuse

基本信息：Yuxiang Xiong、Ruiyan Wang、Wenqiang Wang、Teng Hu、Songhang Shen、Bohao Feng、Hongqian Deng、Ran Yi；Shanghai Jiao Tong University / Alibaba Cloud Computing / Alibaba Token Hub（原文列示）；arXiv:2610.10457v1，2026-10-07 UTC 首次提交；当前为预印本，未核实正式 Venue。
论文：全文 HTML / PDF；代码仓：MORCA GitHub（2026-10-09 检索时 README 仅“Coming soon”，有网页资源但未见训练实现，不能标为完整代码已开源）。
模型：Wan2.2-T2V-A14B、Wan2.1-T2V-1.3B；核心：终局质量 reward + 硬复用预算 + offline-to-online IQL。

12.2 · 一句话定位

将视频 DiT 的“哪些去噪步骤跳过重算”从局部误差阈值启发式，改造成在指定真实加速倍率下最大化最终视频保真度的受约束序贯决策问题。

12.3 · 人话版（约 340 字）

视频扩散模型要反复做几十轮去噪，每一轮都运行昂贵的 DiT。相邻轮的计算结果往往很像，所以可以把某轮的中间残差缓存下来，下一轮直接复用，节省大部分 DiT 计算。但“当前轮残差变化小”不代表“最终视频受影响小”：同样的局部误差在不同噪声阶段、不同视频内容上，可能被后续去噪放大或抵消。MORCA 先用实验发现 latent 特征能预测这种差异，再让一个小型强化学习策略根据当前/前一轮/上次重算的 latent、局部变化指标和剩余缓存预算，逐步决定“复用还是重算”。它先从随机但平滑的缓存策略生成的离线数据中用 IQL 学习，再做少量在线微调。为了满足用户要求的 2.4× 或 3× 加速，它先把倍率校准为必须复用多少轮，再用动作可行性约束保证数量精确。在 Wan2.2 的约 1.8× 设置，MORCA 的 PSNR 为 22.13 dB，SeaCache 为 19.91 dB；真实推理时间分别 549.19 秒和 546.99 秒。它并没有比 SeaCache 明显更快，而是在近似相同 wall-clock 时间下保留更多最终画质。

12.4 · Background & Research Gap：缓存加速究竟在少算什么？

文本到视频扩散生成从高噪声 latent xN 开始，反复执行 denoiser 及 sampler 更新，最后由 VAE 解码成视频。每轮 DiT 包含大量 attention、FFN 与条件交互；50 步就是几十次重算。减少采样步数、蒸馏成少步生成、量化、稀疏 attention 都能加速，但有些需要重新训练大模型或专用 kernel。缓存路线不改主干权重，只在某些 step 复用先前计算的中间结果，因而更轻量。

TeaCache、MagCache、DiCache、SeaCache 采用不同的误差代理、特征复用或修正策略。以 SeaCache 为例，它观察时间步调制的 latent 变化，累加“距离上次重算的变化量”，当小于阈值 δ 就复用。这相当于一个工程规则：当前看起来变化不大，就少算一次。但最终用户看的是完整视频而非某一轮残差，且要求明确加速倍率。一个固定阈值在不同 prompt、模型或显卡上未必恰好对应 3×，还可能把预算浪费在对最终质量最敏感的时间步。

具体例子：一段“人物快速转身、背景保持不变”的视频，在某个高噪声 step，整体 latent 的 L1 变化可能很小，但恰好改变了手臂位置；复用旧残差后，后续 20 步可能持续强化错误姿态。另一个 step 的变化更大，却只影响可被后续采样抵消的背景纹理。按局部变化排序会误判重要性。MORCA 的 research gap 就是：如何根据状态预测终局后果，并在严格固定复用次数的条件下进行全局分配。

12.5 · Core Insight：step error 不是 terminal error

论文 Figure 1 做了有针对性的干预：每次只在某个 step 复用缓存，其他 step 正常重算；记录该 step 残差相对 L1 误差与最终生成视频相对无缓存参考的 PSNR。不同 prompt 的 step-error 形状相似，terminal-error 曲线却差别很大，说明只用局部误差不够。Table 1 给出预测器证据：仅 step error 时预测终局 PSNR 的 RMSE=6.971 dB、Spearman=0.5288；加 step index 变成 4.421/0.7528；加 latent 特征变成 2.849/0.9357；三者都有时为 2.832/0.9361。与 step error 单独相比，RMSE 降低 4.139 dB（约 59.4%），排序相关提高 0.4073。

这是一项很强的机制动机实验：latent 中确实存在能帮助判断最终误差的信息。但预测器在受控的“只复用一步”设置上表现好，并不自动保证多个复用动作相互影响时仍准确；这正是作者采用 MDP 而非简单把预测器输出当阈值的原因。第二个 insight 来自 Figure 3：同一主干中每次复用大致省下相似计算，推理秒数与复用次数 K 近似线性，因此可把用户指定的 speedup ρ* 转换为硬预算 K。这一校准是工程近似，不是所有硬件/批大小都成立的数学定律。

12.6 · Method Deep Dive：从完整视频生成到硬预算策略

Text prompt c + noise seed + target speedup ρ* → 校准 K = C(ρ*)，初始化预算 u=0 → 每个 denoising step 提取 step-error proxy d/D、latent 低维特征 φ → 构造 zₜ=[d,D,t,连续复用次数,φ(xₜ),φ(xₜ₊₁),φ(xⱼ),u,K] → 可行动作掩码（必须仍能完成 K 次复用） → π(aₜ|zₜ)：0 重算 DiT / 1 复用缓存残差 → 更新 latent、缓存与预算，直至 50 步完成 → VAE 解码视频 训练：平滑随机 schedule 生成离线轨迹 → IQL → 在线 rollout + IQL 微调

Step 1：选择缓存粒度——跳过 DiT blocks，而非跳过全部生成

每轮先计算输入 embedding ht=E(xt)。若重算，得到 yt=B(ht,t,c)，缓存残差 Δt=yt−ht；若复用，令 ŷt=ht+Δj，其中 j 是上一次真实重算的时间步。output head 与 sampler 更新仍运行，所以不是整轮完全零成本。CFG 的有条件/无条件分支使用相同决策，但分别保存残差。最早和最后一步以及 Wan2.2 高低噪声专家切换步强制重算，防止缓存未初始化或跨专家误用。

Step 2：局部代理保留，但不让它独裁

继承 SeaCache 的谱演化过滤器得到 x̃t，计算相邻两步归一化 L1 距离 dt，并把从上次重算以来的 d 累加为 Dt。这些信号估计“当前复用可能引入多大局部偏差”，但不直接代表最终 PSNR。MORCA 同时提供 t、连续复用次数 ℓ，以及 latent 内容，使 policy 有机会学到“相同误差在不同内容/阶段的后果不同”。

Step 3：轻量 latent-aware 特征提取

原始 latent 是 C×T×H×W 的高维视频张量，直接喂给调度器会抵消缓存收益。作者对当前 xt、上一轮 xt+1、上次重算时 xj 分别提取：3D pooled spatiotemporal 特征、时间均值的 2D pooled 特征、时间方差的 2D pooled 特征。输入被汇总为 48×4×8×8 的时空张量与两个 48×8×8 张量，经 3D CNN 和 2D CNN 分支分别得到 512/256 维向量，拼接投影到 128 维，再加七个标量状态形成 135 维，送入两层 256 hidden 的 MLP。policy 输出两个动作 logits；Q1/Q2 各输出两个 action values；V 输出标量。部署时仅保留 policy。

Step 4：把 speedup 目标变成动作数量约束

对特定模型、分辨率、硬件和配置，先测不同复用次数 K 的实际秒数，拟合 K≈α−β/ρ。给定用户的 ρ*=3.0×，算出目标 K，再把“恰好复用 K 次”作为约束。每一步还记录已经复用 u 次，剩余 b=K−u；如果剩余步数不足以完成预算，就强制复用；如果预算用尽，就强制重算。这种动作 mask 比 reward 中加一项“超预算惩罚”更可靠，因为惩罚权重只能软约束，不能保证次数恰好达标。注意次数精确不等于实际秒数精确：硬件抖动、offloading、专家切换、VAE 解码会造成偏差。

Step 5：离线 IQL 先学一个不太差的 policy

每条训练轨迹必须真实运行一次视频生成，所以数据昂贵。作者不在每个 step 独立掷硬币，而是随机生成平滑阈值曲线（均值、振幅、几个控制点及 cubic smoothstep 插值），把它用作 SeaCache 的时变阈值，从而产生更有结构的 schedule。每个 schedule 生成完整视频，与同 seed 无缓存视频比较，得到一个终局 PSNR reward；把 50 个 step 转成 transition (z,a,r,z')。IQL 使用双 Q、V expectile regression、advantage-weighted behavior cloning，反复复用有限离线数据，而不是要求每次策略更新都生成新视频。

Step 6：在线微调补上离线分布盲区

从离线学好的策略出发，按当前 policy 对新 prompt 和目标倍率采样 schedule，将轨迹加入含离线数据的 replay buffer。每轮先冻结 actor，只更新 Q/V 5 epochs，使 critic 适应新分布；再联合更新 critic 与 actor 20 epochs。总计 16 轮，每轮 100 条新轨迹。保留旧数据可减少小样本策略漂移，但也会让错误的离线偏好持续影响训练；在线训练本身仍可能因为稀疏终局 reward 而不稳定。

12.7 · 核心公式与数学直觉：缓存、约束、IQL

ŷt = { Bθ(ht,t,c) , at=0 ;   ht+Δj , at=1 }

动作 a=0 运行完整 DiT blocks；a=1 跳过它们、重用上次缓存残差。究竟少算了什么？主要是被跳过 step 的 DiT block 前向计算与相应显存访存；输入 embedding、输出 head、sampler 更新、VAE 解码和 scheduler 都不是免费的。该机制不直接减少视频帧数或视觉 token 数，也不是 KV cache 压缩。总 FLOPs 理论上下降，但论文最可信的证据是 Table 2 的真实 latency。

dt = ‖x̃t−x̃t+1‖₁ / (‖x̃t+1‖₁+ε)；  Dt=Σi=t…j−1di

这是 SeaCache 的局部变化代理；δ 大通常允许更多复用，也会加大质量风险。MORCA 把 d、D 当作状态特征，而不直接阈值决策。它还增加 φ(x) 的时空池化内容，目的是近似“局部偏差在当前 latent 上会不会传播成终局错误”。

maxπ E[R(τ)]   s.t.   Σt=1…Nat=K，  K=C(ρ*)

R 仅在终局给分：r1=min{PSNR(video, reference), rmax}，其余 rt=0。优化方向是最大化同预算下最终视频与无缓存参考的一致性，不是最大化生成速度（速度已由 K 约束）。“正确加速”在这里的意思是先满足资源预算，再在可行策略中追求质量。如果改用 Lagrangian 软惩罚，就会有未达预算的风险；本文的 hard mask 能从构造上避免这种偏差。

bt=K−ut；  Āt={a∈{0,1}: 0≤bt−a≤t−1}

t 按 N→1 递减；u 是已经复用次数，b 是剩余预算。选 a 后，剩余 t−1 步必须还能放下 b−a 次复用，否则该动作不合法。Appendix D 在完整 Markov state 的假设下给出约束 MDP 到增广 MDP 的最优值等价证明。要特别区分：理论证明针对完整状态，实际 CNN 压缩后的 z 未必严格 Markov；工程实现保证的是动作次数可行，不保证 learned policy 达到理论最优 PSNR。

LQ=E[(r+γV(z')−Q(z,a))²]；  LV=E[ℓτ(min(Q̄₁,Q̄₂)−V(z))]
ℓτ(u)=|τ−𝟙[u<0]|u²；  Lπ=−E[exp(β(Q̄−V))·log π(a|z)]

IQL 的 Q 学 Bellman 目标，V 通过 τ-expectile 回归偏向较高 Q 的可实现动作，actor 则模仿离线数据中 advantage 较高的动作。γ=1（有限步终局 reward），τ=0.7，β 在离线为 1.5、在线为 1.0，实际实现还会归一化 advantage 并把 exp 权重上限裁到 30/20。β 越大越聚焦少数高优势动作，也越容易过拟合 critic 噪声；τ 越高越乐观地逼近高价值动作，但离线覆盖不足时可能偏乐观。两套 Q 取 min 减少过估计，EMA=0.999 提升训练稳定性。这里的 advantage 是“此缓存动作相对当前状态平均值好多少”，与 ExpDis 中 token 组内 advantage 的对象完全不同。

12.8 · Toy Example：5 步视频的精确缓存预算

设简化视频只去噪 5 步（真实实验是 50 步），要求恰好复用 K=2 次。按 t=5→1 执行：t=5 必须重算以初始化缓存，u=0；t=4 的局部变化很小，但 latent 显示关键运动边缘正在建立，策略决定重算，u 仍为 0；t=3 背景稳定，策略复用，u=1；t=2 又出现关键人物姿态变化，策略重算；到 t=1 时剩余预算 b=1 且只剩一步，如果这一位置允许复用，则动作 mask 强制 a=1，最终 u=2。真实实现还可能强制最后一步重算；那就必须更早满足 K，不能照搬这个示例的最后一步选择。

更符合论文强制规则的变体：t=5 强制重算，t=4 复用，t=3 重算，t=2 复用，t=1 强制重算，恰好 K=2。设两次复用的局部误差分别 0.08 和 0.12，而候选 t=3 的局部误差只有 0.03，但其终局影响更大；MORCA 可以宁愿复用 t=2，也不复用 t=3。这些误差数值是教学构造，不是论文实测。例子强调：最小化每一步局部误差的贪心策略，不一定最小化完整视频的终局损失。

15 · Metrics 教学：保真度、速度与潜在误导

Latency (s) ↓：一次视频生成的 wall-clock 时间，越低越好；应包含 scheduler 与缓存操作，且依赖硬件、帧数、offloading、warmup、batch size。Speedup ↑：Tfull/Tcache，不是 FLOPs reduction；例如 Wan2.2 原始 990.56s，MORCA 549.19s，990.56/549.19≈1.80×。PSNR (dB) ↑：10log₁₀(MAX²/MSE)，衡量相对于无缓存参考视频的像素误差，越高越接近参考；dB 为对数尺度，+2 dB 不能解释为“视觉质量提高 2%”。SSIM ↑：基于局部亮度、对比度、结构相似性，通常越高越好，但对运动一致性未必敏感。LPIPS ↓：基于感知网络特征距离，越低越接近参考，可能更符合感知差异，但依赖特征网络与预处理。RMSE (dB) ↓：终局 PSNR 预测的均方根误差，越低越准。Spearman ↑：预测与真实终局误差的秩相关，越高表示更能排对重要性；并不等于预测绝对数值精确。Scheduler overhead ↓：policy 决策消耗的总秒数占推理时间比例，越低越好。

三种保真度指标都依赖同种子无缓存 reference；若原始模型生成了违背 prompt 的视频，缓存方法“完美复现错误”仍可能得高分。还应增加 VBench 的语义/时序质量维度、文本遵循、人类偏好和视频闪烁指标。真实服务系统还需要 TTFT/吞吐/显存/能耗，但论文主要报告单次视频 latency，不能凭此推断高并发吞吐收益。

18 · Ablation / Mechanistic Analysis：删什么、掉多少

去掉全部 latent 特征：PSNR 20.38→19.93（−0.45 dB），SSIM 0.6873→0.6420（−0.0453），LPIPS 0.2036→0.2240（变差 0.0204）。仅保留 3D pooling：PSNR 19.92，说明单独的时空特征不足；仅保留 temporal mean：19.76；仅保留 temporal variance：19.27，甚至比无 latent 更差；三种特征联合：20.38 最好。这个消融支持特征互补，但没有证明 CNN 学到了哪种具体的运动因果变量。

用 REINFORCE 代替 IQL：18.97 vs 20.38（−1.41 dB）；在线从零开始：18.84 vs 离线 20.38（−1.54 dB）；去掉在线微调：20.38 vs 20.95（−0.57 dB）。这三个对照比“使用了 RL 所以有效”更有说服力。硬预算：作者报告 Wan2.2/Wan2.1 平均绝对倍率误差 0.03/0.05，平均相对推理时间误差 1.15%/1.55%；剩余误差来自 K 离散化及校准近似。

严格的因果边界是：移除 latent 特征或更换优化器的干预改变了结果，支持组件功能；但 Table 1 的高 Spearman 不等于证明 latent 的某个具体通道“造成”终局画质变化，仍可能捕捉到 prompt 难度、噪声阶段或视频运动复杂度等相关变量。

19 · Claim vs Evidence

Authors Claim / Experiments Actually Show

在两种 Wan 视频生成模型、多个目标倍率、200 VBench prompts 下，MORCA 通常能以相近 wall-clock 提升相对于无缓存参考的保真度；硬预算让复用次数精确可控；IQL 离线初始化和在线微调各有作用。

What Is Not Yet Proven

没有证明跨模型直接迁移；没有证明更长视频、流式生成或不同分辨率仍有效；没有给出统一的 FLOPs/显存/吞吐/能耗测量；没有证明参考视频保真度等于人类感知质量；没有证明所有目标倍率下都是 Pareto 最优。

20 · Contribution：创新类型拆分

Contribution 1 [New Mechanism]：将 latent-aware state 与终局质量 reward 结合用于动态缓存决策，解决局部误差代理与终局效果的错配，是主要机制价值。Contribution 2 [New Objective / Protocol]：把指定加速倍率转为恰好 K 次复用的 hard-constrained MDP；增广状态/可行集合的数学工具来自已有理论，创新在具体系统化落地。Contribution 3 [New System / Engineering]：离线平滑 schedule 数据构造 + IQL + 在线微调 + 轻量 CNN/MLP scheduler；主要是已有组件的有效组合。Contribution 4 [New Empirical Finding]：Table 1 定量证明 latent 能改善终局误差预测，Table 2 显示真实 wall-clock 下的质量优势。非原创部分：IQL、SeaCache residual caching、PSNR/SSIM/LPIPS 与动作 masking 原理均非本文首次提出。

21 · Limitation & Failure Modes：不能只看漂亮 PSNR

Authors' Limitation：不同模型去噪动力学不同，学习到的 scheduler 不能直接跨模型迁移，必须为每个模型重新采集昂贵视频轨迹并训练。Additional Limitation：①固定 50 步与两种 Wan backbone，未验证长视频/流式或不同视频生成架构；②两种模型使用不同帧数和 offloading，难隔离硬件与模型因素；③未报告 GPU memory、FLOPs、能耗、批大小扩展、并发吞吐；④以无缓存视频为 ground truth，可能高保真地复制原始模型的语义错误；⑤latent 池化会丢失小目标与高频运动细节；⑥终局 PSNR reward 稀疏，IQL 的 critic 容易受离线 schedule 覆盖影响；⑦online rollout 的 prompt 分布改变可能使校准 K 偏移；⑧模型/随机种子依赖导致 schedule 过拟合；⑨仓库虽存在但当前仅网页与占位 README，实际复现仍需要自行实现关键训练与推理接口；⑩多分支 CFG、专家切换与强制重算规则容易造成缓存失效错误。

22 · Reproduction View：从最小 scheduler 开始，不必先训练 14B

第一步：在 Wan2.1-1.3B 上复现 SeaCache residual cache，固定 50 steps、832×480、81 frames，建立 no-cache reference，验证 255.94s 原始延迟是否在本机同配置可近似复现；不同 GPU 不要求数值一致。第二步：校准 K 与实际 latency 的曲线，选 2.4×、3×、4× 三个预算，记录 K 的整数取整与强制重算 step。第三步：随机生成平滑 δ(t) 曲线，按论文离线数据方案采集 4,000 条完整轨迹；若资源有限，先做 200 prompts×4 schedules=800 条并清楚标记缩小版。第四步：保存每步 d、D、t、ℓ、latent pooled feature、u、K、action，以及终局 PSNR，训练双 Q/V/actor 的 IQL。第五步：先比较 no-latent 与 full-latent 的离线模型，再追加 16×100 在线 rollout。

23 · Research Value（逐项）

Baseline Potential：高。SeaCache 是强机制对照，MORCA 提供可复用的 learned scheduler 范式。Migration Potential：很高。终局 reward + 硬预算的组合可迁移到视频理解 token 选择、长上下文 KV 淘汰和推理 token budget。Systems Potential：很高。真正优化 wall-clock 下的 quality frontier，适合系统论文，但必须补显存/吞吐/硬件扩展。Attack Potential：中高。可构造高运动复杂度、镜头切换等让 scheduler 失效的输入。Evaluation Potential：高。“同延迟比较终局质量”比只比 FLOPs 更有实践价值。Benchmark Potential：高。可建立包含 prompt、帧数、运动强度、GPU、预算、reference 的视频加速压力测试。New Paper Potential：高但竞争激烈。若实现跨模型迁移、无需每模型训练，或在 streaming/Agent Video 中实现动态预算和可验证终局质量，才有清楚增量。

24 · Migration Analysis：两个可执行的新方向

Migration A：Query-aware Video VLM 的预算约束帧/Token 选择

Original Problem：固定帧采样/视觉 token pruning 依据局部冗余，不能保证最终 QA 正确率。Transferable Mechanism：终局任务 reward + latent-aware state + hard budget mask + offline-to-online scheduler。New Research Question：在给定视觉 token/FLOPs 预算下，能否学习对最终答案最重要的帧与 token，而非简单挑变化最大的帧？Method Modification：把动作从“复用/重算 DiT”改为“保留/跳过当前帧或视觉 token block”；state 包含 query embedding、当前视觉 embedding、运动统计、已用 token 数、剩余预算；reward 改为答案正确性与参考完整模型 log-prob/一致性组合。Minimum Experiment：先取 Video-MME 300 道问题，按 200/50/50 拆 train/dev/test；每视频统一采 32 帧，预算 K∈{8,16,24} 保留帧；离线对每题生成 12 个结构化帧子集，测完整 Video VLM 的答案，训练离线 IQL，再每轮新增 100 条在线 trajectory、做 5 轮；3 seeds；严格相同总帧数与 token 数比较。Model：Qwen2.5-VL-7B 或等量级开源 Video VLM。Dataset：Video-MME + LongVideoBench 作为独立分布外评估。Baseline：uniform sampling、motion-based selection、query similarity top-K、随机采样。Metric：QA accuracy、TTFT、prefill latency、visual tokens、peak VRAM、FPS、latency/accuracy Pareto。Expected Contribution：提出终局任务感知的精确预算视频压缩。Risk：QA reward 稀疏、视频答案有标注噪声、模型输入帧数不同引发位置偏差。Collision Risk：与 query-aware frame selection、adaptive token pruning、learned video routing 高度接近，必须突出硬预算+终局信用分配与真实 wall-clock。

Migration B：Agent / Long-context Inference 的动态 KV 保留

Original Problem：KV cache eviction 往往按局部 attention/recency 选择，可能删掉未来工具调用需要的证据。Transferable Mechanism：把“局部缓存重要性”替换为“对未来任务完成率的终局影响”，并把显存预算做成 hard constraint。New Research Question：能否在固定 KV memory 下学习保留对 Agent 后续行为最重要的历史片段？Method Modification：动作是 eviction/keep 一个 KV page，状态含页面 recency、attention 统计、工具调用阶段、用户 query、已用内存；终局 reward 是任务成功率或参考 full-context 输出一致性；以 page budget 代替 reuse K。Minimum Experiment：构造 500 个多轮工具任务，每个 20–40 turn，按 350/75/75 拆分；预算分别为完整 KV 的 25/50/75%；先收集 4 个启发式策略的离线轨迹，每个任务至少 8 个预算化 eviction schedule；用 IQL 学习后与 LRU、attention-score、H2O/StreamingLLM 风格启发式比较；额外做“关键事实埋在最早 10% 对话”的压力测试。Model：Qwen3-4B 或 Llama-3.1-8B。Dataset：LongBench 的多轮问答子集 + 自建可验证 tool-use tasks；外部用 LongMemEval 风格长期记忆问答测试。Baseline：LRU、attention eviction、固定窗口、full KV oracle。Metric：任务成功率、信息恢复率、KV GB、TTFT/TPOT、tokens/s、GPU memory、recomputation latency。Expected Contribution：面向 Agent 的“终局影响—KV 预算”联合优化及新 stress benchmark。Risk：KV eviction 后不可逆、长程 reward 更稀疏、不同 attention 架构不能共用策略。Collision Risk：与已有 learned KV eviction、cache-aware agent memory、budgeted context compression 重叠，需要独立的未来工具成功率证据。

RL Formulation：真正的 State、Action、Reward 与 Credit Assignment

State：压缩后的 denoising 状态 zt + 已用/目标复用次数；Action：0 重算、1 复用；Policy：小型 CNN/MLP πφ；Trajectory：一条视频从噪声到最终输出的完整 50-step schedule；Reward：最终 PSNR（相对 no-cache reference），仅最后一步非零，属于 rule-based/dense? 明确是 sparse terminal reward；Advantage：Q(z,a)−V(z)；Objective：最大化终局 PSNR，硬约束恰好 K 次复用；KL/Entropy：主文 IQL 目标没有 ExpDis 那样显式 KL 正则项，不能自行补写；Credit Assignment：通过 Q 的 bootstrap 与 advantage-weighted BC，将最终质量差异分配给前面每次复用/重算动作。Reward hacking 风险：policy 可能学会优化像素 PSNR 而牺牲真实语义或运动质量；或在训练 prompt/seed 上过拟合。Sample efficiency：离线 2,500/4,000 条 + 在线 1,600 条轨迹/模型；IQL 相比 REINFORCE 取得更高 PSNR，但未给每单位 GPU-hour 的精确效率曲线。

26 · Attack / Verification Lens：把缓存调度当作可攻击决策系统

可以设计 Cache Sensitivity Stress Test：同样 3× speedup，分别输入静态场景、快速运动、遮挡、镜头切换、文字叠加、细小物体、周期运动，比较每类 prompt 的 PSNR/LPIPS/VBench 时序一致性和真实秒数。若策略在训练分布外出现明显更差的终局质量，即形成黑盒鲁棒性证据。可以构造 Terminal-Error Amplification Ratio：同预算下，某次复用造成的最终质量损失 / 局部残差变化，识别 step-error 代理失效点。还可测试预算校准攻击：改变 batch size、offloading、分辨率或后台 GPU 负载，测目标 ρ* 与实际 ρ 的偏差。若迁到 KV cache，可做关键证据在最早/最晚位置的检索攻击。以上属于可开展的研究提案，不是论文报告的已验证 attack。

28 · 如果只记住这篇论文（9 句话）

  1. 视频 DiT 缓存的本质是跳过部分去噪 step 的 block 计算。
  2. 局部 step error 小，不代表最终视频损失小。
  3. latent 特征把终局 PSNR 预测 RMSE 从 6.971 降到 2.849 dB。
  4. MORCA 用 RL 决定每一步复用还是重算。
  5. 用户的目标倍率先校准为必须复用 K 次的硬预算。
  6. 动作可行集合保证在每个 step 后预算仍可完成。
  7. 离线 IQL 先学策略，再用 16 轮在线数据继续改进。
  8. 在两种 Wan 模型上，同等实际延迟附近的最终保真度优于 SeaCache。
  9. 它的主要价值是“相同速度更高质量”，而非宣称超越所有缓存方法的运行速度。

04 · Cross-Paper Synthesis：两篇共同说明什么趋势？

共同趋势一：优化目标正在从局部代理转向最终任务价值。ExpDis 不把“novelty 分数高”当作学生能力高，而是要求轨迹通过最终正确性与质量过滤；MORCA 不把“step error 小”当作最终画质好，而是直接用完整视频 PSNR 训练决策策略。两者都在提醒：局部代理可以帮助搜索，但必须通过更接近真实目标的终局证据来约束。

共同趋势二：探索成本与部署策略需要显式隔离或约束。ExpDis 在参数空间做隔离——允许 explorer 偏离，但只把可靠轨迹传给 student。MORCA 在动作空间做约束——允许 policy 自由选择哪些 step 复用，但总次数必须满足 K。二者分别体现 information firewall 与 budget firewall。前者降低错误经验迁移，后者防止学习策略突破资源预算。

互补机制：可把 MORCA 的 offline-to-online IQL 当作低成本探索者，将其发现的高质量 schedule 过滤后蒸馏到一个更轻量的确定性调度器；也可以把 ExpDis 的“多个独立 explorer 搜索不同策略”用于 MORCA 的高成本离线数据采集，避免单一随机阈值曲线覆盖不足。冲突假设：ExpDis 的可靠性来自正确性 verifier 和可离散筛选的轨迹，MORCA 的 reward 是连续、相对参考的 PSNR，且所有策略都可能有程度不同的画质损失；“正确/错误”二分不能直接套用。MORCA 的 IQL 可重复利用 off-policy 数据，而 ExpDis 的 student DAPO 是 on-policy，直接混用会改变数据分布假设。

05 · Combined Research Opportunities：今天最值得动手的三条

Idea A · Budgeted Discovery Transfer（最值得优先验证）

面向 Agent/Video VLM 建立一个统一问题：给定训练 rollout 预算 B 和推理资源预算 K，探索者能否发现更多成功轨迹，而学生只学习通过任务终局验证且满足资源约束的行为？将 ExpDis 的探索—过滤—蒸馏用于收集候选帧选择/工具使用轨迹，再借鉴 MORCA 的预算 mask，确保最终部署 policy 不超帧数、token 或 GPU memory。最小实现是 200 个 Video-MME 问答、32 帧输入、K=8/16 帧预算、每题 8 条探索轨迹；对照 uniform、query-topK、单策略 RL、ExpDis 无预算、预算 IQL 无分离；记录正确率、视觉 token、wall-clock、accepted ratio、旧任务准确率。论文价值判据：如果在严格相同 token/rollout 成本下，同时提高成功率并减少旧能力退化，且相对两种单独机制有交互增益，才不是简单拼接。

Idea B · Terminal-Aware KV Eviction for Agent Memory

把 MORCA 的“缓存一页 KV 会怎样影响后续最终答案”与 ExpDis 的“成功轨迹是可靠学习单元”结合：先让探索策略对 Agent 长程对话试验多种 eviction schedule，按后续工具任务成功与关键事实保留率筛选，蒸馏出轻量缓存管理器。对 500 条多轮轨迹，固定 KV 25/50/75% 三档，测 task success、TTFT、TPOT、峰值显存和重算成本；对照 LRU、attention-score、uniform window、full KV。系统贡献机会：提出“以未来行为贡献度为准的缓存重要性”，并提供硬件真实吞吐与失败恢复协议。

Idea C · Verifier / Proxy Gap Benchmark

把两篇共同的 proxy gap 直接变成 benchmark：数学推理中 novelty 高但错误过程的轨迹，视频中 step error 小但 terminal PSNR 低的时间步，Agent 中 memory 相似度高但后续工具选择错误的记录。对每个任务同时存局部代理、终局 outcome、干预成本和真实资源占用，定义 Proxy–Terminal Rank Gap（局部代理排序与终局损失排序的差异）以及 Budgeted Outcome Regret（同预算策略与可获得的更优策略之间的差）。风险：跨模态 outcome 不同，不能把 PSNR 和数学 pass@1 硬凑成一个标量；应采用分任务标准化与分层报告。

06 · Collision / Overlap：哪些想法已经有人做过？

Collision 1（明确概念重叠）：ExpDis 与 Expert Iteration、Go-Explore、STaR/ReST、R²PO、ICE 在“探索轨迹→学习策略”思想上相交。它的区别是独立权重实例 + 正确性/质量过滤 + 多轮/并行预算化，不能把“探索后蒸馏”本身当作全新概念。对于 Agent 的迁移提案，如果只是把数学 verifier 换成单元测试，很可能只是工程应用；必须做隔离机制的因果与成本评估。

Collision 2（明确系统重叠）：MORCA 与 SeaCache、TeaCache、MagCache、DiCache 的缓存粒度和目标设置高度重叠；与 IQL、受约束 MDP 的理论部分也有已有工作。其增量是终局误差动机、latent-aware 调度和硬预算下的 RL 学习，而不是发明缓存、IQL 或动作 mask。若继续做 video acceleration，应优先考虑跨模型迁移 / 多目标质量 / 长视频 / 真正系统吞吐等尚未充分验证的部分。

Strongest Collision（跨论文研究机会层面）：“独立探索者发现高质量缓存 schedule，过滤后蒸馏为部署 scheduler”与现有 Expert Iteration / offline-to-online RL 的组合非常接近，单独拼接不足以成为论文。更有价值的差异化问题是：在昂贵终局反馈和严格推理预算同时存在时，是否能给出更高的发现效率、可靠性与跨模型泛化？截至本次检索，未发现这两篇新论文彼此直接引用；它们的组合是本报告提出的研究假设，不是已确认的相互抄袭或正式优先权冲突。
