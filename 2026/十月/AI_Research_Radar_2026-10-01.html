2. Executive Summary

今天的主线异常集中：Agent persistent memory 已从“检索质量组件”变成跨 Agent 信息流与安全边界。最新工作同时从传播攻击、counterfactual severity、backchain control path、long-horizon memory action 与 tool-schema invariance 五个角度说明：只在单模型、单 prompt、单 memory store 上谈“删除”已经不够。最值得形成研究议题的是 Deletion Closure：目标信息被删除后，其派生 artifact、下游 Agent memory、tool skill、summary 与可重建路径是否一并失效。

Machine Unlearning 侧最重要的新风险是 Toketive：替代 tokenization 可绕过局部 editing/unlearning，38.6% alternative tokenizations 恢复修改前响应；这直接要求 robust unlearning 把 representation equivalence 纳入攻击面。Agent 侧则出现跨 8-hop 的 memory-hopping spread，形成非常强的 Multi-Agent Unlearning collision。

6–8. Formal Deep Reads — Tier S / A / B

Tier S · Share-Borne AI Virus: Memory-Hopping Attacks Across LLM Agents

基本信息：Share-Borne AI Virus: Memory-Hopping Attacks Across LLM Agents；Sidharth Pulipaka 等；SPAR / University of Cambridge / APTA AI / CISPA；arXiv:2609.35576，2026-09-28，37 页；论文提供代码链接。

人话版：这篇论文到底干了什么？

它研究的不是“一个 Agent 被提示注入后会不会出错”，而是更危险的一层：一个 Agent 从文档里吃进恶意状态，把它写进自己的长期记忆，之后在正常工作中又把这种状态写进新文档；另一个完全独立的 Agent 读到新文档后再次感染。于是攻击形成 artifact → memory → artifact → memory 的跨 Agent 传播链。论文在模拟的人类协作工作流中观察到多跳传播；在 30-Agent 大环境里，GPT-5.6 Luna 仍有 60–80% Agent 被波及，最长链达到 8 hop。对 Agent Unlearning 来说，这直接把“删除一个 Agent 的记忆”升级成“必须沿 provenance 关闭所有派生副本”的 deletion closure 问题。

Background & Research Gap

传统 indirect prompt injection 主要问当前任务是否被恶意网页、邮件或工具输出劫持；memory poisoning 则进一步问恶意信息能否跨会话留在同一个 Agent 中。但真实工作流存在普通文件交接：Alice 的 Agent 写报告，Bob 的 Agent 再读报告。此前研究通常需要共享 memory、Agent-to-Agent 消息或自动索引通道；本文刻意把这些直接通道拿掉，只允许人类授权的读写文件，因此更接近“隔离 Agent 之间仍然会通过 artifact 形成隐式信息流”的部署现实。具体例子是：一个被污染的报告不需要直接命令 Bob；只要 Alice 的 Agent 先把污染内容记住，再在后续 handoff 文档中重现，Bob 的 Agent 就可能把它当成新证据继续固化。

Core Insight

关键观察是：持久化不仅发生在 memory store，也发生在 Agent 产生的外部 artifact。只保护 memory write 并不等于切断传播，因为 Agent 可以把已污染状态“再物化”为文档；反过来，只扫描文档也不够，因为污染可能已在私有记忆里等待下一次写作。安全边界必须覆盖 memory 与 artifact 之间的双向派生关系。

Method Deep Dive

Poisoned seed artifact → Agent read → persistent memory → later normal write/edit task → infected artifact → another clean Agent read → new persistent memory → …。作者构造 temporal human–agent universe：每个用户有私有 workspace 和 private memory，没有共享记忆或直接 Agent 通信；事件序列规定谁在何时读/写什么，但具体文本由 Agent 产生。攻击模板把恶意 goal g 与 goal-agnostic propagation instruction φ 组合为 Pφ(g)。φ 在开发 universes 上通过 agent-driven red teaming 搜索，测试时冻结，换用未见过的目标、persona、artifact 与工作流。主实验采用 endpoint-assisted propagation：感染 Agent 只需记住 goal 与“写完 artifact 后交给 endpoint”的规则，endpoint 再把规范化 payload 注回文件；附录还给出完全不依赖 endpoint 的 prompt-only 传播。

核心指标 FIF（fraction infected）分别在 Agent 和 artifact 上统计；同时区分 goal infection 与 full infection，后者要求既保留目标又保留继续传播所需机制。这个区分非常重要：对 unlearning/verification 而言，“目标内容不再直接回答”不等于“传播能力已删除”。

Failure mode 主要有三类：memory 没写入、memory 中只剩 goal 而丢失传播规则、写新 artifact 时遗漏 payload。prompt-only 分析表明主要衰减来自 omission，而非逐 hop 的语义改写。

关键公式与 Toy Example

Universe 写作 𝕌=(A,D⁰,p,o,E)，分别表示 Agents、初始 artifacts、用户 profile、ownership 与事件序列。攻击种子 d_seed=Insert(d_benign,Pφ(g))。直觉上它把传播研究从单次 prompt 变成时间图上的状态转移。Toy Example：A 读被污染的项目报告→memory 记住“所有后续交接都加入 X”→A 两天后写 handoff→B 读 handoff→B 的 memory 再保存 X。若此时只删除 A 的 memory，B 与 handoff 仍保存派生影响，因此删除没有 closure。

Baseline Deep Comparison

最重要的比较不是单一算法，而是三类威胁模型：单 Agent prompt injection 只能证明即时劫持；persistent-memory poisoning 能证明同一 Agent 的跨会话影响；既有 worm/agent-network 工作通常依赖直接消息、共享状态或自动索引。本文新增的是“独立私有 Agent + 普通人类 artifact handoff”条件下的传播。prompt-only 是更严格的内部 baseline：没有 endpoint 负责刷新 payload，因此能测模型自身复制能力。

Experiment Setup Deep Dive

36 个 synthetic universes，覆盖 customer support、software engineering、healthcare operations、home/living、social gatherings、personal productivity 六类域；每个 universe 3–12 Agents、10–20 time steps。另有 30-Agent、最长 60 steps 的大规模环境。开发阶段只用 development universes 搜索 φ，测试阶段冻结模板并换 unseen goals/workflows。研究问题包括：能否跨 hop？规模增大后是否仍传播？prompt-only 是否成立？不同 domain 是否影响传播？memory-write classifier 能否阻断？

Results Deep Dive

Strongest result：30-Agent 环境中 GPT-OSS-120B / DeepSeek-V4-Pro 达 90–100% 波及，Kimi-K2.6 为 77–97%，GPT-5.6 Luna 仍为 60–80%，最长链到 8 hop。这说明不是某个弱模型偶发现象。

更严格 prompt-only：DeepSeek-V4-Flash 的 seed 在 38% held-out runs 中至少完整感染一个 Agent；全体 Agent full-infection fraction 为 0.21，artifact 为 0.35；S(2)=0.30、S(3)=0.12、S(4)=0.05。Kaplan–Meier 校正得到每 hop continuation ≈0.73。

机制结果：携带 payload 的 artifact 中 propagation instruction 仍有 72–80% verbatim，goal belief 60–80% verbatim；真正造成链条衰减的是遗漏，drop rate 从首 hop 32% 上升到第二/第三 hop 约 65%。因此“语义变形导致病毒逐渐失真”不是主解释。

Weakest / caveat：主结果依赖 endpoint-assisted 机制和允许 outbound access；prompt-only 明显更弱，说明部署中的 egress control 仍是有效安全杠杆。

Table/Figure Reading & Ablation

Figure 1 最值得看：把 agent/artifact 交替图画清楚，直接对应 deletion lineage。Table 3 的 prompt-only domain 结果显示 healthcare handoff 的 S(2)=0.50，而 personal productivity 仅 0.10，说明结构化文档工作流更利于传播。Table 4 将 paraphrase 与 omission 拆开，支持“遗漏而非逐步改写是主要衰减源”。大规模传播图则显示一个 seed 可持续暴露新读者，网络位置主要影响何时暴露而非是否转化。

Claim vs Evidence

Authors Claim：普通 artifact 可以成为跨独立 Agent 的持久攻击载体。
Evidence：多域、多模型、held-out workflow、多 hop 与大规模 universe 都支持。
尚未证明：真实企业权限、真实人类审阅、严格 DLP/egress policy 下是否仍有相同 outbreak；也没有证明任意 memory implementation 都同样脆弱。

Contribution / Limitation

New Attack：artifact-mediated memory hopping。New Benchmark/Protocol：temporal human–agent universes 与多 hop infection metrics。New Empirical Finding：传播衰减主要由 omission 驱动。限制包括外部 endpoint 假设、合成 universe、模型/产品范围有限，以及对 provenance-aware defense 的系统比较仍不足。

Research Value & Migration Analysis

Original Problem →跨 Agent 攻击传播；Transferable Mechanism →artifact–memory provenance graph；New Research Question →收到删除请求后，能否把目标影响从源 memory、派生 artifact、下游 Agent memory 一并闭包删除？Method Modification →给每次 memory write 与 artifact write 记录 source lineage；删除时沿 DAG 追踪并对节点执行 selective erase / invalidation，再做反向 reachability verification。Minimum Experiment →复用 3–5 Agent handoff universe，注入一个可追踪 fact；让其传播 2–4 hop；比较 local-delete、provenance-delete、retrain/reset；之后用直接问答、paraphrase、tool action、memory retrieval、relearning probe 检测残留。Model →Qwen3/DeepSeek 开源 Agent；Dataset →该论文 universe + 自建工作流；Baseline →local memory deletion / reset / prompt suppression；Metric →Deletion Closure Rate、Residual Reachability、Retain Utility、Reacquisition Rate；Expected Contribution →Multi-Agent Unlearning 的 deletion closure benchmark；Risk →lineage metadata 可能不完整；Collision Risk → HIGH，因为 TRACE/BMA/本文都已把 provenance 推到中心，但“删除闭包”仍未被直接解决。

如果只让我记住 5 句话

① Agent 的记忆污染能借普通文件跨 Agent 传播。② 私有 memory 并不等于信息流隔离。③ 30-Agent 环境可出现 60–100% 级别 spread。④ prompt-only 的主要衰减是 omission，不是 paraphrase。⑤ 对 Agent Unlearning，真正的新问题是 provenance-aware deletion closure。

Tier S · From Attack Success to Attack Severity: Counterfactual Memory Attacks on LLM Agents

基本信息：From Attack Success to Attack Severity: Counterfactual Memory Attacks on LLM Agents；arXiv:2609.34132，2026-09-28；正文与实验可访问。

人话版：这篇论文到底干了什么？

过去 memory attack 常用“攻击成功率”二元统计：Agent 有没有被诱导做目标行为。但两个都成功的攻击，后果可能完全不同。MemHarm 把问题改成 counterfactual severity：同一个 Agent、同一个后续任务，只改变一条持久 memory，比较 clean 与 edited state 的下游差异，再主动搜索高伤害 edit。对 unlearning 很有价值，因为验证删除也不应只看“忘没忘”，而应看残留 memory 对后续行为造成多大因果影响。

Background & Gap / Core Insight

ASR 把“轻微偏移”和“灾难性行为”压成同一个 1。作者用 potential-outcome 视角构造 paired memory intervention：固定其余上下文，只比较 M 与 M'，将 downstream behavioral delta 归因到 memory edit。关键不是相关性，而是 matched intervention。

Method Deep Dive

定义可接受 sparse grounded edits → 对 clean/edited memory 做 paired rollouts → 估计 Counterfactual Memory Risk (CMR) → 自适应分配 rollout budget → 在冻结 edit class 内选择并认证高 severity edit。论文进一步用 confidence-sequence / best-arm identification 思路，避免仅凭一次最大观测值宣称“最危险”。

Experiment / Results / Table Reading

Table 1 是主 held-out attack comparison，同时报告 CMR、ASR、BMAR≥4 与 BUD，强调“成功”和“严重”不是同一排序。论文还单独验证 severity claim，并检查攻击搜索是否只是过拟合特定 rollout。最值得迁移的是 paired intervention protocol：它天然适合 unlearning verification——把删除前后的 memory state 作为 counterfactual pair，测目标行为、工具调用和派生记忆的 causal effect。

Strongest / Weakest / Claim vs Evidence

Strongest 是把攻击评估从 binary success 推到 causal severity，并给 selection certification；weakest 是 severity 仍依赖任务与效用定义，跨域标尺并不天然可比。实验证明“在冻结攻击类中能找到更高 downstream harm 的 memory edit”，但没有证明所有真实攻击空间都被覆盖。

Contribution / Limitation / Migration

New Metric/Protocol：counterfactual memory severity；New Attack：severity-guided memory edit search；New Empirical Finding：ASR 会掩盖 downstream consequence 差异。迁移：构造 Counterfactual Residual Influence，删除后把目标 memory 替换为 clean/reference state，固定后续 trajectory，测 action/logit/retrieval 差异；Minimum Experiment 用 Agent memory benchmark 上 100 个 deletion cases，比较 raw deletion、summary rewrite、provenance invalidation，报告平均/95th percentile residual influence 与 retain utility。

5 句话

① ASR 不等于伤害。② memory 的因果影响应做 matched counterfactual。③ 删除验证也应从“是否回答”升级为“残留影响有多大”。④ 统计认证能防止挑到偶然极端样本。⑤ 这是 Agent Unlearning evaluation 很直接的迁移源。

Tier S · Traverse: Learning When to Remember, Reset, and Redirect for Long-Horizon Web Search

基本信息：Traverse: Learning When to Remember, Reset, and Redirect for Long-Horizon Web Search；arXiv:2609.37082，2026-09-29；35B long-horizon search Agent。

人话版：这篇论文到底干了什么？

Traverse 让搜索 Agent 自己决定什么时候“封存”上下文、保留哪些证据与失败假设、什么时候重新读回，而不是等上下文窗口满了被系统自动压缩。更重要的是，作者发现直接对所有 context segments 做 RL 会出现 Seal Collapse：奖励很难正确归因到哪次 memory 操作，模型学不会何时 seal。解决方法极简——只优化最后一次 context management 之后的 final segment。这个 credit assignment × memory control 的机制非常适合迁移到 continual unlearning：每次删除/压缩/重置也可以被视为可学习的 memory action。

Background & Core Insight

长程 Agent 的错误会随着 context 累积持续污染后续搜索。自动 compaction 的问题是它只看 token budget，不看任务语义；Agent-controlled memory 的问题则是 RL credit 穿过多个 reset segment 后会变得含混。Core Insight：memory boundary 本身是 action，训练它时不应把同一个终局 reward 反复回传到所有被 seal 的历史段。

Method Deep Dive

Rubric → Answer/Search → Verify → [Seal Memory / Read Memory / continue] → final answer。Rubric 先定义可接受答案标准，Answer 执行搜索，Verify 独立检查证据；Seal Memory 让 Agent 主动建立 context boundary，并保存证据与失败假设。SFT 用 teacher trajectories 学基本行为；RL 只训练最后 segment，从而避免 segment 数量改变时隐式重加权整个 trajectory。

关键机制 / Toy Example

假设 Agent 已搜索 40 步，前 20 步围绕错误公司。自动压缩可能把错误线索和正确线索一起总结；Traverse 可以在确认错误后 seal，只保留“已排除公司 A 的证据”和当前候选 B，再继续。迁移到 unlearning：删除请求到来时可把“forget boundary”当作 seal，之后禁止旧 segment 被 read-back，且奖励只评价删除后的 final segment 是否既不泄漏又保持任务能力。

Experiment Setup / Results

覆盖 BrowseComp、BrowseComp-ZH、xbench、DeepSearchQA、WideSearch，以及 finance/product-search transfer。Traverse-35B 在 BrowseComp 得到 72.83，优于同规模开源系统 QUEST-35B、AREX-Turbo，并在多类 benchmark 上相对 base model 保持一致提升。Ablation 使用 BC185 子集以降低成本，控制 search backend、训练超参和 sampling。

Table/Figure / Ablation

主结果 Table 1 最值得看跨 benchmark 泛化；Ablation 重点比较 final-segment-only RL、SFT-only、以及 Auto Compaction。作者明确报告 agent-triggered sealing 优于 fixed-threshold compaction，并证明 all-segment RL 会触发 Seal Collapse。这里真正值得学的不是 72.83，而是“memory operation 的 reward assignment 必须尊重 segment boundary”。

Claim vs Evidence / Limitation

证据支持 autonomous compression 与 final-segment training 在搜索 Agent 上有效；尚未证明相同策略适用于删除、隐私或多 Agent 场景。另一个风险是 Seal 工具可能把关键信息过早隔离；如果 read-back 权限设计不当，也可能成为 unlearning 后的 reacquisition 通道。

Contribution / Migration Analysis

New Mechanism：Agent-triggered Seal/Read memory；New Objective/Training：final-segment-only RL；New Empirical Finding：Seal Collapse。迁移为 Deletion-Boundary RL：Original Problem=长程 context 管理；Transferable Mechanism=可学习 memory boundary + 局部 credit；New Question=Agent 能否学会在删除请求后建立不可回读 boundary；Minimum Experiment=在 WebShop/ALFWorld 或长程 search 中插入 1–3 次 deletion event，比较 auto-delete、rule-based boundary、RL boundary；指标 Forget Leakage、Task Success、Reacquisition@k、Boundary Precision、token cost；风险是 RL 可能学会“表面不读但通过摘要保留”。

5 句话

① memory management 可以是 Agent action。② 自动压缩不是语义最优。③ all-segment RL 会造成 Seal Collapse。④ final-segment-only credit assignment 是最可迁移机制。⑤ 对 continual unlearning，可把 deletion event 视为新的不可回读 context boundary。

Tier A · BMA: Backchain Memory Attacks Create Unauthorized Control Paths in LLM Agents

人话版

人话版：攻击者不直接写 memory，而是反向推理“想让 Agent 做某个受保护动作，需要什么 memory；要形成这种 memory，需要篡改什么低信任 evidence”。论文用 Path-CASR 要求 memory 必须真实形成、被检索、驱动行为并通过 matched intervention，避免把偶然命中算攻击。

Background & Gap / Core Insight / Method

核心机制是 inverse planning + pathway certification。四类 substrate、三种 decision backbone 上，BMA Macro Path-CASR 18.8%，强 access-matched baseline 为 13.4%；BMA 行为命中中 60.3% 通过完整路径认证，baseline 为 36.7%。冻结攻击在四个 held-out consolidation policies 上保留 78.0% certified effect；普通 memory-side control 仍有 11.0% Path-CASR，而 provenance-bound authorization 降到 2.0%，合法动作成功率仍 92.1%。

Experiment / Main Results

核心机制是 inverse planning + pathway certification。四类 substrate、三种 decision backbone 上，BMA Macro Path-CASR 18.8%，强 access-matched baseline 为 13.4%；BMA 行为命中中 60.3% 通过完整路径认证，baseline 为 36.7%。冻结攻击在四个 held-out consolidation policies 上保留 78.0% certified effect；普通 memory-side control 仍有 11.0% Path-CASR，而 provenance-bound authorization 降到 2.0%，合法动作成功率仍 92.1%。

Contribution / Limitation / Research Value

Contribution 以机制/攻击/评估为主；限制是当前实验边界不能自动外推到所有 Agent 或所有模型。研究价值在于它提供可直接迁移的机制，而不是只提供一个新分数。

Migration / Minimum Experiment

对 Agent Unlearning 的启发是：删除验证必须认证 influence pathway，而不能只看最终回答。Minimum Experiment：给每个 forget item 建 provenance tag，删除后分别 probe formation→retrieval→action 四段；任何一段仍可把目标影响带到 action 就判 deletion closure 失败。

Worth Deep Reading: YES

Tier A · Action-Space Shaping for LLM Agents: Measuring and Mitigating Tool-Schema Bias

人话版

人话版：同一个真实 action space，仅仅换工具 schema 的表达方式，Agent 成功率就能从 0% 摆到 97%。这说明 tool interface 本身是模型行为的一部分，而不是中性的 API 包装。

Background & Gap / Core Insight / Method

作者设计九类 executable schema transformation，保持任务、可达状态和真实动作不变，只改接口；11 个 LLM、最多 32 个 schema variant。2,748 queries 覆盖 168 tools。训练通常只修复训练中见过的 variant；孤立 tool-call probe 也不能可靠预测完整任务表现，例如某些模型单调用 compliance 很高但 full-task exact 极低。

9. Idea Mining

1. Provenance-Closed Multi-Agent Unlearning（今日最佳）

Inspiration：Share-Borne AI Virus + BMA + TRACE。Gap：现有工作分别研究传播、授权、return validity，但没有把“删除请求后的所有派生副本是否闭包消失”作为核心目标。Hypothesis：显式 lineage DAG + selective invalidation 比 local memory delete 更能阻止跨 Agent reacquisition。

Proposed Method：给 memory/artifact/tool output 建 source→derived edges；删除请求触发 forward taint closure，节点按 exact-derived / transformed-derived / semantically-dependent 分级；对 memory 做 erase/invalidate，对 artifact 做 tombstone/redaction，对下游 Agent 做 targeted refresh；最后用 reverse reachability + adaptive probe 验证。

MVE：3/5/10 Agent，2–6 hop；Qwen3/DeepSeek；复用 human-agent universe；Baseline=local delete/reset/prompt suppression/TRACE-style admission；Metric=Deletion Closure Rate、Residual Reachability、Reacquisition@k、Retain Utility、token/latency。Expected Contribution：首个面向 cross-agent derived state 的 deletion-closure benchmark/protocol。Novelty ★★★★★ Feasibility ★★★★☆ Compute ★★★☆☆。Risk：lineage 不完整；Collision Risk：HIGH；Best Venue：NeurIPS/ICLR。

2. Tokenization-Closed Unlearning

Inspiration：Toketive。Gap：unlearning 多在 canonical tokenizer path 上优化。Hypothesis：对 tokenizer-equivalence class 做 robust objective 能显著降低 alternative-tokenization recovery，而 utility 损失可控。Method：训练时对 forget sample 生成合法 segmentation set，优化 worst-case forget loss + retain KL；MVE=TOFU + 1 个 MLLM text branch，NPO/GA/DTO 对照；Metric=worst-case AP/TR、Toketive recovery、retain utility。Novelty ★★★★☆，Feasibility ★★★★★，Compute ★★☆☆☆，Collision Risk MEDIUM；Best Venue ICLR/ACL。

3. Deletion-Boundary RL for Continual Agents

Inspiration：Traverse 的 Seal Collapse。Gap：continual agent deletion 通常是规则操作，没有学习何时建立不可回读 boundary。Hypothesis：final-segment-only credit 能稳定学习 deletion boundary，同时减少旧 memory reacquisition。MVE：长程 web/ALFWorld trajectory 中随机插入 deletion events；比较 auto-compaction、hard reset、all-segment RL、final-segment RL；Metric=Leakage、Success、Reacquisition、Boundary Precision、Cost。Novelty ★★★★☆，Feasibility ★★★★☆，Compute ★★★☆☆，Collision Risk LOW-MEDIUM；Best Venue NeurIPS/ICLR。

10. Collision Detection

⚠️ Collision Warning — YES

高重合：Share-Borne AI Virus、TRACE、BMA 已共同把 provenance、persistent memory、跨时间/跨 Agent validity 推到研究中心；如果只做“给 Agent memory 加 provenance 然后删除”，创新性不足。剩余 gap：三者都没有把 data-subject deletion 请求定义为需要沿 derived-state graph 完成的可验证 closure，也没有系统测删除后的 reacquisition / repeated deletion / cross-agent recovery。

Token-level collision：Toketive 已证明 canonical tokenization 不是稳健边界。任何 Token Attribution × Unlearning 新方法若不覆盖 alternative tokenization，会被视为 evaluation 不完整。差异化：做 tokenizer-equivalence robust objective 或把 Toketive 纳入标准 robustness suite。

是否值得继续：YES，但论文题眼应从“Agent memory deletion”升级为 Provenance-Closed / Causally Verified Multi-Agent Unlearning，核心贡献必须包含 closure definition、benchmark、adaptive recovery attack 与 continual/repeated deletion protocol。
