Tier SRLRECENT Tree-Aware Posterior Distillation for Long-Horizon Agentic Reinforcement Learning

arXiv:2610.23181 · 2026-10-16 · Heming Zou, Qi Wang, Yixiu Mao, Yun Qu, Yuyi Guo 等 · 预印本；Venue 未核验 · 正文 HTML · PDF
Code: 未核验 · Project: 未核验 · Source: arXiv full text

人话版：这篇论文到底干了什么？

Agent 做十几轮检索和工具调用后才知道答案对不对，若只把最终成功/失败奖励平均分给每一步，很多有用步骤会被误罚，无用步骤也会被奖励。TreeOPSD 从同一个中间历史分叉采样不同后续，把末端结果沿树回传，得到各轮的相对贡献；再把贡献转换成有上限的“目标分布”，用蒸馏代替不断朝固定方向推梯度。它同时处理长程 credit 稀疏和训练 mini-batch 中策略变旧两类问题。在 Deep Research 任务上，Qwen3-30B-A3B 的平均成绩比 GRPO 高 4.97 个百分点。重要性在于把「探索出有效轨迹」与「稳定地更新策略」分离。

Background & Research Gap

传统 GRPO 给整条成功轨迹同一个 advantage：假设 agent 先检索了三次，其中第二次找到关键证据、第三次只是重复查询，三次却一起得到正梯度；失败轨迹里第一步正确的工具选择也会被惩罚。PPO 的 critic 和 PRM 可缓解，但增加网络、标注或 reward hacking 风险。另一个独立问题是：采样时的行为策略 π_old 固定，训练一个 batch 内多次更新后，π_θ 已偏离 π_old，原来的梯度仍不断推动同一动作，容易过冲。

Core Insight 与 Observation

同一前缀分叉相当于控制了历史变量，比较不同后续的结果更接近“这一轮决策的作用”。树的 terminal reward 可以递归回传为 V_i，而不必训练 critic。更关键的是：V_i 不是必须直接乘 log-prob 的常数；可将它编码为冻结的 Bernoulli teacher q_i，当前策略只需向 teacher 靠近。作者在正文中给出初始切线与 tree policy-gradient 相同的分析，随后梯度会随 student-teacher gap 收缩，超出目标后改变方向。

Method Deep Dive

Input：问题、工具环境、当前行为策略 → ① 先采 M 条完整 ReAct 轨迹；② 从每条轨迹选 N 个 anchor 前缀，分别继续采样 suffix；③ 合并共享前缀成 rollout tree，末端由 verifier 给 0–1 reward；④ 对 terminal rewards 做组内标准化，并以行为策略分支概率递归回传 V_i；⑤ 对每轮构造固定 q_i=1/2+V_i/τ；⑥ 当前模型计算本轮 token 平均 log-likelihood ratio，经 sigmoid 得 p_i；⑦ 最小化 teacher→student 的 Forward-KL，在各 mini-batch 重新算 p_i。观察 token 不参与 loss，避免把环境返回文本当成模型动作。

关键公式 / Objective

树叶 advantage A_k=(R_k−mean(R))/std(R)；节点 V_i=Σ_c ω_ic V_c，ω_ic 与 π_old 的子动作似然有关。每轮相对分数 s_i=(1/L_i)Σ_j log[π_θ(a_ij|h_ij)/π_old(a_ij|h_ij)]，p_i=σ(s_i)，q_i=1/2+V_i/τ。更新权重与 τ(q_i−p_i) 成正比：初始 p_i=1/2 时恢复树策略梯度，达到 q_i 时为零。τ/目标半径 ρ 决定更新幅度；过小可能保守，过大则可能偏离行为分布。作者使用 β_KL=0 的稀疏终局 reward 设定，不能据此推断所有带 KL 正则任务都稳定。

Toy Example

假设研究代理检索“方法 A 的核心 ablation”。第 1 轮打开论文，第 2 轮找到 Table 4，第 3 轮可能误读数据。沿第 2 轮前缀再分叉：分支 X 正确解释，得 1；分支 Y 错误解释，得 0。树回传让“找到 Table 4”获得来自两分支的共有价值，而“误读”得到低 credit。若后续训练已把正确动作概率推高到 teacher 目标，就不再重复加码；这与整条轨迹 broadcast 的行为不同。

Baseline Comparison

主要对照 ReAct（不做 RL）、GRPO（组相对 outcome）、GSPO（序列级比率）、TreePO（树信用分配但无同样有限 teacher）。关键 strongest baseline 是 TreePO：它已拥有树结构，因此两者差距更能定位 posterior distillation 的贡献。不能将跨不同模型大小的结果直接视作算法因果对照。

Experiment Setup / Research Questions

RQ1：长程 Deep Research 是否比短程 Multi-Hop QA 更受益？训练 HotpotQA、OpenResearcher 6102 个独立问题；评测 HotpotQA/2Wiki/MuSiQue/Bamboogle 与 BrowseComp-Plus、BrowseComp、GAIA、xbench。主模型 Qwen3-4B-Thinking-2507 与 Qwen3-30B-A3B-Thinking-2507。RQ2：同预算分叉数 M,N 怎么选？RQ3：teacher 目标半径 ρ 多大合适？RQ4：点式 V_i 与 listwise V_child−V_parent 是否等效？比较共享检索条件下的均值，并看训练曲线。

Results：数字、现象与权衡

Qwen3-4B 的 Multi-Hop 平均：GRPO 43.37、TreePO 43.40、TreeOPSD 44.13；增益不大，说明短程任务优势有限。Deep Research 平均：TreePO 13.07 → TreeOPSD 15.45（+2.38），而 Qwen3-30B-A3B 上 17.59 → 21.20（+3.61）；相对 GRPO 的 30B 增益是 +4.97。固定目标半径 ρ=0.25 时，(M,N)=(8,0) Deep Research 11.28，(4,2) 为 15.45，(2,6) 为 14.97；说明适度分叉胜过纯独立采样或过密分叉。ρ 从 0.10 到 0.25 对应 Deep Research 14.62→15.45，升到 0.40 反而回落到 14.69。

Table / Figure Reading

Table 1 把 Multi-Hop 与 Deep Research 并列：前者 4B 只有约 0.7–0.8 点领先，后者 2.38 点，支持“更长交互更有价值”，但仍需逐步长度分层分析。Table 2(a) 以 (M,N) 直接暴露 rollout 分配成本，不是仅报告成功率；Table 2(b) 显示有限目标不能任意放大。Figure 2 是关键机制图：同一树回传 credit、冻结 q_i、训练时更新 p_i；Figure 5 对比 pointwise 与 listwise credit，揭示两个都好的子分支不必互相抵消。

Ablation / Analysis

去掉分叉、令 N=0：Deep Research 15.45→11.28（同预期采样预算比较），说明共享前缀的反事实信息重要；但此比较也改变了轨迹分布。过多分叉 (2,6)→14.97，边际收益下降。半径 ρ=0.40→14.69，teacher 过远有害。作者还讨论相同训练时间下的表现与 pointwise/listwise 对照；这些是方法内控制，但不等于严格识别每个树节点的真实因果贡献。

Claim vs Evidence

Authors Claim：树信用与有限目标分布匹配能稳定长程 agent RL。Experiments Actually Show：两类检索任务、两种主模型下，Deep Research 的平均增益和若干分叉/半径消融支持该论断。What Is Not Yet Proven：没有证明真实因果 credit，无人类复杂反馈场景与多 Agent shared reward 结果；不同工具噪声、不同 policy 更新次数、训练成本下的鲁棒性仍需独立复现。

Contribution

① New Mechanism：共享前缀 rollout tree 的 terminal-to-turn credit。② New Objective：行为策略相对 Bernoulli teacher + Forward-KL 的有限目标蒸馏。③ New Empirical Finding：长程任务的分叉与目标半径存在非单调最优点。④ New Evaluation Insight：用短程与长程任务拆分检验 credit assignment，而不是仅展示单一最终成功率。

Limitation

作者讨论 allocation-aware teacher、tree replay、continual agent post-training 尚待研究。额外风险：同一前缀分叉的环境可重现性、工具调用的非确定性、分支概率估计偏差，以及将“未来分支的好坏”归因于当前节点时的混杂。树采样带来额外 rollout 和工具费用；“critic-free”并不等于“低算力”。

Research Value

Baseline Potential：可做 RL long-horizon 强对照。Research Migration：将 tree backup 用于 memory 写入/删除、tool selection 和 skill 保存的信用分配。System Value：需要可恢复的轨迹节点、共享前缀和 verifier 接口。Benchmark Value：可设计可控错误注入的 multi-session agent task。Attack/Evaluation：测 reward hacking 与错误 credit。New Paper Potential：将 pointwise credit 扩展为跨 session/agent 的因果近似，并建立真实反事实验证协议。

Migration：可执行最小实验

Original Problem：单 agent 多轮检索终局奖励稀疏 → Transferable Mechanism：前缀分叉 + reward backup + 有界 teacher → New Research Question：哪个 memory 写入动作真的提升未来会话任务？→ Method Modification：把 write/retrieve/evict 作为树节点，按未来问答正确率与检索成本回传 credit → Minimum Experiment：同一历史固定，分叉“写入/不写入/改写”三种后续 → Model：Qwen3-4B 或同级开源 agent → Dataset：LoCoMo、LongMemEval-S → Baseline：GRPO、Mosaic、固定启发式 memory → Metric：未来准确率、credit 排名与反事实差异相关性、token 成本、10/100-step 稳定性 → Expected Contribution：memory-level causal-credit benchmark + 算法 → Risk：反事实环境不一致和计算预算高。

五句话总结

第一，长程 agent 的终局奖励无法直接可靠地分配给每一轮。第二，共享前缀分叉能获得更细的结果差异。第三，把 credit 转成有界 teacher 让训练有明确停止点。第四，Deep Research 的收益显著高于短程问答，但并非没有额外采样成本。第五，最值得迁移的是 memory/tool/skill 的“反事实贡献 + 稳定更新”组合。

Tier SRLRECENT Lean4AgenticRL: Advancing Agentic RL with Verifiable Multi-level Process Rewards

arXiv:2610.22448 · 2026-10-15 · Ruida Wang, Gerald Friedland, Tong Zhang, Chris Kong · 预印本；Venue 未核验 · 正文 HTML · PDF
Code: 未核验 · Project: 未核验 · Source: arXiv full text

人话版：这篇论文到底干了什么？

终端和软件工程 Agent 通常只在最终修好 Bug 或完成任务时拿到 reward，这会把很多无意义的工具调用和真正解决问题的步骤混在一起。Lean4AgenticRL 把任务拆成可检查的 workflow stage，给每个 tool call、阶段完成情况和最终结果不同层级的反馈；能由 Lean4 或代码判定的尽量形式化，不能机械判定的保留 LLM judge。再用 workflow-stage-normalized GRPO 训练 LAR-9B/27B。27B 模型在 TerminalBench-2.1 达到 77.3%，相对 Qwen3.8-27B 的 69.6% 高 7.7 个百分点。核心价值不是“Lean4 自动保证整个 Agent 正确”，而是把中间过程从模糊语言评分转成部分可验证的 reward。

Background & Research Gap

Outcome-only RL 可能在最终成功时奖励了大量重复命令、盲目搜索或跳过测试的行为；失败时又无法区分“正确定位 bug 但修复失败”和“完全没找对文件”。手工流程能约束行为却不够灵活，纯 ReAct 能适应任务但很难给每一步稳定监督。作者设计 PSWF（problem-specific workflow）在探索后制定阶段计划，并用 predicate 的前置/后置条件给阶段结果提供可检查标准。

Core Insight

Reward 的可信度与粒度可以分层：低层的 toolcall 是否合理、中层 workflow stage 是否达标、高层最终任务是否完成，各自提供不同信息。形式系统不必验证自然语言的全部语义；只要把可决定的约束交给 Lean/Python，把语义判断单独标记，就能比全靠 LLM judge 更可审计。尤其“重复命令”可通过低层惩罚 γ 抑制，这是论文消融中有数字支持的具体机制。

Method Deep Dive

Input：任务描述、可执行环境和通用 workflow → ① Planning Agent 探索代码库/终端，形成针对任务的 PSWF；② Execution Agent 依阶段调用工具，记录 action/observation；③ 把真实轨迹对齐到 workflow 的 stage，循环访问阶段时另记实例；④ 以 precondition/postcondition 检查阶段是否完成，产生 β；⑤ 对低层无效工具行为计算 γ，对整体任务计算 outcome reward；⑥ 在统一 harness 汇总层级信号，用 workflow-stage-normalized GRPO 更新模型。PSWF 本身也是执行时的引导，不应把它的收益全部归功于 reward。

RL Formulation 与公式直觉

State 是代码库、终端、计划阶段与历史 observation；Action 是模型生成的工具调用和最终回答；Trajectory 是完整 SWE/Terminal 任务过程；Reward 至少含最终 outcome、stage β 和 toolcall γ；Policy 是 LAR-9B/27B；Advantage 由组内相对奖励经 workflow-stage 归一化进入 GRPO。论文中的阶段 β 在满足附加 postcondition 时取 +1，否则 −1；部分谓词用 Lean/Python 决定，语义谓词依赖 LLM judge。核心差异是奖励分辨率，而非凭空保证每个动作的因果正确性。

Code: 未核验 · Project: 未核验 · Source: arXiv full text

人话版：这篇论文到底干了什么？

视频扩散 Transformer 在每个去噪步骤里重复做昂贵的 dense self-attention。作者观察到：不同 prompt、随机种子和 denoising step 下，一些 layer/head 的高注意力区域会反复出现。于是先用少量样本离线测出这些稳定的 attention sink block，推理时固定只算这些重要 block；但为了避免完全丢掉远处上下文，再增加一个低分辨率 pooled-KV 补偿支路。这个替换不需要重新训练，也不改采样步数。Wan2.1-T2V-1.3B 报告端到端 1.54× 加速，Z-Image-Turbo 1.57×。价值在于同时报告真正 wall-clock 与质量，而不是只给 FLOPs 理论值。

Background & Research Gap

Video DiT 的 token 来自时间×空间 patch，长度增长后 attention 近似 O(N²)，而去噪要反复运行相同网络。传统全局 sparse mask 可能丢失远程动作一致性；动态 top-k mask 需要额外计算和排序，理论节省不一定转成 GPU 真实加速。这里的问题是：能否在不训练的条件下，利用跨输入稳定的 attention 结构，预先决定大部分计算位置，并给剩余上下文留一个便宜的兜底通道？

Core Insight 与 Observation

论文的 Figure 3 分析不同去噪步中高注意力质量块的覆盖：部分层/头存在可复用的高质量区域，且相同预算下明显优于随机 mask。但覆盖率仍低于 100%，因此只保留 sink 会损伤质量。两分支设计对应两个观察：高质量结构可固定复用；遗漏的弱而分散信息可通过 pooled-KV 粗略补偿。这个 insight 不等于所有视频输入的注意力模式都静态。

Method Deep Dive

Input：预训练 Wan2.1 或其他 DiT + 小规模 calibration prompts → Offline ① 运行 dense attention，记录每个 layer/head/step 的注意力概率；② 按 query/key block 求精确概率质量并跨样本平均；③ 对每个 query block 排序，取达到阈值 τ 的最短 key-block 前缀，形成静态 mask。Online ④ 直接在 sparse sink block 上做 attention；⑤ 保留 full-resolution Q，对 K/V 池化后算一条全局粗粒度补偿支路；⑥ 按两个支路的 log-sum-exp 质量融合输出；⑦ 后续 denoising step 复用相同 mask。它没有减少 diffusion step，也没有跳过整个 Transformer layer。

关键公式 / Objective

令 m_{r,c} 为 query block r 对 key block c 的平均 attention probability mass；mask 选择满足 Σ_{c∈selected} m_{r,c}≥τ Σ_c m_{r,c} 的最小集合。在线主支路密度为 ρ，补偿池化率为 g_comp，则主要复杂度近似 O[(ρ+1/g_comp)N²]，而 dense 为 O(N²)。这只是 attention 算子的近似复杂度，不能直接把 1/(ρ+1/g_comp) 当成端到端加速。论文常用 g_comp=30，示例 τ=0.70/0.85；τ 高一般保留更多块、质量更稳、速度更慢。

Toy Example

想象 100 帧视频有大量静止背景和一个移动主体。某 attention head 长期关注主体附近与特定全局 token：离线测量后，每个 query block 只计算那些常被关注的 key block；但如果后续出现新的物体，静态 mask 可能漏掉，因此 pooled-KV 分支仍让所有 query 看见粗略全局摘要。这样减少的是 QK/AV 的细粒度 pair 计算，而不是少读视频帧。

Baseline Comparison

视频对照 Dense FlashAttention、SVG1、SpargeAttn；图像对照 Dense 和 SpargeAttn。最重要 strongest baseline 应优先看相同实现栈的 SpargeAttn，而非未优化 dense。论文强调 QK-norm、RoPE 等实现保持一致，避免把不同 kernel 的收益错算给新算法。不同模型与不同生成分辨率之间的 speedup 不可直接比较。

Experiment Setup / Research Questions

RQ1：固定 mask 是否能跨 prompt/seed/step 复用？离线 calibration 与评测 prompt 分离。RQ2：补偿分支是否比纯 sparse sink 更好地保留质量？RQ3：阈值 τ 的速度/质量 Pareto 怎样？RQ4：校准集增大是否继续有收益？视频采用 Wan2.1-T2V-1.3B，默认 50 denoising steps，质量参考 VBench 多维指标；图像采用 Z-Image-Turbo，在 2048×2048、8 steps 上评 Soft-TIFA 和时间。核心测量是端到端秒数，不是仅算 attention FLOPs。

Results：数字与权衡

视频 Wan2.1-T2V-1.3B 报告端到端 1.54×；同栈 Dense 基准 164.80 秒，因此对应方法耗时约 107 秒（由速度比推算，非原表精确数）。图像 Z-Image-Turbo：Dense 23.39 秒，Ours-Hybrid 14.88 秒，即 1.57×；SpargeAttn 为 15.92 秒、1.47×。图像 Soft-TIFA AM：Dense 67.80、SpargeAttn 66.88、Ours 66.48，说明加速伴随约 1.32 点质量下降，不能称为完全无损；Soft-TIFA GM 16.38→15.21。视频质量作者报告维持，但具体各维绝对差应以原表核对，不能只用摘要代替。

Ablation / Analysis

去掉 pooled-KV 只用 sink，会暴露遗漏全局上下文的质量风险；τ 较大时保留更多 block，速度收益收缩。作者比较 2×2、4×2、4×4、8×4 prompt-seed 校准预算，质量在中等预算附近趋于饱和；4×2/4×4 因而更实际。需要补的消融是不同运动强度、镜头切换、长视频持续时间与跨域 prompt 的分组分析。

Contribution

① New Mechanism：layer/head-specific static attention sink。② New System：静态稀疏分支与 pooled-KV 全局补偿。③ New Empirical Finding：少量校准后复用，端到端视频 1.54×。④ New Evaluation Practice：同实现栈比较真实 latency 与生成质量，优于只给理论稀疏率。

Limitation

Migration：可执行最小实验

Input：多帧视觉 token → 帧内 optimal-transport inspired matching → 帧间相似帧合并 → 压缩 token 序列交给 VLM。其 insight 是“压缩顺序影响压缩器本身的计算开销”，不是只看最终 token 数。作者称 training-optional，意味着存在无需额外训练的部署路径，但不能假设所有设置完全无训练。

Experiment / Main Finding

论文在 LLaVA-OneVision、InternVL-2.5、LongVA 上测试，强调 zero-shot 精度保留。已核验数字：最多 45% 推理加速、10% token budget 下 55.7% 准确率。FLOPs、显存、FPS 的统一绝对数值未核验，不能从 45% 直接推出 FLOPs 降幅。最值得看压缩预算—准确率曲线与实际 wall-clock。

Contribution / Limitation / Connection

贡献是空间+时间双轴 token 合并和有顺序的计算预算设计。局限是细粒度瞬时事件、小目标和跨帧运动关系可能在合并时消失；query-aware 的重要帧不一定是全局最相似的帧。与 QART 的交叉是让 query 决定哪些时间冗余可安全删除。

Potential Use

最小实验：在 Video-MME 按静止、切镜、小目标三组对比 VETO、均匀采样和 QART-style 选择，测 token、真实延迟、准确率、peak memory；特别检查 10% budget 下时间顺序题是否先崩。

MemCompile 认为 memory retrieval 返回“相关片段”不等于给 reader 一份“可直接回答问题”的上下文。它把寻址与证据呈现分成 Address Plane 和 Evidence Plane：前者通过源链接描述符与容量感知单元找候选，后者在预算内选择互补来源，编译出 answer-ready evidence。LoCoMo 报告 80.52% Judge Accuracy，并称扩展了质量—成本 Pareto 边界。

Background / Core Method

Experiment / Main Finding

Contribution / Limitation / Connection

贡献是 Address/Evidence 双平面、stable SourcePacket、预算感知证据编译。局限是 packet 标准化可能丢失原始时间关系；证据选取仍依赖 query-specific heuristics。与 QEMem 的 Collision 在“query-conditioned sufficient evidence”，差异在源归一化、预算分配和迭代缺口修复。

Potential Use

Tier BRLRECENT Distill Until Divergence: Error-Truncated Hindsight Distillation for Agentic RL

展开完整技术分析（含实验、局限与迁移）

人话版

Agentic RL 的 hindsight distillation 往往把成功/失败轨迹提炼成 skill，再让模型按 skill 改写所有后续步骤。但如果中途一个错误动作已把环境状态改变，错误之后的 skill 可能不再适用。该论文提出 error-truncated hindsight distillation：成功轨迹和错误前步骤用 positive skill，决定性错误用 negative skill 修正，错误之后的 suffix 只用 GRPO，不继续灌输可能状态错配的 skill。

Background / Core Method

Input：轨迹与终局结果 → 识别 error boundary → 从成功路径抽 positive skill、失败原因抽 negative skill → 根据 outcome 与边界路由不同蒸馏监督 → 对 post-error suffix 只做 outcome GRPO。它把“经验是否适用”与“轨迹处于哪个环境状态”关联起来，优于简单全轨迹 skill broadcasting 的直觉。

Experiment / Main Finding

论文摘要称在多个任务上有竞争力并支持更细 credit，但本轮未核验具体模型、数据集和主表数字，因此不把其结果描述成某个百分点提升。优先阅读 error boundary 判定方式与错判时的 sensitivity ablation，尤其检查 negative skill 是否依赖 oracle 失败标注。

Contribution / Limitation / Connection

贡献是 error boundary-aware skill supervision。局限是错误边界可能模糊，成功路径也可能含无效步骤；不正确的 hindsight skill 会放大后续偏差。与 TreeOPSD 的联系是都拒绝把终局 outcome 无差别传播给所有步骤，但一个用状态边界，一个用树状反事实后续。

Potential Use

对长程工具 Agent 注入一个确定的错误工具结果，比较全程 distillation、error-truncated、tree backup 的恢复率与错误传播深度；如果 10/100 步都能降低错误扩散，才有潜力作为新训练目标。

Potential Use

最小实验：在 3–5 个结构相似的模拟网站上训练 source adapters，测试页面重排/按钮改名/新增流程；对照单 adapter、检索最相似 adapter、WebMix，测成功率、scout token、目标站点更新次数与误调用率。

1. Session–Turn–Memory Causal Credit：跨会话记忆贡献的层级反事实学习

Inspiration：TreeOPSD + Mosaic + AiO-Mem + QEMem

Research Gap：现有方法分别在 turn、session、memory operation 层分配 credit，但缺少统一的“哪个写入动作提高后续跨会话正确率”可复现实验；单看 retrieval hit 无法识别真正效用。

Hypothesis：把可恢复 session tree 与 memory write/no-write 分叉结合，能比 broadcast advantage 更准确识别有益 memory，并减少无效写入。

Proposed Method：在固定历史前缀上分叉：保留、删除、改写候选记忆；让后续相同 query 集执行，计算成功差异与 token 成本；先估计 session-level credit，再在 session 内回传 write/retrieve/evict 的 turn-level credit；用有界 teacher 更新 policy。

Minimum Viable Experiment：从 LoCoMo 选 100–200 个跨会话问题，每个建立 3 个 memory counterfactual 分支，冻结 reader，先只评估 credit 与未来性能差异的相关性，再训练轻量 router。

Model：Qwen3-4B-Thinking 或同级开源模型

Dataset：LoCoMo、LongMemEval-S

Baseline：GRPO broadcast；Mosaic；TreeOPSD；AiO-Mem-style reward；固定 Top-k

Metric：后续 QA accuracy、counterfactual credit correlation、token/episode、write utility、错误传播率

Expected Contribution：新层级 credit benchmark + 可审计 memory attribution，先测量再优化

Risk：多分支环境复现难；检索随机性会污染因果估计；开销较高。

Collision Risk：HIGH：Mosaic 已覆盖 session advantage，TreeOPSD 覆盖 turn tree，AiO-Mem 覆盖 memory process reward。必须以跨会话 memory 操作的可检验反事实贡献为新点。
