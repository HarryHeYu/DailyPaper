Tier S

STrajectory Unlearning on LLM-based Agents
Yingdan Shi, Ren Wang · 2026-09-27 · Paper

人话版：这篇论文到底干了什么？

过去 LLM unlearning 多数问“模型还能不能说出被删知识”；这篇论文改问“Agent 还能不能再次走出被删掉的行为路线”。作者认为 Agent 的风险可能藏在长程 action sequence 中：单个动作完全合法，但特定上下文下的一串动作会形成恶意/过时行为。因此它把 trajectory 本身设为 forget unit，并提出 GiRPO：将 forget trajectory 注入 GRPO rollout group、给负向 reward，同时隔离其 advantage normalization，避免忘记信号污染正常轨迹。

Background & Research Gap

知识 unlearning 把训练样本、实体或问答对当删除单位；Agent 却是在环境状态上连续决策。论文用 household 例子说明：完成“把闹钟放桌上”的成功轨迹中可夹入一个无关的 run microwave。这个动作本身不是恶意 token，若直接 action blacklist 会破坏其他正常任务；真正要删除的是“在这一状态历史下复现这条动作序列”的条件行为。

Core Insight / Method Deep Dive

Input → target tasks + forget trajectories → normal group rollout → inject forget trajectory with penalized reward → isolated advantage statistics → policy update → alternative successful trajectories. Agent 被写成 POMDP，history 为 h_t=(o0,a0,...,ot)，policy 是 πθ(a_t|h_t)。目标同时包含：不再复现指定 τf；target 与 untarget task 的 Success Rate 仍高。

GiRPO 的关键不是“负 reward”本身，而是 isolated normalization。GRPO 依赖组内 reward 的相对均值/方差；若极低 forget reward 直接参与正常 rollout 的统计量，会连带改变所有正常 trajectory 的 advantage，造成 utility collapse。GiRPO 把 forget trajectory 的负向梯度做成稳定、有界的独立信号。

关键 Metric / 公式直觉

Success Rate 衡量任务是否仍完成；Exact Match 看动作序列是否完整复现；LLM-as-Judge Similarity 捕捉“没有逐字一样但行为语义仍近似”的泄漏。三者组合非常重要：只把 Exact Match 压到 0 可能只是换了同义动作，而只看 Success Rate 又无法证明 forgetting。

Toy Example

同一任务有 A、B 两条成功路线，A 含恶意中间动作。GA/NPO 若逐 token 压 A，可能连 A/B 共用的 “pick up alarmclock” 一起损伤；GiRPO 把完整 A 作为负轨迹，同时让 B 与其他 rollout 正常竞争。理想结果是 A 的 exact/semantic similarity 下降，但任务仍通过 B 完成。

Baseline Deep Comparison

知识型 GA/NPO 把轨迹拆成响应，忽略 inter-step dependency；prompt-based Secure Forgetting 不改参数，因此原始行为能力可能重现；SBU/Agentic Unlearning 解决 parameter-memory backflow，但主要删除 knowledge influence。GiRPO 的机制性新增点是 sequence-level policy unlearning，而不是单纯 memory pruning。

Experiment Setup & Research Questions

环境覆盖 ALFWorld household tasks 与 WebShop online shopping。RQ1：指定轨迹是否不再复现？RQ2：target task 能否改走其他路线？RQ3：untarget utility 是否保持？RQ4：知识 unlearning baseline 能否真正删除行为？评价用 Success Rate、Exact Match、LLM-as-Judge Similarity形成 forgetting–utility 双轴。

Results / Figure / Ablation

正文报告 GiRPO 在两套 benchmark 上均优于知识 unlearning baselines 的 forgetting–utility trade-off，并保持 target/untarget task success。Figure 1 是最重要的问题定义图：左侧“知识不输出”并不推出右侧“行为不复现”。主实验应联合读 Exact Match/Similarity 与 Success Rate，而不能单看 forget 指标。当前网页正文抽取没有稳定暴露所有主表单元格，因此本报告不编造未核验精确数字。

Strongest result：行为删除与任务能力可以解耦。Weakest evidence：仅两个文本式 Agent 环境；尚未证明 computer-use、multi-agent、真实 tool API、长期 relearning/rebound。

Claim vs Evidence

Authors Claim：trajectory 是 Agent unlearning 的独立删除单位。Evidence：两个长程环境、三类指标和 GiRPO 对比支持。Not proven：跨 Agent 传播、外部 memory/artifact 污染后的系统级消除、adaptive recovery 与 deletion closure。

Contribution / Limitation / Research Value

New Problem + New Objective + New Benchmark + New Mechanism。最大的研究价值是它可以直接成为 Agent Unlearning 新 baseline。限制是环境与模态窄、相似性依赖 evaluator、没有持续更新后的 reacquisition。

Migration Analysis

Original Problem 单 Agent trajectory deletion → Transferable Mechanism group-injected negative trajectory + isolated credit → New RQ 多 Agent 协作轨迹能否闭包删除 → Modification 将 trajectory 扩成 provenance-linked subgraph，按 Agent/action/artifact 分配 credit → Minimum Experiment 2–4 Agent 的 ALFWorld/WebShop workflow，构造 100–300 poisoned collaboration traces，比较 GiRPO/SBU/NPO/flat memory delete；删除后重新注入关联 artifact → Metrics trajectory similarity、task success、cross-agent leakage、reacquisition rate、closure coverage → Expected Contribution Multi-Agent Trajectory Unlearning + Deletion Closure → Risk credit assignment 不稳定 → Collision Risk HIGH。

只记 5 句

  1. Agent 应忘的不只是知识，还可能是一整条行为路径。
  2. 单个动作合法不代表动作序列安全。
  3. GiRPO 用隔离归一化避免 forget signal 污染正常 rollout。
  4. 评价必须同时看 trajectory similarity 与 task success。
  5. 下一步最自然的是 multi-agent provenance-aware trajectory deletion closure。
SMACE: Memory-Agent Co-Evolution with Adaptive Memory Graphs for Multi-Agent Systems
Kairui Yang et al. · 2026-09-18 · Paper

人话版

MACE 不是 unlearning 论文，但它几乎给 Multi-Agent Unlearning 提供了现成的“删除对象”。它把协作历史组织为 functional memory units：条件、动作、输出组成局部子图，再用 support/conflict/repair 关系连接。这样复用 memory 时不把前置条件和下游产物拆散。对于删除问题，这意味着不能只删一条 note，而应沿 functional dependency 做 closure。

Background & Gap

MAS 的 flat memory 容易把“前置条件→动作→产物→下游使用”切断。MACE 的 gap 是：最小可复用单位必须保留功能依赖，而且 memory composition 与 presentation format 要联合适配 Agent 的 role/stage/state。

Method Deep Dive

trace → need descriptor → functional memory graph cell → typed outer relations → budgeted working graph → agent-specific guide/checklist → outcome feedback → update unit/relation/use scores. MemGoG 负责结构；Need-aware Composer 选工作图；Coupler 决定给各 Agent 什么内容、以 instruction 还是 checklist 呈现；Co-Evolver 记录“选了什么 + 怎么呈现 + 结果如何”并更新。

关键数学对象

Agent state 包含 task、role、collaboration stage、history、intermediate artifacts 与 environment response；memory input 有 token budget。Functional unit 的意义是把局部依赖作为不可随意拆开的子图。对 unlearning 而言，如果 U 的输出是 V 的 prerequisite，删除 U 但保留 V 就可能留下 derived influence。

Toy Example

A 查数据库、B 验证、C 写报告。若删除 A 的敏感输入，仅删 A 的 memory 不够：B 的 verification 与 C 的 report 都是派生物。MemGoG 的 support edges 可以直接转成删除 lineage。

Experiments / Results

诊断实验使用 TAT-QA 并以 TabFact 复现。1,024-token budget 下 MemGoG task success 约 80%，Graph 约 68%，Items 约 65%。Functional Units 内部 dependency retention 约 83%，matched grouping 约 68%；加入 outer relations 后 cross-experience complete support 从 52% 提至 69%。Composition-format 甚至发生反转：S1 中 guide 下 C1≈82% vs C2≈76%，checklist 下变成 59% vs 78%。192 calibration tasks 后 Joint≈85%，Fixed≈78%，Separate≈75%。最终 8 benchmarks 平均 81.11%，strongest baseline SAGE 为 78.97%。

Table/Figure / Ablation

Figure 1 四个 panel 是 load-bearing evidence：组织粒度、跨经验关系、composition×format interaction、joint feedback。Figure 2 把 MemGoG→Composer→Coupler→Co-Evolver 串成 pipeline。作者还对 construction、composition、coupling、feedback 做 ablation，支持提升并非单一 retrieval trick。

Claim vs Evidence / Limitations

证据支持“依赖完整性比 flat retrieval 更重要”，但没有证明图边是真实 causal provenance，更没有测试 deletion。LLM 构造 unit/relations 可能错连或漏连；若拿它直接做 unlearning closure，false negative 就会成为泄漏路径。

Contribution / Research Value

New Mechanism：functional memory unit + graph-of-graphs；New Empirical Finding：composition 与 presentation 强交互；Engineering：feedback co-evolution。对 Multi-Agent Unlearning 的价值在于结构迁移。

Migration

Original MAS memory reuse → functional dependency graph → 删除 source 后哪些 unit/artifact/state 必须失效 → 为每个 unit 加 provenance source-set 与 derivation edge → 最小实验：在 TAT-QA/TabFact 历史中植入 50 个可追踪敏感事实，比较 entry deletion、k-hop deletion、exact provenance closure；测 leakage、utility、closure size、recovery after new task → Baseline SBU/G-Memory/flat RAG deletion → Expected: Dependency-Closed Multi-Agent Memory Unlearning → Collision MEDIUM-HIGH。

只记 5 句

  1. Memory 的正确删除单位可能是 functional subgraph。
  2. 83% vs 68% 显示功能边界保留更多依赖。
  3. outer relations 对跨经验 closure 关键。
  4. 内容与呈现方式不能独立优化。
  5. MACE 是 provenance/deletion-closure 的优秀结构底座。
SShare-Borne AI Virus: Memory-Hopping Attacks Across LLM Agents
Sidharth Pulipaka et al. · 2026-09-28 · Paper · Code

人话版

共享 artifact 可以把原本互不通信的持久记忆助手连成传播网络：一个助手读恶意文件，把攻击状态存进 memory；以后生成正常文件时把状态带出去；另一个助手读到后继续传播。大型模拟中 GPT-5.6 Luna 可覆盖约 60–80% agents、最长到 8 hops。对 unlearning 而言，它是“删除后由外部世界重新感染”的天然压力测试。

Method

poisoned artifact → persistent memory infection → later benign writing → payload reproduction → artifact sharing → clean assistant acquisition → repeat. 作者在 temporal human-agent universes 中测 hop survival、infection fraction、传播树和 exfiltration。主实验为 endpoint-assisted variant；外部 endpoint 会 canonicalize payload，因此 headline 结果不能被解释成“所有默认 Agent 都自然自复制”。

核心量 / Toy Example

Hop survival S(k) 表示链至少活到第 k 跳；per-hop continuation 可用几何 survival 近似。例：A 助手读 report 后记住“以后报告附带 X”；A 给 B 写普通报告时夹 X；B 的助手读后保存 X。即使 A 会话结束，攻击状态仍活在 artifact+memory 链中。

Experiments / Results / Figures

Held-out synthetic universes 上，DeepSeek-V4-Pro goal-infection 约 98%，GPT-OSS-120B 约 85%；hop-4 survival 约 76% 与 61%。30-agent 大型描述性 universes 中，GPT-5.6 Luna 约覆盖 60–80%，最长 8 hops。Figure 2 看 hop survival；Figure 3 拆 exposure→memory infection→artifact reproduction；Figures 4–6/10–15 展示 contact network、传播树和 epidemiological dynamics。

Ablation / Failure

Prompt-only 版本显著更弱：full infection 约 21%、S(2)≈0.30。严格 egress controls 与 memory-write screening 会切断机制；security-critical goals 更难传播。这些都是对 headline claim 的重要边界。

Claim vs Evidence

已证明的是：在评测 harness 中，共享 artifact 能承载跨独立助手的持久攻击。尚未证明生产消费者系统默认 memory gate 下有同等传播率，也没有覆盖所有组织网络和 artifact 类型。

Contribution / Limitation / Research Value

New Attack + New Evaluation Protocol + New Empirical Finding。 对 unlearning 最重要的是把 recovery 从“同一模型被提示恢复”扩成“另一个 Agent/外部 artifact 把已删影响重新写回来”。

Migration

Attack propagation → artifact-memory lineage → deletion verification。最小实验：先感染 3 hops，再比较仅删第 2 Agent、本地全删、provenance closure 三策略，继续运行 20 steps；测 residual infection、rebound time、contaminated descendants、utility。Expected: Recontamination-Resistant Agent Unlearning。Collision HIGH but differentiable。

只记 5 句

  1. 共享文件是 Agent 间隐式通道。
  2. persistent memory 让攻击跨会话存活。
  3. 60–80% 来自大型描述性模拟。
  4. prompt-only 明显更弱，endpoint assistance 是关键边界。
  5. 它是 deletion closure 的天然 adaptive attack。

ARRSI: Regularized Recursive Self-Improvement of Agent Harnesses
2026-09-23 · Paper · Project

人话版

Agent harness 自动进化很容易把 benchmark 记住。RRSI 不限制“改什么”，而是 regularize “怎么搜索和接受修改”：annealed edit budget、evidence ledger、leakage critic、noise floor、cost rule、pruning。它对 continual unlearning 的启发是：删除策略也可能只对固定 forget prompts 过拟合。

Method / Experiment

Proposal-side 限制每轮改动规模并鼓励未探索组件；selection-side 先筛 benchmark leakage，再要求 gain 超过噪声地板、额外 token 成本必须被收益支付，并删掉不再有贡献的组件。Harvey LAB 上 unregularized evolution evolve score 92.8，高于 RRSI 90.5；但 OOD Avg 40.3 vs 43.6，policy tokens 3.80M vs 2.42M。去 proposal regularizers 后 OOD 41.9；去 acceptance regularizers 后 41.0，说明两侧都贡献。

Contribution / Limitation / Migration

New Mechanism + Empirical Finding。限制是有限 evolve set、手调 regularization、frozen weights。迁移：把 unlearning maintenance rule 当 harness edits；每次 deletion 后在 unseen paraphrase/attack/relearning set 上做 noise-aware acceptance，避免“forget-set overfitting”。Minimum experiment：50 sequential deletion episodes，比较固定 unlearning 与 RRSI-style maintenance，测 rebound AUC、utility、token cost。Worth Deep Reading: YES。

AMachine Unlearning for Large Language Models: Foundations, Advances, and Agentic Extensions
2026-09-25 · Paper

人话版

这篇 survey 把“删模型知识”升级成“删部署系统里的影响”。五层框架：Request semantics→System scope→Information locus→Intervention→Evidence-backed claim；七阶段：Request→Scope→Localize→Execute→Propagate→Verify→Maintain；六证据维度：efficacy、specificity、utility、robustness、persistence、completeness。

AAgent Zero Memory: Provenance-Aware Long-Term Memory for LLM Agents [BACKFILL]
2026-08-30 · Paper

人话版

AMemSentry: Detecting Persistent Memory Poisoning in Agentic AI
2026-09-08 · Paper

人话版

MemSentry 把防线放在 persistent-memory write path：每次写入输出 Accept/Review/Quarantine，综合 source trust、semantic risk、dependency-DAG attack radius、access risk 和 security-state delta。

Experiment / Result

Migration
