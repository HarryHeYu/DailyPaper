Formal Papers

Tier S · T1: Terminal Agent Reinforcement Learning for Long-Horizon Tasks — RL / Agent

Paper / accessible overview

人话版

T1 把 RL 真正推到 300+ tool-call 的终端 Agent：122B MoE 在真实 shell sandbox 中工作，并针对长轨迹最棘手的两个问题——稀疏 reward 与 rollout/training 不一致——设计训练方案。Terminal-Bench 2.1 从 base 43.8% 提升到 64.0%，Long-Horizon Terminal Bench 达到 27.9%。

Background & Gap

终端任务里，一条失败轨迹可能已经修复 8/10 个测试；纯 0/1 terminal reward 无法区分它和完全失败。另一方面，多轮消息重新 tokenization、MoE router 的数值微差会让训练 forward 与真正生成轨迹走不同 token/expert，导致 policy ratio 不再对应采样行为。

Core Insight / Method Deep Dive

Task → warm-start → shell rollout → verifier partial reward → TITO → R³ → actor-critic update。TITO 保存 sampled token IDs，避免 text↔token 往返产生 drift；R³ 记录 rollout 时每层 expert choice，并在训练 forward 中 replay。训练仍更新 router 权重，但用于 loss 的执行路径与 rollout 对齐。

RL Formulation & Reward

State=对话+shell 状态；Action=token/tool call；Trajectory=多轮命令与观察；Reward=任务 verifier，并以通过 verifier 的绝对数量提供更 dense 的进度信号。它比纯 outcome reward 更利于 credit，但也存在 verifier hacking 风险。作者用与 Terminal-Bench 隔离的 synthesized/OOD tasks 降低 benchmark overfitting。

Toy Example

任务有 5 个测试，agent 第 80 步已经通过 4 个但最终失败。terminal reward=0 会抹掉进展；partial verifier 能保留 4/5 信号。若第 37 步 rollout 走 MoE experts A/B，训练时因微小漂移走 A/C，R³ 强制重放 A/B，使该动作的概率比有意义。

Experiment / Results / Figure

RQ1：RL 是否提升真实长程能力？43.8%→64.0%，+20.2pp。RQ2：一致性机制是否有效？training-to-inference log-prob gap 0.021→0.013，loss region token drift 为 0。RQ3：是否泛化到更长任务？Long-Horizon Terminal Bench 27.9%，论文报告超过 GPT-5.4 与 GLM-5.1。主 benchmark bar chart 最值得看，因为同一 backbone 的 base/SFT/RL 对照减少“只是模型更大”的混淆。

Claim vs Evidence

证据支持“可稳定训练超长 terminal trajectory”与“同 backbone capability 显著提升”；尚未证明 web/GUI/robotics 等弱 verifier 环境同样成立。

Contribution / Limitation

① New Training Mechanism：TITO；② New Training Mechanism：Rollout Routing Replay；③ New Empirical/System：300+ tool-turn RL recipe。限制是 verifier-rich、122B MoE 成本高，partial reward 仍没有精确定位到哪个 action。

Migration

Original terminal RL → exact trajectory provenance → multi-agent handoff credit。MVE：2-agent WebShop/AppWorld，记录 agent-id/tool/memory-write/handoff，比较 terminal GRPO、turn credit、provenance-aware credit；指标 success、sample efficiency、credit localization、wall-clock。

五句话

长 Agent RL 首先是轨迹一致性问题。稀疏 terminal reward 太粗。TITO 修 token drift，R³ 修 MoE routing drift。43.8→64.0 是硬结果。最值得迁移的是 exact rollout provenance + hierarchical credit。

Tier S · KV-streams for Efficient Compaction in Agentic Reinforcement Learning — RL / Agent / Inference

Paper / accessible overview

人话版

Agentic RL 为控制长 context 会反复 compaction；传统方案每次压缩后重新 prefill，吞掉训练吞吐。KV-streams 让 KV 跨 compaction 边界继续流动，在三种 compaction 策略上报告 2.6–5× wall-clock training speedup，且没有观察到性能受损。更关键的是：KV 能携带已经从显式 context 中消失的信息。

Gap / Method

Long rollout → compaction → textual context shortened → stream prior KV → continue → RL update。它减少的是 repeated prefill/KV rebuild，不是模型参数量。显式摘要删除文本并不意味着 hidden state 被清空。

Experiment / Results

RQ1：是真实加速还是 FLOPs 纸面加速？报告 2.6–5× wall-clock，因此证据很强。RQ2：性能是否掉？作者未发现明显损害。RQ3：KV 是否仅是 cache？controlled experiment 表明 streamed KV 可充当 recurrent state，保留早已不在文本 context 的信息，并可由 RL 自发学出。

MetricBaselineKV-streams
Compaction 后 prefill重算stream KV
Wall-clock training1×2.6–5×
Qualityreference无明显下降证据

Contribution / Limitation

New System Mechanism：跨 compaction KV streaming；New Empirical Finding：KV 可成为隐式 recurrent memory。风险是 stale state、权重更新兼容性，以及 privacy/deletion closure：文本删掉后信息可能仍存在。

Migration

做 KV Ghost Memory Audit：长 Agent 写入 canary→compaction 删除显式文本→比较 stream-KV 与 flush-KV；测 canary extraction、task utility、latency、GPU memory。这同时连接 Agent Memory、Efficient RL、Security/Unlearning。

五句话

它加速 compaction 后的重复 prefill。真实 wall-clock 2.6–5×。KV 可能是隐式长期状态。系统收益和安全风险来自同一机制。最值得追的是“文本删了，KV 真的忘了吗？”

Tier S · Resource-Efficient Speculative Decoding for Long-Context LLM Serving — Inference

Paper / accessible overview

人话版

SpecStream 针对长上下文 speculative decoding 的 KV offload：传统系统先把完整历史 KV 从 CPU 搬回 GPU 才开始 verification；它一边流式恢复 KV、一边验证，并用等待内存传输的 compute bubble 同 GPU drafting。

Bottleneck / Acceleration Mechanism

瓶颈是 decode verification 的 KV memory traffic。系统只 offload Target 已 commit history，candidate rollback 留 GPU；每个 streamed chunk 服务本轮所有 query，online softmax 保持 full attention；Target-priority scheduling 控制 Draft 干扰。

MetricResult
Qwen3 throughput相对 offload baseline 平均 1.41×
InternLM2.5 throughput平均 1.32×
Output throughput / GPU相对独立 Target/Draft GPU +55.4%
Quality接近 SGLang speculative decoding

Experiment / Evidence

最强结果是 per-GPU throughput；这是真 wall-clock/serving 指标，不是只给理论复杂度。弱点是收益依赖 PCIe/CPU memory bandwidth、context length、batch 与硬件拓扑。

Contribution / Migration

New System：streamed KV verification；Scheduling：Target-priority concurrent drafting。无需重新训练模型。MVE 可直接放到 AppWorld/terminal Agent 的 32k/64k/128k trajectory，报告 TTFT、TPOT、tokens/s、GPU memory、task success。

五句话

核心瓶颈是 KV 搬运。verification 与 restore 被重叠。Qwen3/InternLM2.5 为 1.41×/1.32×。per-GPU throughput +55.4%。这是今天最扎实的 inference systems 工作。

Tier A · AgenticRag-R1: Agentic Reinforcement Learning with Stack Memory — RL / Agent

Paper / accessible overview

人话版

把 RAG Agent 的 memory 从 append-only 文本改成可 push/pop 的 stack，并显式定义 Plan/Think/Search/Backtrack/Summary/Conclusion 六类动作，再用 hierarchical action-aware rewards 训练。价值在于把 memory operation 本身变成 policy action。

Method / RL

State=stack+retrieval evidence；Action=六类 cognitive/tool action；Reward=hierarchical action-aware signal，并用 information-aware trajectory rejection 去掉低信息 rollout。pop-based attention mask 防止已 backtrack 内容继续影响后续推理。

Experiment / Contribution

对比 Search-R1 等 agentic RAG。当前可访问页面未稳定给出完整主表数字，因此不杜撰。New Mechanism：stack memory + explicit memory actions；New Objective：action-aware reward。

Limitation / Migration

LIFO 未必适合图状 evidence。MVE：AppWorld/Search task 比较 append-only、ACM、stack memory，测 success、context tokens、backtrack precision、memory pollution。Worth Deep Reading: YES。

Tier A · Granularity-Adaptive Credit Assignment for Long-Horizon LLM Agent RL — RL / Agent

Paper / accessible overview

人话版

GACA 认为 credit 粒度应该随 state 变化：真正的分叉点要细分，例行步骤不必。它把 GRPO/GiGPO 中固定的 step/episode 混合变成 uncertainty-based criticality 驱动的自适应 estimator。

Method

Reward 仍来自环境/最终结果；创新点是 Advantage estimator。高 criticality state 使用更细 step-level credit，低 criticality state 借助 coarse estimate 降 variance。

Evidence / Limitation

当前页面确认其针对 GiGPO 固定权重缺陷；本次未稳定获得完整主表数字。最大风险是 uncertainty ≠ causal importance。

Migration

扩展为 multi-agent communication-edge criticality，MVE 用 WebShop/AppWorld 比较 GRPO、GiGPO、agent/turn adaptive credit，测 success、variance、sample efficiency。Worth Deep Reading: YES。

Tier A · GSTEP: Global Spatio-Temporal Density-Driven Visual Token Pruning — Video Acceleration

Paper / accessible overview

人话版

GSTEP 把视频看成连续时空信息流，用 frame-change temporal density + intra-frame spatial density 全局采样。LLaVA-OneVision-7B 剪 75% visual tokens，平均性能最高保持原模型 100.2%，但端到端仅 1.17× speedup。

Method

Frames → smoothed temporal density → spatial density → global coverage-aware sampling → VideoLLM。它避免 segment-local quota 丢掉短而密集的关键事件。

MetricChange
Visual Tokens-75%
E2E speed1.17×
Average qualityup to 100.2% baseline
FLOPs/GPU memory本次摘要未给完整数字

Evidence / Limitation

最重要结论反而是 token reduction 没有线性变成 wall-clock speedup，说明视觉编码、I/O、固定 LLM 开销或 kernel 利用率仍是瓶颈。

Migration

做 query-conditioned density + latency budget controller；Video-MME/LongVideoBench 同时报告 tokens、FLOPs、E2E latency、memory、accuracy。Worth Deep Reading: YES。

Tier A · KVShareArena: KV-Cache Reuse Across Contexts and Model Checkpoints — Inference / Agent

Paper / accessible overview

人话版

KVShareArena 专测 RAG/Multi-Agent 中“缓存内容被换位置、重新组合、甚至来自不同 checkpoint”时 KV reuse 是否还可靠，弥补 exact-prefix benchmark 与真实 workload 的差距。

Method

RAG track 组合独立 chunks；MAS track 让 specialized agents 先写 report，再由 coordinator 在新 context 中使用。评估 cache repair 的质量、成本与跨 checkpoint robustness。

Main Finding

摘要指出 training-free repair 对 checkpoint shift 较稳，而只在单 checkpoint cache 上训练的 adapter 会退化。它主要是 New Benchmark/Evaluation，不是新 accelerator。

Migration

把真实 multi-agent handoff traces 转成 benchmark workload，测 TTFT、repair overhead、quality、cross-agent reuse。Worth Deep Reading: YES。

Tier B · Agent Memory Is a Surface for Endogenous Authorization Laundering — Agent Security

Paper / accessible overview

人话版

长期 Agent 会把权限状态写进 memory；一旦摘要错写撤销/授权，Agent 自己的 memory 就可能“洗”出历史上不存在的权限。EAL-Bench 在 procurement、cybersecurity、finance 中测 writer→memory→executor 的错误传播。

Contribution

New Failure Mode + New Benchmark：endogenous authorization laundering。它提醒 memory evaluation 不能只有 retrieval accuracy，还要测 provenance 与 authority semantics。

Limitation / Connection

真实 IAM/tool capability token 比文本权限更复杂。Potential Use：Agent Security / Memory Evaluation / Continual Agent。

Tier B · MetaKV: Adaptive KV-Cache Compression for Constrained LLM Inference — Inference

Paper / accessible overview

人话版

MetaKV 不发明新 compressor，而是针对每个 prompt 和 latency/memory budget，在 FP16、KVQuant、H2O、RocketKV 等配置中动态选择。

Method

轻量 predictor 估计每个配置的 E2E latency、peak memory、正确概率；过滤超预算方案，再选预期准确率最高者。

Main Finding / Limitation

价值是 prompt-dependent Pareto selection；本次可获取页面没有完整主表数字，故不虚构 speedup。预测器可能 distribution shift，候选集合决定性能上限。

Connection

适合 Agent serving：按 trajectory length、SLA、任务难度动态切换 KV 策略。Potential Use：adaptive serving baseline。

Tier B · ACM: Agentic Context Management for Long Horizon Tasks — Agent Memory

Paper / accessible overview

人话版

ACM 让 Agent 自己决定何时压缩 context、把什么移到 external memory、何时查回，而不是固定 token 阈值机械 summarize。

Core Method

提供 purpose-built context editing tools；被移出的内容进入外部 memory 并可 retrieval，再用 post-training demonstrations 教会模型何时操作。

Main Finding / Limitation

论文在 agentic search/coding 上报告提升；本次抓取没有稳定完整数字。所谓 lossless 依赖 retrieval 真能找回，失败可能延迟暴露。

Connection

与 KV-streams 形成强交叉：显式 context 被 offload 后，隐式 KV 是否仍保留？Potential Use：Agent Memory / Long-horizon baseline。
